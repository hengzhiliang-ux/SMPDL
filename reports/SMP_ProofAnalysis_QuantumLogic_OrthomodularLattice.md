## 1. 声明与版本

**主声明**（Birkhoff–von Neumann 1936：量子命题格）：设 `H` 为 Hilbert 空间，其**闭子空间（等价地正交投影算子）**集合 `L(H)` 在 `∧ = ∩`、`∨ = span 闭包`、`¬ = ⊥（正交补）` 下构成**正交模格（orthomodular lattice）**，但**不满足分配律**（当 dim H ≥ 3）：

**分配律反例**（dim ≥ 3，取两两不正交的三平面构造）：存在子空间 `A, B, C` 使

```text
A ∧ (B ∨ C) ⊋ (A ∧ B) ∨ (A ∧ C)
```

**取代分配律的结构**：

1. **正交模律**：`A ≤ C ⇒ C = A ∨ (A^⊥ ∧ C)`——分配律的"局域残存"（仅在兼容/可同时对角化命题间恢复分配性）；
2. **Kochen–Specker 定理（1967）**：dim ≥ 3 时**不存在**非语境 0/1 真值指派——经典真值表语义**整体不可能**；
3. **Gleason 定理（1957）**：dim ≥ 3 时，格上的概率测度必由密度算子给出（Born 规则被**推导**而非假设）；
4. **兼容性结构**：分配性在"相互正交/可交换"的布尔子格内恢复——量子逻辑 = "局域布尔 + 全局非布尔"的拼图。

**版本信息**：
- **形式化基础**：Birkhoff–von Neumann (1936)；Gleason (1957)；Kochen–Specker (1967)
- **依赖前提**：Hilbert 空间、闭子空间格、投影算子
- **AxiomaticBase**：`OrthomodularLattice` + `ProjectionLattice`
- **历史定位**：分配律被识别为"经典性的结构指纹"——它一倒，真值表、非语境性、经典概率三角联动坍塌。

### 2.2 S*L — 语义逻辑结构

- 量子语义反转：**命题不再是集合而是子空间**——"并"取闭张量包后比集合并"更大"，分配律的破坏源于 `A ∧ (B ∨ C)` 中 `B ∨ C` 的"膨胀"。
- "真值"语义降档：无全局 0/1 指派（KS）；"真"只能是**语境内**（布尔子格内）的真——语境性是量子语义的税。
- ⚠️ 风险：把正交模格当作"另一种布尔代数"使用全局真值表；或把兼容命题间的分配性误推广到全域。
