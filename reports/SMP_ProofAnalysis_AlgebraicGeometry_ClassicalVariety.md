## 1. 声明与版本

**主声明**（仿射 Nullstellensatz，经典版本）：设 `k` 为代数闭域，`I ⊆ k[x₁,…,x_n]` 为理想，则

```text
I(V(I)) = √I
```

其中 `V(I) = {x ∈ k^n | ∀f ∈ I, f(x)=0}` 是 `I` 的零点簇，`√I` 是 `I` 的根理想。

**版本信息**：
- **形式化基础**：经典代数几何（19 世纪–20 世纪上半叶；Hilbert 零点定理）
- **依赖前提**：代数闭域、多项式环、理想、代数簇、Zariski 拓扑
- **典型实例**：`V(x²+y²-1)` 是平面圆；`V(x²)` 与 `V(x)` 在经典视角下是同一根理想定义的簇
- **AxiomaticBase**：`ClassicalAlgebraicGeometry` + `AlgebraicallyClosedField`

## 2. S/M/P × D/L 六格审计

### 2.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| 代数闭域 `k` | 每个非常数多项式有根 | ✅ |
| 多项式环 `k[x₁,…,x_n]` | 交换环、Noetherian | ✅ |
| 理想 `I` | 多项式环的子集，对加法和乘法封闭 | ✅ |
| 零点簇 `V(I)` | `k^n` 中满足所有 `f ∈ I` 的点集 | ✅ |
| 根理想 `√I` | `{f | ∃m, f^m ∈ I}` | ✅ |

### 2.2 S*L — 语义逻辑结构

- Nullstellensatz 建立了代数对象（理想）与几何对象（簇）之间的双向对应。
- 经典视角下，几何对象是 **k^n 中的点集**；代数对象由理想描述。
- ⚠️ 风险：学生容易把 `V(I)` 与 `I` 混为一谈；经典框架下 `V(I) = V(√I)`，因此不同理想可定义同一簇。

### 2.3 M*D — 数学依存

```text
AffineNullstellensatz(k, I)
    │
    ├── k algebraically closed
    │
    ├── k[x₁,…,x_n]
    │
    ├── Ideal I
    │
    ├── Variety V(I) ⊆ k^n
    │
    ├── Vanishing ideal I(V(I))
    │
    └── I(V(I)) = √I
```

- 依赖关系闭合：核心依赖 Hilbert 基定理、Zorn 引理/选择公理（在证明中）、代数闭域性质。

### 2.4 M*L — 数学逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 定义量词 | ✅ | `V(I)` 用全称，`I(V)` 用全称。 |
| 代数闭域必要性 | ✅ | 反例：`x²+1` 在 `ℝ[x]` 中无零点，`I(V(I))` 会大于 `√I`。 |
| 根理想必要性 | ✅ | `V(x²) = V(x)`，因此 `I(V(x²)) = (x) = √(x²)`。 |
| 退化情形 | ✅ | 空簇对应 `I = (1)`；全空间对应 `I = (0)`。 |

### 2.5 P*D / P*L — 编程层

- Lean 4 / Mathlib：`AlgebraicGeometry` 库中 `PrimeSpectrum` 与 `Scheme` 正在发展；经典簇形式化较少。
- Macaulay2 / Singular：计算代数几何标准工具，可直接计算 `√I` 与 `V(I)`。
- 风险：经典簇作为“点集”的形式化需要基域可计算且通常要求代数闭。

## 4. 人类科学家可执行的验证动作

1. 在 `ℂ[x,y]` 中验证 `I = (x², y³)` 时 `V(I) = {(0,0)}` 且 `I(V(I)) = (x, y) = √(x², y³)`。
2. 验证代数闭域假设：在 `ℝ[x]` 中取 `I = (x²+1)`，说明 `I(V(I)) = (1) ≠ √I`。
3. 用 Macaulay2 计算若干理想的根，确认 `I(V(I)) = √I`。
