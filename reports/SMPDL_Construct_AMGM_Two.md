# 防前视构建报告：二元 AM-GM 不等式

> 使用流程：`SMPDL_ProofConstruction_AntiForesight.md` v1.0  
> 案例：证明对 a,b ≥ 0，(a+b)/2 ≥ √(ab)  
> 日期：2026-10-12

---

## 0. 显式化

### 0.1 目标命题 P

**自然语言**：任意两个非负实数的算术平均不小于它们的几何平均。  
**形式化**：

```
∀ a,b ∈ ℝ, a ≥ 0 ∧ b ≥ 0 → (a+b)/2 ≥ √(ab)
```

**结论类型**：全称不等式命题。

### 0.2 前提 A

- 实数 ℝ、加法、乘法、有序域性质；
- 平方根定义：对 x ≥ 0，√x 是满足 (√x)² = x 的非负实数；
- 实数平方非负：∀x, x² ≥ 0；
- 不等式基本运算规则。

### 0.3 可用工具

- 代数变形；
- 平方非负事实；
- 平方根性质。

### 0.4 禁用（含等价形式）

- 禁止直接使用 AM-GM 不等式或其等价表述；
- 禁止在变形过程中假设 (a+b)/2 - √(ab) ≥ 0 来化简；
- 禁止把「等号成立当且仅当 a=b」当作已知前置条件。

## 1. 反向草图（全部标记 OPEN）

```
P: ∀a,b ≥ 0, (a+b)/2 ≥ √(ab)
  G₁: 引入任意 a,b ≥ 0
    G₂: 构造 (√a - √b)² ≥ 0
      G₃: 展开为 a + b - 2√(ab) ≥ 0
        G₄: 移项得 a + b ≥ 2√(ab)
          G₅: 两边除以 2 得结论
```

**前视风险点**：

- G₂ 不能因为是「通往 AM-GM 的标准形式」而被选中；必须说明它来自显然的平方非负。
- G₃–G₅ 必须是纯代数操作，不能依赖目标不等式成立。

---

## 2. 正向重写

### 步骤 1：引入变量（闭合 G₁）

**主张**：设 a, b 是任意非负实数。  
**理由**：全称命题的任意实例化。  
**前驱**：目标命题。  
**状态**：✅ 闭合。

### 步骤 2：利用平方非负（闭合 G₂）

**主张**：(√a - √b)² ≥ 0。  
**理由**：对任意实数 x，x² ≥ 0；√a 和 √b 是实数（因 a,b ≥ 0）。  
**前驱**：步骤 1、平方非负事实。  
**状态**：✅ 闭合。

### 步骤 3：代数展开（闭合 G₃）

**主张**：(√a - √b)² = a + b - 2√(ab)。  
**理由**：

```
(√a - √b)² = (√a)² - 2√a√b + (√b)²
            = a - 2√(ab) + b
            = a + b - 2√(ab)
```

其中 √a√b = √(ab) 在 a,b ≥ 0 时成立。

**前驱**：步骤 2、平方根性质。  
**状态**：✅ 闭合。

### 步骤 4：移项（闭合 G₄）

**主张**：a + b ≥ 2√(ab)。  
**理由**：由步骤 2 和步骤 3，(√a - √b)² ≥ 0 等价于 a + b - 2√(ab) ≥ 0，移项即得。  
**前驱**：步骤 2、步骤 3。  
**状态**：✅ 闭合。

### 步骤 5：两边除以 2（闭合 G₅ 与 P）

**主张**：(a+b)/2 ≥ √(ab)。  
**理由**：不等式两边同除以正数 2，方向不变。  
**前驱**：步骤 4。  
**状态**：✅ 闭合。

### 3.1 M 层详细检查

**依赖图**：

```
引入 a,b ≥ 0
    ↓
√a, √b 为实数
    ↓
(√a - √b)² ≥ 0
    ↓
展开 = a + b - 2√(ab)
    ↓
a + b ≥ 2√(ab)
    ↓
同除 2 得 (a+b)/2 ≥ √(ab)
```

- **无循环**：没有从 P 指向中间节点的边。
- **隐藏假设**：平方根存在性与性质；实数有序域。

### 3.2 P 层详细检查（Lean 骨架）

```lean
theorem amgm_two_anti_foresight (a b : ℝ) (ha : 0 ≤ a) (hb : 0 ≤ b) :
    (a + b) / 2 ≥ Real.sqrt (a * b) := by
  have h1 : (Real.sqrt a - Real.sqrt b) ^ 2 ≥ 0 := sq_nonneg (Real.sqrt a - Real.sqrt b)
  have h2 : (Real.sqrt a - Real.sqrt b) ^ 2 = a + b - 2 * Real.sqrt (a * b) := by
    rw [sub_sq]
    rw [Real.sq_sqrt ha, Real.sq_sqrt hb]
    rw [← Real.sqrt_mul (by linarith)]
    ring
  have h3 : a + b - 2 * Real.sqrt (a * b) ≥ 0 := by linarith [h1, h2]
  linarith [h3, Real.sqrt_nonneg (a * b)]
```

无等价循环。

## 4. 等价循环探测

| 命题 | 是否与 P 等价 | 是否允许 | 说明 |
|---|---|---|---|
| (√a - √b)² ≥ 0 | 否 | ✅ | 平方非负事实 |
| a + b - 2√(ab) ≥ 0 | 是（等价变形） | ✅ | 由展开得到 |
| a + b ≥ 2√(ab) | 是（等价变形） | ✅ | 移项 |
| (a+b)/2 ≥ √(ab) | 是 | ✅ | 目标 P，由前序推出 |

**说明**：这里没有等价循环，因为每一步等价变形都由独立代数规则支持，而不是用 P 自身来证明 P。
