# S/M/P × D/L 审查报告：前 n 个奇数之和等于 n²

> 目标：对经典证明「Σ_{i=1}^n (2i-1) = n²」执行六格审计。  
> 框架：Göttingen S/M/P × D/L v1.3  
> 日期：2026-10-12

---

## 0. 证明原文（数学归纳法）

```text
命题：对任意正整数 n，1 + 3 + 5 + ... + (2n-1) = n²。

证明：

基例 n = 1：左边 = 1，右边 = 1² = 1，成立。

归纳假设：设对某个 k ≥ 1，命题成立，即
  1 + 3 + ... + (2k-1) = k²。

归纳步骤：考虑 k+1 时，
  1 + 3 + ... + (2k-1) + (2(k+1)-1)
  = k² + (2k+1)
  = (k+1)²。

因此，若命题对 k 成立，则对 k+1 也成立。

由数学归纳法，命题对所有正整数 n 成立。证毕。
```

### 1.3 M*D：数学依存闭合

```
命题 P(n): Σ_{i=1}^n (2i-1) = n²
       ↓
基例 P(1): 1 = 1²
       ↓
归纳假设 P(k)
       ↓
Σ_{i=1}^{k+1} (2i-1) = Σ_{i=1}^k (2i-1) + (2(k+1)-1)
       ↓
= k² + (2k+1)  （使用归纳假设）
       ↓
= (k+1)²  （代数恒等式）
       ↓
P(k+1) 成立
       ↓
∀n ≥ 1, P(n) 成立
```

依赖图从基例和归纳假设到全称结论，无反向边。

**M*D：✅ 通过**

### 1.5 P*D：编程/形式化依存闭合

Lean 骨架：

```lean
theorem odd_sum_square (n : ℕ) (hn : n > 0) :
    ∑ i in Finset.Icc 1 n, (2 * i - 1) = n ^ 2 := by
  induction n with
  | zero =>
    -- n = 0 被假设排除
    exfalso
    exact Nat.lt_irrefl 0 hn
  | succ n ih =>
    cases n with
    | zero =>
      -- 基例 n = 1
      norm_num
    | succ n =>
      -- 归纳步骤：从 n+1 推到 n+2
      rw [Finset.sum_Icc_succ_top (by linarith)]
      rw [ih (by linarith)]
      ring
```

所有步骤在 Lean 中可由 `norm_num`、`linarith`、`ring` 自动处理。

**P*D：✅ 通过**
