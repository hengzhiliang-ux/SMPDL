# SMPDL 审计报告：可计算分析中的中间值定理

**报告编号**：SMP-CMP-IVT-001  
**AxiomaticBase**：`ComputableAnalysis`（可计算分析，要求函数可计算且能提取求根算法）  
**审计框架**：S/M/P × D/L v1.5  
**日期**：2026-10-13  

---

## 一、命题陈述

> **可计算中间值定理（Computable IVT）**
>
> 设可计算函数 `f: [0, 1] → ℝ` 连续，且 `f(0) < 0 < f(1)`，并且 `f` 是**有效一致连续**的（effectively uniformly continuous），则存在**可计算**的 `c ∈ [0, 1]` 使得 `f(c) = 0`，且可以构造算法从任意精度 `ε > 0` 计算出满足 `|c - c_ε| < ε` 的 `c_ε`。

---

## 二、标准证明

### 2.1 证明概要（区间二分法）

1. 初始化 `a₀ = 0`, `b₀ = 1`。由假设 `f(a₀) < 0 < f(b₀)`。
2. 在第 `n` 步，计算中点 `m_n = (a_n + b_n) / 2` 的近似值，精度足够判断 `f(m_n)` 的符号。
3. 利用 `f` 的有效一致连续性，确定需要计算 `f(m_n)` 到什么精度才能可靠判断符号。
4. 选择新的区间：
   - 若 `f(m_n) < 0`（在足够精度下），令 `a_{n+1} = m_n`, `b_{n+1} = b_n`；
   - 若 `f(m_n) > 0`，令 `a_{n+1} = a_n`, `b_{n+1} = m_n`；
   - 若 `|f(m_n)|` 极小，可直接返回 `m_n` 作为近似根。
5. 区间长度以 `2^{-n}` 指数衰减，因此 `|a_n - b_n| → 0`，且极限 `c = lim a_n = lim b_n` 满足 `f(c) = 0`。
6. 由于所有运算都是可计算的，且收敛速率明确，故 `c` 是可计算实数。

## 三、S/M/P × D/L 审计

### 3.1 S 层（语义层）

#### S*D：语义定义

| 概念 | 定义 | 状态 |
|---|---|---|
| 可计算函数 | Type-2 可计算函数 / 逼近算法 | ✅ 明确 |
| 可计算实数 | 快速收敛的有理数序列 | ✅ 明确 |
| 有效一致连续 | 存在可计算模函数 `ω(ε)` | ✅ 明确 |
| 存在 `c` | 可计算 witness + 收敛算法 | ✅ 明确 |

#### S*L：语义合法性

- “存在”采用构造性/可计算语义：必须给出算法和收敛速率。
- 若 `f` 连续但非有效一致连续，则无法保证 `c` 可计算。

**S 层判定**：✅ 低风险（在 `ComputableAnalysis` 基础下）

### 3.2 M 层（数学层）

#### M*D：数学依赖

| 依赖 | 来源 | 是否闭合 |
|---|---|---|
| 可计算实数理论 | Type-2 可计算性 | ✅ 闭合 |
| 区间套定理 | 构造性/可计算版本 | ✅ 闭合 |
| 有效一致连续性 | 额外假设 | ⚠️ 必须显式声明 |
| 排中律 | 不依赖无限 LEM | ✅ 避免非构造性分情况 |

#### M*L：数学合法性

- 证明在 `ComputableAnalysis` 框架内合法。
- 关键：有效一致连续性保证了二分法所需的符号判断可以在有限精度下完成。

**M 层判定**：🟡 中风险（依赖有效一致连续性这一额外假设）

### 3.3 P 层（证明/编程层）

#### P*D：证明对象依赖

- 可实现为具体算法（如 Coq 中的 `CoRN`、Lean 中的 `ComputableAnalysis` 库）。
- 依赖类型：可计算实数表示、模函数、有理数近似。

#### P*L：证明对象合法性

- 证明项携带算法，可提取为程序。
- Lean/Mathlib 目前对可计算分析支持有限，需借助外部库或手动实现。

**P 层判定**：🟡 中风险（形式化库支持不如经典分析成熟）

## 四、跨层映射检查

| 映射 | 检查项 | 结果 |
|---|---|---|
| S → M | “可计算存在”是否对应有效一致连续 + 区间套？ | ✅ 一致 |
| M → P | 二分法算法是否可在证明助手中提取？ | ⚠️ 需要专门库支持 |
| S → P | 结论中的 `c` 是否附带收敛速率？ | ✅ 是，`2^{-n}` |

**跨层风险**：可计算版本比经典版本“更重”，但可提取更多信息。若只关心存在性，可计算分析提供了过度证明；若需要实际算法，经典分析不足够。
