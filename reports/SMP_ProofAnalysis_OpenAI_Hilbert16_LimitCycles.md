## 1. 命题与声明

论文声称证明：存在一个仅依赖于多项式次数 n 的有限常数 H(n)，使得任意 n 次实平面多项式向量场

\[
\dot{x} = P(x,y), \quad \dot{y} = Q(x,y)
\]

的孤立周期轨道（极限环）数量不超过 H(n)。

这是 Hilbert 第 16 问题中的核心部分：对任意次数的多项式向量场，极限环的数量是否有一致上界。

已知背景包括：
- Dulac (1923) 曾声称证明，但后来发现错误。
- Ilyashenko (1991) 和 Écalle (1992) 独立证明 Dulac 的有限性猜想：每个固定向量场的极限环数量是有限的。
- 但「一致有界性」——即仅依赖于次数 n 的全局上界——至今未解决。
- 对于低次（n = 1, 2）有特殊结果，但一般 n 仍然开放。

## 2. S/M/P × D/L 六格审计

### 2.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| 一致有界性 H(n) < ∞ | 对全局分岔树的统一控制 / 非退化性假设 | 🔴 核心策略未披露 |
| 局部有限性 | Dulac / Ilyashenko / Écalle 的有限性结果 | 🟢 已知 |
| 全局一致界 | 对退化奇点、高重分岔的uniform控制 | ⚠️ 未说明 |
| 度依赖界 | 显式函数或归纳构造 | ⚠️ 未说明 |

**发现**：从局部有限性到全局一致有界性是问题的核心难点。README 未说明如何控制所有可能的退化情形。

### 2.2 S*L — 语义逻辑结构

- 命题形式清晰：每个 n 次多项式向量场的极限环数量有一致上界。
- 但"有限"不等于"一致有界"：Ilyashenko–Écalle 证明每个固定系统只有有限多个极限环，但上界可能依赖于系统的系数。
- 风险：可能把「对某族系统的统一控制」误作「对所有 n 次系统的一致控制」；或把局部估计简单加总到全局。
- 局部与全局分岔计数的差异是主要风险点。

### 2.3 M*D — 数学依存

| 依赖 | 状态 |
|---|---|
| Dulac/Ilyashenko/Écalle 有限性理论 | 🟢 已知 |
| 退化奇点的统一处理 | ⚠️ 未说明 |
| 分岔理论中的高重控制 | ⚠️ 未说明 |
| 与 Petrovski-Landis、Arnold、Ilyashenko 的对比 | 🔴 未讨论 |
| 低次情形的显式界 | ⚠️ 待查 |

**关键风险**：证明一致有界性需要对所有退化奇点、鞍结分岔、同宿/异宿环等给出uniform控制，这是现有文献远未解决的。

### 2.4 M*L — 数学逻辑结构

- 典型证明结构：通过 Hilbert 数 H(n) 的归纳或某种组合估计，证明所有 n 次系统的极限环数量可被统一控制。
- 陷阱：证明可能只对非退化情形有效，但退化情形可能产生任意多个极限环（如 Bogdanov-Takens 分岔）。
- 或者：证明中使用的 Dulac 级数展开可能在退化奇点处不 terminate uniformly。

### 2.5 P*D — 编程/形式化依存

- README 提到 Lean，但未说明形式化范围。
- 风险：Lean 可能只形式化了低次系统的极限环计数或某个局部引理，而非完整的「所有 n 次系统一致有界」主定理。
- 特别风险：形式化可能只覆盖代数闭域或特殊情形，未处理实平面上的完整多项式向量场。

### 2.6 P*L — 编程逻辑结构

- 如果形式化存在，需要检查：
  - 是否严格定义了多项式向量场、极限环、H(n)；
  - 是否处理了退化奇点和分岔；
  - 是否给出了度依赖界的显式或存在性证明；
  - 是否区分了局部有限性与全局一致有界性。

## 5. 人工可能需要确认/补充证明的地方

1. **显式度依赖界**：给出 H(n) 的具体表达式或存在性证明，并说明其增长速率。
2. **退化奇点的统一控制**：证明所有退化奇点、鞍结分岔、同宿/异宿环等不会产生超过 H(n) 的极限环。
3. **Dulac 级数的uniform终止**：证明局部 Dulac 级数在次数控制下一致终止。
4. **与已知结果的对比**：明确解释新结果如何超越 Ilyashenko、Écalle、Petrovski-Landis、Movshuk-Yakovenko 等人的工作。
5. **Lean 主定理范围**：确认 Lean 文件中的 `theorem` 是否对所有 n 成立，还是仅对特定次数。
6. **低次情形验证**：验证 n=1,2,3 时的界限是否与已有结果一致。
