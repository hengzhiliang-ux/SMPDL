## 0. 证明原文

```text
命题（Wilson 定理）：设 n > 1 为整数。则 n 是素数当且仅当 (n-1)! ≡ -1 (mod n)。

证明：

（⇒）设 n 为素数。

考虑乘法群 (ℤ/nℤ)^× = {1, 2, ..., n-1}。

对群中每个元素 a，存在唯一的逆元 a^{-1}，使得 a·a^{-1} ≡ 1 (mod n)。

若 a ≠ a^{-1}，则 a 与 a^{-1} 在乘积中配对相消。

自逆元素满足 a² ≡ 1 (mod n)，即 n | (a-1)(a+1)。
因 n 是素数，这蕴含 a ≡ 1 或 a ≡ -1 (mod n)。
在 {1,...,n-1} 中，自逆元只有 1 和 n-1。

因此
  (n-1)! ≡ 1 · (n-1) · ∏_{配对 a,a^{-1}} (a·a^{-1}) ≡ -1 (mod n)。

（⇐）设 (n-1)! ≡ -1 (mod n)。

若 n 是合数，则存在真因子 d 满足 1 < d < n。
因 d 出现在 (n-1)! 中，有 d | (n-1)!。
又 (n-1)! ≡ -1 (mod n)，故 n | (n-1)! + 1。
于是 d | (n-1)! + 1。
但 d | (n-1)!，所以 d | ((n-1)! + 1) - (n-1)! = 1，矛盾。

故 n 必为素数。证毕。
```

### 1.3 M*D：数学依存闭合

```
目标：n 素数 ⟺ (n-1)! ≡ -1 (mod n)
       ↓
⇒ 方向：n 素数
       ↓
(ℤ/nℤ)^× 是群/域
       ↓
每个非零元有唯一逆元
       ↓
自逆元满足 a² ≡ 1
       ↓
域中 a²=1 只有 ±1 两解
       ↓
配对相消 ⇒ (n-1)! ≡ -1
       ↓
⇐ 方向：假设 (n-1)! ≡ -1
       ↓
若 n 合数，取真因子 d
       ↓
d | (n-1)! 且 d | (n-1)!+1
       ↓
d | 1，矛盾
       ↓
n 素数
```

依赖图闭合，无反向边。

**M*D：✅ 通过**

### 1.5 P*D：编程/形式化依存闭合

Lean 骨架：

```lean
theorem wilson_theorem (n : ℕ) (hn : n > 1) :
    Nat.Prime n ↔ Nat.factorial (n - 1) % n = n - 1 := by
  constructor
  · -- ⇒ 方向：素数 ⇒ (n-1)! ≡ -1
    intro h_prime
    -- 使用模逆元配对论证
    sorry -- Mathlib 已有 wilson 相关结果
  · -- ⇐ 方向：(n-1)! ≡ -1 ⇒ 素数
    intro h
    by_contra h_comp
    -- 取最小素因子或真因子
    rcases Nat.exists_dvd_of_not_prime2 hn h_comp with ⟨d, hd1, hd2, hd3⟩
    -- d | (n-1)!
    have h1 : d ∣ Nat.factorial (n - 1) := by
      apply Nat.dvd_factorial
      · linarith
      · linarith
    -- d | (n-1)! + 1
    have h2 : d ∣ Nat.factorial (n - 1) + 1 := by
      rw [Nat.dvd_iff_mod_eq_zero]
      rw [Nat.add_mod, h]
      -- n-1 ≡ -1 (mod n)，需转换为模 d
      sorry
    -- d | 1
    have h3 : d ∣ 1 := by
      exact Nat.dvd_sub' h2 h1
    -- 与 1 < d 矛盾
    linarith
```

主要 `sorry` 在 Mathlib 中可填充；核心逻辑清晰。

**P*D：✅ 通过**
