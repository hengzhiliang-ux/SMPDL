## 1. Kempe 四色谬误

### 1.1 目标 P

任意平面图都是 4-可着色的。

### 1.2 反向草图

```
P: 任意平面图 4-可着色
  G₁: 反证，假设存在最小反例图 G
  G₂: 证明 G 必有一个顶点 v 的度数 ≤ 5（Euler 公式）
  G₃: 移除 v，对 G - v 用归纳假设 → 4-着色
  G₄: 把 v 放回，尝试扩展着色
  G₅: 若 deg(v) ≤ 4， trivially 可扩展
  G₆: 若 deg(v) = 5，用 Kempe 链互换释放一种颜色
```

### 1.3 正向重写失败点

步骤 G₆ 的具体构造：

- v 的 5 个邻居已经用了 4 种颜色（由鸽巢原理，必有一种颜色出现两次）；
- 设颜色为 c₁, c₂, c₃, c₄，其中 c₁ 出现两次；
- 构造两条 Kempe 链：
  - 链 A：从 v 的两个 c₁-邻居出发，交换颜色 c₁ 和 c₃；
  - 链 B：从 v 的一个 c₂-邻居和一个 c₄-邻居出发，交换颜色 c₂ 和 c₄；
- 这样 v 的邻居颜色变成 3 种，释放一种颜色给 v。

### 1.4 前视漏洞

**假设**：两条 Kempe 链 A 和 B 互不干扰，即交换 A 不影响 B，交换 B 不影响 A。

**问题**：这个假设**没有正向证明**。事实上，A 和 B 可能相交（Errera 图等反例），导致两次同时交换破坏合法着色。

**前视来源**：Kempe 知道需要释放一种颜色，所以**假设**两次互换是独立的。

### 1.5 S/M/P × D/L 判定

| 层 | 结果 | 说明 |
|---|---|---|
| S*D | ⚠️ | "两次互换互不干扰" 没有显式前驱 |
| S*L | ❌ | 该假设是目标所需，不是已知 |
| M*D | ❌ | G₆ 依赖一个未证的独立性假设 |
| M*L | ❌ | 非法推广：单次 Kempe 互换合法 ≠ 两次同时互换合法 |
| P*D | ❌ | 形式化中两次互换后的 proper coloring 无法证明 |
| P*L | ❌ | 留下不可填充的 `sorry` |

### 1.6 结论

正向链在 G₆ 处断裂。断裂根因：把「单次 Kempe 互换合法」非法推广到「两次同时 Kempe 互换合法」。这与等腰三角形谬误类似：目标所需的操作独立性被当作已知。

## 2. RH 诊断：Riemann 假设

### 2.1 目标 P

Riemann ζ 函数的所有非平凡零点都位于临界线 Re(s) = 1/2 上。

### 2.2 反向草图（开放问题）

```
P: ∀ρ, ζ(ρ)=0 ∧ 0<Re(ρ)<1 → Re(ρ)=1/2
  G₁: 证明零点密度界足够强
  G₂: 证明所有零点满足某个矩条件
  G₃: 证明某个 L-函数与 ζ 的对应关系
  G₄: 构造 Hilbert–Pólya 算子
  G₅: 建立函数域类比并 transfer 到数域
```

### 2.3 正向重写状态

| 子目标 | 正向进展 | 缺口 |
|---|---|---|
| G₁ | 部分 | 零点密度界只能排除「大部分」零点离临界线，不能排除单个零点 |
| G₂ | 部分 | 矩条件对临界线成立，但无法证明其刻画了所有零点 |
| G₃ | 研究 | L-函数与 ζ 的对应不足以推出 RH |
| G₄ | 启发 | 算子存在性无构造 |
| G₅ | 失败 | 函数域 Weil 猜想已证，但向数域的 transfer 同构不存在 |

### 2.4 前视风险

RH 证明尝试中的典型前视：

- **统计→精确**：把「几乎所有零点在临界线上」推广为「所有零点在临界线上」；
- **函数域→数域**：把函数域上已证的结论直接套用到数域；
- **等价循环**：用「某谱条件等价于 RH」来「证明」RH，而该谱条件本身未证。

### 2.5 S/M/P × D/L 判定

| 层 | 结果 | 说明 |
|---|---|---|
| S*D | ✅ | 各路线语义清晰 |
| S*L | ⚠️ | "临界线比例 67.2%" 与 "所有零点" 之间的量词跳跃 |
| M*D | ⚠️ | 依赖图大致闭合，但关键引理（如 transfer 同构）缺失 |
| M*L | ❌ | 局部/统计结果非法推广到全称结论 |
| P*D | ⚠️ | 形式化库覆盖大量中间结果 |
| P*L | ❌ | 最终 `sorry` 无法填充 |

### 2.6 结论

RH 的防前视构建**无法在当前数学框架下完整闭合**。核心缺口在 M*L：缺少一个能把局部/统计信息合法提升为全称结论的刚性结构。

## 3. 鸽巢原理

### 3.1 目标 P

若 n 个物品放入 m 个抽屉且 n > m，则至少有一个抽屉包含 ≥ 2 个物品。

### 3.2 反向草图

```
P: n > m → ∃抽屉，|抽屉| ≥ 2
  G₁: 反证，假设每个抽屉最多 1 个物品
  G₂: 推出总物品数 ≤ m
  G₃: 与 n > m 矛盾
```

### 3.3 正向重写

1. 假设每个抽屉最多 1 个物品；
2. 总物品数 ≤ 1 × m = m；
3. 但已知 n > m；
4. 矛盾，因此 ∃抽屉包含 ≥ 2 个物品。

### 3.4 检查

- **S 层**：每个理由都指向前置假设或算术 ✅
- **M 层**：依赖图从假设到矛盾，无反向边 ✅
- **P 层**：可直接形式化为 `by_contra` + `linarith` ✅
- **边界扫描**：n > m 的边界 n = m + 1 已覆盖 ✅

### 3.5 结论

正向链闭合。✅

## 4. √2 无理性

### 4.1 目标 P

√2 不能表示为两个整数的比。

### 4.2 反向草图

```
P: √2 是无理数
  G₁: 假设 √2 = p/q 且 gcd(p,q)=1
    G₂: 平方得 p² = 2q²
      G₃: 2 | p²
        G₄: 2 | p
          G₅: 设 p = 2k
            G₆: 代入得 2k² = q²
              G₇: 2 | q²
                G₈: 2 | q
                  G₉: 2 | p 且 2 | q
                    G₁₀: gcd(p,q) ≥ 2
                      G₁₁: 与 gcd=1 矛盾
```

### 4.3 正向重写

1. 假设存在 p,q 使得 √2 = p/q，约分为 gcd(p,q)=1；
2. 平方得 p² = 2q²，故 2 | p²；
3. 由「奇数平方为奇数」的逆否，2 | p；
4. 设 p = 2k，代入得 2k² = q²，故 2 | q²；
5. 同理 2 | q；
6. 于是 2 同时整除 p 和 q，与 gcd(p,q)=1 矛盾。

### 4.4 检查

- **S 层**：每个理由都指向前置步骤或引理 ✅
- **M 层**：依赖图从反证假设到矛盾，无反向边；p 和 q 的偶性均由引理正向证明 ✅
- **P 层**：Lean 骨架中 `have` 均有独立证明体，无等价循环 ✅
- **边界扫描**：q>0、p=0、非最简分数均已处理 ✅

### 4.5 结论

正向链闭合，无等价循环。✅ 完整构建报告见 `SMPDL_Construct_Sqrt2_Irrational.md`。

## 5. Cantor 对角线论证

### 5.1 目标 P

[0,1] 区间内的实数不可数。

### 5.2 反向草图

```
P: [0,1] 不可数
  G₁: 反证，假设存在满射 f : ℕ → [0,1]
    G₂: 写出每个 f(n) 的十进制展开
      G₃: 构造对角数字 e_n ≠ d_{n,n}
        G₄: 证明 y = 0.e_1e_2... 是合法 [0,1] 实数
          G₅: 证明 ∀n, y ≠ f(n)
            G₆: 与满射假设矛盾
```

### 5.3 正向重写

1. 假设存在满射 f : ℕ → [0,1]；
2. 取每个 f(n) 的十进制展开 x_n = 0.d_{n,1}d_{n,2}...；
3. 定义 e_n = 1（若 d_{n,n} ≠ 1），否则 e_n = 2；
4. y = 0.e_1e_2... 只含数字 1,2，表示唯一且 y ∈ [0,1]；
5. 对每个 n，y 与 x_n 在第 n 位不同，故 y ≠ f(n)；
6. y 不在 f 值域中，与满射矛盾。

### 5.4 检查

- **S 层**：e_n 的定义只依赖 d_{n,n}，不依赖目标 ✅
- **M 层**：依赖图从反证假设到逐位差异再到矛盾，无反向边 ✅
- **P 层**：对角构造可形式化为级数，每个 `have` 独立 ✅
- **边界扫描**：避开 0.999.../1.000... 双重表示 ✅

### 5.5 结论

正向链闭合，无等价循环。✅ 完整构建报告见 `SMPDL_Construct_Cantor_Diagonal.md`。

## 6. 前 n 个奇数之和 = n²

### 6.1 目标 P

∀n ≥ 1, Σ_{i=1}^n (2i-1) = n²。

### 6.2 反向草图

```
P: ∀n ≥ 1, Σ_{i=1}^n (2i-1) = n²
  G₁: 基例 n = 1
    G₂: 1 = 1²
  G₃: 归纳步骤
    G₄: 假设 P(k)
      G₅: Σ_{i=1}^{k+1} (2i-1) = Σ_{i=1}^k (2i-1) + (2k+1)
        G₆: 代入 P(k)
          G₇: 化简 k² + (2k+1) = (k+1)²
```

### 6.3 正向重写

1. 基例 n=1：1 = 1²；
2. 假设 P(k) 成立；
3. 拆分 k+1 和为前 k 项加第 k+1 项；
4. 用归纳假设替换前 k 项为 k²；
5. 代数恒等式 k² + 2k + 1 = (k+1)² 推出 P(k+1)。

### 6.4 检查

- **S 层**：归纳假设在引入后使用，无目标牵引 ✅
- **M 层**：依赖图从基例和归纳假设到全称结论，无循环 ✅
- **P 层**：`induction` + `ring` 结构清晰 ✅
- **边界扫描**：n=1 基例覆盖最小正整数 ✅

### 6.5 结论

正向链闭合，无等价循环。✅ 完整构建报告见 `SMPDL_Construct_OddSum_Square.md`。

## 7. 二元 AM-GM 不等式

### 7.1 目标 P

∀a,b ≥ 0, (a+b)/2 ≥ √(ab)。

### 7.2 反向草图

```
P: (a+b)/2 ≥ √(ab)
  G₁: 引入 a,b ≥ 0
    G₂: (√a - √b)² ≥ 0
      G₃: 展开为 a + b - 2√(ab) ≥ 0
        G₄: 移项得 a + b ≥ 2√(ab)
          G₅: 两边除以 2
```

### 7.3 正向重写

1. 对非负 a,b，√a, √b 为实数；
2. 实数平方非负，故 (√a - √b)² ≥ 0；
3. 展开得 a + b - 2√(ab) ≥ 0；
4. 移项得 a + b ≥ 2√(ab)；
5. 同除以 2 得结论。

### 7.4 检查

- **S 层**：每步理由为已知代数规则，非目标驱动 ✅
- **M 层**：依赖图从平方非负到不等式，无反向边 ✅
- **P 层**：`sq_nonneg`、`sub_sq`、`sqrt_mul`、`linarith` 链清晰 ✅
- **边界扫描**：a=b 等号成立；a=0 或 b=0 仍成立 ✅

### 7.5 结论

正向链闭合，无等价循环。✅ 完整构建报告见 `SMPDL_Construct_AMGM_Two.md`。

## 8. Wilson 定理

### 8.1 目标 P

n > 1 是素数 ⟺ (n-1)! ≡ -1 (mod n)。

### 8.2 反向草图

```
P: n 素数 ⟺ (n-1)! ≡ -1 (mod n)
  G₁: ⇒ 方向：n 素数
    G₂: (ℤ/nℤ)^× 中每个元有唯一逆元
      G₃: 自逆元满足 a² ≡ 1
        G₄: 素数模下 a²=1 只有 ±1
          G₅: 非自逆元配对相消 ⇒ (n-1)! ≡ -1
  G₆: ⇐ 方向：(n-1)! ≡ -1
    G₇: 反证 n 合数
      G₈: 取真因子 d
        G₉: d | (n-1)!
          G₁₀: d | (n-1)!+1
            G₁₁: d | 1 矛盾
```

### 8.3 正向重写

1. ⇒ 方向：n 素数 ⇒ 非零元可逆；自逆元仅 ±1；其余配对相消得 (n-1)! ≡ -1。
2. ⇐ 方向：若 (n-1)! ≡ -1 且 n 合数，取真因子 d，则 d 同时整除 (n-1)! 与 (n-1)!+1，推出 d|1 矛盾。

### 8.4 检查

- **S 层**：双向分别证明，无目标牵引 ✅
- **M 层**：⇒ 用群论逆元，⇐ 用整除矛盾；依赖图无反向边 ✅
- **P 层**：`constructor` + `by_contra` 结构清晰 ✅
- **边界扫描**：n=2 成立；n=4 不成立 ✅

### 8.5 结论

正向链闭合。✅ 完整构建报告见 `SMPDL_Construct_Wilson_Theorem.md`。

## 9. Fermat 小定理

### 9.1 目标 P

p 素数 ∧ p ∤ a ⇒ a^{p-1} ≡ 1 (mod p)。

### 9.2 反向草图

```
P: p 素数 ∧ p ∤ a → a^{p-1} ≡ 1 (mod p)
  G₁: a 模 p 可逆
    G₂: φ(x)=a·x 是 S→S 单射
      G₃: S 有限 ⇒ φ 双射
        G₄: {a·x} 模 p 是 S 的排列
          G₅: 两边乘积相等
            G₆: a^{p-1}·(p-1)! ≡ (p-1)!
              G₇: (p-1)! 可逆
                G₈: 消去得 a^{p-1} ≡ 1
```

### 9.3 正向重写

1. p ∤ a ⇒ a 模 p 可逆；
2. 映射 x ↦ a·x 在 S={1,...,p-1} 上是单射，因而是双射；
3. 像集是 S 的排列，故两边乘积相等；
4. 整理得 a^{p-1}·(p-1)! ≡ (p-1)!；
5. (p-1)! 可逆，消去后得结论。

### 9.4 检查

- **S 层**：目标等式由乘积相等自然流出 ✅
- **M 层**：双射 ⇒ 排列 ⇒ 乘积相等 ⇒ 消去，无循环 ✅
- **P 层**：可用 Finset 排列与模运算形式化 ✅
- **边界扫描**：p=2 时 a 为奇数成立 ✅

### 9.5 结论

正向链闭合。✅ 完整构建报告见 `SMPDL_Construct_FermatLittle_Theorem.md`。

## 10. Basel 问题

### 10.1 目标 P

Σ_{n=1}^∞ 1/n² = π²/6。

### 10.2 反向草图

```
P: Σ 1/n² = π²/6
  G₁: 构造 f(x)=x² 在 [-π,π] 的 Fourier 级数
    G₂: 计算 a_0 = 2π²/3
      G₃: 计算 a_n = (-1)^n · 4/n²
        G₄: 证明级数在 x=π 收敛于 π²
          G₅: 代入 x=π 并利用 cos(nπ)=(-1)^n
            G₆: 解方程得 Σ 1/n² = π²/6
```

### 10.3 正向重写

1. 对 f(x)=x² 做 Fourier 余弦展开；
2. 分部积分两次得 a_n = (-1)^n · 4/n²；
3. Dirichlet 逐点收敛定理保证 x=π 处收敛于 π²；
4. 代入并化简：π² = π²/3 + 4Σ1/n²；
5. 解得 Σ1/n² = π²/6。

### 10.4 检查

- **S 层**：每步引用 Fourier 定理或代数规则 ✅
- **M 层**：收敛性在代入前独立证明 ✅
- **P 层**：依赖 Mathlib Fourier 分析库，代数整理可分离 ✅
- **边界扫描**：n=0 不在求和范围；x=±π 连续 ✅

### 10.5 结论

正向链闭合。✅ 完整构建报告见 `SMPDL_Construct_Basel_Problem.md`。

## 11. Andrews-Curtis 猜想（构造尝试）

### 11.1 目标 P

任意平衡平凡表示 ⟨x₁,...,xₙ | r₁,...,rₙ⟩ 可通过 AC 变换化为 ⟨x₁,...,xₙ | x₁,...,xₙ⟩。

### 11.2 反向草图

```
P: 平衡平凡表示 P 可 AC-平凡化
├── G₁: 存在 AC 不变量 I 区分等价类
├── G₂: 对 n 归纳
├── G₃: 通过 Nielsen 变换桥接
├── G₄: 通过稳定化桥接
└── G₅: 通过拓扑解释桥接
```

### 11.3 正向重写尝试

- **G₁**：候选不变量均不成立（Nielsen 类、共轭类均不被 AC 保持）。❌
- **G₂**：基例 n=1 ✅；归纳步骤缺构造性消去引理。❌
- **G₃**：Nielsen 变换 ≠ AC 变换，桥接失败。❌
- **G₄**：AK(3) 稳定 AC-平凡 ✅；但去稳定化引理缺失。⚠️
- **G₅**：拓扑关联 ✅；但结果非构造性且仅覆盖稳定版。❌

### 11.4 检查

- **S 层**：语义清晰，无循环 ✅
- **M 层**：M*L 显著缺口——缺乏统一结构性理由解释为何所有平衡平凡表示应 AC-平凡 ❌
- **P 层**：计算可检验但搜索空间超指数，Bridson–Lishak 下界排除纯搜索方法 ✅
- **等价循环探测**：G₂ 归纳步骤可能隐含假设比 n-1 更强结论 ⚠️
- **边界扫描**：n=1 ✅；n=2 总长≤13 除 AK(3) 外 ✅；AK(3) 仅稳定版 ✅；一般情形 ❓

### 11.5 结论

**部分闭合**——五条路线全部阻塞，但识别出具体缺口：
1. 无非平凡 AC 不变量；
2. 消去引理非构造性；
3. 变换集不等价；
4. 去稳定化引理缺失；
5. 拓扑结果非构造性。

完整构造报告见 `SMPDL_Construct_AndrewsCurtis.md`。

## 13. 教学建议

1. **正确证明**（欧几里得、鸽巢、√2、Cantor、奇数和、AM-GM、Wilson、Fermat 小定理、Basel）：展示流程如何自然闭合，强调正向链末端的成就感。
2. **经典谬误**（等腰、Kempe）：展示流程如何在中间步骤卡住，强调前视的隐蔽性。
3. **证伪猜想**（Fermat 素数猜想、Euler 幂和猜想）：展示一个反例如何干净地推翻全称命题。
4. **开放问题**（RH、Andrews-Curtis）：展示流程如何帮助刻画核心缺口，避免无效探索方向；Andrews-Curtis 特别展示了「语义清晰但结构缺口显著」的开放问题形态。
5. **对比训练**：让学生用同一流程先审计一个已完成证明，再从头构造同一证明，体会审计与构建的双向验证关系。
