## 1. 声明与版本

**主声明**（二阶逻辑元性质失效，全语义 standard semantics 下）：

1. **紧致性失效**：存在理论 `T`，其每个有限子集可满足，但 `T` 整体不可满足。
   - 反例：二阶句子集 `{ "存在至少 n 个元素" : n ∈ ℕ } ∪ { "论域有限" }`——每有限子集可满足，整体矛盾。更强的：Dedekind 无穷的刻画使"非标准模型"在二阶全语义下被排除。
2. **LS 失效**：二阶 Peano 公理（含归纳公理的二阶形式）在全语义下**范畴**（categorical，唯一同构模型 `ℕ`）；同理二阶实数完备性刻画范畴。故不可能有可数初等子模型。
3. **不可判定性升级**：有效式集高度不可判定（远超一阶的递归可枚举）。

**结构性后果**：
- 二阶能"抓住"真正的 `ℕ` 与 `ℝ`（范畴性），代价是失去紧致性、LS、可判定性等全部好性质；
- ZFC 无法提供二阶语义的完备证明系统（Gödel 不完备的二阶体现）；
- Henkin 语义（弱语义）恢复紧致性但退化为"多类一阶"——旋钮的第三档。

**版本信息**：
- **形式化基础**：二阶逻辑（Frege 1879；范畴性 Dedekind 1888 / 二阶 Peano）
- **依赖前提**：全语义（量词遍历论域的全部子集/关系）
- **AxiomaticBase**：`SecondOrderLogic` + `FullSemantics`
- **历史定位**：表达力与元性质的根本权衡；现代基础论选择一阶+公理模式的直接原因。

### 2.2 S*L — 语义逻辑结构

- 二阶全语义核心：**量词遍历全部子集**——"有限""Dedekind 有限""完备"等概念被精确刻画，非标准模型被消灭。
- 代价：可满足性不再紧致；模型不再可向下压缩；无完备证明系统。
- ⚠️ 风险：混淆全语义与 Henkin 语义——同一语法，两种语义，元性质截然不同（语义旋钮的隐藏第三档）。

### 2.3 M*D — 数学依存

```text
SecondOrderFullSemantics
    │
    ├── Quantify over ALL subsets (full semantics)
    │
    ├── Categoricity: 2nd-order PA ≅ ℕ; 2nd-order RCF ≅ ℝ

    │

    │
    └── No complete proof system (Gödel II shadow)
```
