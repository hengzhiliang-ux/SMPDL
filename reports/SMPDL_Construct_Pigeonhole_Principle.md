# 防前视构建报告：鸽巢原理（基本形式）

> 使用流程：`SMPDL_ProofConstruction_AntiForesight.md` v1.0  
> 案例：证明若 n 个物品放入 m 个抽屉且 n > m，则至少有一个抽屉包含不少于 2 个物品  
> 日期：2026-10-12

---

## 0. 显式化

### 0.1 目标命题 P

**自然语言**：如果物品数多于抽屉数，那么至少有一个抽屉里有不少于两件物品。  
**形式化**：

```
∀ n,m ∈ ℕ, n > m → 任意把 n 个物品放入 m 个抽屉的方式都导致 ∃抽屉，|抽屉| ≥ 2
```

**结论类型**：全称条件命题（反证法适用）。

### 0.2 前提 A

- 自然数 ℕ、加法、乘法、序关系；
- 有限和的基本性质；
- 计数原理：总物品数等于各抽屉物品数之和。

### 0.3 可用工具

- 反证法；
- 计数/求和；
- 不等式运算。

### 0.4 禁用（含等价形式）

- 禁止直接使用鸽巢原理或其等价表述；
- 禁止假设「必然有一个抽屉拥挤」作为理由；
- 禁止在未证明的情况下使用「平均值」论证。

---

## 1. 反向草图（全部标记 OPEN）

```
P: n > m ⇒ ∃抽屉，|抽屉| ≥ 2
  G₁: 反证，假设每个抽屉最多 1 个物品
    G₂: 推出总物品数 ≤ m
      G₃: 与已知 n > m 矛盾
        G₄: 得出 P
```

**前视风险点**：

- G₂ 必须由「每个抽屉最多 1 个」和抽屉数 m 推出，不能提前知道总数会矛盾。
- G₄ 必须等待矛盾出现后才能得出，不能把 P 当作已知。

---

## 2. 正向重写

### 步骤 1：引入反证假设（闭合 G₁）

**主张**：假设每个抽屉中的物品数都不超过 1。  
**理由**：反证法允许假设 ¬P。  
**前驱**：反证法规则。  
**状态**：✅ 闭合。

### 步骤 2：计算总物品数上界（闭合 G₂）

**主张**：总物品数 ≤ m。  
**理由**：

- 共有 m 个抽屉；
- 由假设，每个抽屉 ≤ 1 个物品；
- 因此总物品数 ≤ Σ_{i=1}^m 1 = m。

**前驱**：步骤 1、计数原理。  
**状态**：✅ 闭合。

### 步骤 3：与已知条件矛盾（闭合 G₃）

**主张**：总物品数 ≤ m 与 n > m 矛盾。  
**理由**：已知物品总数为 n，n > m 意味着 n 严格大于 m，不可能同时 ≤ m。  
**前驱**：步骤 2、已知条件 n > m。  
**状态**：✅ 闭合。

### 步骤 4：得出原命题（闭合 G₄ 与 P）

**主张**：因此至少有一个抽屉包含不少于 2 个物品。  
**理由**：反证法下，¬P 导致矛盾，故 P 成立。  
**前驱**：步骤 1、步骤 3。  
**状态**：✅ 闭合。

### 3.1 M 层详细检查

**依赖图**：

```
反证假设 H：∀抽屉，|抽屉| ≤ 1
    ↓
总物品数 n = Σ |抽屉_i| ≤ Σ 1 = m
    ↓
n ≤ m
    ↓
与 n > m 矛盾
    ↓
P 成立
```

- **无循环**：没有从 P 指向中间节点的边。
- **隐藏假设**：抽屉为有限集合；物品不可分割（每个物品恰好在一个抽屉）。

### 3.2 P 层详细检查（Lean 骨架）

```lean
theorem pigeonhole_principle_anti_foresight {α β : Type*} [Fintype β]
    (f : α → β) (ha : Fintype.card α > Fintype.card β) :
    ∃ y : β, {x | f x = y}.toFinset.card ≥ 2 := by
  by_contra h
  push_neg at h
  have h1 : ∀ y, {x | f x = y}.toFinset.card ≤ 1 := by
    intro y
    exact Nat.le_of_lt_succ (h y)
  have h2 : Fintype.card α ≤ Fintype.card β := by
    -- 利用 Σ_y |f⁻¹(y)| = |α|
    sorry
  linarith
```

所有 `sorry` 可在 `Finset` 库中填充，无等价循环。
