## 1. 命题与声明

论文研究整系数多项式 $f \in \mathbb{Z}[x]$ 取无平方值或 $k$-幂自由值的分布。典型声明形如：

- 对四次无平方多项式 $f$，集合 $\{ n \le X : f(n) \text{ 无平方} \}$ 具有正密度，且密度可表示为 Euler 积；
- 对一般 $k \ge 2$ 与适当不可约多项式，$f(n)$ 取 $k$-幂自由值的比例也有类似公式。

该方向的经典结果是 Hooley (1967) 对三次无平方值的工作，以及 Poonen (2003) 对多维幂自由值的几何单分性方法。四次情形比三次更复杂，因为更高次项的筛法余项需要更精细的算术几何控制。

## 2. S/M/P × D/L 六格审计

### 2.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| 四次多项式无平方值正密度 | Hooley 型筛法 / 几何单分性 | 🟡 方法名未披露 |
| 幂自由值的 Euler 积常数 | 局部密度乘积 / Möbius 反演 | 🟡 常数是否显式 |
| 可容许例外集定义 | 重根判别式 / 局部条件 | 🟡 未说明 |

**发现**：README 仅给出标题与引用，未说明论文处理的是单变量四次多项式、多变量情形，还是更一般的 $k$-幂自由值。Lean 形式化若存在，可能只覆盖某个具体引理（如局部密度计算），而非完整密度公式。

### 2.2 S*L — 语义逻辑结构

- 命题的全称量词需要明确：是对**所有**四次不可约多项式成立，还是对满足某种非退化条件的四次多项式成立？
- "power-free" 需要区分 $k$-自由值与无平方值；对 $k > 2$，结论的精度可能不同。
- 风险：可能把「存在一个 Euler 积公式」滑移到「对所有不可约多项式给出一致有效误差项」。

### 2.3 M*D — 数学依存

| 依赖 | 状态 |
|---|---|
| Hooley 三次无平方筛法 | ⚠️ 方法是否推广到四次 |
| Poonen 几何单分性 | ⚠️ 高维/高次适用性未说明 |
| Bombieri–Vinogradov / 算术级数素数分布 | ⚠️ 若使用，需说明范围 |
| 局部密度乘积的收敛性 | 🟡 通常可证，但需显式 |

**关键风险**：四次多项式无平方筛法的主项通常可由 Möbius 反演得到，但余项需要控制「$f(n)$ 被 $d^2$ 整除」的多项式指数和。对四次多项式，Weil 界或 Deligne 界是否足够取决于具体形式。

### 2.4 M*L — 数学逻辑结构

- 典型证明结构：
  1. 写出 $\sum_{n \le X} \mu^2(f(n)) = \sum_{d \le \sqrt{X}} \mu(d) \cdot \#\{n \le X : d^2 \mid f(n)\}$；
  2. 对主项 $d \le D$ 用局部密度逼近；
  3. 对余项 $D < d \le \sqrt{X}$ 用指数和或几何方法估计。
- 陷阱：四次多项式的同余方程 $f(n) \equiv 0 \pmod{d^2}$ 的解数可能随 $d$ 波动，主项/余项分割需要明确。
- 风险：若论文声称对**所有**四次多项式成立，需排除 $f$ 有重因子或判别式为零的退化情形。

### 2.5 P*D — 编程/形式化依存

- README 提到 [Lean](lean/docs/020.md)，但未说明形式化范围。
- 风险：Lean 可能只形式化了：
  - 局部密度的 Euler 积公式；
  - 某个具体四次多项式（如 $f(x)=x^4+1$）的无平方计数；
  - 筛法恒等式，但未证明余项估计。
- 特别风险：形式化中的多项式次数、系数类型（`int`, `rat`, `poly`）与纸面声明是否一致。

### 2.6 P*L — 编程逻辑结构

- 若形式化完整，需要检查：
  - 是否定义了「$f(n)$ 无平方」的可判定谓词；
  - 是否显式给出误差项 $O(X^{\theta})$ 与 $	heta$ 的取值；
  - 是否处理了 $f$ 可约或有重根的边界情况。

## 5. 人工可能需要确认/补充证明的地方

1. **多项式次数与退化条件**：明确定理是对所有四次不可约多项式成立，还是需要额外条件（如无固定素平方因子、判别式非零、无重根）。
2. **局部密度 Euler 积的显式公式**：给出
   \[
   c_f = \prod_p \left(1 - \frac{\rho_f(p^2)}{p^2}\right)
   \]
   的推导，其中 $\rho_f(p^2)$ 是同余 $f(n) \equiv 0 \pmod{p^2}$ 的解数；验证乘积收敛并给出有效下界。
3. **余项估计的显式控制**：说明对 $d > D$ 的求和如何被控制，是用 Weil/Deligne 指数和、Burgess 界，还是几何单分性；给出 $D$ 与最终误差项的依赖关系。
4. **$k$-幂自由值的推广**：若论文涉及 $k > 2$，需说明同余 $f(n) \equiv 0 \pmod{p^k}$ 的解数估计与 $k=2$ 时有何不同。
5. **Lean 形式化主定理范围**：确认 Lean 文件中的主定理是否 literally 给出「$\sum_{n \le X} \mu^2(f(n)) = c_f X + O(X^{\theta})$」形式，还是仅证明某个引理。
6. **具体多项式的数值验证**：对 $f(x)=x^4+1$、$x^4+2x^2+2$ 等具体多项式，人工计算 $X=10^6$ 时的无平方计数，并与定理预测比较，检验常数 $c_f$ 是否正确。
7. **文献支持性核查**：若引用 Hooley (1967)、Poonen (2003)、Granville (1998) 等，需确认其定理的假设（次数、变量数、域特征）与本论文声明匹配。

## 7. 结论与后续建议

族 020 的声明比千年未决问题更具体，数学结构相对清晰，因此风险等级为 **🟡 中度**。主要风险不在于「方向本身不可能成立」，而在于：

- README 未披露证明方法、Lean 形式化范围、误差项与退化条件；
- 四次无平方筛法的余项控制需要精细的算术几何工具，人工应重点核查这部分是否完整；
- 从 Lean 形式化到纸面完整定理之间可能存在 scope gap。

3. 对至少 3 个具体四次多项式做数值验证。
