## 2. PreFix 版本 SMPDL 速览（Riemann）

- **S*D**：分划-达布和语义链；可积性绑定连续性。
- **S*L**：⚠️ "每项可积 ⇒ 极限可积"是语义陷阱。
- **M*D**：`f_n = 1_{q_1..q_n}` → Dirichlet 函数 → 不可积。
- **判定**：反例正确，标记框架 🔴 级断裂。

## 3. PostFix 版本 SMPDL 六格审计（Lebesgue）

### 3.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| σ-代数 + 测度 | 可测结构 | ✅ |
| 可测函数 | a.e. 收敛 | ✅ |
| 控制函数 g | 可积上界 | ✅ |
| MCT / Fatou | DCT 引理链 | ✅ |

### 3.2 S*L — 语义逻辑结构

- "可积"同名异义：Riemann 可积 ⇒ Lebesgue 可积；反向不成立（`sin x/x`）。
- "几乎处处"（a.e.）是 Lebesgue 特有的宽容语义——允许零测集上的任意例外。

### 3.3 M*D — 数学依存

```text
MCT → Fatou → DCT（Fatou 应用于 g±f_n 双向夹逼）
```

### 3.4 M*L — 数学逻辑结构

| 检查项 | Riemann | Lebesgue | 差异 |
|---|---|---|---|
| Dirichlet 型列 | 极限不可积 | 极限可积（∫=0） | 断裂修复 |
| 交换条件 | 即使一致有界也失败 | 可积控制即足 | 条件明确化 |
| 单调列 | 单调有界可交换 | MCT 无需控制 | 更强 |

### 3.5 P*D / P*L — 编程层

- Mathlib：`MeasureTheory` 完整；Riemann 层薄。
- 数值实验盲区：采样积分无法区分两个框架——**这是 P 层的隐形断裂**。

## 4. 跨层映射检查

| 映射 | Riemann（PreFix） | Lebesgue（PostFix） |
|---|---|---|
| S → M | "连续性 ⇒ 可积" → 达布和判据 | "可测性 ⇒ 可积候选" → 测度积分 |
| M → P | 达布和形式化薄 | MCT/Fatou/DCT 全链形式化 |
| S ↔ S | "可积" = 分划和收敛 | "可积" = 测度积分有限（同名异义） |

**跨层结论**：这不是参数微调，而是**积分定义的根本重构**——分划方向从定义域翻转到值域，换来极限封闭性。

## 6. 变化类型归类

- **变化方式**：**升级迁移**（积分定义从"定义域分划"升级为"值域分划 + 测度"）+ 局部结论反转（不可积 → 可积）。
- **SMPDL 同构标签建议**：`S-BISIM / M-BISIM / P-BISIM`。
- **关键 lesson**：AI 生成分析证明时若写"由控制收敛定理"，必须声明是 Lebesgue 版；Riemann 框架下该交换无一般保证，数值实验也无法暴露此差异。

## 6.5 概念奇点（Conceptual Singularity）

### 6.5.1 关键人工洞察

- **把分划方向从 x 轴翻转到 y 轴**：Lebesgue 的天才一步——水平集 `{x : f(x) > t}` 的测度比"区间采样"更适合处理极限。
- **用"几乎处处"宽容零测例外**：允许在不破坏积分的前提下忽略病态点集。
- **识别"积分算子的封闭性"才是本质需求**：19 世纪分析的痛点不是计算个别积分，而是交换运算次序的合法性。

### 6.5.2 为什么机器难以自动迁移

机器可以在给定 DCT 时验证引理链，但**发现"翻转分划方向"这一重构**需要历史级洞察——它是被 Fourier 级数、三角级数收敛问题逼出来的，不是形式推演的自然结果。数值层完全无法提示此断裂（采样积分对 Dirichlet 列恒给出 0）。

## 6.6 断裂强度（Breakage Strength）

| 评估项 | 等级 | 说明 |
|---|---|---|
| **断裂强度** | 🔴 结论反转或不可证 | PreFix 侧交换失败（极限函数不可积）；PostFix 侧恢复——两侧结论方向相反。 |
| **S 层影响** | 高 | "可积""积分"同名异义；"a.e."语义为新增。 |
| **M 层影响** | 高 | 核心工具从达布和换为测度论引理链。 |
| **P 层影响** | 中高 | 形式化厚度极不对称；数值验证存在盲区。 |

**判定**：两侧结论方向相反（断裂 vs 成立），评为 🔴；但从"理论升级"视角亦可视为最强等级的**升级迁移**。
