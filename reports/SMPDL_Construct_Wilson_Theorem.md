# 防前视构建报告：Wilson 定理

> 使用流程：`SMPDL_ProofConstruction_AntiForesight.md` v1.0  
> 案例：证明 n > 1 是素数 ⟺ (n-1)! ≡ -1 (mod n)  
> 日期：2026-10-12

---

## 0. 显式化

### 0.1 目标命题 P

**自然语言**：大于 1 的整数 n 是素数，当且仅当 (n-1)! 模 n 等于 -1。  
**形式化**：

```
∀ n ∈ ℕ, n > 1 → (Nat.Prime n ↔ (n-1)! % n = n-1)
```

**结论类型**：双向刻画命题（⟺）。

### 0.2 前提 A

- 自然数 ℕ、乘法、阶乘、同余定义；
- 素数定义与合数定义；
- 模逆元基本事实：若 gcd(a,n)=1，则 a 模 n 可逆；
- 域/整环性质：方程 a² ≡ 1 (mod p) 在素数 p 下只有 ±1 两解。

### 0.3 可用工具

- 双向证明（constructor）；
- 模运算；
- 逆元配对；
- 整除矛盾。

### 0.4 禁用（含等价形式）

- 禁止直接使用 Wilson 定理作为理由；
- 禁止在 ⇒ 方向提前知道「(n-1)! ≡ -1」再寻找配对；
- 禁止在 ⇐ 方向假设 n 的素性来论证 (n-1)! 可逆。

## 1. 反向草图（全部标记 OPEN）

```
P: n 素数 ⟺ (n-1)! ≡ -1 (mod n)
  G₁: 证明 ⇒ 方向
    G₂: 假设 n 为素数
      G₃: 考虑 (ℤ/nℤ)^× = {1,...,n-1}
        G₄: 证明每个元素有唯一逆元
          G₅: 找出所有自逆元
            G₆: 证明自逆元只有 1 和 n-1
              G₇: 将非自逆元配对相消
                G₈: 得出 (n-1)! ≡ -1
  G₉: 证明 ⇐ 方向
    G₁₀: 假设 (n-1)! ≡ -1 (mod n)
      G₁₁: 反证，假设 n 为合数
        G₁₂: 取真因子 d，1 < d < n
          G₁₃: 证明 d | (n-1)!
            G₁₄: 证明 d | (n-1)! + 1
              G₁₅: 推出 d | 1，矛盾
```

**前视风险点**：

- G₅–G₆ 不能先假设自逆元只有 ±1 再验证；必须从 a² ≡ 1 出发用素数性质推导。
- G₁₄ 不能直接说「因为 (n-1)! ≡ -1，所以 (n-1)!+1 被 n 整除，从而被 d 整除」；需要显式使用同余的传递性。

## 2. 正向重写

### 步骤 1：⇒ 方向引入素数假设（闭合 G₂）

**主张**：假设 n 为素数。  
**理由**：双向证明的左半部分。  
**前驱**：constructor 规则。  
**状态**：✅ 闭合。

### 步骤 2：考虑模 n 非零剩余类（闭合 G₃）

**主张**：集合 S = {1,2,...,n-1} 在模 n 乘法下构成群。  
**理由**：n 素数 ⇒ ℤ/nℤ 是域，非零元可逆。  
**前驱**：步骤 1、域的定义。  
**状态**：✅ 闭合。

### 步骤 3：每个元素有唯一逆元（闭合 G₄）

**主张**：对任意 a ∈ S，存在唯一 b ∈ S 使得 a·b ≡ 1 (mod n)。  
**理由**：域中非零元可逆，且逆元唯一。  
**前驱**：步骤 2。  
**状态**：✅ 闭合。

### 步骤 4：自逆元满足 a² ≡ 1（闭合 G₅）

**主张**：若 a = a^{-1}，则 a² ≡ 1 (mod n)。  
**理由**：由 a·a ≡ a·a^{-1} ≡ 1。  
**前驱**：步骤 3。  
**状态**：✅ 闭合。

### 步骤 5：在素数模下只有 ±1 自逆（闭合 G₆）

**主张**：a² ≡ 1 (mod n) 在 S 中只有 a ≡ 1 和 a ≡ n-1 两个解。  
**理由**：

- a² ≡ 1 ⇒ n | (a-1)(a+1)；
- n 素数 ⇒ n | (a-1) 或 n | (a+1)；
- 因 1 ≤ a ≤ n-1，得 a=1 或 a=n-1。

**前驱**：步骤 1、步骤 4。  
**状态**：✅ 闭合。

### 步骤 6：配对相消（闭合 G₇）

**主张**：将 S 中除 1 和 n-1 外的元素两两配对为 (a, a^{-1})，每对乘积 ≡ 1。  
**理由**：步骤 3 保证每个非自逆元有唯一不同逆元；配对不重复。  
**前驱**：步骤 3、步骤 5。  
**状态**：✅ 闭合。

### 步骤 7：⇒ 方向结论（闭合 G₈、G₁）

**主张**：(n-1)! ≡ 1 · (n-1) · ∏配对 (a·a^{-1}) ≡ -1 (mod n)。  
**理由**：配对乘积均为 1；1·(n-1) ≡ -1。  
**前驱**：步骤 6。  
**状态**：✅ 闭合。

### 步骤 8：⇐ 方向引入假设（闭合 G₁₀）

**主张**：假设 (n-1)! ≡ -1 (mod n)。  
**理由**：双向证明的右半部分。  
**前驱**：constructor 规则。  
**状态**：✅ 闭合。

### 步骤 9：反证假设 n 合数（闭合 G₁₁）

**主张**：假设 n 为合数，推出矛盾。  
**理由**：反证法。  
**前驱**：步骤 8。  
**状态**：✅ 闭合。

### 步骤 10：取真因子 d（闭合 G₁₂）

**主张**：存在整数 d 满足 1 < d < n 且 d | n。  
**理由**：合数定义。  
**前驱**：步骤 9。  
**状态**：✅ 闭合。

### 步骤 11：d 整除 (n-1)!（闭合 G₁₃）

**主张**：d | (n-1)!。  
**理由**：d ≤ n-1，因此 d 出现在乘积 1·2·...·(n-1) 中。  
**前驱**：步骤 10、阶乘定义。  
**状态**：✅ 闭合。

### 步骤 12：d 整除 (n-1)! + 1（闭合 G₁₄）

**主张**：d | (n-1)! + 1。  
**理由**：

- 由步骤 8，n | (n-1)! + 1；
- 由步骤 10，d | n；
- 整除的传递性 ⇒ d | (n-1)! + 1。

**前驱**：步骤 8、步骤 10。  
**状态**：✅ 闭合。

### 步骤 13：推出矛盾（闭合 G₁₅、G₉、P）

**主张**：d | 1，与 1 < d 矛盾。  
**理由**：步骤 11 和步骤 12 给出 d 同时整除 (n-1)! 和 (n-1)!+1，故 d 整除其差 1。  
**前驱**：步骤 11、步骤 12。  
**状态**：✅ 闭合。

### 3.1 M 层详细检查

**依赖图**：

```
目标 P
    ├─⇒ 方向
    │   ├─ n 素数
    │   ├─ (ℤ/nℤ)^× 是群
    │   ├─ 每个元有逆元
    │   ├─ 自逆元 ⇒ a²=1
    │   ├─ 素数模下 a²=1 只有 ±1
    │   ├─ 非自逆元配对
    │   └─ (n-1)! ≡ -1
    └─⇐ 方向
        ├─ (n-1)! ≡ -1
        ├─ 反证 n 合数
        ├─ 真因子 d
        ├─ d | (n-1)!
        ├─ d | (n-1)!+1
        └─ d | 1 矛盾
```

- **无循环**：没有从 P 指向中间节点的边。
- **隐藏假设**：域/群论基本事实；可用初等配对法替代。

### 3.2 P 层详细检查（Lean 骨架）

```lean
theorem wilson_anti_foresight (n : ℕ) (hn : n > 1) :
    Nat.Prime n ↔ Nat.factorial (n - 1) % n = n - 1 := by
  constructor
  · -- ⇒ 方向
    intro h_prime
    -- 利用模逆元配对
    sorry
  · -- ⇐ 方向
    intro h
    by_contra h_comp
    rcases Nat.exists_dvd_of_not_prime2 hn h_comp with ⟨d, hd1, hd2, hd3⟩
    have h1 : d ∣ Nat.factorial (n - 1) := by
      apply Nat.dvd_factorial
      · linarith
      · linarith
    have h2 : d ∣ Nat.factorial (n - 1) + 1 := by
      -- 由 n | (n-1)!+1 与 d | n 推出
      sorry
    have h3 : d ∣ 1 := Nat.dvd_sub' h2 h1
    linarith
```

所有 `sorry` 在 Mathlib 中可填充，无等价循环。
