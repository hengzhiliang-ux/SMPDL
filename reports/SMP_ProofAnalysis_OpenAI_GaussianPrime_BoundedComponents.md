# SMPDL 审计报告：OpenAI「高斯素数图的有界连通分支」

**审计对象**：Uniformly bounded components of Gaussian-prime graphs
**来源**：OpenAI math 仓库，族 028，2026-09-26 发布
**审计日期**：2026-10-13
**审计框架**：Göttingen S/M/P × D/L 六格审计 v2.1
**审计结论**：🔴 **高度风险研究级声明。Gaussian 素数图的结构强烈依赖于素数对 / k-tuple 在 Gaussian 整数中的分布；若"有界连通分支"涉及任意步长或全局有界，则可能需要未解决的 Gaussian 素数对猜想。**

---

## 1. 命题与声明

论文研究以 Gaussian 整数 Z[i] 为顶点、以某种 Gaussian 素数关系为边构成的图。典型声明形如：

- 对固定的步长集合 S ⊂ Z[i]（例如 S = { z : |z| ≤ R } 或特定有限步长集），图 G_S 的每个连通分支的大小 / 直径一致有界；
- 或：存在某个有界步长集，使得 Gaussian 素数图的全部连通分支一致有界。

该问题与 Euclidean 素数图、prime k-tuples、Bateman-Horn 猜想等密切相关。Greenfeld-Tao 等近期工作研究了高维格点中的素数 walks，但 Gaussian 整数情形仍有大量未解决问题。

### 2.2 S*L — 语义逻辑结构

- 必须精确定义邻接关系：两顶点相邻当且仅当差为 Gaussian 素数？还是差为某种素数乘积？
- 必须区分"每个连通分支有限"与"所有分支一致有界（uniform bound）"：前者是局部性质，后者是全局一致性质。
- 风险：可能把"对特定步长集成立"滑移到"对所有有界步长集成立"。

### 2.3 M*D — 数学依存

| 依赖 | 状态 |
|---|---|
| Gaussian 素数分布 / 角向等分布 | 🔴 是否依赖未证猜想 |
| Prime k-tuples / Bateman-Horn | 🔴 若需要，则为重大依赖 |
| Euclidean prime walks (Gethner, Granville 等) | ⚠️ 是否被引用 |
| 覆盖系统 / 组合几何 | 🟡 可能部分可证 |

**关键风险**：若"一致有界"要求覆盖所有方向 / 所有步长，则通常等价于 Gaussian 素数对的强分布结果，这在当前数学中尚未解决。

### 2.4 M*L — 数学逻辑结构

- 典型证明结构（若可证）：
  1. 定义步长集与邻接关系；
  2. 利用 Gaussian 素数的角向等分布或筛法证明某区域内存在素数；
  3. 用组合论证说明无法形成任意大的连通分支。
- 陷阱：若步长集包含任意方向，素数对的分布可能不均匀；若步长集有限，图的结构又可能过于稀疏。
- 风险：证明可能隐含假设了某些素数对的无穷性。

### 2.5 P*D — 编程/形式化依存

- README 可能指向 [Lean](lean/docs/028.md)，但未说明形式化范围。
- 风险：Lean 可能只形式化了：
  - Gaussian 整数与 Gaussian 素数的定义；
  - 特定步长集下的小规模图；
  - 某个组合引理，而非素数分布结论。
- 特别风险：形式化可能无法表达"一致有界"这一全称量词。

### 2.6 P*L — 编程逻辑结构

- 若形式化完整，需要检查：
  - 是否严格定义了图 G_S；
  - 是否给出"一致有界"的形式化表述；
  - 是否明确依赖哪些解析或组合引理。

## 5. 人工可能需要确认/补充证明的地方

1. **图的精确定义**：明确顶点是否为 Z[i]，边是否由差为 Gaussian 素数定义，步长集 S 是否有限、是否固定、是否旋转不变。
2. **"有界"的度量**：说明有界是指每个连通分支的顶点数一致有界，还是直径一致有界，还是两者皆有。
3. **素数分布依赖**：明确证明是否依赖 Gaussian 素数对、prime k-tuples、Bateman-Horn 等未证猜想；若依赖，结论应降级为条件性。
4. **与 Euclidean 素数 walk 的比较**：说明与 Gethner-Wagon-Wick (1998)、Granville 等结果的关系，以及 Gaussian 情形与整数情形的差异。
5. **小步长集验证**：对 |z| ≤ R 的小 R（如 R=1,2,3），人工绘制 Gaussian 素数图并观察分支结构，检验"一致有界"是否显然或反直觉。
6. **Lean 主定理范围**：确认 Lean 是否形式化了一般步长集上的一致有界性，还是仅证明某特殊步长集。
7. **构造性 vs 存在性**：若结论为存在性，是否给出构造 tile / 步长集；若为一般性，是否给出一致上界 B(R)。
