# S/M/P × D/L 审计报告：交换环中二项式幂恒等式

> **定理**：设 (R, +, ·, 0, 1) 为交换环。对任意 a, b ∈ R 与 n ∈ ℕ，有 (ab)ⁿ = aⁿ bⁿ。
> 
> **来源**：标准抽象代数教材，交换环基本性质。
> 
> **分析日期**：2026-10-13 | **审计框架**：Göttingen S/M/P × D/L v1.5 | **AxiomaticBase**：`CommutativeRing`
> 
> **风险评级**：⚪ 已确认正确（在交换环公理体系内）。

---

## 0. 分析目标

1. 对交换环中 (ab)ⁿ = aⁿ bⁿ 的归纳证明做一次 S/M/P × D/L 六格审计。
2. 明确证明依赖的核心假设：乘法交换律 ab = ba。
3. 为后续与非交换环版本做同构对比建立基准（S/M/P 标签、证明骨架、风险点）。

## 1. S 层审计（语义层）

### 1.1 S*D：语义依存

| 自然语言元素 | 支持的后续元素 | 依赖说明 |
|---|---|---|
| 环 R 的定义 | 元素 a, b ∈ R 与乘法封闭性 | 需先承认环结构 |
| 乘法结合律 | 将 (ab)ⁿ 展开为 a·b·a·b·…·a·b | 允许省略括号 |
| 乘法交换律 ab = ba | 重排 a 与 b 的乘积顺序 | 将交错乘积整理为 aⁿ bⁿ |
| 幂的定义 aⁿ = a·a·…·a | 得到 aⁿ bⁿ | n 个 a 与 n 个 b 的连乘 |
| 归纳假设 (ab)ᵏ = aᵏ bᵏ | 推导 k+1 情形 | 数学归纳法的语义支点 |

### 1.2 S*L：语义逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 量词显式化 | ✅ | “对任意 a, b ∈ R 与 n ∈ ℕ”可显式写为 ∀a, b ∈ R, ∀n ∈ ℕ。 |
| 术语单义性 | ⚠️ 中 | “交换环”在代数中标准；但自然语言常省略“乘法交换”这一关键语义条件。 |
| 隐喻/图示依赖 | ✅ | 无图示依赖；证明是符号操作。 |
| 隐含跳跃 | 🟡 中 | 从 (ab)ⁿ = a·b·a·b·…·a·b 到 aⁿ bⁿ 依赖交换律，常被当作“显然”。 |
| 蕴涵方向 | ✅ | 由交换律与结合律推出 (ab)ⁿ = aⁿ bⁿ，方向正确。 |

**S 层结论**：自然语言证明简洁，但核心语义依赖“乘法交换律”必须显性化。若忽略该条件，证明骨架无法移植到非交换情形。

## 2. M 层审计（数学层）

### 2.1 M*D：数学依存

```text
(ab)^n = a^n b^n
    │
    ├── Ring Axioms
    │       ├── (R, +) is an abelian group
    │       ├── (R, ·) is a monoid with identity 1
    │       └── Distributivity: a(b+c) = ab + ac, (b+c)a = ba + ca
    │
    ├── Commutativity of multiplication
    │       └── ∀ a, b ∈ R : a·b = b·a
    │
    ├── Associativity of multiplication
    │       └── ∀ a, b, c ∈ R : (a·b)·c = a·(b·c)
    │
    ├── Definition of power: a^n = a · a · ... · a (n times)
    │
    └── Mathematical induction on n
            ├── Base n = 0: (ab)^0 = 1 = a^0 b^0
            └── Inductive step: (ab)^{k+1} = (ab)^k (ab)
                                          = a^k b^k a b   (IH)
                                          = a^k a b^k b   (commutativity)
                                          = a^{k+1} b^{k+1}
```

| 数学对象 | 结构签名 | 在证明中的作用 |
|---|---|---|
| 交换环 R | `(R, +, ·, 0, 1)` with ab = ba | 论域与公理基础 |
| 元素 a, b | R 中任意元素 | 定理对象 |
| 自然数 n | 指数，用于归纳 | 归纳变量 |
| 乘法结合律 | 环公理 | 允许展开幂为连乘 |
| 乘法交换律 | 交换环附加公理 | 重排因子顺序 |
| 数学归纳法 | 自然数递归原理 | 证明对所有 n 成立 |

### 2.2 M*L：数学逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 公理系统一致性 | ✅ | 在交换环公理体系内可严格证明。 |
| 构造合法性 | ✅ | 仅涉及符号展开与重排，无额外构造。 |
| 量词范围 | ✅ | 对任意 a, b ∈ R 与 n ∈ ℕ 成立。 |
| 边界情况 | ✅ | n = 0 时约定 a⁰ = b⁰ = 1，(ab)⁰ = 1，成立。 |
| 隐藏假设 | ⚠️ 中 | 证明默认 R 是含幺环；若仅要求无幺环，n = 0 需单独处理。 |
| 等价命题循环 | ✅ | 无。 |

**M 层结论**：证明在交换环公理系统内逻辑结构完整。核心依赖为乘法交换律；结合律与幂的定义次之。

## 3. P 层审计（编程/形式化层）

### 3.1 P*D：形式化依存

> 本证明在 Mathlib/Lean 4 中有直接对应的形式化。`CommRing` 类型类封装了交换环公理，幂运算由 `npow` 或 `^` 提供。

```text
CommutativeBinomialPower
    │
    ├── Mathlib.Algebra.Ring.Defs
    │       └── CommRing R
    │
    ├── Mathlib.Algebra.GroupWithZero.Defs
    │       └── npow (a ^ n)
    │
    ├── Mathlib.Algebra.Group.Commute
    │       └── commute a b  (a * b = b * a)
    │
    └── Theorem: mul_pow
            └── ∀ (a b : R) (n : ℕ), (a * b) ^ n = a ^ n * b ^ n
```

### 3.2 P*L：形式化逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 语法可编译 | ✅ | Mathlib 提供 `mul_pow` 定理，可直接调用或重写。 |
| 类型签名一致 | ✅ | 输入：a, b : R, n : ℕ；输出：(a*b)^n = a^n * b^n。 |
| 定义等价 | ✅ | `CommRing` 与数学定义“含幺交换环”等价。 |
| 命题等式 | ✅ | 目标等式可直接作为 `mul_pow` 的实例。 |
| `#print axioms` | ✅ | 依赖环公理与自然数归纳；不意外依赖选择公理。 |

**P 层结论**：Mathlib 中已有完整形式化。本证明的 P 层风险极低，可直接复用 `mul_pow`。

## 6. 结论

交换环中 (ab)ⁿ = aⁿ bⁿ 的证明是一个**结构极简单、依赖极明确**的代数案例：

- **S 层**：自然语言一句话即可说完，但“交换律”是常被省略的关键语义条件。
- **M 层**：数学结构完整，核心为 ` associativity + commutativity → reordering → equality`。
- **P 层**：Mathlib 已提供 `mul_pow` 定理，可直接复用，实现风险极低。
- **跨层映射**：三层对应关系明确，同构强度为 ⭐⭐⭐ 高。

该样本建议标记为：`CommutativeRing`、`S-ISO / M-ISO / P-ISO`（自洽），并作为与 `NonCommutativeRing` 版本对比的基准版本。
