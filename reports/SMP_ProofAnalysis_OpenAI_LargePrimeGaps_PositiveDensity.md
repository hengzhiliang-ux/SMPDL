# OpenAI 大素数间隙正密度猜想

## 声明摘要

声明：对每个固定 C>0，在足够大的素数初始段中，正比例的连续素数间隙超过 C log p_n；进而 p_n/n 增加的指标集具有正下密度。

该结论强化 Erdős 关于大素数间隙的猜想，属于解析数论中素数分布的精细问题。

**Lean 形式化范围**：Lean 形式化范围：仅证明了 prime-ratio 推论——即满足 p_n/n < p_{n+1}/(n+1) 的指标 n 具有正下渐近密度。主定理（大间隙正密度）本身未在形式化中直接出现。
