## 1. 声明与版本

**主声明**：设 `X₁,…,X_n ~ Bernoulli(p)` 独立同分布，观测到 `k` 次成功，则样本比例 `p̂ = k/n` 是 `p` 的最大似然估计。在 `n` 充分大时，`p̂` 近似服从 `N(p, p(1-p)/n)`，频率主义 `(1-α)` 置信区间为

```text
p̂ ± z_{α/2} · √(p̂(1-p̂)/n)
```

**版本信息**：
- **形式化基础**：频率主义统计学（Fisher, Neyman-Pearson, 20 世纪上半叶）
- **依赖前提**：独立同分布、大数定律、中心极限定理、重复抽样框架
- **典型实例**：抛硬币 `n` 次估计正面概率；临床试验中估计治愈率
- **AxiomaticBase**：`FrequentistStatistics` + `LargeSampleTheory`

## 2. S/M/P × D/L 六格审计

### 2.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| 随机样本 i.i.d. | 重复实验的可重复性假设 | ✅ |
| 概率 = 长期频率 | 大数定律保证 `p̂ → p` | ✅ |
| 置信区间 | 覆盖率在重复抽样下为 `1-α` | ✅ |
| 中心极限定理 | `n` 充分大时近似正态 | ✅ |

### 2.2 S*L — 语义逻辑结构

- 频率主义把“概率”定义为**长期相对频率**，因此参数 `p` 是固定但未知的客观常数。
- 置信区间的语义是：若重复抽样无数次，大约有 `1-α` 比例的区间会覆盖真实 `p`。
- ⚠️ 风险：学生常把“95% 置信区间”误解读为“参数落在该区间的概率为 95%”，这是贝叶斯式解释，在频率主义中不合法。

### 2.3 M*D — 数学依存

```text
Frequentist_Binomial(p, n, k)
    │
    ├── X_i ~ Bernoulli(p) i.i.d.
    │
    ├── MLE p̂ = k/n
    │
    ├── CLT: √n(p̂ - p) → N(0, p(1-p))
    │
    └── CI: p̂ ± z_{α/2} · √(p̂(1-p̂)/n)
```

- 依赖关系闭合：依赖概率论中的极限定理。

### 2.4 M*L — 数学逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 估计量无偏性 | ✅ | `E[p̂] = p`。 |
| 相合性 | ✅ | 由大数定律，`p̂ → p`（依概率收敛）。 |
| 区间覆盖率 | ✅ | 渐近覆盖率为 `1-α`。 |
| 退化情形 | ✅ | `k=0` 或 `k=n` 时区间收缩为端点，可用 Wilson 分数区间修正。 |

### 2.5 P*D / P*L — 编程层

- Python/NumPy/SciPy：`statsmodels.stats.proportion.proportion_confint` 实现多种频率主义区间（Wald, Wilson, Clopper-Pearson）。
- R：`binom.test` 与 `prop.test`。
- 风险：实现中需明确使用 Wald 还是精确区间，否则覆盖率可能与名义 `1-α` 有偏差。

## 4. 人类科学家可执行的验证动作

1. 模拟 `n=100, p=0.3` 的 Bernoulli 样本，验证 `p̂` 的样本均值是否接近 `p`。
2. 重复构造 1000 个 95% Wald 区间，验证覆盖率是否接近 0.95。
3. 验证 `k=0` 时 Wald 区间退化为 `[0,0]`，说明需要 Wilson 或 Agresti-Coull 修正。
