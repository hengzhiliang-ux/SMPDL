序言：1843 年 10 月 15 日之夜，于都柏林皇家运河畔夜色已深，冷月照 Fring Bridge（布鲁姆桥）的石栏。多年来，我一直试图将平面上的复数几何（如高斯与阿冈所启示的那样）推广到三维空间。然而，每当尝试构筑三维的"三元数组"时，除法的运算便在闭合性或非零元的倒数上陷入泥沼。今日，我不得不做出一个激进的决断：若三维的几何直觉与代数的整除性不可兼得，且我们必须抛弃那神圣不可侵犯的"乘法交换律"（即允许 $ab \neq ba$），那么，代数的世界究竟会呈现何种面貌？以下为我基于现今（1843 年 10 月）全部合法数学知识所作的审判与重建。

## 第一节：三维之困与四元之构（数系之重建与三维尝试的报告）

### 1. 三维二元组式尝试的失败报告

在此前的数月中，我曾反复试验形如 $x + y\epsilon + z\eta$ 的三维数组。若仿照复数的模长性质，企图让乘积的模等于模的乘积，并保证除法可行，我发现：

**失败之所在**：在三维系统中，若要求对除零以外的任何元素都能进行唯一的除法运算，其分量方程组所对应的行列式恒会因某些非零元的交叉项消去而退化为零。换言之，三维空间中必然会不可避免地涌现出"零因子"（即两个非零元相乘得零），这彻底摧毁了解除法方程的基石。三维的尝试，在代数闭合与除法畅通上撞上了不可逾越的高墙。

### 2. 四单位系统的可信构造

既然三维不通，让我们跃入四维。设想一个由四个实数分量构成的数系，其一般形式为：

$$q = w + x\epsilon + y\eta + z\theta$$

其中 $w, x, y, z$ 为平常之实数，而 $\epsilon, \eta, \theta$ 为三个独立的非实根源（可视为三个不同的"虚单位"），它们满足以下基本乘法法则：

**平方皆为负一**：$\epsilon^2 = \eta^2 = \theta^2 = -1$

**非交换之交叉乘积**：

$$\epsilon\eta = \theta, \quad \eta\epsilon = -\theta$$
$$\eta\theta = \epsilon, \quad \theta\eta = -\epsilon$$
$$\theta\epsilon = \eta, \quad \epsilon\theta = -\eta$$

### 3. 运算法则与非平凡计算例

加减法：按对应分量相加减，显然满足交换律与结合律。

乘法：服从分配律，但由于交叉项的正负差异，乘法严格不满足交换律。

**非平凡计算例**：
设两数 $A = 1 + \epsilon$ 与 $B = 1 + \eta$。

计算正向积 $AB$：
$$AB = (1 + \epsilon)(1 + \eta) = 1 + \eta + \epsilon + \epsilon\eta = 1 + \epsilon + \eta + \theta$$

计算反向积 $BA$：
$$BA = (1 + \eta)(1 + \epsilon) = 1 + \epsilon + \eta + \eta\epsilon = 1 + \epsilon + \eta - \theta$$

可见 $AB \neq BA$。由于 $\theta \neq -\theta$（除非分量为零），交换律在此彻底失效，但乘法依然封闭且导出了清晰的新单位。

## 第二节：旧代数定理之崩塌与幸存（代数运算的审判）

在抛弃乘法交换律后，昔日大厦中的许多定理遭遇了命运的分化：

**二项展开式 $(a+b)^2$ 的崩塌**：
旧式定理中，$(a+b)^2 = a^2 + 2ab + b^2$ 依赖于 $ab = ba$。
在非交换系中，展开为：
$$(a+b)(a+b) = a^2 + ab + ba + b^2$$
不可合并项：中间的 $ab$ 与 $ba$ 因次序不同，绝不可合并为 $2ab$。若 $a, b$ 不可交换，二项式定理的系数统统需要重写。

**二次方程求根公式的塌陷**：
对于形如 $ax^2 + bx + c = 0$ 的方程（若系数与未知数属于该非交换系），传统的配方法与求根公式在提取因式 $(x - r_1)(x - r_2) = 0$ 时失效。因为展开后为 $x^2 - (r_1 + r_2)x + r_1 r_2$ 仅在系数与根可交换时成立；若未知数夹在系数之间，求根公式的代数推导步步皆错，根的位置将直接影响方程的值。

**行列式乘法性对交换律的依赖**：
柯西（Cauchy, 1812）关于行列式乘法定理 $\det(AB) = \det(A)\det(B)$ 的证明，在其核心的代数展开式中，大量利用了矩阵元之间的乘法交换。当我们将矩阵推广到其元素属于非交换数系时，行列式的定义本身即因各项排列相乘的次序不同而变得暧昧，传统的行列式乘法性质在此处完全失效。

## 第三节：复数性质之存活清单

当我们审视昔日复数的经典性质时，哪些得以幸存？清单如下：

**加法与减法结构（存活）**：
加法的交换律、结合律完全存活。数系的底层群结构依然是阿贝尔的（Abelian）。

**模长的乘积性质（存活）**：
定义共轭数 $\bar{q} = w - x\epsilon - y\eta - z\theta$，其模长的平方为 $N(q) = q\bar{q} = w^2 + x^2 + y^2 + z^2$。经计算，乘积的模仍等于模的乘积：
$$N(AB) = N(A)N(B)$$
这一欧拉四平方恒等式的代数内核得以完整保存。

**非零元的求逆与除法（存活）**：
利用共轭，非零元的倒数可明确给出为 $q^{-1} = \frac{\bar{q}}{N(q)}$。除法（左除与右除）依然畅通无阻。

**一次方程的求解（部分存活）**：
形如 $ax = b$ 的一次方程，只要 $a \neq 0$，可通过左乘逆元 $x = a^{-1}b$ 唯一求解。但需注意，方程 $xa = b$ 与 $ax = b$ 的解不再相同。

## 第四节：隐蔽使用交换律之陷阱（传统证明的审判）

在过往的数学经典中，有许多表面上未曾提及 $ab = ba$，实则处处依赖它的隐蔽陷阱：

**陷阱例证：多项式因式分解的唯一性证明**

在许多关于多项式根的定理中，常隐蔽地使用如下推理："若 $r$ 为方程之根，则 $(x - r)$ 必为多项式之因式"。

在证明这一结论时，旧有论证将多项式在 $x = r$ 处展开，利用各项系数与变量的自由交换，将余数归结为纯数值。

然而，若乘法不可交换，代入 $x$ 时，因 $x$ 处于不同的乘积项左侧或右侧，余数项不再是一个简单的常数，多项式的带余除法与因式定理由于次序的错位而暗中失效。传统证明在此处隐蔽地依赖了交换律带来的项序自由。

## 第五节：维数之谜与未竟之业

关于「非交换数系究竟能在几个维度上存在」这一宏大问题：

**现状声明**：以我 1843 年 10 月 15 日晚的全部数学工具来看，无法给出完全的刻画。

**卡在何处**：我们目前仅在实验中摸索了 2 维（复数，交换）、3 维（失败）、以及眼前的 4 维（四单位系统，非交换）。我的朋友约翰·格雷夫斯（John Graves）近期曾写信探讨过更高维度的可能性，但对于"为什么某些维数允许除法而另一些维数必然引入零因子"这一根本规律，我们缺乏足够高明的分析工具。代数方程的阶数、超复数单位的乘法契合性、以及空间维数之间的内在鸿沟，远非目前的行列式理论或多项式理论所能完全照亮。

明晨，当我和夫人再次走过那座桥时，或许唯有将这四个单位及其乘法规则铭刻在石桥之上，才能向世人宣告：代数已然挣脱了交换的枷锁，驶入了更为广阔而汹涌的汪洋。

# 非交换数系的可能性与旧代数的边界

都柏林，1843年10月15日晚 · 一份尚待检验的数学札记

## 第一节　清点崩溃：撤去交换律之后，究竟还剩下什么？

我首先须划清问题的界限。我们惯用的数，从实数到复数，乘法皆可交换；然而，习惯本身不是证明。若有一套运算规则，使加法、减法、乘法、除法（除数非零时）均有意义，且乘法对于加法分配，那么我没有理由在未作检验以前，便宣布交换律为不可废弃的真理。

我将研究对象称为一种广义数系，但不预先假定其乘法交换。

为避免暗中借回旧法则，我把需要的规则逐条列明：

1. 加法满足结合律与交换律，存在加法单位 \(0\)，每个元素 \(a\) 有相反元素 \(-a\)。
2. 乘法满足结合律，存在乘法单位 \(1\)，且 \(1\ne0\)。
3. 乘法左右两侧都对加法分配：
   \[
   a(b+c)=ab+ac,\qquad (a+b)c=ac+bc.
   \]
4. 每个非零元素 \(a\) 都有左右逆元；也就是说，存在元素 \(u,v\)，使
   \[
   ua=1,\qquad av=1.
   \]
   在具有结合律的前述规则下，这两个逆元必相等。证明如下：
   \[
   u=u(av)=(ua)v=v.
   \]
   因而可将它记作 \(a^{-1}\)，并有
   \[
   aa^{-1}=a^{-1}a=1.
   \]

这些条件足以构成一个严肃的问题。这里有一项特别说明：我保留乘法结合律，却不保留乘法交换律。 结合律说的是三个因子如何分组，交换律说的是两个因子能否调换位置；二者绝非同一件事。

本札记的目标不是宣称所有旧定理皆已失效，而是逐一检查：哪些只靠分配律与结合律，哪些确实偷用了交换律，以及哪些存在性问题超出了我现有的证明能力。

## 第二节　重建：一种确实可行的四维数系

### 2.1 从平面数出发

我已知复数可以写成 \(z=x+yp\)，其中 \(x,y\) 为实数，且

\[ p^2=-1. \]

复数的乘法交换，但我们可以试着引入另一种平面方向，使它与原有的方向相互作用，而不预先要求交换。

令新数写成有序对

\[ A=(z,w),\qquad z,w\in\mathbb C. \]

这里的 \(z,w\) 都是通常意义上的复数。定义加法为

\[ (z,w)+(u,v)=(z+u,w+v), \]

定义乘法为

\[ \boxed{(z,w)(u,v) =(zu-w\bar v,\;zv+w\bar u).} \]

横线表示通常的复共轭。这是明确的运算法则，不是对尚未定义的乘法作任何假设。

实数 \(r\) 对应 \((r,0)\)。于是

\[ (z,w)=(x+yp,u+vp) \]

共有四个独立的实数坐标，故这是一个四维的实数扩充。

### 2.2 单位元、分配律与结合律

加法的单位元是 \((0,0)\)，加法相反元为

\[ -(z,w)=(-z,-w). \]

乘法单位元是

\[ \mathbf 1=(1,0). \]

直接代入定义可得

\[ (z,w)(1,0)=(z,w)=(1,0)(z,w). \]

由于复数乘法对加法分配、复共轭对加法分配，所定义的乘法在左、右两侧都满足分配律。

更关键的是结合律。为不把这一点留给直觉，我们将三对元素相乘进行核算。设

\[ A=(z,w),\quad B=(u,v),\quad C=(s,t). \]

先计算 \((AB)C\)，其两个坐标分别为

\[ \begin{aligned} X_1={}&zus-w\bar v s-zv\bar t-w\bar u\bar t,\\ Y_1={}&zut-w\bar v t+zvs+w\bar u s. \end{aligned} \]

再计算 \(A(BC)\)。因为

\[ BC=(us-v\bar t,\;ut+v\bar s), \]

得到

\[ \begin{aligned} X_2={}&zus-v\bar t z-w\bar t\bar u-w\bar s\bar v,\\ Y_2={}&zut+zv\bar s+w\bar s\bar u-w\bar v s. \end{aligned} \]

利用复数的交换律与共轭性质，可逐项重排：

\[ X_1=X_2,\qquad Y_1=Y_2. \]

故

\[ (AB)C=A(BC). \]

请注意：这里使用了组成各坐标的普通复数之间的交换律。这并没有假定新数 \(A,B,C\) 之间可交换；恰恰相反，我们正在构造一个允许它们不交换的体系。

### 2.3 非零元素是否都能除？

定义数的模平方：

\[ N(z,w)=|z|^2+|w|^2. \]

当 \((z,w)\ne(0,0)\) 时，\(N(z,w)>0\)。定义

\[ (z,w)^*=(\bar z,-w). \]

由乘法规则，

\[ \begin{aligned} (z,w)(\bar z,-w)&=(|z|^2+|w|^2,0),\\ (\bar z,-w)(z,w)&=(|z|^2+|w|^2,0). \end{aligned} \]

因此，非零元素有双侧逆元：

\[ \boxed{(z,w)^{-1} =\frac{(\bar z,-w)}{|z|^2+|w|^2}.} \]

分母是正实数，它与所有元素相乘均可交换；这里没有偷偷交换两个一般元素的位置。

### 2.4 一个非平凡计算：乘法果然不交换

令

\[ P=(p,0),\qquad Q=(0,1). \]

依照刚才的定义，

\[ PQ=(0,p),\qquad QP=(0,\bar p)=(0,-p). \]

所以

\[ \boxed{PQ\ne QP.} \]

再计算一次乘法，以检验规则是否一致：

\[ P^2=(-1,0),\qquad Q^2=(-1,0). \]

但

\[ (PQ)^2=(0,p)(0,p)=(-1,0). \]

这里两个乘积恰好相同，并不意味着 \(P\) 与 \(Q\) 可以交换；前面的直接计算已明确否定了这一点。

因此，我已交付一个满足加法、减法、乘法、非零除法、分配律与结合律的四维数系，而且它的乘法确实不交换。

### 2.5 三维尝试：哪里失败，哪里尚不能断言？

我先试图只用三个独立方向构造同样的数系。令 \(P,Q\) 满足

\[ P^2=Q^2=-1,\qquad PQ=-QP. \]

若把第三个方向记作 \(R=PQ\)，则

\[ QP=-R. \]

而由结合律，

\[ PR=P(PQ)=P^2Q=-Q, \]

\[ RP=(PQ)P=P(QP)=P(-PQ)=Q, \]

其中每一步都可由已写明的规则核对。同样，

\[ QR=Q(PQ)=(QP)Q=-PQ^2=P, \]

\[ RQ=(PQ)Q=P Q^2=-P. \]

因此，\(R\) 不能被随意删去；它承担了由 \(P,Q\) 的乘法产生的新方向。

若我们把体系限制为 \(1,P,Q\) 三个独立元素方向，那么这个尝试无法按上述规则封闭：\(PQ=R\) 必须有位置，而 \(R\) 不在原先选定的三个方向中。

但必须严守结论的范围：这只否定了这一种三维构造尝试，并未证明所有三维构造都不可能。 要证明不存在其他乘法规则，我目前没有一套完整论证。

## 第三节　旧代数的审判：哪些定理存活？

### 3.1 平方展开：第一个立即发生的改变

在交换乘法的旧数系中，

\[ (a+b)^2=a^2+2ab+b^2. \]

证明依赖于将 \(ab+ba\) 合并成 \(2ab\)。若不允许交换，正确公式只能是

\[ \boxed{(a+b)^2=a^2+ab+ba+b^2.} \]

其中 \(ab\) 与 \(ba\) 是两个不同次序的乘积，不能合并。

同理，

\[ (a-b)^2=a^2-ab-ba+b^2. \]

但有些公式并不受影响。只要结合律成立，

\[ a(b+c)=ab+ac,\qquad (a+b)c=ac+bc \]

依然成立；而对于任意整数 \(n\)，\(a^n a^m=a^{n+m}\) 也仍成立（负指数要求 \(a\ne0\)）。这些结论没有把两个不同元素调换位置。

### 3.2 二次方程：配方法究竟在哪一步断裂？

考虑

\[ x^2+bx+c=0. \]

旧法将前两项配成平方：

\[ x^2+bx=\left(x+\frac b2\right)^2-\frac{b^2}{4}. \]

若 \(b\) 是普通实数，那么它与 \(x\) 相乘可交换，因此这一配方仍然成立。非交换性本身并不会毁掉所有二次方程的求根公式。

真正的问题出现在 \(b\) 也是一般新数时。展开得

\[ \left(x+\frac b2\right)^2 =x^2+\frac{xb+bx}{2}+\frac{b^2}{4}. \]

它并不等于 \(x^2+bx+b^2/4\)，除非另外证明 \(xb=bx\)。所以，传统配方步骤在一般情形下失效。

若方程为

\[ x^2+px+q=0, \]

而 \(p,q\) 都可以是非交换元素，那么我不能直接照搬旧的二次公式。即使 \(p\) 可逆，尝试左乘或右乘 \(p^{-1}\)，也会产生不同的次序；更不能把含 \(x\) 的乘积随意重排。

这里应当区分两个命题：

- 旧证明不再有效：已由展开核算证明。
- 该方程必无根或不能求根：没有证明，不能如此宣称。

某些特殊系数仍可处理。例如，当 \(p,q\) 都是实数时，方程仍是旧的二次方程。又如，当 \(p\) 与所求的 \(x\) 可交换时，配方可以恢复。困难在于一般情形，而非一切情形。

### 3.3 行列式乘法性：交换律藏在哪里？

Cauchy 所发展的行列式理论，给出熟悉的公式

\[ \det(AB)=\det(A)\det(B). \]

但它的传统证明会把乘积矩阵的行列式展开为各项的和，再按因子分组。对一般元素而言，这种分组可能把乘积的先后次序改变。

看一个最简单的二阶情形。若矩阵元素不交换，形式上仍可写

\[ D\begin{pmatrix}a&b\\c&d\end{pmatrix}=ad-bc. \]

然而，乘积矩阵的四个元素是

\[ AB= \begin{pmatrix} ae+bg & af+bh\\ ce+dg & cf+dh \end{pmatrix}. \]

若照旧计算 \(D(AB)\)，会得到

\[ \begin{aligned} D(AB)={}&(ae+bg)(cf+dh)\\ &-(af+bh)(ce+dg). \end{aligned} \]

展开后出现 \(aecf\)、\(bgdh\) 等项。要将这些项配对抵消，必须仔细保留每个因子的次序；传统证明中诸如把 \(ae cf\) 改写为 \(ac ef\) 的步骤，不能在一般情况下使用。

因此，我能下的准确结论是：传统行列式乘法性的证明依赖交换律；旧的证明不能直接用于任意非交换元素。

但我不能进一步断言，任何可能重新定义的行列式都绝无乘法性。上面的形式 \(ad-bc\) 也不能自动获得旧行列式的一切性质。要推广此理论，须重新指定定义，并逐项检验其性质。

### 3.4 一处更隐蔽的交换律使用

考虑通常的恒等式

\[ (ab)^2=a^2b^2. \]

在交换数系中，

\[ (ab)^2=abab=aabb=a^2b^2. \]

关键步骤是将中间的 \(ba\) 改成 \(ab\)。在本札记的数系中，这一步一般不成立。

用第二节的 \(P,Q\) 检验：

\[ (PQ)^2=(-1,0), \]

而

\[ P^2Q^2=(-1,0)(-1,0)=(1,0). \]

两者不等。这是一个直接反例：不能把交换律的作用藏在"重新排列因子"这句话里。

同样，若某证明把

\[ (a+b)(a-b) \]

直接写成 \(a^2-b^2\)，它也暗中使用了交换律。真正展开应为

\[ a^2-ab+ba-b^2. \]

只有在 \(ab=ba\) 时，中间两项才抵消。

## 第四节　镜像：复数的哪些性质依赖交换律？

复数理论中，有些事实来自加法结构，有些来自乘法交换，有些则只依赖共轭与模的性质。不能将它们混为一谈。

| 复数性质       | 在新数系中是否存活？ | 理由                   |
| ---------- | ---------- | -------------------- |
| 加法交换、结合    | 存活         | 加法定义逐坐标沿用复数加法        |
| 加法相反元      | 存活         | \((-(z,w)=(-z,-w)\) |
| 乘法结合       | 存活         | 第二节已逐项验证             |
| 乘法交换       | 不存活        | \(PQ\ne QP\)       |
| 左右分配律      | 存活         | 乘法定义及复数分配律           |
| 非零元素有逆元    | 存活         | 第二节给出了双侧逆元           |
| 一般一次方程有唯一解 | 存活，但须注明次序  | 左乘与右乘的解法不同           |
| 复数共轭的原有公式  | 部分存活       | 需区分普通复共轭与新定义的星号运算    |
| 模的乘法性      | 存活         | 可由直接计算证明             |
| 传统二次公式     | 一般不存活      | 配方中出现不可合并的交叉项        |

### 4.1 一次方程：解仍在，但次序重要

考虑

\[ ax=b,\qquad a\ne0. \]

左乘 \(a^{-1}\)，得到唯一解

\[ x=a^{-1}b. \]

反过来，若方程是

\[ xa=b, \]

则应右乘 \(a^{-1}\)，得到

\[ x=ba^{-1}. \]

这两个公式不能在没有额外条件时混用。唯一性也可直接证明：若 \(ax=b=ay\)，则

\[ a(x-y)=0. \]

左乘 \(a^{-1}\)，即得 \(x-y=0\)，所以 \(x=y\)。

因此，一次方程的解法并未崩溃；崩溃的是不顾因子次序、把左乘与右乘视为同一操作的习惯。

### 4.2 共轭：须分清两种不同的操作

普通复数共轭记作 \(\bar z\)。在新数系中，我定义的星号操作为

\[ (z,w)^*=(\bar z,-w). \]

它满足

\[ (AB)^*=B^*A^*. \]

这条公式可以从第二节的乘法定义逐项验证。它与普通复共轭的性质相似，却不能将二者混为一谈：星号操作作用于整个有序对，而横线只作用于单个复数。

此外，

\[ A^*A=AA^*=N(A)\mathbf 1, \]

其中

\[ N(A)=|z|^2+|w|^2. \]

所以新数系也保留一种正的模平方。它不是因为乘法交换而存在，而是因为共轭操作与乘法规则彼此配合。

### 4.3 模长的乘法性

还可以证明

\[ \boxed{N(AB)=N(A)N(B).} \]

证明可直接从定义出发。令

\[ AB=(zu-w\bar v,\;zv+w\bar u). \]

于是

\[ \begin{aligned} N(AB) ={}&|zu-w\bar v|^2\\ &+|zv+w\bar u|^2. \end{aligned} \]

展开两项后，第一项的交叉项为

\[ -2\operatorname{Re}(zu\,\overline{w\bar v}), \]

第二项的交叉项为

\[ 2\operatorname{Re}(zv\,\overline{w\bar u}). \]

两者相消。其余各项合并为

\[ (|z|^2+|w|^2)(|u|^2+|v|^2). \]

故所述等式成立。

这里使用的是普通复数的模、共轭和实部运算，而不是新数系的乘法交换律。

存活清单的核心结论是： 加法结构、分配律、结合律、非零逆元、一次方程的唯一解、共轭型运算以及模平方的乘法性，都能在一个非交换数系中共同存在。交换律不是这些性质的共同根源。

## 第五节　总结：能证明什么，不能证明什么？

现在回到最初的问题：如果撤去乘法交换律，一个数系还能否存在？

答案是肯定的。第二节给出了明确的四维构造，验证了它的运算规则、结合律、分配律、非零逆元，并用 \(PQ\ne QP\) 证明其乘法确实不交换。

但若问题进一步要求：非交换数系究竟能存在于哪些维度，是否存在完整的维度分类？ 我必须承认：

以现有工具无法解决。

理由并非没有任何线索，而是缺少足够的排除性证明。

我已经展示了一个四维实例；也说明了一种三维尝试为何不能封闭。但从一种尝试失败，推不出所有三维尝试都失败。要完成分类，我必须证明：在每一个被排除的维度中，任何可能的乘法规则都不满足要求；而这远远超出了当前札记已经建立的论证。

我也没有证明二维实数扩充中所有可能的乘法规则必然交换。因此，我不能把几个成功的构造和一个失败的尝试，冒充为完整的维度定理。

最后，将本次调查所得列成四条：

1. 存在性已证： 四维实数扩充中可以构造满足所列规则、且乘法不交换的数系。
2. 旧代数的失效点已定位： 平方展开、一般二次方程配方及传统行列式乘法性的证明，都存在不能忽略因子次序的关键步骤。
3. 存活的性质已举证： 分配律、结合律、非零逆元、一次方程唯一解，以及一种共轭与模平方理论，均不要求新数系的乘法交换。
4. 维度的完全刻画尚未完成： 三维构造的失败不等于三维不可能；四维实例也不等于四维是唯一可能的非交换维度。

我宁可将这条界线写清，也不愿以一条未经证明的普遍断言，换取表面上的完满。

都柏林，1843年10月15日晚。

## 一、清点崩溃：三维二元组式尝试为何失败

先试最自然的三秩形式：元素写作

\[
x=a+b\,\mathrm p+c\,\mathrm q,\qquad a,b,c\in\mathbb R,
\]

希望 \(1,\mathrm p,\mathrm q\) 三单位闭合，且乘法满足结合律、分配律、有单位，并令

\[
\mathrm p^2=\mathrm q^2=-1.
\]

闭合性要求

\[
\mathrm p\mathrm q=\alpha+\beta\,\mathrm p+\gamma\,\mathrm q
\]

其中 \(\alpha,\beta,\gamma\) 为实数。若乘法满足结合律，则左乘 \(\mathrm p\)：

\[
\mathrm p(\mathrm p\mathrm q)=\mathrm p^2\mathrm q=-\mathrm q.
\]

另一方面

\[
\mathrm p(\alpha+\beta\mathrm p+\gamma\mathrm q)
=\alpha\mathrm p+\beta\mathrm p^2+\gamma\mathrm p\mathrm q
=(-\beta+\gamma\alpha)+(\alpha+\gamma\beta)\mathrm p+\gamma^2\mathrm q.
\]

比较 \(\mathrm q\) 的系数，得

\[
-1=\gamma^2.
\]

但 \(\gamma\) 是实数，矛盾。

故这条三维闭合路线失败。失败点不在分配律，而在三处同时坚持：乘法闭合、结合律、以及两个独立单位平方皆为 \(-1\)。若撤去结合律或撤去平方假设，是否另有三维构造，以我现有工具不能断言；此处只如实报告该自然尝试不可修复。

## 二、重建：一个四秩非交换算术

### 定义

取四个单位 \(1,\mathrm u,\mathrm v,\mathrm w\)，元素写作

\[
x=a+b\,\mathrm u+c\,\mathrm v+d\,\mathrm w,\qquad a,b,c,d\in\mathbb R.
\]

加法、减法逐支进行。乘法由分配律与下表决定：

\[
\mathrm u^2=\mathrm v^2=\mathrm w^2=-1,
\]

\[
\mathrm u\mathrm v=\mathrm w,\quad
\mathrm v\mathrm w=\mathrm u,\quad
\mathrm w\mathrm u=\mathrm v,
\]

\[
\mathrm v\mathrm u=-\mathrm w,\quad
\mathrm w\mathrm v=-\mathrm u,\quad
\mathrm u\mathrm w=-\mathrm v.
\]

单位 \(1\) 与一切元素相乘不变。等价地，若

\[
x=(a,b,c,d),\quad y=(a',b',c',d'),
\]

则乘积为

\[
\begin{aligned}
xy={}&(aa'-bb'-cc'-dd',\\
&ab'+ba'+cd'-dc',\\
&ac'+ca'+db'-bd',\\
&ad'+da'+bc'-cb').
\end{aligned}
\]

分配律由公式对两支系数线性而成立。结合律不能靠"显然"带过；可对四个单位的每个三元组逐项核对。例如

\[
(\mathrm u\mathrm v)\mathrm w=\mathrm w\mathrm w=-1,
\]

而

\[
\mathrm u(\mathrm v\mathrm w)=\mathrm u\mathrm u=-1.
\]

其余三元组同法核对，再由线性展开推到一般元素。

### 除法与逆

定义共轭式

\[
\bar x=a-b\,\mathrm u-c\,\mathrm v-d\,\mathrm w.
\]

直接展开得

\[
x\bar x=\bar x x=a^2+b^2+c^2+d^2=:N(x).
\]

若 \(x\ne0\)，则 \(N(x)>0\)，故

\[
x^{-1}=\frac{\bar x}{N(x)}
\]

为双侧逆：

\[
xx^{-1}=x^{-1}x=1.
\]

所以每个非零元素可除，且左逆右逆同一。

### 非平凡计算例

\[
(1+\mathrm u)(1+\mathrm v)
=1+\mathrm u+\mathrm v+\mathrm u\mathrm v
=1+\mathrm u+\mathrm v+\mathrm w,
\]

而

\[
(1+\mathrm v)(1+\mathrm u)
=1+\mathrm u+\mathrm v+\mathrm v\mathrm u
=1+\mathrm u+\mathrm v-\mathrm w.
\]

二者不等，故乘法不交换。

又

\[
(1+\mathrm u)(1-\mathrm u)
=1-\mathrm u+\mathrm u-\mathrm u^2
=1+1=2,
\]

所以

\[
(1+\mathrm u)^{-1}=\frac{1-\mathrm u}{2}.
\]

再如

\[
(\mathrm u+\mathrm v)(\mathrm u-\mathrm v)
=\mathrm u^2-\mathrm u\mathrm v+\mathrm v\mathrm u-\mathrm v^2
=-1-\mathrm w-\mathrm w+1=-2\mathrm w,
\]

而反向相乘得 \(2\mathrm w\)，次序不可轻动。

## 三、审判：旧代数定理哪些存活、哪些先坏

### 仍成立者

加法交换、结合、消去、零与负元；乘法对加法分配；乘法结合；单位元；非零元素有逆；同底幂的指数相加律

\[
x^m x^n=x^{m+n}.
\]

一次方程若写作左乘形式

\[
ax=b,\qquad a\ne0,
\]

则有唯一左解

\[
x=a^{-1}b.
\]

若写作右乘形式

\[
xa=b,
\]

则有唯一右解

\[
x=ba^{-1}.
\]

但二者一般不同。例如

\[
\mathrm u x=\mathrm v
\]

给出 \(x=\mathrm u^{-1}\mathrm v=(-\mathrm u)\mathrm v=-\mathrm w\)，而

\[
x\mathrm u=\mathrm v
\]

给出 \(x=\mathrm v\mathrm u^{-1}=\mathrm v(-\mathrm u)=\mathrm w\)。

### 先坏者

第一，

\[
(a+b)^2=aa+ab+ba+bb.
\]

这里 \(ab\) 与 \(ba\) 不可合并为 \(2ab\)，除非已知二者相等。故旧式

\[
(a+b)^2=a^2+2ab+b^2
\]

只在交换情形成立。

第二，二次方程求根的配方一步塌。传统写法要把

\[
a(x+d)^2=ax^2+axd+adx+ad^2
\]

中的 \(axd\) 与 \(adx\) 合并为 \(2adx\)，再令其等于 \(bx\)。这一步实际用了 \(xd=dx\)。在非交换情形，\(axd+adx\) 不能合并；求根公式所依赖的配方因此失效。甚至在

\[
x^2+1=0
\]

中，\(\mathrm u,\mathrm v,\mathrm w\) 皆是根，旧"至多两根"的图像也坏了。

第三，行列式的乘法性依赖交换。取二行二列表

\[
A=\begin{pmatrix}\mathrm u&1\\0&\mathrm v\end{pmatrix},\qquad
B=\begin{pmatrix}\mathrm w&0\\1&\mathrm u\end{pmatrix},
\]

并令

\[
\det\begin{pmatrix}a&b\\c&d\end{pmatrix}=ad-bc.
\]

则

\[
\det A=\mathrm u\mathrm v=\mathrm w,\qquad \det B=\mathrm w\mathrm u=\mathrm v,
\]

故

\[
\det A\det B=\mathrm w\mathrm v=-\mathrm u.
\]

但

\[
AB=\begin{pmatrix}1-\mathrm v&\mathrm u\\ \mathrm v&-\mathrm w\end{pmatrix},
\]

于是

\[
\det(AB)=(1-\mathrm v)(-\mathrm w)-\mathrm u\mathrm v
=-\mathrm w+\mathrm v\mathrm w-\mathrm w
=\mathrm u-2\mathrm w.
\]

而 \(\mathrm u-2\mathrm w\ne-\mathrm u\)。所以

\[
\det(AB)=\det A\det B
\]

不成立。其证明中把展开项因子重排，正是隐蔽使用交换。

## 四、镜像：复数的哪些性质由交换律给出

逐条判定如下。

**一次方程。** 在复数中 \(ax=b\) 与 \(xa=b\) 同解，因为 \(a\) 与 \(x\) 可交换。非交换四秩算术中，左解 \(a^{-1}b\) 与右解 \(ba^{-1}\) 一般不同；左右可解性仍存活，同解性坏。

**加法结构。** 加法交换、结合、零元、负元、分配律全部存活；实数部分与一切元素可交换，也存活。

**共轭式。** 加性

\[
\overline{x+y}=\bar x+\bar y
\]

存活。乘性必须反序：

\[
\overline{xy}=\bar y\,\bar x.
\]

例如

\[
\overline{\mathrm u\mathrm v}=\overline{\mathrm w}=-\mathrm w,
\]

而

\[
\bar{\mathrm v}\bar{\mathrm u}=(-\mathrm v)(-\mathrm u)=\mathrm v\mathrm u=-\mathrm w.
\]

但旧式

\[
\overline{xy}=\bar x\bar y
\]

一般不成立；它由交换律给出。

**模长。** 定义

\[
N(x)=x\bar x=\bar x x=a^2+b^2+c^2+d^2.
\]

它恒为实数且非负，零仅当 \(x=0\)。并且

\[
N(xy)=N(x)N(y)
\]

在本构造中仍成立，可由乘法表直接展开核对。例如

\[
N(1+\mathrm u)=2,\quad N(1+\mathrm v)=2,
\]

而

\[
(1+\mathrm u)(1+\mathrm v)=1+\mathrm u+\mathrm v+\mathrm w,
\]

其模长为 \(1+1+1+1=4\)。故模长乘性不靠交换律；但旧式展开中若把共轭因子随意换序，就会偷偷把交换律请回来。

**存活清单。** 加法结构、分配、结合、单位、逆、左/右一次方程、共轭加性、共轭反序乘性、模长及其乘性存活。乘法交换、\(ab=ba\)、二项式合并、因式分解、二次方程旧求根公式、行列式乘性、共轭直接乘性、左右方程同解性先坏。

**隐蔽使用交换的一处传统证明。** 配方

\[
a(x+d)^2=ax^2+axd+adx+ad^2
\]

中，传统把 \(axd+adx\) 写成 \(2adx\)，表面只说"合并同类项"，实际需要 \(xd=dx\)。这正是表面未提 \(ab=ba\)、实际依赖交换的位置。

## 五、总结：能造什么，不能断言什么

能造出四秩非交换算术：其元素可加、可减、可乘、可除，乘法对加法分配，乘法满足结合律，但乘法不交换。三维二元组式在"闭合、结合、两单位平方为 \(-1\)"的同时要求下失败，失败点为 \(\gamma^2=-1\) 而 \(\gamma\) 为实数。

但"非交换数系在几个秩上存在"的完全刻画，以我现有工具无法解决。已知者仅：一秩实数交换；二秩复数交换；四秩有上述构造；三秩在上述自然假设下失败。卡点在于：需对所有可能的乘法表同时解结合条件与每非零元素有逆的条件；行列式方法只在交换情形可靠；二次型与旋转对应只提供局部线索；现有工具既不能排除更高秩构造，也不能证明其不可能。故此问题如实申报为未决，不把未证之事写成已证。

# 撤去乘法交换律后的一份代数试验

**都柏林，1843 年 10 月 15 日夜**

今设一数系，加法、减法如常，乘法保持结合律，并对加法左右分配；又设每一非零元皆有左右同一之逆元。所撤去者，仅为 ab=ba 之普遍保证。

先记两条随后反复使用的事实：(a+b)c=ac+bc，c(a+b)=ca+cb；(ab)⁻¹=b⁻¹a⁻¹。后一式不可误写为 a⁻¹b⁻¹，因为 (ab)(b⁻¹a⁻¹)=a(bb⁻¹)a⁻¹=1。

---

## 一、重建：三重数组之失败与四重数之造成

### 1. 三重数组为何不能成功

先取三重复数 x=a+bu+cv，其中 a,b,c 为实数，1,u,v 互相独立。若仍要求乘法对加法分配，则乘法完全由 u²,uv,vu,v² 等基元乘积决定。看似尚有充分自由选择这些乘积，故失败不能只归咎于某一张乘法表选得不好。

实际上，有一个更普遍的障碍，而且论证不必假定乘法结合。

设所论数系只有三个实坐标，任取其中一元素 t，考察"以 t 左乘"所成的线性代换。它由一个三行三列的实数阵列表示。作行列式方程

det(sI−L_t)=0，

左端为 s 的三次实多项式，故至少有一实根 λ。于是相应线性代换为奇异，必有一非零元素 y，使

(t−λ1)y=0。

但在此种数系内不能有零因子：若 x≠0 而 xy=0，则 y=x⁻¹(xy)=0，与 y≠0 不合。故只能有 t−λ1=0，即 t=λ1。

既然 t 是任意元素，所有元素便都只是实数倍之 1，不可能另有两个独立坐标。故**三重数组之企图不可修复**。同一论证实际排除了一切大于一的奇数坐标数。

### 2. 四重数的定义

改取四重数组。称其元素为**四重数**，记作 x=a+bu+cv+dw，其中 a,b,c,d 为实数。加法按坐标相加，实数乘法按坐标作用。乘法按分配律展开，并由下表规定：

u²=v²=w²=−1，

uv=w，vw=u，wu=v，

vu=−w，wv=−u，uw=−v。

实数与 1,u,v,w 均可交换，但这只是定义中实系数的性质，并不推出任意两个四重数可交换。

结合律不能从分配律推出，故须另验。对 u,v,w 的二十七种三项乘积，可依下列情形穷尽：有因子 1 时，直接消去该因子；三因子全同为 p 时，两种加括法均得 −p；两同一异时，若异元为 q，三种排列分别使两侧同得 −q、−q、−p；三因子全异时，循环次序的两种加括法均得 −1，逆循环次序均得 1。

例如 (uv)w=ww=−1，u(vw)=uu=−1，而 (uw)v=(−v)v=1，u(wv)=u(−u)=1。基元既验，按分配律展开，便得一切元素之乘法结合律。

### 3. 非平凡计算

取 x=1+u，y=1+v。则 xy=(1+u)(1+v)=1+u+v+w，而 yx=(1+v)(1+u)=1+u+v−w。所以 xy−yx=2w≠0。这便确证乘法交换律已经失去，而非仅换了一套写法。

### 4. 共轭式、模与除法

定义 x̄=a−bu−cv−dw，N(x)=a²+b²+c²+d²。直接展开得 x·x̄=x̄·x=N(x)。这里交叉项两两相消，例如 uv+vu=0，其余亦然。由于 N(x) 为平方和，故 N(x)=0 ⟺ x=0。因此每一非零 x 都有逆元

**x⁻¹ = x̄/N(x)**

例如 (1+u)⁻¹=(1−u)/2。

除法必须分左右两种写法：xy⁻¹ 与 y⁻¹x 一般不同。仍取 x=1+u, y=1+v，有 xy⁻¹=(1+u−v−w)/2，而 y⁻¹x=(1+u−v+w)/2。故"分子除以分母"若无左右次序说明，已不再是一个完全确定的运算。

---

## 二、清点崩溃：旧公式何者犹存，何者先坏

### 1. 平方与二项式

由分配律只能得到 **(a+b)²=a²+ab+ba+b²**。其中 ab 与 ba 不可合并。只有对所论特定两元素另有 ab=ba 时，才能写成 a²+2ab+b²。同理 (a−b)(a+b)=a²+ab−ba−b²，故传统公式 (a−b)(a+b)=a²−b² 一般失效。

同一元素的正整数幂仍可照常处理：aᵐaⁿ=a^{m+n}，因为这里只须结合律。但 (ab)ⁿ=aⁿbⁿ 一般失效。例如 (uv)²=w²=−1，u²v²=(−1)(−1)=1。

### 2. 二次方程求根在哪一步塌陷

试将 x²+bx+c=0 配方。形式上写 x+b/2，其实际平方为 (x+b/2)²=x²+(xb+bx)/2+b²/4。要把中间项写成 bx，必须用 xb=bx。因此，**配方这第一步就已经塌陷**，并非仅在最后开平方时才出问题。

因式分解也同样受限：(x−r)(x−s)=x²−xs−rx+rs，一般不能把 −xs−rx 合并成 −(r+s)x。

不过，若 b,c 都是实数，则它们与一切元素可交换，配方仍然有效：x²+bx+c=(x+b/2)²+c−b²/4。所以应精确判定为：**实系数二次方程的配方法存活；任意系数的一般配方法失效。**

即便配方法存活，旧的根的数目结论也不存活。在上述四重数中，凡 x=bu+cv+dw 且 b²+c²+d²=1，皆有 x²=−1。故 x²+1=0 有无穷多根，不再是复数中的两根。

### 3. 行列式乘法性

对于实数或复数阵列，Cauchy 的定理 det(AB)=det A·det B 仍然成立；因为这些数本身仍可交换。其传统证明在重排各项乘积时确实使用了交换律，只是当时这一前提完全有效。

若把阵列元素换为四重数，并仍沿用二阶公式 δ(a b; c d)=ad−bc，则乘法性即可失败。取 A=(u 0; 0 u)，B=(v 0; 0 v)。则 δA=u²=−1，δB=v²=−1，但 AB=(w 0; 0 w)，δ(AB)=w²=−1。于是 δ(AB)=−1≠1=δA·δB。所以这不是证明细节上的小修补，而是旧行列式公式及其乘法性在新元素上**不可照旧保留**。

---

## 三、审判：复数诸性质的存活清单

| 性质 | 判定 | 理由 |
|---|---|---|
| 加法可交换、可结合，有零元与相反元 | 存活 | 完全属于加法，与乘法交换无关 |
| 实数倍按坐标作用 | 存活 | 定义中保留 |
| 分配律 | 存活 | 已作为基本法则保留 |
| ax=b 在 a≠0 时有唯一解 | 存活 | x=a⁻¹b |
| xa=b 在 a≠0 时有唯一解 | 存活 | x=ba⁻¹ |
| 两种一次方程的解必相同 | 不存活 | 一般 a⁻¹b≠ba⁻¹ |
| ax+xb=c 可用合并系数后直接除法求解 | 不存活 | ax+xb 一般既非 (a+b)x，亦非 x(a+b) |
| 非零元之逆元唯一 | 存活 | 若 ax=xa=1，逆元由 x 完全确定 |
| xy=0 推出 x=0 或 y=0 | 存活 | 非零元可逆 |
| 共轭式保持加法与实数倍 | 存活 | 由坐标定义直接成立 |
| xy 的共轭 = x̄·ȳ | 不存活 | 正确次序应反转 |
| xy 的共轭 = ȳ·x̄ | 存活 | 基元上可验，再按分配律展开 |
| x·x̄=N(x) 为非负实数 | 存活 | 交叉项相消 |
| N(x)=0 当且仅当 x=0 | 存活 | 实平方和性质 |
| |xy|=|x||y| | 存活 | 见下方证明 |
| |x+y|≤|x|+|y| | 存活 | 化为四个实坐标的平方和不等式，可用 Cauchy 不等式 |
| 任意乘法公式中可任意调动因子 | 不存活 | 这正是被撤去之法 |

共轭式次序反转不可忽视。例如 uv 的共轭 = w̄ = −w，而 ū·v̄=(−u)(−v)=uv=w。相反，v̄·ū=(−v)(−u)=vu=−w，与 uv 的共轭相符。

模的乘法性仍成立，证明如下：N(xy)=(xy)·(xy 的共轭)=xy·ȳ·x̄=x·N(y)·x̄=N(y)·x·x̄=N(x)N(y)。其中调动 N(y) 是合法的，因为它是实数，而不是因为任意四重数可交换。故**模的乘法性并非交换律的私产**。

复平面的几何解释在其原有范围内完全不受损害：加法仍对应平移的合成，复数乘法仍对应旋转与伸缩。但四重数不能全部塞回同一复平面而保持上述全部运算法则；它必须作为四重数组另行处理。

---

## 四、镜像：一处传统证明中的隐蔽交换

复数模的乘法性有一常见证明：|zw|²=(zw)(z̄·w̄)=z z̄ w w̄=|z|²|w|²。纸面上似乎只写了共轭式与结合律，实际在 zw z̄ w̄ → z z̄ w w̄ 这一步，已经把 w 移过 z̄，即暗中用了 w z̄=z̄ w。在复数中这完全合法；在四重数中则不合法。该证明的修复不是硬把同一式子保留下来，而是先改用 zw 的共轭 = w̄ z̄，于是 (zw)(zw 的共轭)=zw w̄ z̄=z N(w) z̄=N(z)N(w)。

此外，这条传统证明还有第二层隐蔽前提：它把 zw 的共轭直接写成了 z̄ w̄。在新数系里，这一步本身也已错误。故此处同时暴露了两处未经明言的交换依赖。

---

## 五、总结：坐标数问题能判定到何处

今夜所能辩护的结论如下：

1. **一个坐标：**即实数，不能产生非交换乘法。
2. **两个坐标：**复数确实可行，而且在非零元皆可逆的要求下，实质上不能造成非交换的新系统。理由是：取 1,u 为基，写成 u²=p+qu。经平移 e=u−q/2，便有 e²=r，其中 r 为实数。若 r≥0，则 e²−r=(e−√r)(e+√r)=0 会产生零因子；故只能 r<0，再将 e 适当缩放，即得 e²=−1，仍归复数。
3. **三个坐标：**不可能；第三节式行列式论证已经排除。更大于一的奇数坐标数也同样被排除。
4. **四个坐标：**本文所造四重数可行，乘法确实非交换，每一非零元皆可逆。
5. **六个及更多偶数坐标：**本文方法没有给出普遍判定。三次行列式方程的论证只处理奇数坐标；四重数的乘法表又不足以决定其他偶数情形。

因此，对于"非交换数系究竟能在几个坐标数上存在"的完全刻画，我必须如实写明：

**以现有工具无法解决。**

已经确知的是：坐标数 1、2 不产生所需的非交换系统，坐标数 3 及一切大于一的奇数均不可能，坐标数 4 可以实现；其余情形尚无可辩护的普遍结论。把这点写成已经解决，便越出了今夜所得证明的界限。
