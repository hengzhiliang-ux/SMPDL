# 撤去乘法交换律后的一份代数试验

**都柏林，1843 年 10 月 15 日夜**

今设一数系，加法、减法如常，乘法保持结合律，并对加法左右分配；又设每一非零元皆有左右同一之逆元。所撤去者，仅为 ab=ba 之普遍保证。

先记两条随后反复使用的事实：(a+b)c=ac+bc，c(a+b)=ca+cb；(ab)⁻¹=b⁻¹a⁻¹。后一式不可误写为 a⁻¹b⁻¹，因为 (ab)(b⁻¹a⁻¹)=a(bb⁻¹)a⁻¹=1。

---

## 一、重建：三重数组之失败与四重数之造成

### 1. 三重数组为何不能成功

先取三重复数 x=a+bu+cv，其中 a,b,c 为实数，1,u,v 互相独立。若仍要求乘法对加法分配，则乘法完全由 u²,uv,vu,v² 等基元乘积决定。看似尚有充分自由选择这些乘积，故失败不能只归咎于某一张乘法表选得不好。

实际上，有一个更普遍的障碍，而且论证不必假定乘法结合。

设所论数系只有三个实坐标，任取其中一元素 t，考察"以 t 左乘"所成的线性代换。它由一个三行三列的实数阵列表示。作行列式方程

det(sI−L_t)=0，

左端为 s 的三次实多项式，故至少有一实根 λ。于是相应线性代换为奇异，必有一非零元素 y，使

(t−λ1)y=0。

但在此种数系内不能有零因子：若 x≠0 而 xy=0，则 y=x⁻¹(xy)=0，与 y≠0 不合。故只能有 t−λ1=0，即 t=λ1。

既然 t 是任意元素，所有元素便都只是实数倍之 1，不可能另有两个独立坐标。故**三重数组之企图不可修复**。同一论证实际排除了一切大于一的奇数坐标数。

### 2. 四重数的定义

改取四重数组。称其元素为**四重数**，记作 x=a+bu+cv+dw，其中 a,b,c,d 为实数。加法按坐标相加，实数乘法按坐标作用。乘法按分配律展开，并由下表规定：

u²=v²=w²=−1，

uv=w，vw=u，wu=v，

vu=−w，wv=−u，uw=−v。

实数与 1,u,v,w 均可交换，但这只是定义中实系数的性质，并不推出任意两个四重数可交换。

结合律不能从分配律推出，故须另验。对 u,v,w 的二十七种三项乘积，可依下列情形穷尽：有因子 1 时，直接消去该因子；三因子全同为 p 时，两种加括法均得 −p；两同一异时，若异元为 q，三种排列分别使两侧同得 −q、−q、−p；三因子全异时，循环次序的两种加括法均得 −1，逆循环次序均得 1。

例如 (uv)w=ww=−1，u(vw)=uu=−1，而 (uw)v=(−v)v=1，u(wv)=u(−u)=1。基元既验，按分配律展开，便得一切元素之乘法结合律。

### 3. 非平凡计算

取 x=1+u，y=1+v。则 xy=(1+u)(1+v)=1+u+v+w，而 yx=(1+v)(1+u)=1+u+v−w。所以 xy−yx=2w≠0。这便确证乘法交换律已经失去，而非仅换了一套写法。

### 4. 共轭式、模与除法

定义 x̄=a−bu−cv−dw，N(x)=a²+b²+c²+d²。直接展开得 x·x̄=x̄·x=N(x)。这里交叉项两两相消，例如 uv+vu=0，其余亦然。由于 N(x) 为平方和，故 N(x)=0 ⟺ x=0。因此每一非零 x 都有逆元

**x⁻¹ = x̄/N(x)**

例如 (1+u)⁻¹=(1−u)/2。

除法必须分左右两种写法：xy⁻¹ 与 y⁻¹x 一般不同。仍取 x=1+u, y=1+v，有 xy⁻¹=(1+u−v−w)/2，而 y⁻¹x=(1+u−v+w)/2。故"分子除以分母"若无左右次序说明，已不再是一个完全确定的运算。

## 二、清点崩溃：旧公式何者犹存，何者先坏

### 1. 平方与二项式

由分配律只能得到 **(a+b)²=a²+ab+ba+b²**。其中 ab 与 ba 不可合并。只有对所论特定两元素另有 ab=ba 时，才能写成 a²+2ab+b²。同理 (a−b)(a+b)=a²+ab−ba−b²，故传统公式 (a−b)(a+b)=a²−b² 一般失效。

同一元素的正整数幂仍可照常处理：aᵐaⁿ=a^{m+n}，因为这里只须结合律。但 (ab)ⁿ=aⁿbⁿ 一般失效。例如 (uv)²=w²=−1，u²v²=(−1)(−1)=1。

### 2. 二次方程求根在哪一步塌陷

试将 x²+bx+c=0 配方。形式上写 x+b/2，其实际平方为 (x+b/2)²=x²+(xb+bx)/2+b²/4。要把中间项写成 bx，必须用 xb=bx。因此，**配方这第一步就已经塌陷**，并非仅在最后开平方时才出问题。

因式分解也同样受限：(x−r)(x−s)=x²−xs−rx+rs，一般不能把 −xs−rx 合并成 −(r+s)x。

不过，若 b,c 都是实数，则它们与一切元素可交换，配方仍然有效：x²+bx+c=(x+b/2)²+c−b²/4。所以应精确判定为：**实系数二次方程的配方法存活；任意系数的一般配方法失效。**

即便配方法存活，旧的根的数目结论也不存活。在上述四重数中，凡 x=bu+cv+dw 且 b²+c²+d²=1，皆有 x²=−1。故 x²+1=0 有无穷多根，不再是复数中的两根。

### 3. 行列式乘法性

对于实数或复数阵列，Cauchy 的定理 det(AB)=det A·det B 仍然成立；因为这些数本身仍可交换。其传统证明在重排各项乘积时确实使用了交换律，只是当时这一前提完全有效。

若把阵列元素换为四重数，并仍沿用二阶公式 δ(a b; c d)=ad−bc，则乘法性即可失败。取 A=(u 0; 0 u)，B=(v 0; 0 v)。则 δA=u²=−1，δB=v²=−1，但 AB=(w 0; 0 w)，δ(AB)=w²=−1。于是 δ(AB)=−1≠1=δA·δB。所以这不是证明细节上的小修补，而是旧行列式公式及其乘法性在新元素上**不可照旧保留**。

## 三、审判：复数诸性质的存活清单

| 性质 | 判定 | 理由 |
|---|---|---|
| 加法可交换、可结合，有零元与相反元 | 存活 | 完全属于加法，与乘法交换无关 |
| 实数倍按坐标作用 | 存活 | 定义中保留 |
| 分配律 | 存活 | 已作为基本法则保留 |
| ax=b 在 a≠0 时有唯一解 | 存活 | x=a⁻¹b |
| xa=b 在 a≠0 时有唯一解 | 存活 | x=ba⁻¹ |
| 两种一次方程的解必相同 | 不存活 | 一般 a⁻¹b≠ba⁻¹ |
| ax+xb=c 可用合并系数后直接除法求解 | 不存活 | ax+xb 一般既非 (a+b)x，亦非 x(a+b) |
| 非零元之逆元唯一 | 存活 | 若 ax=xa=1，逆元由 x 完全确定 |
| xy=0 推出 x=0 或 y=0 | 存活 | 非零元可逆 |
| 共轭式保持加法与实数倍 | 存活 | 由坐标定义直接成立 |
| xy 的共轭 = x̄·ȳ | 不存活 | 正确次序应反转 |
| xy 的共轭 = ȳ·x̄ | 存活 | 基元上可验，再按分配律展开 |
| x·x̄=N(x) 为非负实数 | 存活 | 交叉项相消 |
| N(x)=0 当且仅当 x=0 | 存活 | 实平方和性质 |
| |xy|=|x||y| | 存活 | 见下方证明 |
| |x+y|≤|x|+|y| | 存活 | 化为四个实坐标的平方和不等式，可用 Cauchy 不等式 |
| 任意乘法公式中可任意调动因子 | 不存活 | 这正是被撤去之法 |

共轭式次序反转不可忽视。例如 uv 的共轭 = w̄ = −w，而 ū·v̄=(−u)(−v)=uv=w。相反，v̄·ū=(−v)(−u)=vu=−w，与 uv 的共轭相符。

模的乘法性仍成立，证明如下：N(xy)=(xy)·(xy 的共轭)=xy·ȳ·x̄=x·N(y)·x̄=N(y)·x·x̄=N(x)N(y)。其中调动 N(y) 是合法的，因为它是实数，而不是因为任意四重数可交换。故**模的乘法性并非交换律的私产**。

复平面的几何解释在其原有范围内完全不受损害：加法仍对应平移的合成，复数乘法仍对应旋转与伸缩。但四重数不能全部塞回同一复平面而保持上述全部运算法则；它必须作为四重数组另行处理。

## 四、镜像：一处传统证明中的隐蔽交换

复数模的乘法性有一常见证明：|zw|²=(zw)(z̄·w̄)=z z̄ w w̄=|z|²|w|²。纸面上似乎只写了共轭式与结合律，实际在 zw z̄ w̄ → z z̄ w w̄ 这一步，已经把 w 移过 z̄，即暗中用了 w z̄=z̄ w。在复数中这完全合法；在四重数中则不合法。该证明的修复不是硬把同一式子保留下来，而是先改用 zw 的共轭 = w̄ z̄，于是 (zw)(zw 的共轭)=zw w̄ z̄=z N(w) z̄=N(z)N(w)。

此外，这条传统证明还有第二层隐蔽前提：它把 zw 的共轭直接写成了 z̄ w̄。在新数系里，这一步本身也已错误。故此处同时暴露了两处未经明言的交换依赖。

## 五、总结：坐标数问题能判定到何处

今夜所能辩护的结论如下：

1. **一个坐标：**即实数，不能产生非交换乘法。
2. **两个坐标：**复数确实可行，而且在非零元皆可逆的要求下，实质上不能造成非交换的新系统。理由是：取 1,u 为基，写成 u²=p+qu。经平移 e=u−q/2，便有 e²=r，其中 r 为实数。若 r≥0，则 e²−r=(e−√r)(e+√r)=0 会产生零因子；故只能 r<0，再将 e 适当缩放，即得 e²=−1，仍归复数。
3. **三个坐标：**不可能；第三节式行列式论证已经排除。更大于一的奇数坐标数也同样被排除。
4. **四个坐标：**本文所造四重数可行，乘法确实非交换，每一非零元皆可逆。
5. **六个及更多偶数坐标：**本文方法没有给出普遍判定。三次行列式方程的论证只处理奇数坐标；四重数的乘法表又不足以决定其他偶数情形。

因此，对于"非交换数系究竟能在几个坐标数上存在"的完全刻画，我必须如实写明：

**以现有工具无法解决。**

已经确知的是：坐标数 1、2 不产生所需的非交换系统，坐标数 3 及一切大于一的奇数均不可能，坐标数 4 可以实现；其余情形尚无可辩护的普遍结论。把这点写成已经解决，便越出了今夜所得证明的界限。
