我是 1924 年前的逻辑研究者。长期以来，在面对 Frege 的《概念文字》与 Russell 的《数学原理》时，我深感变元机制（特别是约束变元与辖域交错）乃是逻辑大厦中一块沉重的赘疣。为了将一个简单的概念施用于不同的对象，我们不得不引入复杂的代入规则、辖域限制以及防范变元捕获的冗长防范条款。

这是一个激进的思想实验：彻底废除约束变元机制。以下是我对这一无变元逻辑语言的清点、重建与反思。

## 一、【清点】无变元语言的边界

在移除了约束变元、量词辖域以及自由/约束之分后，我们的语言仅保留：具体对象常项（如 a,b）、函数/概念（如 F,R）、函数作用于主目的施用关系，以及基础逻辑联结词（否定 ∼、合取 ∧、蕴涵 ⊃）。

**能表达什么**：

- **单称命题与复合命题**：如 F(a)（对象 a 具有概念 F）、R(a,b)（对象 a 与 b 具有关系 R），以及由其通过联结词构成的任何真值复合命题（如 F(a)⊃G(b)）。
- **特定对象间的结构关系**：如针对固定对象 a,b,c 的三段论式联结：R(a,b)∧R(b,c)⊃R(a,c)（特定对象间的传递性）。
- **高阶概念的施用**：诸如某特定概念 F 自身是否满足某种高阶概念 P，记作 P(F)。

**不能表达什么**：

- **无限定的普遍性断言（「对所有……」）**：无法在没有显式列出所有对象的情况下，直接断言某个概念在整个域上普遍成立。
- **存在性断言（「存在……」）**：无法断言"存在某个满足条件的对象"，除非该对象已被命名为常项。
- **多对象交错量化关系**：诸如"对每一个对象 x，都存在一个对象 y，使得关系 R(x,y) 成立"这类依赖变元同名呼应的复杂命题。

## 二、【替代机制】多对象断言与普遍性的功能主义重构

既然我们拒绝了通过"变元占位与量词辖域捆绑"来表达普遍性的旧路，那么如何在保持无变元纯洁性的同时，表达"普遍有效性"与"多对象关联"？

我引入以下不依赖变元的全新记号与构件：

**全称施用算子（Totality Operator, 记作 T）**：
这是一个第二级函数（即概念的概念），它直接作用于一个第一级函数（概念）F 上。记式为 T(F)。其意义是：概念 F 是全域满载的（即对于全域中一切可作为主目的对象，该概念皆真）。这彻底取代了 ∀xF(x)，因为此处没有 x，只有概念 F 自身作为一个整体对象接受全称性质的判定。

**结构组合子（Structural Combinators）**：
为了处理多对象关系（如二元函数/关系 R）中的位置与普遍性问题，我们不使用变元脚标，而是引入纯粹的函数组合与变位算子：

- **交换算子（Swap）**：将二元关系的左右主目对调，Swap(R) 对应于旧逻辑中的 R(y,x)。
- **对角化算子（Diag）**：将二元关系收缩为一元概念，Diag(R) 对应于 R(x,x)。
- **恒等算子与复合算子**：允许通过纯粹的函数代数来组合关系，而无需借由变量串联。

由此，形如"关系 R 是自反的"无需写作 ∀xR(x,x)，而直接表达为：

T(Diag(R))

## 三、【翻译】数学家语言的无变元对应

数学家常说："任取 ε>0，存在 δ>0，使得当 0<∣x−a∣<δ 时，有 ∣f(x)−f(a)∣<ϵ。"

在无变元语言中，由于缺乏跨辖域的变元呼应（即 δ 依赖于 ε 的动态关联），我们无法直接翻译这种带有嵌套变元约束的语句。以现有工具无法直接逐字翻译此句，因为其中"ϵ"与"δ"在旧逻辑中充当了相互关联的占位符。

**局部的替代翻译方案（借助选择函数算子）**：
我们必须将这种动态依赖关系静态化为高阶函数之间的既存结构。如果我们将"连续性"视为一种高阶泛函关系 C，它直接连接了"正数概念"（记作 Pos）、"函数 f"以及一个选择函数 Δ（该函数将给定的 ε 映射为对应的 δ）：

设 Δ 为一个已知的概念间映射（选择函数）。

我们断言：全域范围内，由 Pos、Δ 与基础算术关系复合而成的极限控制概念具有全称有效性：

T(Composite(ContinuityCondition, f, Δ))

说明：这里的代价是，我们必须把"存在一个 δ 依赖于 ε"具象化为一个高阶函数实体 Δ 的存在或给定，而无法在命题内部临时"创造"一个绑定变元。

## 四、【命题】可行命题与对照例

**可行命题 1：概念的自反律**
构造：设 R 为任一二元关系。
命题：T(Disjunction(Diag(R), ∼Diag(R)))
证明概要：这断言了"对一切对象，要么该对象关于 R 与自己相关，要么不相关"。由于这是排中律在对角概念上的全称施用，根据底层逻辑的真值结构，它直接成立。

**可行命题 2：关系的对称性**
构造：设 R 为二元关系。
命题：运用恒等算子断言 R 与其交换形式等价：Identity(T(R, Swap(R)))（注：此处二元全称施用可简记为复合算子）。
证明概要：表明关系在主目对调下保持真值不变，无需涉及 x 和 y 的位置代入保护。

**可行命题 3：高阶概念的纯粹性质**
构造：设 P 为表示"非空性"的高阶概念。
命题：P(F)（断言概念 F 是非空的，即存在至少一个主目使其为真——当 F 伴随一个具体见证常项 a 时，可写为 F(a)）。

**表达不了的对照例（控制例）**
对照例语句："存在一个对象，它与所有对象都不同（即没有两个不同的对象是相同的，或者说存在一个孤立元）。"
理由：在无变元语言中，由于没有量词的嵌套辖域和约束变元来表示"对所有 y 而言，若 y≠x 则……"，我们无法在没有给该对象起名字（赋予常项）的情况下，表达"存在一个具有某种全局隔离性质的个体"。这种涉及"存在"与"全称"交错且作用于未命名个体的命题，以现有无变元工具无法表达。

## 五、【总结】1924 年前的总结

回顾这一激进的思想实验：

**牺牲了什么**：
我们牺牲了传统数理逻辑中无拘无束的变元泛指能力与嵌套量化自由度。我们再也无法随心所欲地写下诸如 ∀x∃yR(x,y) 这样优美而复杂的多元交错命题；数学中依赖临时变元引申证明的便捷技巧在大受打击。

**换来了什么**：
我们彻底根除了逻辑语言中的毒瘤——变元捕获、α-等价性混淆、复杂的辖域划界规则以及繁琐的代入引理（Substitution Lemmas）。符号表达式不再是依赖于"赋值环境（valuation）"的半开放句群，而是具有绝对客观结构的、纯粹的概念实体与函数组合。逻辑回归到了最纯粹的"函数论"本质：对象、概念、以及概念之间的纯粹组合。

## 第一节 · 清点：无变元语言能说什么、不能说什么

保留的家当：专名（Sokrates、2）、概念词（Frege 意义的「不饱和」函项，如「ξ 是有死的」）、函项作用于主目、否定/合取/蕴涵。

**能表达的**：
- 关于指定对象的单称命题：「Sokrates 是有死的」「2 是偶数」——闭合函项式，毫无障碍。
- 关于有限多个指定对象的复合命题：「Sokrates 有死 ∧ Platon 有死」——连词照常工作。只要对象的名单有限且个个有专名，多对象命题不缺任何东西。
- 闭合函项项的嵌套：「7 的后继的后继是偶数」——函项作用于闭合主目，可以任意叠加，因为每一步都有确定所指。

**不能表达的（这是要害，照实说）**：
- **无专名对象的个别断言**。世上物多于名。变元语言里「存在一个 x 使 φ(x)」可以谈论一个我们叫不出名字的东西；废变元后，「存在」若不被新装置拯救，凡无专名者皆不可说。
- **「对所有……」类断言**。Frege 的凹弧（—x—）与 Russell 的「(x).φx」恰恰是为普遍性设的；它们被废除后，「一切人皆有死」不再等于任何有限合取——对象是无限的，合取永远写不完。纯命题层 + 专名的语言，其每句话只有有限的「视野」，普遍性在原则上越出了这个视野。
- **数学实践的「任取」句式**。「任取 ε > 0」之为用，在于说者不指定任何具体的 ε，却要结论对每一个皆成立。这不是一个命题，而是一种以任意性为凭的推论手续。废变元后，这个手续的皮（一个可代入的字母）被剥掉了，但它的骨（普遍性）还在——第三节处理它。
- **同一对象在多处的复现**。「x ≤ y ∧ y ≤ z → x ≤ z」中 x 出现两次，靠的正是变元的「同名即同物」。没有变元，「同物复现」这个模式本身无法指认——这是比量词更深的损失，第二节必须单独补救。

## 第二节 · 替代机制：位算子方案

**方案核心（新造，但与 Peirce–Schröder 的关系代数精神同源）**：变元在旧语言里干两件事——(i) 标记函项的空位，(ii) 宣告遍历哪个范围。第一件事 Frege 已用「不饱和性」免费给了我们：概念词自带空位（ξ、ζ），无需字母标记。要补的只有第二件，外加「复现」的指认。

引入五个作用于概念名（而非变元）的算子：

| 新造名称 | 记号 | 作用 |
|---|---|---|
| 遍取 | Uᵢ(R) | 由 n 位关系得 n−1 位关系：「对第 i 位的一切填法皆成立」 |
| 择存 | Eᵢ(R) | 「第 i 位有某种填法使之成立」 |
| 自复 | W(R) | 由二位 R(ξ, ζ) 得一位概念「ξ 与自身有 R」 |
| 换位 | C(R) | R(ξ, ζ) ↦ R(ζ, ξ) |
| 穿引 | T_f(R) | 由 R(ξ, ζ) 得一位概念「ξ 与 f(ξ) 有 R」 |

连词逐点提升为概念运算：由概念 P、Q 得概念「P 且 Q」（记 P ⊓ Q）、「非 P」（记 P̄）。

**诚实声明（纪律所要求）**：U 与 E 做的推论工作与量词完全相同——「U₁(R) 真」当且仅当旧语言「∀x R(x, …)」真。我没有消灭普遍性，只把它从「约束字母」改造成「作用于完整概念名的算子」。这不是换名请回约束变元：算子的主目是概念名本身（完整符号），全式中没有任何字母被「约束」，因为全式中根本没有字母。辖域、自由/约束、捕获避免三样技术负担确实消失了——因为先得有变元，才谈得上辖域。代价见第五节。

多对象断言：有限专名情形照旧（第一节）；无限域上的多对象普遍性，由 U/E 按位序叠加表达——位序即旧语言的量词序，「先遍后择」与「先择后遍」的差别由算子书写次序保持，无歧义、无辖域争议。

复现：W 与 T_f 负责「同物再现」。但此处有一真实的缺陷，照实说：复现的模式（哪几位相同、哪位经哪个函项穿出）因命题而异，我的算子表须随模式扩充；变元的厉害恰在于一套字母通吃一切模式。一个对一切模式通用的有限小算子集，以现有工具我无法给出——缺的是一种「空位之间任意接线」的一般组合方案；我能逐命题构造，给不出通法。这是本方案最诚实的一道裂缝。

## 第三节 · 翻译：「任取 ε > 0，存在 δ > 0……」

数学家的原话，旧式展开为 ∀ε ∃δ ∀x：|x − a| < δ → |f(x) − f(a)| < ε。

翻译方案：
第一步，把内层看作三位关系 S(ε, δ, x)——即「ε、δ、x 三者满足：|x − a| < δ 蕴涵 |f(x) − f(a)| < ε」。此处 ε、δ、x 不是变元，是关系 S 的三个空位，如同 Frege 的 ξ、ζ；S 是一个整体的概念名。
第二步，逐位消去，次序即量词序：

U₁( E₂( U₃( S ) ) )

U₃(S)：一位概念「(ε, δ) 对一切 x 位置成立」；E₂(·)：一位概念「ε 配得某个 δ」；U₁(·)：真命题「对一切 ε 皆然」。

全式无一字母被约束，辖域问题不存在——算子的作用范围就是它括住的概念名，与算术里根号的作用范围一样无可争论。

「任取 ε」的推论手续对应一条推演规则（新造）：若由含任意专名 c 的式子不借 c 之特殊性推出结论，则得 U₁(·)。这是把旧语言「对自由变元的普遍化规则」改写为「对任意常名的普遍化规则」——任意常名不是变元，它是一个被宣告为无所特指的专名，Frege 时代此类手续在算术中本是通行的。

## 第四节 · 三个可行命题与一个对照例

可行一（单称）：「Sokrates 是有死的」——Mortal(s)。闭合函项式，构造即填写。

可行二（有限多对象）：「Sokrates 与 Platon 皆有死」——Mortal(s) ∧ Mortal(p)。连词原样保留。

可行三（普遍性 + 复现）：「一切物与其自身相等」：U₁(W(Equal))。W 把 Equal(ξ, ζ) 收成一位概念「ξ 等于 ξ」，U₁ 再收成命题。两步消位，无变元。

可行四（混合量词序）：「每数皆有大于它者」：U₁(E₂(Less))。Less 为二位关系名；E₂ 得概念「ξ 被某物超过」；U₁ 得命题。量词序由算子序保有，无歧义。

对照例（表达不了）：**数学归纳法的完全形式**。Frege 与《数学原理》皆须陈述为「对一切概念 F：若 F(0) 且 F 遗传，则 F 遍及一切数」。困难不在「遍及一切数」（U 能办），而在「一切概念 F」：要对概念遍历，须先能指称任一被遍历的二层函项（Frege 语：以概念为主目的的函项），如「把概念 F 映到『F(0) ∧ F 遗传』之真值」的那个二层函项。而指定它的通行方式只有一句：「即对任意 F 做如此这般者」——这恰恰要求一个概念变元。废除变元后，我们只剩有限个可逐一点名的二层函项，「一切概念」无所附着。以现有工具无法解决：缺的是一种不借助概念变元而指称任意二层函项的手段；空位算子能遍历物，不能遍历概念，因为概念在我们的语言里没有「位」可消——它们是消位动作的主目，不是消位的对象。一阶普遍性可救，二阶普遍性不可救。不删除此条，不假装完备。

## 第五节 · 总结（以 1924 年前的语言）

牺牲了三样：
其一，通吃的灵活性。一个字母 x 走天下，复现模式、嵌套深度、函项穿插全由它一身担当；我的位算子须按模式添置，至今给不出通用有限集。
其二，二阶的普遍性。「对一切概念」死于第四节——这不是技术不熟，是结构性缺失：遍历概念须先指称概念之任意作用方式，而指称之法正是变元。
其三，可读性。U₁(E₂(U₃(S))) 之于「任取 ε 存在 δ 对一切 x」，如电报之于口语；变元本是数学的代词，代词废除后，每句话都成了官衔罗列。

换来了三样：
其一，三类技术病痛连根拔除——辖域争议、自由/约束之别、代入捕获，皆因变元而有；无变元则无病，不是治好了，是器官摘除了。
其二，概念的整体性被扶正。Frege 本说概念是不饱和的整体，变元却诱使人把 φ(x) 误认为一个「关于 x 的命题」；位算子语言里，概念永远以完整之名出现，倒是更忠于 Frege 的图景。
其三，一条诚实的边界：这个实验恰好在「一切概念」处撞墙，证明了一件事——变元机制的真正用处不在遍历物，而在遍历函项自身。约束变元是二阶普遍性的入场券；谁废除它，谁就只能留在物的世界里。

一句话收束：废变元可行于第一层，溃败于第二层；换得的是句法的清白，失掉的是说「一切概念」的资格。

# 无约束变元的逻辑语言：一项稳固性修复的尝试

立场设定：站在 1924 年以前的逻辑研究者立场上。

首先须区分两个问题：

1. 取消变元：不再以字母代替对象，不再讨论字母的自由出现与受约束出现。
2. 取消普遍性与存在性的表达能力：不再有任何构件能够表达「每一个对象」或「至少一个对象」。

两者并非同一回事。前者是本思想实验的出发点；后者却不是前者必然带来的结果。真正困难的是：倘若我们连一切能够承担普遍性作用的语言构件也一并禁止，那么如何表达数学中的一般命题？

我将尝试保留概念作用于主目的思想，同时严格禁止任何暗中引入的绑定装置。结论先行：无变元语言可以用对象名称、有限的命题组合以及某些新设的整体断言构件表达相当多的内容；但若只保留命题、概念、函数作用与逻辑连词，而不增加任何普遍性构件，就不能从有限的个别命题构造出通常意义上的无限普遍命题。

## 第一节【清点】无变元语言的表达能力

### 1.1 原始语言及其限制

设原始语言 L₀ 只有以下构件：

- 对象 a,b,c,…：彼此可区别的个别对象名称。
- 概念 F,G,H,…：可作用于主目的概念或函数。
- 命题：例如「苏格拉底是人」。
- 逻辑连词：否定、合取、蕴涵。
- 函数作用：概念作用于一个或多个已经指定的主目。

这里的对象名称是专名，而不是可供任意替换的字母。概念 F 作用于对象 a，写作 F(a)，表示「a 落在概念 F 之下」。

若概念本来只接受一个主目，我们不应擅自假定它能接受两个。为表达多对象关系，可以另行允许多主目概念，或者把一对对象构成的复合对象作为一个主目。这是两种不同的语言设计。

### 1.2 能表达与不能表达的内容

| 内容 | 原始无变元语言能否表达？ | 理由 |
|---|---|---|
| 个别对象的性质 | 能 | F(a) |
| 两个个别对象的性质关系 | 能，须有相应构件 | R(a,b) |
| 有限个已指定对象的合取 | 能 | F(a)∧F(b) |
| 个别命题的否定、蕴涵 | 能 | 直接使用逻辑连词 |
| 任意对象都具有某性质 | 不能直接表达 | 没有指向整个对象领域的构件 |
| 至少一个对象具有某性质 | 不能直接表达 | 没有表示概念适用对象存在的构件 |
| 对所有正数，都存在相应的正数 | 不能直接表达 | 缺少普遍性、存在性以及两者之间的依赖表达 |
| 数学中不指定具体对象的「任取」 | 不能直接表达 | 不是一个个别对象名称，也不是有限个命题的合取 |

表中的「不能」是指不能从 L₀ 的原始构件中，按照通常的有限构造规则得到相应的一般断言；它不是说这些断言不能用汉语说出来。

### 1.3 为什么有限的个别命题不够？

假定我们有一批对象名称 a,b,c，并且知道：F(a), F(b), F(c)。我们可以构造：F(a)∧F(b)∧F(c)。但这只说三个指定对象具有性质 F，并不说一切对象都具有 F。

即使我们知道每个已列出的名称都满足 F，也不能由此断定不存在一个尚未列出的对象不满足 F。

若对象领域是无限的，这个缺口尤其明显：有限次合取不能穷尽无限多个对象。

因此必须区分：逐个确认（指定的这些对象具有性质）与普遍断言（整个对象领域中的每个对象都具有性质）。这不是措辞上的区别，而是推理根据的区别。

## 第二节【替代机制】不使用绑定机制，如何表达普遍性？

我提出两种方案。第一种完全不增加语言构件，但表达能力有限；第二种增加原始的整体断言构件，以恢复一般性。

### 2.1 方案甲：对象名称与有限构造

在最严格的 L₀ 中，我们只允许：F(a), G(b), F(a)∧G(b), ¬F(a), F(a)⇒G(b)。其中所有主目均已指定。

这一方案的优点是完全不涉及绑定机制。没有量词，没有自由变元与约束变元的区别，也没有代入时发生捕获的问题。

缺点也很明确：它不能仅凭自身构造出「所有对象都具有性质 F」这样的普遍命题。

若坚持不增加任何其他构件，普遍性表达能力的缺失便无法修复。我们必须放弃普遍命题，或者放弃原始语言构件的限制。

### 2.2 方案乙：概念的整体断言

现在允许一种新构件。它不是对象名称，不是变元，也不含任何绑定规则。

为它取一个中性名称：**全概念断言**。记号为：Tot(F)。

其意义规定如下：Tot(F) 为真，当且仅当对象领域中的每一个对象都落在概念 F 之下。

这是一个直接作用于概念的整体断言，而不是先引入一个字母，再规定该字母在某个辖域中代表任意对象。

同样，可以引入另一种构件，称为概念的**有例断言**：Ex(F)。

规定：Ex(F) 为真，当且仅当至少有一个对象落在概念 F 之下。

这里有一个必须坦白的事实：这两个构件分别承担了通常全称量词和存在量词的语义职务。它们不是纯粹由命题连词推导出来的。

但是，它们确实没有恢复约束变元机制：
- 没有任何变元出现。
- 没有任何量词辖域。
- 没有自由与约束的区别。
- 没有把一个对象名称代入某个变元的规则。
- 也就没有由这种代入引起的变元捕获问题。

因此，这是一种以概念为对象的整体断言语言，而不是通常变元语言的换名版本。

当然，它牺牲了另一项简洁性：我们必须把整体断言的意义直接写进语言的基本规则中。

### 2.3 多对象关系：以关系概念为基础

假设 R 是一个二主目关系，表示「小于」。我们希望表达两个指定对象之间的关系：R(a,b)。这并不需要变元。

若希望对关系作整体断言，可以采用有序对对象。令 ⟨a,b⟩ 表示由 a,b 构成的有序对，令 R* 是适用于有序对的概念。于是 R*(⟨a,b⟩) 表示 a 与 b 之间具有关系 R。

若我们还要表达「每一对满足某条件的对象都具有某关系」，就必须再有一个针对有序对领域的整体断言构件，或者把相关对象对组成的概念作为整体断言的主目。

这里不能偷偷把一个二主目关系变成无限多个个别命题，再假装已经完成普遍证明。整体断言必须有明确的语义规定。

### 2.4 普遍性是否因此得到免费恢复？

没有。

若「全概念断言」是原始构件，我们确实不需要绑定变元，但必须承认：语言已增加了表达普遍性的原始资源。

若连这种资源也不允许，原始语言中就没有足够的构件来恢复通常的普遍性。

这正是本思想实验的关键界线：可以取消变元机制而保留普遍性；不能只靠有限命题与逻辑连词，无代价地恢复普遍性。

## 第三节【翻译】「任取 ε>0，存在 δ>0……」

考虑一个典型的数学句式：任取 ε>0，存在 δ>0，使得只要 x 与 a 的距离小于 δ，就有 f(x) 与 f(a) 的距离小于 ε。

这类句式在通常语言中需要处理多个对象、普遍性、存在性以及对象之间的依赖关系。现在尝试不使用任何约束变元来表达它。

### 3.1 先明确需要表达的内容

设：E：正数的概念。D：正数的概念，作为 δ 的候选范围。P(ε,δ)：表示给定 ε,δ 后，所要求的距离条件成立。

为免混淆，P 只是一个关系名称。它不是带有隐形变元的公式。

若采用通常的变元语言，这句话可以写成：∀ε(E(ε)⇒∃δ(D(δ)∧P(ε,δ)))。但这不是我们要保留的语言。它只用来说明原句包含的逻辑结构。

### 3.2 无变元翻译：直接的整体断言

为表达这个结构，我们新增一种关系构件。

令 Sec(P,d) 表示：对指定对象 d，关系 P 在以 d 为第一主目的那一部分中至少有一个第二主目，使关系成立。

这里的 d 是已经指定的对象名称；Sec 是原始构件，其意义直接规定，不通过替换变元来定义。

再令：H(d) ≡ D(d)∧Sec(P,d)。

这里 H 是一个新概念的名称，而非一个含有自由变元的公式。它的解释是：对象 d 为正数，并且在关系 P 中有一个合适的对应对象。

于是原句可表达为：Tot(H)。

如果 Tot 对象领域覆盖全部对象，那么还需要保证 H 在非正数对象上为真，或者把整体断言改为限定概念的全称断言。

更准确的构件可以记作：All(E,H)。其原始意义规定为：每一个落在概念 E 之下的对象，也落在概念 H 之下。

于是翻译是：All(E, H_P)——其中 H_P 是一个预先规定的概念，其意义为：某对象为正数，并且在关系 P 中至少存在一个与它相配的正数对象。这里 H_P 的构造规则属于语言的原始规定，而不是通过公式抽象或变元绑定形成。

### 3.3 这个翻译究竟保留了什么？

它保留了原句的主要逻辑结构：只考察正的 ε；对每个这样的 ε，要求有一个正的 δ；所选的 δ 必须与该 ε 满足关系 P。

但它没有保留通常公式的自由组合能力。

例如，如果要把「存在适当的 δ」这一条件应用于另一种关系 Q，我们必须预先为 Q 规定相应的概念构造或关系截取构件。不能简单地把 P 换成 Q，再指望所有复杂表达式都能按原来的代入规则自动工作。

因此，这种语言能够表达所需的句子，却依赖更多预先规定的概念构件。

### 3.4 如果连这些新构件也不允许呢？

那么，在严格的原始语言 L₀ 中，答案是：无法翻译。

理由不是数学句子含糊，而是原始语言没有：对整个正数概念作整体断言的构件；对某一对象所对应的对象作存在断言的构件；将这种对应关系与普遍性结合的构件。

仅用有限的个别对象名称和命题连词，不能得到这句话的通常意义。

这就是必须承认的表达能力边界。

## 第四节【命题】可行命题与一个不能表达的对照例

命题一：两个指定对象都具有人性。构造：M(a)∧M(b)。证明概要：M(a) 表示 a 落在人的概念之下；M(b) 同；合取表示两命题同时为真。整个构造只涉及两个指定对象，没有变元。所得内容：两个特定对象都具有人性。它没有声称所有对象都是人。

命题二：指定对象之间的关系。构造：L(a,b)；若要进一步断言 a<b 且 b<c，则可以构造 L(a,b)∧L(b,c)。这显示无变元语言并不只能表达单对象性质；它也能表达涉及多个指定对象的命题。

命题三：对概念作整体断言。设 E 表示正数的概念，H 表示「与指定对象 c 的距离小于某给定正数」的概念。构造：All(E,H)。它的意思是：每一个正数都落在概念 H 之下。证明概要：E 是正数的概念；H 是已经明确规定的概念；All(E,H) 的原始意义是：凡属于 E 的对象，皆属于 H。这里没有任何变元出现，也没有先建立辖域再让变元在其中取值的过程。但是要特别注意：这项命题之所以可行，是因为我们已经增加了整体断言构件。它不属于最严格的原始语言 L₀。

对照例：所有对象都具有性质 F。在完全不增加新构件的原始语言中无法表达：每个原始命题只涉及已经指定的对象；有限次命题构造只能涉及有限个指定对象；若对象领域中存在一个没有在构造中指定的对象 d，则关于其他对象的命题并不能确定 F(d) 的真假。因而不能仅凭这些命题的结构，断定整个对象领域都满足 F。例如，已知 F(a)∧F(b) 并不排除存在对象 c 使得 ¬F(c)。因此，在原始语言 L₀ 中，普遍命题无法表达。若加入 All 一类构件，它才可表达；但那是语言的扩充，而不是原始构件的推导结果。

## 第五节【总结】以 1924 年以前的语言作结

这项尝试的出发点，是对变元的技术性复杂感到不满：一个概念既然能够作用于对象，为什么还必须经过变元、辖域以及代入规则，才能表达一般断言？

答案是：并非所有这些技术安排都不可替代，但它们确实承担着重要的逻辑职务。

若我们彻底废除约束变元机制，却只保留个别对象名称、概念作用和逻辑连词，那么我们得到一种简单而有限的语言。它能够表达个别命题、多对象关系以及有限的命题组合，却不能仅靠自身构造出通常意义上的普遍命题和存在命题。

若我们进一步加入概念的整体断言、有例断言以及关系的截取构件，则可以恢复不少普遍性与存在性的表达能力，而不必重新引入变元的自由出现、受约束出现以及捕获避免规则。

但代价是明确的：我们失去了用少数一般规则处理任意复杂关系的统一方法；我们必须为某些概念和关系规定专门的整体断言构件；我们不能保证原有代入规则的简洁性在新语言中得到同样的保留；我们也不能声称，仅凭命题与逻辑连词便已恢复全部数学表达能力。

换言之，所获得的是一种较少依赖变元技术的语言，而不是一套无需额外逻辑资源便能表达一切的语言。

最后的判断是：废除约束变元，并不必然废除普遍性；然而，若要在没有约束变元的情况下保留普遍性，就必须把某种整体断言能力直接赋予概念或关系。若连这种能力也不许增加，则以现有工具无法解决普遍命题的表达问题。

这项修复可以成立，但只能作为一种明确承认其代价的语言设计。它换来了对象名称与概念作用的直接性，牺牲的则是变元语言在一般性、统一性与组合性方面所具有的便利。

# 无约束变元的逻辑语言：一项稳固性修复的尝试

立场设定：站在 1924 年以前的逻辑研究者立场上。

首先须区分两个问题：

1. 取消变元：不再以字母代替对象，不再讨论字母的自由出现与受约束出现。
2. 取消普遍性与存在性的表达能力：不再有任何构件能够表达「每一个对象」或「至少一个对象」。

两者并非同一回事。前者是本思想实验的出发点；后者却不是前者必然带来的结果。真正困难的是：倘若我们连一切能够承担普遍性作用的语言构件也一并禁止，那么如何表达数学中的一般命题？

我将尝试保留概念作用于主目的思想，同时严格禁止任何暗中引入的绑定装置。结论先行：无变元语言可以用对象名称、有限的命题组合以及某些新设的整体断言构件表达相当多的内容；但若只保留命题、概念、函数作用与逻辑连词，而不增加任何普遍性构件，就不能从有限的个别命题构造出通常意义上的无限普遍命题。

## 第一节 · 清点：无变元语言能说什么、不能说什么

保留的家当：专名（Sokrates、2）、概念词（Frege 意义的「不饱和」函项，如「ξ 是有死的」）、函项作用于主目、否定/合取/蕴涵。

能表达的：
- 关于指定对象的单称命题：「Sokrates 是有死的」「2 是偶数」——闭合函项式，毫无障碍。
- 关于有限多个指定对象的复合命题：「Sokrates 有死 ∧ Platon 有死」。
- 闭合函项项的嵌套：「7 的后继的后继是偶数」。

不能表达的（这是要害，照实说）：
- **无专名对象的个别断言**。世上物多于名。变元语言里「存在一个 x 使 φ(x)」可以谈论一个我们叫不出名字的东西；废变元后，「存在」若不被新装置拯救，凡无专名者皆不可说。
- **「对所有……」类断言**。Frege 的凹弧（—x—）与 Russell 的「(x).φx」恰恰是为普遍性设的；它们被废除后，「一切人皆有死」不再等于任何有限合取。
- **数学实践的「任取」句式**。「任取 ε > 0」之为用，在于说者不指定任何具体的 ε，却要结论对每一个皆成立。
- **同一对象在多处的复现**。「x ≤ y ∧ y ≤ z → x ≤ z」中 x 出现两次，靠的正是变元的「同名即同物」。没有变元，「同物复现」这个模式本身无法指认——这是比量词更深的损失。

## 第二节 · 替代机制：位算子方案

方案核心（新造，但与 Peirce–Schröder 的关系代数精神同源）：变元在旧语言里干两件事——(i) 标记函项的空位，(ii) 宣告遍历哪个范围。第一件事 Frege 已用「不饱和性」免费给了我们：概念词自带空位（ξ、ζ），无需字母标记。要补的只有第二件，外加「复现」的指认。

引入五个作用于概念名（而非变元）的算子：

| 新造名称 | 记号 | 作用 |
|---|---|---|
| 遍取 | Uᵢ(R) | 由 n 位关系得 n−1 位关系：「对第 i 位的一切填法皆成立」 |
| 择存 | Eᵢ(R) | 「第 i 位有某种填法使之成立」 |
| 自复 | W(R) | 由二位 R(ξ, ζ) 得一位概念「ξ 与自身有 R」 |
| 换位 | C(R) | R(ξ, ζ) ↦ R(ζ, ξ) |
| 穿引 | T_f(R) | 由 R(ξ, ζ) 得一位概念「ξ 与 f(ξ) 有 R」 |

连词逐点提升为概念运算：由概念 P、Q 得概念「P 且 Q」（记 P ⊓ Q）、「非 P」（记 P̄）。

诚实声明（纪律所要求）：U 与 E 做的推论工作与量词完全相同——「U₁(R) 真」当且仅当旧语言「∀x R(x, …)」真。我没有消灭普遍性，只把它从「约束字母」改造成「作用于完整概念名的算子」。这不是换名请回约束变元：算子的主目是概念名本身（完整符号），全式中没有任何字母被「约束」，因为全式中根本没有字母。辖域、自由/约束、捕获避免三样技术负担确实消失了——因为先得有变元，才谈得上辖域。

多对象断言：有限专名情形照旧；无限域上的多对象普遍性，由 U/E 按位序叠加表达——位序即旧语言的量词序，「先遍后择」与「先择后遍」的差别由算子书写次序保持，无歧义、无辖域争议。

复现：W 与 T_f 负责「同物再现」。但此处有一真实的缺陷，照实说：复现的模式（哪几位相同、哪位经哪个函项穿出）因命题而异，我的算子表须随模式扩充；变元的厉害恰在于一套字母通吃一切模式。一个对一切模式通用的有限小算子集，以现有工具我无法给出——缺的是一种「空位之间任意接线」的一般组合方案；我能逐命题构造，给不出通法。这是本方案最诚实的一道裂缝。

## 第三节 · 翻译：「任取 ε > 0，存在 δ > 0……」

第一步，把内层看作三位关系 S(ε, δ, x)。此处 ε、δ、x 不是变元，是关系 S 的三个空位，如同 Frege 的 ξ、ζ；S 是一个整体的概念名。

第二步，逐位消去，次序即量词序：U₁( E₂( U₃( S ) ) )

U₃(S)：一位概念「(ε, δ) 对一切 x 位置成立」；E₂(·)：一位概念「ε 配得某个 δ」；U₁(·)：真命题「对一切 ε 皆然」。全式无一字母被约束，辖域问题不存在——算子的作用范围就是它括住的概念名，与算术里根号的作用范围一样无可争论。

「任取 ε」的推论手续对应一条推演规则（新造）：若由含任意专名 c 的式子不借 c 之特殊性推出结论，则得 U₁(·)。这是把旧语言「对自由变元的普遍化规则」改写为「对任意常名的普遍化规则」。

## 第四节 · 三个可行命题与一个对照例

可行一（单称）：Mortal(s)。构造即填写。

可行二（有限多对象）：Mortal(s) ∧ Mortal(p)。

可行三（普遍性 + 复现）：「一切物与其自身相等」：U₁(W(Equal))。W 把 Equal(ξ, ζ) 收成一位概念「ξ 等于 ξ」，U₁ 再收成命题。两步消位，无变元。

可行四（混合量词序）：「每数皆有大于它者」：U₁(E₂(Less))。量词序由算子序保有，无歧义。

对照例（表达不了）：数学归纳法的完全形式。Frege 与《数学原理》皆须陈述为「对一切概念 F：若 F(0) 且 F 遗传，则 F 遍及一切数」。困难不在「遍及一切数」（U 能办），而在「一切概念 F」：要对概念遍历，须先能指称任一被遍历的二层函项，而指定它的通行方式只有一句：「即对任意 F 做如此这般者」——这恰恰要求一个概念变元。废除变元后，「一切概念」无所附着。以现有工具无法解决：缺的是一种不借助概念变元而指称任意二层函项的手段；空位算子能遍历物，不能遍历概念，因为概念在我们的语言里没有「位」可消——它们是消位动作的主目，不是消位的对象。一阶普遍性可救，二阶普遍性不可救。不删除此条，不假装完备。

## 第五节 · 总结

牺牲了三样：通吃的灵活性（算子表须按模式添置，给不出通用有限集）；二阶的普遍性（结构性缺失：遍历概念须先指称概念之任意作用方式，而指称之法正是变元）；可读性（U₁(E₂(U₃(S))) 之于「任取 ε 存在 δ 对一切 x」，如电报之于口语）。

换来了三样：三类技术病痛连根拔除（辖域争议、自由/约束之别、代入捕获——不是治好了，是器官摘除了）；概念的整体性被扶正（概念永远以完整之名出现，更忠于 Frege 的图景）；一条诚实的边界（变元机制的真正用处不在遍历物，而在遍历函项自身。约束变元是二阶普遍性的入场券）。

一句话收束：废变元可行于第一层，溃败于第二层；换得的是句法的清白，失掉的是说「一切概念」的资格。
