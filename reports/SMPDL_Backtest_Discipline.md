# SMPDL 回测纪律（Backtest Discipline）

> **总则**：预测的证据价值 = **登记、冻结、遮蔽、判定、解禁**五环节的可分离性。任何一环同源，战绩自动降格为「历史拟合」，不得对外引用为预测力。
> **版本**：v2.0（B4-2 后重写版；取代 README §五"预测纪律"行的旧三条款）
> **日期**：2026-10-15
> **教训来源**：独立审计 🔴-1（2026-10-15）+ B4-2 盲判全链条翻车实录（§三案例表逐条对应）
> **适用范围**：一切"预测→回验"活动——律移除涌现预测、算子透镜 OS 轮、B4 系盲判、未来 B4-3+ 扩样；上溯适用于已有战绩的口径重审。

## 一、五阶段协议（每阶段硬规则）

### 阶段 1 · 登记（预测文本落地）

| # | 条款 | 违反后果 |
|---|---|---|
| R1 | **先登记后入库**——预测文本必须先于任何回验结论存在 | 无登记即无预测，战绩记 0 |
| R2 | **登记即入 git**——预测文本落地的同一批次必须 commit；无 git 时间戳的登记不具证据资格 | 登记时间不可证 → 全轮降格 |
| R3 | **登记侧与判定侧物理隔离**——登记文本只写"预测"列；"结果/回验/判定"列留空或整表不建 | 判定措辞渗入预测列 → 该列剔除 |
| R4 | **预测不得事后修饰**——修订以修订案编号追加（A/B/C/…），原文本永久留档 | 静默改文 → 该轮战绩作废 |

### 阶段 2 · 冻结（预测文本抽取）

| # | 条款 | 违反后果 |
|---|---|---|
| F1 | **冻结文件由第三方会话或脚本生成**——建库会话/预测会话禁自抽自冻 | 冻结无效，须重冻 |
| F2 | **术语首现时间扫描（防回填）**——对冻结文本逐术语/逐列跑 `git log -S`；任何术语在库内首现**晚于**登记 commit 的，该列整体剥离、不计分，剥离记录写入冻结文件头注 | 回填列计分无效（两个方向都是：命中=同义反复，未中=无信息） |
| F3 | **只抽预测列**——结果列、判定列、修正案措辞严禁混入；抽取脚本应按列名硬过滤而非人眼复制 | 混入即污染，按 §二勘误流程剔除 |
| F4 | **冻结独立 commit**——冻结文件单独提交，哈希即存证时间戳；头注注明登记 commit 哈希以构成证据链 | 无独立存证 → 冻结时间不可证 |

### 阶段 3 · 遮蔽（盲判材料包制作）

| # | 条款 | 违反后果 |
|---|---|---|
| M1 | **自判结果物理删除**——工单/材料包不得携带自判列（✅/❌/命中/分数）；打包前删除该列，而非"判定者承诺不看" | 泄露=协议偏差，必须在判定报告 §〇披露并评估污染面 |
| M2 | **判定者白名单材料**——可读：冻结预测 + 事件描述（PreFix/PostFix）+ 自由检索权；禁读：原自判章节、计分表、透镜判定段落 | 越界阅读 → 该判定者结果作废重跑 |
| M3 | **材料包发布前零泄露核查**——由制作方以外的会话/脚本复查材料包全文无判定信息残留 | 未核查即分发 → 视同 M1 |

### 阶段 4 · 判定（独立会话执行）

| # | 条款 | 违反后果 |
|---|---|---|
| J1 | **判定者 ≠ 预测者（会话级分离）**——判定在全新独立会话执行，禁在预测/建库会话续跑 | 同会话自判 → 全部降格「历史拟合」 |
| J2 | **预注册判定标准冻结**——三问制（D1 规模/D2 时间/D3 功能）、D1 优先、规则 H（即时涌现 ≤5 年）、前置入格裁定由判定者独立盲评；判定者不得修改标准 | 标准漂移 → 判定无效 |
| J3 | **三档分开报告（✅ 全中/🟡 半中/❌ 未中）**——禁用"0 未命中"式合并概括 | 合并报告 → 报告退回重写 |
| J4 | **基线同步计分**——每轮与 B0（朴素多数类）/B4（凡移除皆 β）基线对照，报告框架-基线增益 | 无基线 → 命中率不可解读 |
| J5 | **判定者强制披露**——协议偏差、D1 计数口径声明（紧/宽）、网络核验清单、日期依赖项，全部写入报告 | 隐瞒偏差 → 报告作废 |
| J6 | **天然锚点保留**——已知 ❌ 样本（诚实保留者）不从样本中剔除，用于检验判定者独立性 | 剔除锚点 → 一致性证据链断裂 |

### 阶段 5 · 解禁与对照（κ 计算）

| # | 条款 | 违反后果 |
|---|---|---|
| K1 | **判定报告落盘后才解禁原自判**——解禁动作本身写入报告尾注 | 先看后判 → 全轮作废 |
| K2 | **κ 双层报告**——主型层 κ 与三档层 κ 分别计算报告 | 单层报告不完整 |
| K3 | **预注册判读规则**——κ ≥ 0.6 且独立命中率 ≥ 自判 80% → 战绩恢复；κ ∈ [0.4, 0.6) → 主判据保留、细化降格；κ < 0.4 或命中率 < 60% → 永久降格「历史拟合」，对外只以独立口径报告 | 事后选阈值 → 判读无效 |

## 二、勘误与版本纪律（判定报告的生命周期）

| # | 条款 |
|---|---|
| E1 | **版本化勘误**——判定报告允许且必须勘误；每次勘误升版本号并在卷首写修订记录（触发指令、发现、后果） |
| E2 | **旧版留档不删**——被勘误版本保留 git 存证（勘误前的结论同样属于证据） |
| E3 | **连锁更正**——勘误波及的一切引用点（战绩声明、行注、透镜文档、对外文本）同批更正；被剔除内容对下游发布（如 C-1 arXiv）发布引用禁令 |
| E4 | **净效应如实报告**——勘误可能让结论变好（B4-2 剔除回填列后 κ 0.641→1.00）也可能变坏；**不得因"结果变好"而放松剔除标准**，剔除的唯一依据是证据资格，不是计分方向 |
| E5 | **判定人自省条款**——判定者自身的盲区（如"只能读冻结文件"与"冻结文件可能被污染"之间的空隙）随勘误一并披露，作为协议改进输入 |

## 三、案例对照表（每条纪律的血债）

| 实际翻车案例 | 暴露缺陷 | 固化条款 |

| OS-II 判定者分离首验抓到 1/4 自判偏宽 | 分离协议有真实辨别力（正面锚） | J1 的正当性依据 |
| 工单 §三样本表自带"原自判 ✅/❌"列，执行模板无法遮蔽 | 材料包制作无物理删除环节 | M1、M3 |
| 冻结文件 R1/R7 辅型列混入结果措辞（"γ 辅""β 确为辅"出自结果列） | 人工抽取按行复制，列过滤缺失 | F3 |
| 冻结文件算子列 = lens 术语回填（术语首现晚于登记 17 小时；14/14 可由 lens 配对表机械推导；R2 行自供"当时未单列算子"） | 冻结环节无术语时序审计，建库会话自抽自冻 | **F1、F2（本案立例）** |

| "0 未命中"式概括掩盖三档分布 | 合并计分抹掉半中信息 | J3 |

## 四、十关 checklist（每轮回测逐关打勾，缺一不开判）

```
□ 1  预测文本已 git commit（登记时间可证）？              [R2]
□ 2  登记文本零判定侧内容（结果列空/不建）？              [R3]
□ 3  冻结文件由第三方会话或脚本生成？                    [F1]
□ 4  术语首现扫描通过（无晚于登记 commit 的术语入列）？     [F2]
□ 5  冻结只含预测列（列名硬过滤，非人眼复制）？            [F3]
□ 6  冻结文件独立 commit + 头注登记哈希？                 [F4]
□ 7  材料包自判列已物理删除 + 零泄露复查？                [M1/M3]
□ 8  判定在全新独立会话执行？                           [J1]
□ 9  预注册判定标准未被修改（含规则 H / 复合事件整判）？     [J2]
□ 10 三档分开 + 基线同步 + κ 双层 + 判读规则预注册？        [J3/J4/K2/K3]
```

## 五、战绩引用规则（对外文本）

1. **独立口径优先**：对外（arXiv/主站/README）战绩一律以独立判定口径为主叙述；自判口径只作附录。
2. **被剔除内容发布禁令**：经 F2 剥离的列（如 B4-2 算子列）不得在任何对外文本中作为战绩引用；引用时标注"回填剔除，见 B4-2 报告 §八"。
3. **战绩声明须挂证据链**：登记 commit + 冻结 commit + 判定报告版本号三件套缺一不可。
4. **半盲/规则压力测试不得称战绩**：OS 轮自判文件明确标注"规则压力测试，非最终战绩"——凡预测者知情的历史重演，一律用此口径。
