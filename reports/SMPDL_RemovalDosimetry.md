# 移除剂量学：结构降解的计量理论（视角转换立论）

> **版本**：v1.0（立论稿）
> **日期**：2026-10-15
> **触发**：咖啡指令「移除涌现不要这个命题，换视角，看移除每一个算子内部——内涵数学结构分类，移除多少会破坏原本数学结构」
> **地位**：与移除-涌现理论（事后视角）**并列不互斥**的新方向——本方向问**事中**：移除操作自身的数学结构；剂量-承重-临界，而非死亡-填补

## 一、视角转换：从事后到场内

| | 旧命题（移除-涌现） | 新命题（移除剂量学） |
|---|---|---|
| 问什么 | 移除后**长出什么** | 移除**本身**如何计量；**移除多少**会破坏原结构 |
| 单元 | 事件（律死亡 → 涌现） | **操作**（移除剂量 d → 存活函数 σ(d)） |
| 时间向 | 纵向（历史后果） | 横向（同一时刻的结构剖面） |
| 隐喻 | 伤口与愈合 | **承重结构与爆破工程** |
| 可证伪形式 | 涌现类型可预测 | 降解曲线形状/临界剂量可预测 |

移除-涌现的 46 组数据**不浪费**：每组的 PreFix 侧与 PostFix 侧恰好给出剂量 d=0 与 d=1 两个测量点——本方向把它们升格为剂量阶梯上的**首两点**，并向下述多剂量设计扩张。

## 二、计量定义（剂量学的四件仪器）

设结构 S = (A, T, ⊢)：公理/律组 A + 关键定理群 T（keystone 清单预注册）+ 可推导关系。

| 仪器 | 定义 | 意义 |
|---|---|---|
| **承重图 L(S)** | 二部图：边 a—τ 当且仅当去掉 a 后 τ 不可证（其余保留） | 每条公理的**独占承重** = 仅由它支撑的 keystone 数；**桥公理** = 独占承重 ≥1 |
| **存活函数 σ(R)** | σ(R) = \|T(A∖R)\| / \|T(A)\|（R 为移除集） | 移除集 R 的剂量-响应值 |
| **临界剂量 k_c** | min{\|R\| : 指定核 ⊄ T(A∖R)} | 破坏指定核的最少移除数（承重图的 vertex cover 型量） |
| **k-鲁棒** | 对一切 \|R\|≤k 有 σ(R)=1 | 结构吸收 k 次任意移除而无损 |

**剂量的多种计量单位**（本理论的关键主张：剂量不是一维的）：

1. **公理数剂量**（离散）：移除几条公理；
2. **实例剂量**（模式律）：归纳/概括/分离等是模式——移除**部分实例**（PA 片段 IΣₙ、二阶算术 Big Five）vs 全部；
3. **量词复杂度剂量**：同一公理的 Π₂ 版 vs Π₁ 版（强化=反向移除）；
4. **证明论序数剂量**：|T| 的 proof-theoretic ordinal 为连续刻度；
5. **解释强度剂量**（interpretability）：T₁ ≤ T₂ 偏序刻化"内容量"。

同一结构在不同单位下的降解曲线**可以不同型**——单位选择本身是实验变量。

## 三、内涵结构分类学（降解四型 · 初版）

| 型 | 名称 | 特征 | 库内/数学界证据 | 判据 |
|---|---|---|---|---|
| **I 脆性** | 单点坍塌 | 存在桥公理，k_c=1，悬崖曲线 | **候选稀少**（诚实登记）：Pasch 公理之于序几何；朴素概括之于朴素集合论 | 桥公理密度高 |
| **II 冗余稳健** | 等价基重组 | 公理集有冗余等价基；一侧公理可由另一侧导出 | 群公理单侧化（左幺+左逆 ⇔ 右侧版）；布尔代数多等价基/Sheffer 单轴/Robbins 问题；**切消定理 = cut 规则可删**（P 层冗余的典范） | σ({任意非桥公理})=1 |
| **III 分层剥落** | 核-壳结构 | 移除外壳定理群、内核存活；存在嵌套子结构链 | 欧氏 −平行 = **绝对几何**（中立定理群全存活）；经典 −LEM = **否定片段存活**（Glivenko ¬¬ 翻译）；ZFC 塔（−C 存 ZF、−Replacement 存 ZC、−Foundation 存反基础替代）；域 −交换 = 除环（**线性代数核存活**：维数理论不倒）；分离公理梯 T0…T4 | 承重图呈**同心层**结构 |
| **IV 阈值相变** | 连续降解至临界 | 剂量连续/随机，临界点集体性质突变 | 组合结构的经典领域：图连通性阈值（Erdős–Rényi）、k-核涌现、matroid 连通度/临界数；公理结构侧候选：可判定性在片段阶梯上的跳变 | σ(d) 有拐点/相变 |

**首条经验命题（来自 46 组的重读）**：成熟数学结构的公理层**几乎没有纯 I 型**——单条移除几乎总留下富余烬（这正是旧命题"移除必被填补"看到的另一半）。解释假说（组织性，待验）：历史公理化是从**重叠的定理群**逆向工程的，重叠 ⇒ 天然冗余 ⇒ 纯脆性稀有。**"移除多少会破坏原结构"的初步答案：对成熟结构，一次移除几乎从不整体破坏；破坏的是承重图上该公理的独占层——整体坍塌需要打击多个独立承重层（k_c 通常 > 1）或打击内核定理群本身。**

## 四、数学界既有的"剂量阶梯"（现成仪器进口清单）

数学史已经做过大量隐式剂量实验，只是从未被收进同一台仪器：

| 阶梯 | 剂量单位 | 刻度点 | 对应库资产 |
|---|---|---|---|
| **逆向数学 Big Five** | 概括公理强度 | RCA₀ ⊂ WKL₀ ⊂ ACA₀ ⊂ ATR₀ ⊂ Π¹₁-CA₀，每档钉着一批定理 | H21 二阶侧 |
| **选择公理谱** | AC 强度谱 | 全 AC / DC / 可数选择 / BP-DC / 无 | **H8 + H20 本身就是同一条谱上的两个剂量点**（库内已有而未被如此并读） |
| **分离公理梯** | 分离强度 | T0 ⊂ T1 ⊂ T2 ⊂ T3 ⊂ T3½ ⊂ T4 | H41（旋钮族） |
| **PA 片段动物园** | 归纳实例剂量 | IΔ₀ / IΔ₀+exp / IΣₙ / PA | — |
| ** varieties 格** | 恒等式移除 | Birkhoff：删恒等式 = 子簇格上移；区间长度 = 结构损失量 | lens 自由算子的认证定理直接复用 |
| **规则可采纳性** | 推理规则剂量 | cut 可删（Gentzen）；admissible rules 普查 | H22 / P 层 |
| **解释序** | 理论间解释 | T₁ ≤ T₂ 偏序（Gödel/Visser 传统） | — |

**统一宣言**：以上七条阶梯是同一台仪器（存活函数 σ 对剂量 d）在不同货币下的读数。剂量学的任务之一是做**跨阶梯汇率表**。

## 五、算子内部的剂量参数（回应"看移除每一个算子内部"）

lens 七型算子每型内部自带连续剂量参数——移除剂量与恢复算子强度**配对**：

| 算子型 | 内部剂量参数 | 剂量配对律（候选） |
|---|---|---|
| 完备化 | 完备步数/秩（一步 vs 超限迭代） | 移除剂量 ↑ ⇒ 所需完备化强度 ↑ |
| 自由 | 生成元秩 | 被解禁对象族的秩 = 原结构约束的"负剂量" |
| 规范化 | 规范强度（弱/强规范化） | 移除行为保证 ⇒ 恢复所需的算法强度递增 |
| 不变量 | 商的粗细 | 商越粗 = 承认损失越多 |
| 对偶化 | 反变等价的完全度 | 完全对偶 = 零损失恢复 |
| 形变 | 参数 t 连续 | **连续恢复通道**（离散移除的连续解毒剂） |
| 缺陷定位 | 函子阶数（Tor₁ vs 高阶 Tor/Ext） | 失效越深 ⇒ 需要越高阶缺陷函子 |

**配对律总假说（组织性）**：恢复算子的内部剂量 ≈ 被移除剂量的单调函数；曲线形状按算子型分类——这是旧「功能类型 → 涌现主型」查表的**连续化升级**。

## 六、与既有资产的接口

1. **承重墙隐喻转正**：从修辞变为 L(S) 图的可计算对象——M*D 审计的依存图就是承重图的原材料（数据已在 132 份报告里，只欠汇总）；
2. **E/D/I 档位的新读法**：I 档 = 双向零剂量存活（加减皆无矛盾）——独立性命题正是 σ 的**双侧测量**；
3. **P 层剂量计**：`#print axioms` 与公理依赖图（Metamath/Mizar/Lean 已有现成依赖数据）= 承重图的机械化来源——**D-1 工单**：从 Mathlib 依赖图批量提取某结构（如群/格/拓扑基）的承重图并算 k_c；
4. **H20 升格**：从"独立组"改读为"AC 剂量谱上的点"——库内首个多剂量并读试点；
5. **绝对几何重读**：H1/H16 的 PreFix 隐含"中立定理群"存活层——剂量学把它从脚注升为正式数据点。

## 七、可证伪预测（预注册候选）

- **P1（乙级悬崖律）**：乙级表征律对其表征类是桥公理（k_c=1 且坍塌面 = 整个表征类）——因表征律 ⇔ 结构，移除即失指纹；可在 varieties 格与分离梯上验证；
- **P2（模式律缓降律）**：模式律（归纳/概括）以实例剂量计时呈**缓降**（III 型）而非悬崖——PA 片段与 Big Five 的既有结果可直接复核；
- **P3（冗余增长史律）**：公理系统的等价基数量与可采纳规则比例随历史**增长**（早期系统最小化、晚期系统教学化冗余）——预测 Sheffer/Meredith 单轴晚于 Boole 体系 80 年量级、cut 可删的发现晚于 Frege 体系一代——文献计量可验；
- **P4（配对律）**：第五节算子-剂量配对曲线存在且按算子型分类——用库内已完成七轮前向的样本回测。

## 九、诚实款

- σ 与 k_c 依赖 keystone 清单的**预注册**——否则可事后选择定理操纵结论（回测纪律 v2.0 的剂量学版十关须另立）；
- I 型样本候选稀少本身可能是**幸存者偏差**（纯脆结构早已坍塌，不入史册）；
- 四型分类学为初版（n=46 且多为 d≤1 数据点），多剂量设计（d=2,3…）的库内样本**尚不存在**——D-2 是第一手补数据工单；
- 配对律（P4）与冗余增长史律（P3）均未做任何前向登记，当前为假说。
