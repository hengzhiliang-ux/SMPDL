> **对比对象**
> - "PreFix" 版本：Hilbert 系统（无切消去、无子公式性质）（`SMP_ProofAnalysis_ProofTheory_HilbertSystem.md`）
> - "PostFix" 版本：自然演绎 + 规范化定理（`SMP_ProofAnalysis_ProofTheory_NaturalDeduction.md`）
> 
> **审计日期**：2026-10-14  
> **审计框架**：Göttingen S/M/P × D/L v1.5  
> **历史编号**：H22  
> **总体评价**：⚪ ↔ ⚪ 两侧各自正确；核心差异是**证明结构元定理的有无**——这直接决定证明能否成为可分析对象。

## 2. PreFix 版本 SMPDL 速览（Hilbert）

- **S*D**：K/S 公理 + MP；演绎定理为元层补丁。
- **S*L**：⚠️ 证明平坦无结构——无法从结论读出证明形状。
- **判定**：⚪ 可靠完备，但结构分析贫乏。

## 3. PostFix 版本 SMPDL 六格审计（自然演绎）

### 3.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| 引入/消除对偶 | 意义即用法 | ✅ |
| detour 定义 | 最大公式 | ✅ |
| 规范化 | 局部归约 + 终止性 | ✅ |
| 子公式性质 | 正规形 | ✅ |
| Curry–Howard | β 归约同构 | ✅ |

### 3.2 S*L — 语义逻辑结构

- 语义核心反转：**"证明"从字符串序列变为可归约的结构对象**——证明论由此成为数学分支。
- 规范化使 NJ 与 H7（直觉主义存在 witness）在证明论层接通。
- ⚠️ 风险：经典 NK 与直觉主义 NJ 的规范化强度不同，混谈会误植 witness 提取。

### 3.3 M*D — 数学依存

```text
intro/elim duality → detour identification → normalization (Prawitz) → subformula property → {consistency, witness, Curry–Howard}
```

### 3.4 M*L — 数学逻辑结构

| 检查项 | Hilbert | 自然演绎 | 差异 |
|---|---|---|---|
| 规范化 | ❌ | ✅ | 元定理反转 |
| 子公式性质 | ❌ | ✅ | 结构性反转 |
| 一致性（证明论） | 难 | 直接 | 方法升级 |
| 证明=程序 | 弱（组合子） | 强（λ+SN） | P 层质变 |

### 3.5 P*D / P*L — 编程层

- 整个证明助手产业建立在本侧：规范化 = β 归约，证明检查 = 类型检查。
- Hilbert 侧只有组合子逻辑的弱影像。

## 4. 跨层映射检查

| 映射 | Hilbert（PreFix） | 自然演绎（PostFix） |
|---|---|---|
| S → M | 公理+MP → 演绎定理元层 | intro/elim → 规范化对象 |
| M → P | 组合子（弱） | λ 演算 + SN（强） |
| S ↔ S | "证明" = 公式序列 | "证明" = 带结构可归约树（同名异义） |
| M ↔ M | 无结构元定理 | 结构元定理群 |

**跨层结论**：两侧**证明能力等价**（同一逻辑），但**证明分析能力**天差地别——"证明"一词的语义从句法序列升级为结构对象。本组是"框架选择影响可提取信息"的教科书案例，与 H9（集合论/类型论）在基础层互为镜像。

## 6. 变化类型归类

- **变化方式**：**框架迁移（公理化风格 → 规则对偶风格）引发证明结构元定理从无到有** —— 升级迁移。
- **SMPDL 同构标签建议**：`S-BISIM / M-BISIM / P-BISIM`。
- **关键 lesson**：AI 生成证明时，输出的"证明对象"格式决定了后续可分析性——Hilbert 式串只能检查，自然演绎树可规范化、提 witness、转程序。

## 6.5 概念奇点（Conceptual Singularity）

### 6.5.1 关键人工洞察

- **把"证明"本身当作研究对象**：Gentzen 的方法论革命——元数学从研究定理转向研究证明的结构。
- **用规则对偶替代公理**：意义论洞察（联结词的意义 = 引入规则），换来结构可控性。
- **识别 detour 并证明可消除**：局部归约 + 整体终止的双层归纳是证明论第一块基石。

### 6.5.2 为什么机器难以自动迁移

机器可在 Hilbert 系统内做证明搜索，但**意识到"换个表述框架就获得整套结构定理"**是方法论级重构。规范化定理的终止性证明（极小序数/多元归约序数）也需要超越初等归纳的序数直觉。

## 6.6 断裂强度（Breakage Strength）

| 评估项 | 等级 | 说明 |
|---|---|---|
| **断裂强度** | 🟠 引理替换 | 表达能力不变（同逻辑），但结构元定理从无到有；工具箱整体更换；有转译桥（Hilbert↔ND 可互译）。 |
| **S 层影响** | 中高 | "证明"同名异义（序列 vs 树对象）。 |
| **M 层影响** | 高 | 切消去/子公式/一致性/witness 全套仅在 PostFix。 |
| **P 层影响** | 高 | 从组合子弱像到证明助手产业。 |

**判定**：能力等价但分析力反转，有互译桥，评为 🟠。
