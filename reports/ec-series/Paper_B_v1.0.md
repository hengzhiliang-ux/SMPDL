## 1. Introduction / 引言

**EN.** This paper documents the construction of a case library for a specific class of epistemic events: moments in the history of mathematics when a structure was completed, refounded, falsified, or unified. The library is deliberately built on an *inductive discipline*: sub-categories of structural change are **not enumerated a priori**; only changes that actually occurred in the historical record are registered, and each sub-item is tagged with its first-appearance case. This inverts the usual taxonomy-first methodology: the library is an open, growing record of what mathematics *did*, not a closed classification of what changes are *possible*.

**中.** 本文记录一个案例库的构建，其对象是一类特定的认识论事件：数学史上结构被补全、被重构奠基、被证伪、或被统一的那些时刻。该库的构建遵循一条**归纳纪律**：结构变化的子类**不做先验枚举**；只登记史料中实际发生过的变化，且每个子项标注其首次出现的案例。这与通常「先立分类学」的方法论相反：本库是一份开放的、持续生长的「数学实际做过什么」的记录，而不是一份封闭的「变化在理论上可能有哪些」的分类。

**EN.** The library originated in a prior project — the SMPDL three-layer audit of existing proofs (Semantic / Mathematical / Programming × Dependency / Logic) — and inherits its central question: *what does it mean for a mathematical structure to be complete?* The present line turns that question from proofs to structures: instead of auditing finished arguments, we catalogue the events in which structure itself changed.

**中.** 本库脱胎于前置项目——SMPDL 对已有证明的三层审计（语义/数学/编程 × 依存/逻辑）——并继承了其核心问题：*一个数学结构「完整」究竟意味着什么？* 本线将该问题从证明转向结构：不再审计已完成的论证，而是编目结构本身发生变化的事件。

## 2. The Dual-Axis Design / 双轴设计

**EN.** Every case carries two orthogonal tags.

**Axis 1 — Seven open event types (A–G):**

| Type | Event class | Examples |
|---|---|---|
| A | Concept emergence / 概念产生 | zero, negative numbers, irrationals, imaginary unit, limit, Cantor's infinities, Turing machine |
| B | Proof completion / 证明完成 | Fermat's Last Theorem, Poincaré, Prime Number Theorem, Four-Color, Matiyasevich |
| C | Number-system self-completion / 数系自完备 | N→Z→Q→R→C→H→O chain, finite fields, p-adics, Boolean algebra |
| D | Unclosed (open problems) / 未闭合 | Riemann Hypothesis, HIlbert–Pólya, twin primes, Collatz, ABC/Mochizuki dispute |
| E | Axiomatic refoundation / 公理化重构 | non-Euclidean geometry, ZF, Kolmogorov probability, nonstandard analysis, intuitionism |
| F | Counterexample / falsification / 反例证伪 | √2, Berkeley's attack, Russell's paradox, Skolem, Euler's conjecture (1966) |
| G | Unification / 统一论 | Galois theory, Erlangen, category theory, Langlands, mirror symmetry |

**中.** 每个案例带两个正交标签。轴一为七类**开放**事件类型（A 概念产生 / B 证明完成 / C 数系自完备 / D 未闭合 / E 公理化重构 / F 反例证伪 / G 统一论；例见表）。类型框架标注为开放——非理论钉死，后续可增补（如「定理推广」已在讨论中）。

**Axis 2 — Eight historical stages (ST1–ST8):**

| Stage | Period | Character |
|---|---|---|
| ST1 | Ancient & Greek / 古代与希腊 | birth of deduction; first crisis |
| ST2 | Medieval & Eastern / 中世纪与东方 | algebraic accumulation; zero & negatives systematized |
| ST3 | Renaissance & early modern / 文艺复兴与早期近代 | symbolic algebra; cubic wars; imaginaries enter |
| ST4 | Calculus century / 微积分世纪 | infinite methods bloom on shaky ground |
| ST5 | Rigor & abstraction / 严格化与抽象 | analysis arithmetized; groups; non-Euclidean; set theory |
| ST6 | Axiomatization & foundational crises / 公理化与基础危机 | three schools; Gödel; computation's dawn |
| ST7 | Structuralist golden age / 结构主义黄金期 | categories, homology, model theory; computer proofs |
| ST8 | Contemporary & computational / 当代与计算 | grand programs; proof assistants; AI mathematics |

**EN.** The type axis answers *what kind of change*; the stage axis answers *where in the evolution of mathematical practice*. Their crossing yields the library's signature statistic: which structural events recur across stages (e.g., type-C self-completion events recur in ST1–ST7), and which are stage-specific (e.g., type-E axiom revolutions cluster in ST5–ST6).

**中.** 类型轴回答「变化属于哪一类」；史期轴回答「发生在数学实践的哪个演进阶段」。两轴交叉给出本库的标志性统计：哪些结构事件跨史期反复发生（如 C 类自完备事件贯穿 ST1~ST7），哪些是特定史期独有（如 E 类公理革命集中于 ST5~ST6）。

**中.** 当前分布（库 v2.0，136 案例）：A 28 / B 21 / C 17 / D 19 / E 15 / F 15 / G 21。封存基线 50 案例（v1.0，2026-10-29 08:06 封存）永不改动；一切增长只以追加方式进行。史期覆盖自 ST1（芝诺、不可公度）至 ST8（凝聚数学、AlphaProof、Fargues–Scholze、望月争议作为进行中的 D 类活案例）。

**EN.** Five-dimension recording. Each case is registered along five dimensions — **S** (language/semantics), **M** (mathematical objects), **L** (logic), **D** (dependency structure), **T** (translatability) — each entry a plain declarative sentence of what actually changed on that dimension. A methodological decision: **T replaces P** (programming ⊂ translatability), since formalizing a structure into code is one species of translating it into another symbolic system (coffee ruling, 2026-10-29).

**中.** 五维记录。每案例沿五维登记——**S**（语言/语义）、**M**（数学对象）、**L**（逻辑）、**D**（依存结构）、**T**（可翻译性）——每维一句如实的「该维上实际发生了什么变化」的陈述句。一项方法论决策：**T 顶替 P**（编程 ⊂ 可翻译性），因为把结构形式化为代码只是「将其翻译进另一符号系统」的一个特类（咖啡 2026-10-29 拍板）。

## 5. Translatability Spectrum / 可翻译形态谱系

**EN.** Dimension T received a dedicated deepening: 37 cases of translation events, organized into **seven forms** — arithmetization (T-a), computation (T-b), machine verification (T-c), relation-ization (T-d), typing (T-e), axiomatization (T-f), quantification (T-g). Each case is annotated with a three-precision framework:

- **P1 discern-amplify / 分辨-增殖**: what conflations were split, what became sayable that was not before;
- **P2 preservation / 保全**: which established usages survive;
- **P3 decidability / 判定**: which assertions became mechanically checkable.

**EN (thesis).** The governing proposition, ratified by the project lead (2026-10-29): **no "correct translation" exists; the value of a translation derives from the precision of its description.** Evidence: ε-δ (P1-dominant) and nonstandard analysis (P2-dominant) are two legitimate, non-interchangeable formalizations of "infinitesimal" — points in precision-space, not correct/incorrect rivals. Failure modes are reinterpreted as precision collapse: gilded translation (P1≈0, no new discernment), fake-understanding (P2 collapse, established theorems silently break), circular translation (P2=1 but P1=0).

**中.** T 维获得专项深化：37 个翻译事件案例，组织为**七形态**——算术化（T-a）、计算化（T-b）、机器验证化（T-c）、关系化（T-d）、类型化（T-e）、公理化（T-f）、量化化（T-g）。每案例标注三维精确性框架：P1 分辨-增殖（劈开了哪些混同、新说了什么原来说不出的）；P2 保全（哪些既有有效用法存活）；P3 判定（哪些断言变得机械可验）。核心命题（项目负责人 2026-10-29 拍板）：**不存在「正确翻译」；翻译的价值来源于描述的精确性。** 证据：ε-δ（P1 主导）与非标准分析（P2 主导）是「无穷小」的两条合法且不可互换的形式化——精确性空间中的两个点，而非对错之争。失败模式被重新解释为精确性坍缩：镀金翻译（P1≈0，无新分辨）、装懂翻译（P2 坍缩，老定理悄悄失效）、循环翻译（P2=1 但 P1=0）。

**EN.** A registered historical anomaly: Martin-Löf type theory is the only spectrum case where P2 **collapsed first** (Girard's paradox, Type:Type, 1972) and was **repaired by restructuring** (predicative universes, 1984) — translation failure itself driving theory evolution, further evidence for the no-correct-translation thesis.

**中.** 一项登记在案的历史异常：Martin-Löf 类型论是全谱系唯一「P2 先坍缩（Girard 悖论 Type:Type，1972）后经重构修复（预置全域层级，1984）」的案例——翻译失败本身成为理论演化的驱动力，为「不存在正确翻译」命题再添实证。

## 6. Action-Sample Anchor Index / 动作-样本锚定索引

**EN.** The bridge from library to experiment: twelve cognitive operations (six proposition-level commands: weaken / decompose / cross-translate / strengthen-reduce / falsify-narrow / open-declare; plus constructive group: define-new-object / system-extend / axiom-operate / structure-abstract; plus T-group: formalize / model-intertranslate), each anchored to a primary dimension (S2 / M2 / L3 / D2 / T3) and 4–7 reference samples drawn from the library. Reference samples give **operational forms only, never answers** — e.g., system-extension's four forms: "adjoin inverses with no sacrifice" / "ascend dimension, sacrificing commutativity" / "change metric, parallel completion" / "restrict to substructure for finite closure."

**中.** 从库到实验的桥梁：十二个认知操作（六条命题级命令：弱化/分解/跨域翻译/化归加强/证伪收窄/开放声明；构造组四条：定义新对象/系统扩张/公理操作/结构抽象；T 组补齐两条：形式化重述/模型互译），各锚定主作用维度（S2/M2/L3/D2/T3）并配 4~7 个出自案例库的参照样本。参照样本**只给操作形态、绝不给答案**——例如「系统扩张」的四种形态：「加逆元·无牺牲扩张 / 升维·牺牲交换律 / 换度量·平行完备化 / 限制到子结构·换有限封闭」。

**EN.** R2 composite coding: analogy-transfer events are registered as R2-dimension-action (e.g., R2-M-8 "source: number-system extension") enabling cross-tabulation of which dimension hosts which transfer type, and clustering of analogy sources.

**中.** R2 复合编码：类比迁移事件登记为「R2-维度-动作号」（如 R2-M-8「源：数系扩张」），使「哪个维度承载哪类迁移」可交叉制表，类比源可聚类。

## 7. Open Boundary / 开放边界

**EN.** Honestly registered: (i) the seven-type frame is open — candidate eighth types (theorem generalization) under discussion; (ii) the reserve pool holds verified-but-unrecorded cases (Weil conjectures, Iwasawa main conjecture, string-theoretic unification); (iii) sub-item library grows only by induction from newly appended cases, never by a-priori addition; (iv) stage-axis boundaries (ST4/ST5) are conventional, and cases may straddle stages (tagged by primary stage).

**中.** 如实登记：(i) 七类型框架开放——候选第八类型（定理推广）在议；(ii) 储备池存有已核实未录入案例（Weil 猜想、岩泽主猜想、弦论统摄）；(iii) 子项库只经新追加案例归纳而增长，永不先验添加；(iv) 史期轴边界（ST4/ST5）系约定划分，案例可跨期（以主史期标注）。
