# 第 0 步：SMPDL 五维审计——结构现状登记

**S（语言／语义）**
现有术语包括 Riemann ζ／ξ 函数、非平凡零点、自伴算子、谱、虚部和显式公式。尚有四处含混：ξ 的归一化是否固定；"谱恰好等于"是否要求保持重数；是否同时包含正、负虚部；"存在算子"是否允许直接把零点表写入算子定义。最后一点决定构造是字面实现，还是具有独立解释力的实现。

**M（数学）**
已有对象是 ξ 的解析延拓、函数方程、零点及其有限重数、零点与素数之间的显式公式。零点在复平面中没有有限聚点，因此其虚部也形成无有限聚点的离散集合。当前没有 Hilbert 空间、算子定义域、预解式、谱测度或迹运算。复分析中的乘积、微分、Mellin／Fourier 变换可使用，但一般自伴算子的和、积并不天然封闭，定义域必须另行处理。

**T（可翻译性）**
现有结构可在复分析、傅里叶分析、解析数论和计算零点之间翻译。缺失的是从"整函数的零点因子"到"自伴算子的点谱及谱重数"的函子式翻译；尤其缺少把函数方程转成算子对称性、把显式公式转成迹公式的一般桥梁。

**D（依存性）**
ξ 的零点结构依赖 ζ、Gamma 因子和函数方程；显式公式同时依赖零点与素数数据。目标断言则悬空依赖三个尚未提供的对象：Hilbert 空间、其上的稠定自伴算子，以及证明该算子谱与零点虚部一致的方法。若研究要求独立来源，该算子还不能以待证零点表作为定义输入。

**L（逻辑）**
目标的逻辑形式是"存在一个算子，使某一谱等式成立"，不是"所有自然候选算子都成立"。不能默认 Riemann 假设、零点简单性或临界线对称性。主要循环风险是：先用零点构造对角算子，再宣称解释了零点来源；另一风险是把谱的集合等式误当成包含重数的等式。

# 第 2 轮：分解命题

# 第 4 轮：证伪收窄——排除有界及连续谱候选

**动作声明**：命令 5。作用维度 L、M。参照：证明某类表示方式原则上达不到目标。

**执行**——以下类别不能实现 Z：
1. **任何有界自伴算子**：谱 ⊂ [-‖H‖,‖H‖]，而 Z 无界。
2. **有限维算子或紧自伴算子**：谱均有界。
3. **未经离散限制的普通位置或动量算子**：L²(ℝ) 上乘法算子 x 与 -i d/dx 的谱均为连续谱 ℝ。
4. **任何带非空连续谱部分的候选**：目标谱只有孤立点。

因此后续候选必须是**无界、离散谱、自伴**算子；有限截断只能逼近。
