# 第 0 步：SMPDL 五维基线审计

**S（语言／语义）——现状登记**
目标是寻找自伴算子，使其谱与 Riemann ξ 函数非平凡零点的虚部相对应。这里至少有三个需要严格区分的概念：零点本身、零点虚部构成的数值集合，以及自伴算子的谱。若零点有重数，还必须明确所要求的是集合相等，还是包含重数的谱相等。所谓「找到算子」也有两种不同强度：仅存在一个由零点数据定义的算子，或存在一个从其他数学结构独立构造、再证明其谱具有目标性质的算子。当前尚未给定目标算子的定义域、作用规则或构造方式。

**M（数学）——现状登记**
现有对象包括 ζ(s)、ξ(s)、它们的函数方程与解析延拓、已知零点分布性质，以及联系素数与零点的显式公式。可以研究这些函数的解析性质，并从零点数据构造数值序列或辅助算子。但这些材料本身尚未给出一个定义在指定希尔伯特空间上的自伴算子，也没有给出其定义域、作用规则、自伴性证明或完整谱刻画。因此，现有系统在解析数论层面有丰富结构，而从这些结构到目标算子的实现仍存在缺口。

**T（可翻译性）——现状登记**
零点可以用复平面中的点集、复数序列、计数函数或测度等方式表达；素数与零点的联系可以通过显式公式表述；算子问题则可以在希尔伯特空间、谱理论和矩阵近似等语言中表达。这些语言提供了潜在的翻译接口，但尚未建立一个由现有解析结构自然产生的自伴算子模型，并证明它与目标零点数据之间的对应关系。尤其缺少从显式公式到具体算子谱定理的完整翻译。

**D（依存性）——现状登记**
目标算子的存在性与自伴性、谱的准确刻画、以及候选构造的独立来源，是相互关联但不同的证明任务。若先把目标零点写进算子的定义，再证明其谱等于这些零点，虽然可能解决字面上的存在性问题，却没有解释如何从残余结构中产生该对象。若只从函数方程、显式公式或其他已知结构出发定义候选，则仍须证明它确实具有所要求的谱。目前最关键的悬空依赖是：从现有解析结构到具有目标谱的、可独立刻画的自伴算子之间，缺少已验证的构造与证明链条。

**L（逻辑）——现状登记**
需要区分存在性命题、候选对象的定义、候选对象的自伴性，以及谱等式。任何一个环节都不能仅由其他环节的表述自动推出。还须注意，零点虚部的集合表达不自动保证重数、离散性、下有界性或其他谱性质与候选算子相容。若目标被解释为自伴算子的离散谱，则还需证明相应谱的离散性；若允许连续谱，则须另行说明目标等式的精确定义。现阶段没有足够依据宣布目标断言已经闭合，也不能仅凭缺少已知构造就断言其不可能。

记 Z_ξ 为 ξ(s) 的非平凡零点多重集。对每个零点 ρ，记其虚部为 Im ρ。定义目标数值多重集 Γ_ξ = {Im ρ : ρ∈Z_ξ}（保留重数）；若只关心数值集合，另记 Γ_ξ^set。

将目标拆成三个层次：
- **命题 A（字面存在性）**：存在希尔伯特空间 H 和自伴算子 A，使 σ(A) = Γ_ξ^set（按集合相等理解）。

## 2. 执行动作

假定目标零点多重集已可列举为 Z_ξ = (ρ_n)_{n≥1}，γ_n = Im ρ_n（按零点重数列举）。令 H = ℓ²(ℕ)，定义对角算子 A e_n = γ_n e_n，D(A) = {x∈ℓ² : Σ γ_n²|x_n|² < ∞}。

逐项检查：
第一，**自伴性**：每个 γ_n 都是实数，实对角乘法算子在给定最大定义域上自伴。不需要假设 RH，也不需要知道所有零点是否位于临界线上。

## 2. 执行动作
考虑把目标问题从「寻找算子」翻译为「寻找能够由现有解析数据验证的谱恒等式」。

设 h 是适当测试函数。显式公式将素数幂一侧的加权求和与零点一侧的加权求和联系起来（示意：Σ_ρ h(ρ) ⟷ 素数幂项 + 其他解析项；实际等式取决于测试函数、收敛条件及所选显式公式，不能把示意式当成完整定理）。

如果存在合适的自伴算子 A 且其离散谱正好由目标零点虚部给出，那么在适当条件下算子的谱和可表现为 Tr f(A) = Σ_γ f(γ)（f 需满足使迹存在的条件，求和按指定重数解释）。

跨域对应：
- 解析侧：由 ξ 函数和显式公式得到的零点加权和。
- 算子侧：由候选算子的谱得到的特征值加权和。
- 桥接条件：两侧加权和必须在一个足够丰富的测试函数类上严格相符，并且候选算子须先独立定义且满足自伴性。

这项翻译保留了显式公式所表达的素数—零点联系，也使原先含混的「算子应该体现零点」变成可逐项核验的迹恒等式问题。
