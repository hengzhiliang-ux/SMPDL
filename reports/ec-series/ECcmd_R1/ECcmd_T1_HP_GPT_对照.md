# Riemann 谱算子缺失：SMPDL 五维审计与四轮结构操作登记

先明确本次试验的判定边界：我们要处理的不是已经给定的算子如何求谱，而是在没有已知实现目标零点的自伴算子的情况下，怎样严格区分已有数学结构、允许的新构造，以及尚未解决的存在性问题。

全程遵守三条规则：

1. 不把形式上的相似、数值上的吻合或猜想中的对象当作已经存在的数学事实。
2. 可以定义新对象、提出新命题，但必须分别标明定义、已证结论与待证断言。
3. 每轮操作必须产生可核验的数学内容；若无法继续，明确记录阻塞位置，而不以改名或循环定义伪造闭合。

## 第 0 步：SMPDL 五维基线审计

### S — 语言与语义

当前使用的核心术语包括 Riemann ζ 函数、完成的 ξ 函数、自伴算子、谱、非平凡零点、虚部、函数方程、解析延拓与显式公式。需要特别区分三个不同对象：ξ 函数的零点、这些零点的虚部组成的数值集合，以及某个算子的谱。前两者可以由函数论定义；第三者必须依托一个具体算子及其定义域、作用空间和算子性质来定义。所谓「谱恰好等于零点虚部」，也需要约定谱的重数、零点的重数以及谱集合是否包含连续谱等问题。基线状态：目标的数值侧有明确含义，但实现它的算子侧缺少已知构造；不能将二者的对应关系预先当成事实。

### M — 数学对象、运算与定理

现有对象包括复变函数 ζ(s)、完成的 ξ(s)、其解析延拓与函数方程、零点及其分布信息，以及联系素数和零点的显式公式。可以在适当的收敛或正则化条件下研究这些对象，并形成关于零点、素数和相关求和表达式的数学命题。另一方面，自伴算子通常需要指定希尔伯特空间、稠密定义域、作用规则以及自伴性条件；其谱由该算子及其所在空间决定。当前没有给定一个满足目标谱条件的算子，因此尚无可对其执行谱计算的对象。这里的缺失不是某个既有运算不封闭，而是从已知函数论数据到目标算子构造的数学桥梁尚未建立。

### T — 可翻译性

目标已经能够在复分析语言中表述，也能够通过显式公式与素数分布联系起来。零点还可以作为数列或离散点集处理，并研究其计数、间距及统计性质；这些描述各自保留部分数值信息，却不自动产生自伴算子。形式幂级数、矩阵、积分核、概率模型或几何对象可以作为潜在的表示语言，但每一种表示都必须证明其与目标零点的具体对应关系。基线状态：函数论到数值数据的翻译已经可用；从这些数据到具有规定谱的自伴算子的有效翻译尚缺失，而且不同表示语言是否能承载全部目标信息，尚未确定。

### D — 依存关系与悬空支持

目标断言至少包含以下依存链：

零点数据 → 候选算子构造 → 自伴性证明 → 谱与零点对应证明。

零点数据一端由现有函数论提供；其余各环节不能仅凭目标断言本身补齐。尤其是，即使找到一个具有部分匹配数值的算子，也仍须证明其自伴性，并证明它的完整谱与目标零点虚部相符。当前悬空的依存项包括候选算子的定义、定义域与作用规则、自伴性证明，以及谱对应的完整性和重数控制。基线状态：目标依赖的关键中间对象尚未建立，不能将这些依存边视为已满足。

### L — 逻辑与量词边界

需要区分「存在一个自伴算子，使其谱具有指定性质」这一存在命题，与「给定某算子，证明它具有指定谱」这一验证命题。前者要求给出构造或存在性证明；后者只有在对象已经明确之后才可执行。还应区分必要条件与充分条件、有限范围的数值吻合与全谱相等，以及谱集合相等与重数一致。若先假定目标算子存在，再用其谱性质反过来定义该算子，便会出现循环论证；若只定义一个抽象符号并规定它满足目标性质，则只是将待证命题写进定义，并没有证明存在性。基线状态：逻辑上允许提出候选、建立条件性定理或证明不可能性，但目标存在性目前仍是开放断言，不能作为推演前提使用。

## 第 1 轮：命令 11 — 形式化重述

### 1. 选择动作并声明

- 主要作用维度：T（可翻译性），兼及 L（逻辑）。
- 历史参照形态：②将日常概念改写为公理化定义；③将多个构造的共性改写为公理满足者。
- 选择理由：基线审计发现，「谱恰好等于零点虚部」存在集合相等、重数相等以及谱类型等不同解释。若不先固定目标的精确含义，后续构造无法得到明确的验收标准。

### 2. 执行动作：将目标改写为形式命题

先定义目标零点的数值数据。令

Z_ξ = {ρ∈C : ξ(ρ)=0}（零点按解析重数计入），

定义零点虚部的多重集 Γ_ξ = {Im ρ : ρ∈Z_ξ}。使用多重集是为了不在定义阶段丢失不同零点可能具有相同虚部这一信息。

目标命题（形式化版本）：存在复希尔伯特空间 H 及其上的自伴算子 H，使 H 的谱为纯点谱，且其特征值按特征空间维数计重后与 Γ_ξ 完全一致。

逻辑形式：P : ∃H_space ∃H [ H=H* ∧ Spec(H)=Γ_ξ ∧ 谱重数与零点重数相符 ]。

两个必须保留的限定：
1. 纯点谱要求是本轮采用的强目标版本，不意味着所有谱算子研究都必须采用此条件。
2. 形式化不假定所有非平凡零点都在临界线上；不能由此断言 Riemann 假设成立，也不能将其偷偷加入前提。

形式化前后保留的内容是零点与谱的对应要求；新增的是谱类型及重数的明确约束。形式化本身未产生任何候选算子。

### 3. 自审

- 编造检查：没有声称目标算子存在；P 只是明确写出的待证命题。
- 跳步检查：没有从函数方程或显式公式推导算子存在性。
- 循环论证检查：没有用待证算子的谱性质定义算子再宣称存在性已证。

自审通过。

### 4. 变化登记

- S：将「谱恰好等于零点虚部」区分为集合层面与含谱类型、重数条件的强目标版本。
- M：明确目标涉及的零点多重集及对应谱对象，但没有增加已知存在的算子。
- T：将自然语言目标翻译为含量词、自伴性及谱对应条件的形式命题。
- D：将依存链验收终点明确为满足规定谱条件的自伴算子；原有悬空依存项仍未解决。
- L：固定强目标版本，避免把集合相等、重数相等及纯点谱混为一谈。

## 第 2 轮：命令 5 — 证伪收窄

### 1. 选择动作并声明

- 主要作用维度：L（逻辑），兼及 T（可翻译性）。
- 历史参照形态：②证明某种编码或表示方式原则上达不到目标。
- 选择理由：形式化之后，最容易出现的错误是把有限范围的数值吻合误认为无限谱对应的证明。应先排除这种不充分的补完方式。

### 2. 执行动作：证明有限数值吻合不足以证明目标命题

对任意有限实数样本 γ_1,…,γ_N，可构造两个不同的无限实数序列，前 N 项完全一致而在之后不同（两组不同的、均无有限聚点的递增正数序列）。故有限样本不能唯一确定完整无限数值集合。

即便某候选算子的前若干特征值与已计算零点虚部一致，也不能仅凭此推出完整谱与目标多重集一致。同样，有限精度数值吻合不能单独证明自伴性：自伴性是关于算子、内积及定义域的数学条件，不是有限个近似特征值能替代的。

本轮排除的是不合法推理：「有限数值吻合 ⟹ 完整谱对应已证明」。数值证据可帮助发现候选对象，但不能独立完成存在性证明。

### 3. 自审

- 编造检查：没有声称所有数值方法无效；只否定有限吻合本身足以证明完整对应的推理。
- 跳步检查：通过不同无限序列共享有限前缀的构造，明确说明有限数据的非唯一性。
- 循环论证检查：论证没有预设目标算子存在，也不依赖零点的任何未证性质。

自审通过。

### 4. 变化登记

- S：明确区分「数值吻合」与「谱对应已证明」两种表述。
- M：增加了有限样本无法唯一确定无限数据的反例机制，没有新增目标算子。
- T：明确了从有限计算结果到完整谱对象的翻译缺口。
- D：排除了把有限数值吻合直接当作完整谱对应证明的依存路径。
- L：证明了有限吻合不足以单独推出目标命题，收紧了允许采用的证明标准。

## 第 3 轮：命令 3 — 跨域翻译

### 1. 选择动作并声明

- 主要作用维度：T（可翻译性），兼及 M（数学对象）。
- 历史参照形态：①几何与代数互译；②抽象结构转化为可计算表示。
- 选择理由：第 2 轮排除了有限数据直接当证明的做法，但未说明零点数据能否在其他语言中形成可操作对象。本轮将零点多重集翻译为测度与计数结构。

### 2. 执行动作：建立零点计数测度（本轮引入的数学表示，不是目标算子的构造）

定义零点虚部的局部有限计数测度：

μ_ξ = Σ_{ρ∈Z_ξ} m_ρ · δ_{Im ρ}，

其中 m_ρ 是零点解析重数，δ_γ 是集中于 γ 的单位点质量。若不同零点同虚部，质量相加。

非平凡零点在任意有界高度内只有有限多个，故 μ_ξ 在每个有界区间取有限值，是局部有限正测度。

对紧支撑连续函数 f: R→C，⟨μ_ξ, f⟩ = Σ m_ρ f(Im ρ)，只有有限多非零项，意义明确，不需假定目标算子存在。

**翻译保留了什么？** 保留零点虚部位置及重数；将区间内零点计数转化为测度质量；允许测试函数加权求和与研究极限行为。

**翻译新增了什么表达能力？** 离散零点数据可用测度论语言描述——可区分同总计数但分布不同的区间，可研究缩放后的计数测度极限。

**这项翻译是否完成了缺失？** 没有。零点数据→μ_ξ 是已完成的表示转换；μ_ξ→满足目标条件的自伴算子仍是未完成的构造问题。测度不是算子，也不携带自动成立的自伴性证明。

### 3. 自审

- 编造检查：计数测度明确标记为新表示；定义直接来自已知零点，没有宣称它是某算子的谱测度。
- 跳步检查：局部有限性保证紧支撑求和有意义；没有从测度存在性跳到算子存在性。
- 循环论证检查：构造不依赖目标算子，没有把目标谱性质写入测度定义。

自审通过。

### 4. 变化登记

- S：引入「零点计数测度」术语，区分零点数据表示与算子实现。
- M：构造了局部有限正测度 μ_ξ，可对紧支撑测试函数积分。
- T：完成零点多重集到测度语言的翻译；测度到目标自伴算子的翻译未完成。
- D：依存链增加一条已闭合中间表示路径；测度到算子的构造与自伴性证明仍悬空。
- L：证明计数测度定义的良定性，但未证明该测度可由满足目标条件的自伴算子实现。

## 第 4 轮：命令 6 — 开放声明

### 1. 选择动作并声明

- 主要作用维度：D（依存性），兼及 M 与 L。
- 历史参照形态：①登记「对象存在性未证」及精确卡点；③区分已闭合弱形态与悬空强形态。
- 选择理由：前三轮完成形式化、排除错误证明策略、建立计数测度，但都没有构造目标算子。现有推演无法再推出算子存在性，故明确登记缺失并停止，不以未经证明的猜想填补空缺。

### 2. 执行动作：登记未解决的缺失

开放声明：以现有工具无法解决目标算子的存在性问题。「无法解决」指本次四轮操作尚未获得能证明目标命题的构造或定理；不是声称已证明目标算子不存在，也不是证明所有方法均告失败。

| 依存环节 | 当前状态 | 尚缺少的内容 |
|---|---|---|
| 零点数据 | 已有 | 无须假定目标算子存在 |
| 零点数据的测度表示 | 已建立 | 不构成算子实现 |
| 候选算子的构造 | 未解决 | 具体的空间、定义域及作用规则 |
| 自伴性 | 未解决 | 针对候选算子的严格证明 |
| 完整谱对应 | 未解决 | 排除额外谱成分，证明全部目标数据均被实现 |
| 重数对应 | 未解决 | 零点重数与谱重数严格对应 |

最后三个问题不能合并成一句「算子具有正确的谱」而略过。

可确立的结论：已闭合弱形态（严格形式化目标、定义计数测度、证明有限吻合不足）；仍悬空强形态（未构造并证明满足谱条件的自伴算子）；没得到的结论（未证明算子存在，也未证明不存在；未证明 Riemann 假设）。

### 3. 自审

- 编造检查：没有将候选算子、谱对应或存在性当作已证事实。
- 跳步检查：明确列出尚未完成的环节。
- 循环论证检查：没有以目标命题作新定义前提，也没有以测度存在性代替算子存在性。
- 结论强度检查：只报告本次未能解决，不将「尚未构造」误写成「不可能构造」。

自审通过。

### 4. 变化登记

- S：将「未解决」限定为当前推演尚未完成目标证明，而非断言目标不成立。
- M：没有新增算子或已证定理；区分已定义的计数测度与未构造的目标算子。
- T：确认零点数据到测度的翻译已闭合；测度到自伴算子的实现未完成。
- D：将悬空依存项逐项登记为算子构造、自伴性、完整谱对应和重数对应。
- L：将最终结论限定为开放问题的准确登记，不从未完成证明推断命题为假。

## 最终结构状态登记

已完成：五维基线审计；目标命题形式化；有限吻合不足的论证；零点虚部局部有限计数测度构造。
尚未解决：目标自伴算子构造；自伴性证明；完整谱及重数对应证明。
不得宣称：目标算子已存在；目标算子不可能存在；Riemann 假设已获证明。

终止结论：我们确实补全了若干表示层与逻辑层的结构，但没有补全核心的算子实现缺失。诚实的数学登记必须保留这条边界：能够表示零点数据，不等于能够实现这些数据；能够提出一个候选结构，也不等于证明该结构满足目标条件。
