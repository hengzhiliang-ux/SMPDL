# 第 0 步：SMPDL 五维基线审计

**S（语言／语义）**
现有语言包括 Riemann ζ 函数、ξ 函数、非平凡零点、临界线、虚部、自伴算子与谱。这里有两处必须区分：其一，零点 ρ=β+iγ 的"虚部"γ 总是实数，所以"谱等于所有 γ"本身并不直接排除临界线外零点；其二，"谱相同"可能只指集合相同，也可能要求点谱、重数完全相同，并排除连续谱和剩余谱。

**M（数学）**
已有对象是 ζ、ξ、其零点及其重数，以及素数幂和显式公式中的测试函数。ξ 是整函数，满足函数方程与共轭对称；零点在有限区域内没有聚点。整函数对加法、乘法和求导封闭，但对除法、取对数及在零点处取预解式并不封闭。当前没有给定 Hilbert 空间、算子定义域、算子作用规则或谱测度。

**T（可翻译性）**
现有结构可翻译为整函数零点分布、对数导数的极点与留数、Fourier／Mellin 变换下的分布恒等式，以及潜在的谱迹公式。缺失的翻译是：如何从 ξ 的解析数据得到一个具有稠密定义域的自伴算子，并把"函数零点"逐项译成"算子特征值"。

**D（依存性）**
显式公式把零点信息同素数幂信息相连，但这种联系本身不提供 Hilbert 空间，也不自动提供正内积或自伴定义域。目标算子的存在依赖于三个悬空支持者：独立的算子载体、自伴性证明、零点与谱的精确对应。若以零点本身直接排列成对角算子，还会产生循环构造风险。

**L（逻辑）**
目标是一个存在性断言，不能只构造出"如果零点已经满足所需条件，那么算子就存在"的条件模型。主要风险有四种：把弱读法冒充成强读法；只验证特征值集合而遗漏重数；忽略连续谱或剩余谱；把待证的自伴性偷偷当作定义的一部分。

# 第 1 轮：形式化重述

## 1. 动作声明
- **命令**：命令 11，形式化重述。
- **主要维度**：T，同时清理 S、L。
- **历史操作形态**：参照"把直觉表述改写为严格量词语言"的形态，不采用任何具体历史答案。
- **选择理由**：原表述中的"虚部"和"谱恰好等于"存在语义落差，若不先固定目标，后续可能只证明一个更弱命题。
- **对象级别**：本轮不构造新算子。

## 2. 执行动作

定义 F(z) := ξ(1/2 + iz)，Z_F := {z ∈ C : F(z) = 0}，零点按其在 F 中的阶数记重数。由 ξ 的函数方程与共轭对称可得 F(-z) = F(z)，F(z̄) = F(z)‾。

**强读法 P_spec**：存在一个 Hilbert 空间 H 及其上的稠定自伴算子 H，使得：
1. σ(H) = Z_F；
2. H 没有连续谱和剩余谱；
3. 对每个 z ∈ Z_F，dim ker(H - zI) = ord_z F。

这比"谱等于零点的虚部集合"更严格，也保留了通常希望从谱实现获得的临界线结论。

事实上，若 ρ = β + iγ 是非平凡零点，则对应的 z 满足 1/2 + iz = ρ ⟹ z = γ + i(1/2 - β)。若 P_spec 成立，自伴性给出 Z_F = σ(H) ⊂ ℝ，故 β = 1/2。因此 **P_spec ⟹ Riemann 假设**。

形式化后保留了零点、重数和谱之间的对应；排除了"只取虚部""只比较集合""允许额外谱"这三个含混出口。

## 3. 自审
没有宣称 P_spec 已成立；上述蕴含只使用"自伴算子的谱为实集"和坐标变换。强读法确实比字面弱读法更强，本轮没有将二者谎称为等价。

## 4. 变化登记
- **S**：明确区分字面弱读法与含重数、无额外谱的强读法。
- **M**：新增派生级整函数 F(z) 及其复零点集 Z_F。
- **T**：把"零点由算子实现"译为严格的谱与重数条件。
- **D**：确认临界线结论依赖于"所有 Z_F 中元素都是实谱点"，而非仅依赖"虚部是实数"。
- **L**：证明 P_spec ⟹ RH，目标量词和排除项现已固定。

# 第 2 轮：分解命题

## 1. 动作声明
- **命令**：命令 2，分解命题。
- **主要维度**：L，同时作用于 D。
- **历史操作形态**：参照"拆成存在性与性质""正命题与逆命题分别处理"的操作形态。
- **选择理由**：形式化后的目标仍把载体、自伴性、零点覆盖和谱穷尽混在一起，容易只完成其中一部分便宣称成功。
- **对象级别**：无新对象。

## 2. 执行动作

将 P_spec 拆成三个内容互不重叠的子断言：

**A．载体与自伴性**：存在 Hilbert 空间 H 和稠定算子 H，并验证 D(H) 稠密，H = H*。包括定义域与边界条件，而不只是形式上的对称表达式。

**B．零点覆盖**：对每个 z ∈ Z_F，z 都是 H 的特征值，并且 dim ker(H - zI) ≥ ord_z F。保证没有遗漏零点或降低其重数。

**C．谱穷尽**：反向地，H 的每个谱点都来自 Z_F；每个零点的特征空间维数不超过 ord_z F，且连续谱、剩余谱均为空。

三者合取恰好给出 P_spec。它们并非逻辑上彼此独立：例如 A 与 B 合起来已经迫使被覆盖的零点为实数；拆分的目的是隔离证明责任，而不是声称三个子问题难度相同。

## 3. 自审
没有跳过定义域，也没有把"所有特征值都属于零点集"误当成"所有零点都是特征值"。A、B、C 的合取与原强目标一致，拆分没有暗中削弱命题。

## 4. 变化登记
- **S/M/T**：无变化。
- **D**：把悬空依赖分为自伴载体、零点覆盖、谱穷尽三项。
- **L**：确立后续每个候选必须分别接受 A、B、C 检查，不能用局部吻合替代完整证明。

# 第 3 轮：定义实现级候选算子

## 1. 动作声明
- **命令**：命令 7，定义新对象。
- **主要维度**：M，同时作用于 T、D、L。
- **历史操作形态**：参照"直接为缺失对象给出空间、定义域与作用规则"的实现级尝试。
- **选择理由**：前两轮已经给出验收标准，现在可以直接构造一个精确承载 F 全部零点及重数的候选，检验失败究竟发生在哪一项。
- **对象级别**：**实现级候选**；但它以待实现的零点集为输入，不是独立构造。

## 2. 执行动作

**这是新定义。** 将 Z_F 中零点列成 (z_n)_{n∈I}，每个零点按 ord_z F 重复出现。取 H_N = ℓ²(I)，并定义对角算子 N：

D(N) := {x = (x_n) ∈ ℓ²(I) : Σ |z_n x_n|² < ∞}，(Nx)_n := z_n x_n。

有限支承向量属于 D(N)，所以 N 稠定。其伴随为 D(N*) = D(N)，(N*x)_n = z̄_n x_n。因此 N 是闭正规算子：N*N = NN*。

由于整函数的零点在有限区域内无聚点，{z_n} 是闭集，从而 σ(N) = {z_n : n ∈ I} = Z_F。每个 z_n 都是特征值，特征空间维数恰为相应零点重数；连续谱和剩余谱为空。因此，若把 A 中的"自伴"暂时放宽为"正规"，则正规版本已经满足相应的 A、B、C。

但对标准基向量 e_n，Ne_n = z_n e_n，N*e_n = z̄_n e_n，故

**N = N* ⟺ z_n ∈ ℝ 对所有 n ⟺ Z_F ⊂ ℝ。**

结合第 1 轮的坐标变换，这等价于所有非平凡零点都位于临界线上。因此：

> **该候选把"自伴性缺口"精确转化成了 Z_F 的实性缺口；它没有消除这个缺口。**

## 3. 自审
构造本身有效，但具有循环性：它直接读取待研究的零点，而不是从独立的系数、素数数据或边界条件生成谱。没有宣称 N 自伴，也没有把正规实现冒充为目标完成。它满足精确零点覆盖和谱穷尽，却恰好在最关键的自伴性上未闭合。

## 4. 变化登记
- **S**：新增"正规实现"与"自伴实现"的明确区分。
- **M**：新增实现级候选 N，并确定其空间、定义域、作用规则、伴随和谱。
- **T**：建立 F 的零点及重数与 N 的特征值及特征空间维数之间的逐项翻译。
- **D**：正规版本的覆盖与穷尽已经闭合，剩余依赖集中为 Z_F 的实性及构造的非循环性。
- **L**：得到严格等价关系"N 自伴 ⟺ Z_F ⊂ ℝ"，同时确认该关系不能反过来充当证明。

## 2. 执行动作

**目标断言 P_spec 未闭合，Riemann 假设也未因本轮操作得到证明。**

已闭合的弱形态是：存在一个由 F 的零点数据定义的稠定闭正规算子 N，其纯点谱与 Z_F 完全一致，重数一致，且无连续谱和剩余谱。

仍有三个明确卡点：

1. **非循环载体缺失**：N 直接使用零点坐标。若要成为有证明效力的构造，需要改用不预先知道零点位置的独立数据定义算子，再导出其谱，而不是把零点写进对角线。
2. **自伴性未证**：对当前 N，证明 N = N* 与证明所有 z_n 为实数是同一个问题。这里没有任何额外的斜算子、相似变换或形式对称性可以绕过这一等价关系。
3. **独立候选的谱识别方法缺失**：即便另给一个自伴算子，仍须证明它覆盖全部零点、保持重数并排除额外谱；仅有若干迹公式或局部数值吻合不足以完成 C。

因此，本轮终止不是因为证明了"不可能存在"，而是因为现有构造已把缺口压缩为一个明确的等价难点，继续对同一对角模型操作不会推进证明。

没有编造新定理，没有把构造失败扩张成不可能性结论，也没有把正规算子实现登记成自伴实现。已证部分、定义部分与未证部分均已分开。
