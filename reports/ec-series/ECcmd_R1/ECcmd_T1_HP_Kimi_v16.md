# 第 0 步：SMPDL 五维审计

**S（语言／语义）**
当前核心术语是 ξ(s)、非平凡零点 ρ=β+iγ、自伴算子和谱。至少有四处含混：谱是否要求计入重数；"谱"是否允许连续谱；"实现零点"是否允许把零点坐标直接写进算子定义；以及"特征值为 γ"是否与"ξ(½+iH) 的零点"混同。最后一项尤其危险：前者只涉及 γ，后者还把零点放在直线 ℜs=½ 上，二者不是同一断言。

**M（数学）**
现有对象是 ξ 函数、其解析延拓与函数方程、零点集及其重数、素数幂与 von Mangoldt 权重，以及显式公式中的测试函数。函数层面的四则运算和解析延拓已经具备，但这些运算并不自动产生 Hilbert 空间、稠定算子、自伴扩张或谱 calculus。当前没有任何非循环构造，使"零点纵坐标"成为某个独立于零点集定义的算子的谱。

**T（可翻译性）**
零点数据可以形式地翻译成原子测度、对角矩阵或乘法算子的谱数据；显式公式可以把"零点求和"翻译成"素数幂项加阿基米德项"。缺失的是反向翻译：从素数、Γ 因子等算术材料出发，构造一个自伴算子，并把其普通谱迹翻译成显式公式。

**D（依存性）**
ξ 依赖 ζ、Γ 因子及规范化因子；显式公式同时依赖零点分布和素数分布。目标算子若存在，谱识别应依赖其定义与自伴性，而不能反过来依赖预先给出的零点表。当前悬空的依赖是：算术显式公式已经有了，但承载其"谱侧"的独立算子没有。

**L（逻辑）**
目标的量词结构是"存在 Hilbert 空间与自伴算子 H，使所有零点纵坐标及重数恰为其点谱"。主要逻辑风险有三项：用目标零点定义 H 造成循环；只证明对称性便宣称自伴性；以及只证明某些测试函数上的迹等式，便未经论证推出完整谱与重数相同。

以下将"含重数、无连续谱"作为登记版本；它比只要求谱集合相等略强。

# 第 1 轮：形式化重述

**动作声明**：选择命令 11，主作用 T，兼及 S、L。参照"把含混表述改写为量词语言"的操作形态。当前首先需要消除"实现"和"谱"的歧义，否则后续构造无法审计。

形式化目标：存在 Hilbert 空间 H 及自伴算子 H，σ(H)=σ_p(H)=Z，σ_c(H)=∅，dim ker(H-γI)=m(γ)。

**另设非循环条件 NC**：H 的定义域和作用规则可以使用 ξ 的函数数据、素数幂、Γ 因子等，但**不得把 Z、各个 γ 或 m(γ) 作为构造输入**；谱等式必须是从算子定义推出的结论。

两个层次：1. 字面目标（允许预先使用 Z）；2. 实质目标（同时要求 NC）。"ξ(½+iH) 的谱零点实现"另列为更强问题，不偷偷并入。

**自审**：没有把 NC 冒充为原题的形式逻辑后果；它是为排除循环构造而明确增加的许可条件。重数和连续谱已分别处理。

**变化登记**：S 区分字面/非循环/临界线行列式实现；M 定义局部有限多重集及重数函数；T 改写为 Hilbert 空间语言；D 新增 NC 为实质构造的独立支撑条件；L 明确量词与谱等式，排除三类跳步。

# 第 4 轮：把显式公式翻译成谱迹问题

# 第 5 轮：构造素数侧的算术算子模型

**动作声明**：命令 7，主作用 M、T。参照"把抽象结构矩阵化、可算化"。**派生级对象**，标注：**这是新定义**。

**执行动作**：指标集 I = {(p,k)}，H_P = ℓ²(I)，**P e_{p,k} = (k·log p)·e_{p,k}**，稠定自伴对角算子，σ(P) = {k log p}。定义加权算术配对 τ_P(φ) = Σ (log p/p^{k/2})[g(k log p)+g(-k log p)]（g=φ̂）——组合 P 的谱坐标、素数权重、傅里叶变换为显式公式素数侧模型。
