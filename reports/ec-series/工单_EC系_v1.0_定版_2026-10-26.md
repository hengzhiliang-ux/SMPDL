## 〇、范式定位：EC 系与 G 系的同血统差异

| 维度 | G 系一二轮（拆→修复） | **EC 系（拆→涌现补完）** |
|---|---|---|
| 输入 | 成熟结构 − 拆除一个部件（时间锁 T_L） | 同左（继承拆法谱系：律/结构/算子三拆面） |
| 任务指令 | 重建/修复被拆部件 | **禁止等价复现**（任务级硬条款）；将剩余公理系统发展为一门自洽的公理化理论 |
| 主测量物 | 受创槽修复度（40% 权重） | **涌现物本身**：α/β/γ 主型 + 被拆律处置方式 + 新概念命名事件 |
| 理论角色 | 移除-涌现理论作事后解释语言 | 移除-涌现理论作**事前预测基准**（T→主型查表，盲态首测） |
| 复现地位 | B1 基线 = 低分陷阱（非平凡性 15% 兜底） | 等价复现 = **任务级违规**（登记不评分）+ 复现允许对照臂 |
| 预测性质 | PFE 时代忠实 + 修复路径预测 | **涌现类型可预测性**（P10）：理论预测删除点将生成何种补偿结构，盲会话是否实际生成 |

**一句话**：G 系问「AI 能把删去的部件证回来吗」；EC 系问「**AI 是否会在删除点生成理论所预测的补偿结构**」——移除-涌现理论（α 补偿/β 解禁/γ 回收）从描述性框架升级为可证伪的前向预测规则集。

## 三、任务指令模板（B 区生成用 · 与 G 系的关键分叉）

```
[时间锁 T_L] 同代数学家视角。结构 M 的部件 X 已被移除/从未被引入。
任务：在 X 缺席下将 M 发展为一门自洽的公理化理论（含明确定义、公理陈述与证明）。
硬条款：
① 禁止以任何等价形态重新导入 X（等价复现 = 任务失败）；
② 补完产物须包含至少 3 条非平凡定理（多产性下限）；
③ 诚实降级：无法解决处如实标注，不虚构。
测量目标（对候选隐藏）：候选在删除点生成的新结构属何种类型。
```

与 G 系指令的分叉点：G 系说「重建 X」；EC 系说「**禁止重建 X，沿剩余公理系统向前发展**」。

## 五、评分卡 v2（机械算分 · 权重待拍板 D-EC4）

**涌现度 40%**（主型命中预测基准 + 非平凡新结构 + 新概念命名）｜ **PFE 时代忠实 25%** ｜ **自洽性 20%** ｜ **理论多产性 15%**（非平凡定理群产出度，fertility 口径）。
等价复现式产出：涌现度记 0 并触发 EC-L1 登记（不评分）。平分并列不掷币。

**处置四分类判定操作（形式化口径，判定者盲填）**：
设被拆律为 X，候选引入的新条款为 Y（可为新公理/新对象类/新算子）：
- **等价复现** ⇔ T ⊢ (Y ↔ X)（Y 与 X 在候选理论内互推）——删除测试：去掉 Y 后理论退化为剩余公理系统且无任何新增结构；替换测试：Y 与 X 为记号变体（notational variant）→ 违规登记不评分
- **相对化** ⇔ T ⊢ (D → X) 且 D 是候选**显式定义**的受限结构（标记类/受限语句域/显式使用条件），X 仅在 D 内有效、D 外显式失效——「律不自由回归：全域律降格为 D 上的局部律」
- **异构替代** ⇔ T ⊢ Y 且 F(Y) = F(X)（功能等价）但 Y ⊬ X 且 X ⊬ Y（互不蕴含）——旧功能由结构上不同的条款承担
- **未决申报** ⇔ 候选显式声明该功能缺口未被实现 + 指认所缺工具（「以现有工具无法解决」条款触发）

## 六、假说族 H-C（随 v1.0 commit 预注册）

- **H-C1 涌现主型可盲预测**：盲补完的涌现主型与 T→主型机械查表一致（EC-1→α+元层 / EC-2→β / EC-3→α+γ）；判定标准 = 靶级主型命中率 ≥2/3。
