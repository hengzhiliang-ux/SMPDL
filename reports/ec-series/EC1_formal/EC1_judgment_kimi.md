我会先核对四份候选的规则与定理，再用原始历史文献确认 Lambek 演算、线性逻辑及相位语义的时间与结构对应，重点区分"概念相似"和"规则级同构"。

初步核验显示，四份候选都越过了"仅仅拆掉两条规则"的层面，但至少到达了乘法式线性演算；是否到达 1987 年锚核心，则取决于有没有显式模态域、证明网或真正的相位语义，而不能只凭"资源"措辞判定。候选三、四的析取规则方向不同，我会分开登记，不把它们强行归为同一系统。

我确认按题设锚点判定：以 1935 年 Gentzen 相继式演算为拆除锚、以 1987 年 Girard 线性逻辑及其 MLL 前站为结构锚，锚年异议只登记、不改判。  
我确认②的门槛是至少两个规则级对应点；"资源""守恒""令牌"等概念相似本身不计分，是否恢复 W/K 则按相继式上的实际可推导能力判断。

## 二、规则级同构对照

### 候选一

| 候选规则或定理 | 历史对应 | 判定 |
|---|---|---|
| ∧R（上下文分立） | IMLL 的 ⊗R | 完全同构：两个上下文严格分立，结论是乘法合取 |
| ∧L（复合分解） | IMLL 的 ⊗L | 完全同构：复合资源分解为两个分量 |
| →R | IMLL 的 ⊸R | 完全同构：线性蕴涵引入 |
| →L（双上下文分配） | IMLL 的 ⊸L | 完全同构：函数资源、输入资源和外围上下文各用一次 |
| 定理一：前件排列律 | 交换体系中的前件排列 | 依赖 C，不依赖 W/K |
| 定理二：受限合成 | 线性蕴涵合成 | 各函数及输入恰消费一次 |
| 定理三：curry 化 | ⊗ 与 ⊸ 的 curry 化方向 | 乘法剩余关系的标准结果 |

因此候选一至少具有四个独立规则级对应点，明显超过②门槛；其三条"非平凡定理"本身都是已知乘法式演算中的常规定理。

### 候选二

候选二的 §3.2 与候选一具有同一四规则核心，只是明确写成 ⊗、⊸，所以对应更直接：

| 候选内容 | 历史对应 |
|---|---|
| ⊗R：Γ、Δ 并置 | 线性逻辑的 tensor-right |
| ⊗L：将 A⊗B 分解为 A,B | 线性逻辑的 tensor-left |
| ⊸R | 线性蕴涵右规则 |
| ⊸L（双上下文分配） | 线性蕴涵左规则 |
| 定理 2 | 交换型 IMLL 中 tensor 的交换性 |
| 定理 3 | 受控切／线性函数合成 |
| 定理 5 | 局部线性 Curry–Howard 对应 |

候选二对"相同公式不等于相同资源出现"的区分是准确的，但其新东西是表述与组织方式，不是历史上未知的演算结构。

### 候选三

其 ∧R、∧L、→R、→L 与候选一、二相同，分别对应 ⊗R、⊗L、⊸R、⊸L。此外：

| 候选内容 | 历史对应及限制 |
|---|---|
| Cut | IMLL 的乘法切 |
| 定理三：单用切 | 受控替换／切规则的资源解释 |
| 定理四：切消保持单用性 | Lambek—线性逻辑传统的切消结果；候选只给证明略述 |
| ∨R₁、∨R₂ | 与加法式 ⊕Rᵢ 相同 |
| ∨L：两支使用 Γ 与 Δ，结论并置二者 | **不是** MALL 的 ⊕L；后者两支必须共享同一上下文 |

所以应判"乘积核心命中 IMLL"，不能判"整个演算就是 MALL"。其所谓 ∨ 资源幂等由它自己的分叉式 ∨L 支持，但不能拿来证明它与标准加法式析取同构。

### 候选四

候选四的乘积核心同样对应 IMLL；其关键进步是正确地区分了乘法分支与互斥情形：

| 候选规则或定理 | 历史对应 |
|---|---|
| ∧R、∧L | ⊗R、⊗L |
| →R、→L | ⊸R、⊸L |
| ∨L 中同一 Γ 分别进入两个互斥分支 | 加法式 ⊕L：共享上下文，而非资源复制 |
| 定理 4：切消 | 无 W/K 相继式演算的标准切消路线 |
| 定理 5：有限逆向证明搜索 | 无指数模态的命题线性片段可判定；MALL 后来更精确地被证明为 PSPACE 完全 |
| 定理 6：主切消去对应项化约 | 证明规范化与构造项化约的对应 |
| 定理 7：析取与存在见证 | 由切消和末规则分析得到的构造性性质 |

线性逻辑的加法式与乘法式区别，正是撤走 W/K 后不再能互相推导的规则区别；候选四共享外围上下文的 ∨L 与标准 ⊕L 相符。[SEP: These two presentations are equivalent in classical logic, because of the availability of a few so-called "structural" rules, namely contraction and weakening.]

## 三、附加问题

### E1．复制／丢弃许可与 bang ! 的对应程度

**四份候选都没有抵达 bang ! 相对化。**

- 候选一明确拒绝通用复制、丢弃许可。
- 候选二明确拒绝设置一类可任意复制、丢弃的前提，并申报普遍许可问题未决。
- 候选三所谓"复制允许"，实际是结论中本来就有两个独立前提出现；所谓"丢弃允许"，实际是逻辑规则对主公式的正常分解或假设解除。二者都不是对同一前提使用 W 或 K。
- 候选四同样只允许显式重数及逻辑消耗，没有为任何公式类恢复自由复制和丢弃。

因此，没有任何候选定义了类似 D={!A:A 为公式} 的显式标记域，更没有给出 !W、!C、dereliction、promotion 等规则。标准线性逻辑恰恰只在带 ! 标记的公式上恢复弱化和收缩，这一层在四份候选中均缺席。[SEP: In particular, the "of-course" exponential ! permits contraction and weakening to be applied to the formula !B in the left-hand sequent context.]

**显式标记域：无候选抵达。计价结构：候选四抵达。**其整数赋值不是模态相对化，而是独立的代数语义／反驳结构。

### E2．多支乘法式规则与 MLL 的同构性

- **候选一、二：完全命中。**∧R 是 ⊗R，∧L 是 ⊗L，→R 是 ⊸R，→L 是 ⊸L。
- **候选三：上述乘积规则同样命中，切规则也命中；但 ∨L 不命中 MALL。**
- **候选四：乘积规则命中，且共享上下文的 ∨L 还命中加法式 ⊕L。**

所以"多支上下文严格分立"与 MLL 的关系不是泛泛相似，而是逐规则同构；但完整 MLL 还涉及经典双侧相继式、否定及 par 等内容，四份候选均未覆盖。

### E3．记账判据与线性蕴涵语义

- **候选一：**"每份前提恰消费一次"给出了正确的操作直觉，但主要是非形式化守恒描述。
- **候选二：**把前提位置、资源分配和构造项使用次数明确对应，已经是较严格的句法资源解释；仍不是独立语义。
- **候选三：**令牌双射和账本等式直接表达 ⊸ 的"消费一个输入、交付一个输出"及切的功能复合，但仍属于证明记账，而非独立模型。
- **候选四：对应最强。**在 (Z,+,≤) 中，v(A∧B)=v(A)+v(B)、v(A→B)=v(B)−v(A)，正对应乘法单调运算及其剩余；相继式有效性取 v(Γ)≤v(C)，正是有序剩余结构的语义形式。v(A∨B)=max(v(A),v(B)) 则配合其共享情形的加法式析取。它可用于可靠反驳，但候选没有证明完备性，也不是 Girard 的相位空间正交闭包语义。Avron 后来确实把整数及其加法、序和格运算作为线性逻辑代数语义的具体实例。[Arnon Avron, Types 邮件档案: When the additive operations are added one should demand (D,<) to be a lattice and then the additives are interpreted as the lattice operations.]

## 四、史实与形式勘误

1. **候选三的量词特征变量条件写窄了。**其统一说明只要求 y 不在 Γ 与主公式中自由；对 ∃L，还必须排除它在上段结论 C 中自由，即不得在整个下相继式中自由。标准线性逻辑量词规则也是这样规定的。[SEP: the variable y must not be free in the formulas of the lower sequent of those inference rules.]

2. **候选三的"单用证明对象是三元组"与实际写法不符。**随后列出的 (Γ,A,Π,τ) 是四元组。

3. **候选三的公式型账本等式不足以单独表达"资源双射"。**按公式型 D 汇总会抹平不同出现及复合公式分解的来源；它至多是保形出现级双射的粗化计数后果，不能无条件替代该双射。

4. **候选三的定理四只提供"证明略述"。**可登记为合理的切消纲领，不能按已经展示完整逐情形归纳证明来计分；这里没有据此判定定理为假。

5. **候选四的 A→(B→A) 数值有符号错误。**按候选自己的定义：v(B→A)=v(A)−v(B)，因而 v(A→(B→A))=(v(A)−v(B))−v(A)=−v(B)，不是表中的 v(B)。有效反例应取 v(B)=1，此时数值为 −1；候选所写 v(B)=−1 反而给出 +1，不能反驳该式。

6. **候选一不宜把"仿射／线性约束"并列为同义词。**仅禁止复制而允许丢弃对应仿射方向；同时禁止复制和丢弃、要求恰用一次才是这里所说的线性约束。候选后续"禁止死代码"的说明本身是正确的。

## 五、本靶整体观察

- **最深处抵达：候选四。**它不仅重建乘法式核心，还正确处理加法式互斥情形，并给出切消、命题判定、构造项化约和整数代数反驳模型。但它仍未给出 ! 模态、证明网或相位语义，因此 C 仍只能判为**锚前一站**，不能判"锚核心"。
- **四候选同型性很高。**主型全部为 α，乘积核心全部命中 IMLL；主要分化在候选三的分叉式 ∨L、候选四的共享式 ∨L，以及候选三、四不同程度的元理论建设。
- **无结构性违规。**各候选中的"逻辑吸收""显式两份前提""互斥分支共享情形"均不等于在固定相继式上重新获得 W/K；候选三的非标准 ∨L 是历史对应上的偏差，不是偷渡被拆律。
- **真正缺失的共同层是"相对化"。**四份候选都在禁用域内建立资源纪律，却没有建立一个受限域 D，使 W/K 在 D 内恢复、在 D 外失效，所以均未触及 Girard 锚的核心控制机制。
- **锚年异议：无实质异议。**Gentzen 论文通常标作 1934–1935 年，取 1935 年作为相继式演算与切消锚是常规史学选择；Girard《Linear Logic》发表于 1987 年，且证明网、指数模态和相位语义确属该锚体系。[The Review of Symbolic Logic: Gentzen, G. (1934–1935). Untersuchungen über das logische Schließen.]
