## 1. 声明与版本

**主声明**：设 `X₁,…,X_n ~ Bernoulli(p)`，选择 Beta 先验 `p ~ Beta(α, β)`。观测到 `k` 次成功后，后验分布为

```text
p | data ~ Beta(α + k, β + n - k)
```

贝叶斯 `(1-α)` 可信区间（credible interval）是后验分布的任意满足 `P(p ∈ I | data) = 1-α` 的区间，常用最高后验密度区间（HPD）或等尾区间。

**版本信息**：
- **形式化基础**：贝叶斯统计学（Bayes, 1763；Laplace；Jeffreys；20 世纪复兴）
- **依赖前提**：参数可视为随机变量、先验分布、似然函数、贝叶斯更新、概率作为信念度
- **典型实例**：相同抛硬币数据下，用先验 `Beta(1,1)` 得到后验 `Beta(k+1, n-k+1)`；临床试验中结合历史数据作为先验
- **AxiomaticBase**：`BayesianStatistics` + `SubjectiveProbability`

## 2. S/M/P × D/L 六格审计

### 2.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| 参数随机化 | 把未知参数 `p` 视为随机变量 | ✅ |
| 先验分布 | 观测前对 `p` 的信念编码 | ✅ |
| 似然函数 | `P(data | p)` 作为 `p` 的函数 | ✅ |
| 贝叶斯更新 | 先验 × 似然 ∝ 后验 | ✅ |
| 可信区间 | 给定数据后 `p` 落在区间的后验概率 | ✅ |

### 2.2 S*L — 语义逻辑结构

- 贝叶斯把“概率”定义为**信念度（degree of belief）**，因此参数 `p` 是随机变量，具有分布。
- 可信区间的语义是：在观测到当前数据后，参数 `p` 落在区间内的后验概率为 `1-α`。
- ⚠️ 风险：学生常把“95% 可信区间”与“95% 置信区间”混为一谈；两者语义不同，不能互相替代。

### 2.3 M*D — 数学依存

```text
Bayesian_Binomial(p, n, k)
    │
    ├── Prior: p ~ Beta(α, β)
    │
    ├── Likelihood: data | p ~ Binomial(n, p)
    │
    ├── Posterior: p | data ~ Beta(α + k, β + n - k)
    │
    └── Credible interval: P(p ∈ I | data) = 1 - α
```

- 依赖关系闭合：共轭先验使后验闭式可得；非共轭先验需数值方法（MCMC、变分推断）。

### 2.4 M*L — 数学逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 后验规范性 | ✅ | Beta 是二项似然的共轭先验，后验积分恒为 1。 |
| 后验相合性 | ✅ | 在温和条件下，随着 `n → ∞`，后验集中于真实 `p`。 |
| 先验敏感性 | ✅ | 小样本时先验选择影响显著；大样本时似然主导。 |
| 退化情形 | ✅ | `k=0` 时后验为 `Beta(α, β+n)`，区间不收缩为点。 |

### 2.5 P*D / P*L — 编程层

- Python：`scipy.stats.beta.ppf` 计算等尾可信区间；`pymc`、`Stan` 处理非共轭模型。
- R：`bayestestR::hdi` 计算 HPD 区间；`rstan` 处理复杂模型。
- 风险：需明确先验选择并报告其影响；MCMC 收敛性需单独诊断。

## 4. 人类科学家可执行的验证动作

1. 取先验 `Beta(1,1)`，观测 `n=10, k=3`，验证后验为 `Beta(4,8)`，并计算 95% 等尾可信区间。
2. 对比同一数据下频率主义 95% Wald 区间与贝叶斯 95% 等尾区间，观察两者在 `n` 较小时的差异。
3. 验证当 `n → ∞` 时，贝叶斯后验均值的渐近行为与 MLE 一致。
