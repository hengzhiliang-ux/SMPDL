# S/M/P × D/L 审计报告：差分方程中的指数增长

> **定理**：给定时间步长 h > 0、增长率 k ∈ ℝ 与初值 P₀ ∈ ℝ，差分方程
> 
> P_{n+1} = (1 + hk) P_n, P₀ 给定
> 
> 的唯一解为
> 
> P_n = P₀ (1 + hk)^n, n ∈ ℕ。
> 
> **来源**：标准差分方程 / 数值分析教材（如 Elaydi, *An Introduction to Difference Equations*；Atkinson, *Numerical Analysis*）。
> 
> **分析日期**：2026-10-13 | **审计框架**：Göttingen S/M/P × D/L v1.5 | **AxiomaticBase**：`DifferenceEquation`
> 
> **风险评级**：⚪ 已确认正确（在差分方程公理体系内）。

---

## 0. 分析目标

1. 对差分方程指数增长模型 P_{n+1} = (1 + hk) P_n 的求解做一次 S/M/P × D/L 六格审计。
2. 明确证明依赖的核心假设：自然数索引、递推关系、数学归纳法。
3. 为后续与微分方程版本做同构对比建立差异图谱（S/M/P 标签、证明骨架、风险点）。
4. 检查自然语言中是否把“离散近似”与“连续解”混为一谈，忽略步长 h 的作用。

## 1. S 层审计（语义层）

### 1.1 S*D：语义依存

| 自然语言元素 | 支持的后续元素 | 依赖说明 |
|---|---|---|
| 时间步长 h > 0 | 离散时间 t_n = nh | 离散化参数 |
| 增长率 k ∈ ℝ | 比例因子 (1 + hk) | 方程参数 |
| 初值 P₀ | 序列起点 | 定解条件 |
| 递推关系 P_{n+1} = (1+hk)P_n | 定义整个序列 | 核心语义 |
| 数学归纳法 | 证明对所有 n ∈ ℕ 成立 | 证明策略 |
| 闭式解 P_n = P₀(1+hk)^n | 归纳结论 | 最终解 |

### 1.2 S*L：语义逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 量词显式化 | ✅ | “对所有 n ∈ ℕ”可显式写为 ∀n ∈ ℕ。 |
| 术语单义性 | ⚠️ 中 | “解”在差分方程中指满足递推关系的序列；需与 ODE 的“函数解”区分。 |
| 隐喻/图示依赖 | ⚠️ 中 | “每步增长 (1 + hk) 倍”是强直觉隐喻；严格证明需回到递推与归纳。 |
| 隐含跳跃 | 🟡 中 | 自然语言常把闭式解当作“显然的等比数列”，忽略归纳验证。 |
| 蕴涵方向 | ✅ | 由递推关系 + 归纳推出闭式解，方向正确。 |

**S 层结论**：自然语言证明直观，但“等比数列”的闭式解需要数学归纳法严格验证。教学中若省略归纳，易造成“猜答案”幻觉。

## 2. M 层审计（数学层）

### 2.1 M*D：数学依存

```text
DifferenceEquation_ExponentialGrowth
    │
    ├── Parameters
    │       ├── h > 0 (time step)
    │       ├── k ∈ ℝ (growth rate)
    │       └── P₀ ∈ ℝ (initial value)
    │
    ├── Discrete time index
    │       └── n ∈ ℕ
    │
    ├── Difference equation
    │       └── P_{n+1} = (1 + hk) P_n
    │
    ├── Initial condition
    │       └── P_0 = P₀
    │
    ├── Mathematical induction
    │       ├── Base n = 0: P_0 = P₀ = P₀ (1 + hk)^0
    │       └── Inductive step
    │               ├── Assume P_n = P₀ (1 + hk)^n
    │               ├── P_{n+1} = (1 + hk) P_n
    │               │              = (1 + hk) P₀ (1 + hk)^n
    │               │              = P₀ (1 + hk)^{n+1}
    │               └── QED
    │
    └── Convergence note (optional)
            └── If t = nh is fixed and h → 0, then
                P_n = P₀ (1 + kt/n)^n → P₀ e^{kt}
```

| 数学对象 | 结构签名 | 在证明中的作用 |
|---|---|---|
| 时间步长 h | 正实数 | 离散化尺度 |
| 增长率 k | 实数 | 比例参数 |
| 初值 P₀ | 实数 | 序列起点 |
| 离散时间 n | 自然数 | 序列索引 |
| 递推关系 | P_{n+1} = r P_n，r = 1 + hk | 差分方程核心 |
| 数学归纳法 | ℕ 的归纳原理 | 证明工具 |
| 等比数列闭式 | P_n = P₀ r^n | 结论 |
| 极限收敛 | (1 + kt/n)^n → e^{kt} | 与连续解的联系 |

### 2.2 M*L：数学逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 公理系统一致性 | ✅ | 在标准差分方程 / Peano 算术内严格。 |
| 构造合法性 | ✅ | 递推关系唯一确定序列；归纳法显式验证闭式。 |
| 量词范围 | ✅ | 对所有 n ∈ ℕ 成立。 |
| 边界情况 | ✅ | n = 0 时 (1+hk)^0 = 1，P_0 = P₀。 |
| 隐藏假设 | 🟡 中 | 证明默认 h 固定；若 h 变化，需额外讨论稳定性与收敛性。 |
| 等价命题循环 | ✅ | 无。 |

**M 层结论**：证明在差分方程公理系统内逻辑结构完整。核心依赖为递推关系与数学归纳法。

## 3. P 层审计（编程/形式化层）

### 3.1 P*D：形式化依存

> 在 Mathlib/Lean 4 中，序列可用 `ℕ → ℝ` 表示，递推关系用 `Nat.rec` 或自定义递归函数定义。闭式解的证明用 `Nat.rec` / `induction` 完成。

```text
DifferenceEquation_ExponentialGrowth
    │
    ├── Mathlib.Data.Nat.Basic
    │       └── ℕ
    │
    ├── Mathlib.Data.Real.Basic
    │       └── ℝ
    │
    ├── Sequence definition
    │       └── P : ℕ → ℝ with P 0 = P0 and P (n+1) = (1 + h*k) * P n
    │
    └── Theorem sketch
            └── theorem difference_equation_solution
                    (h k P0 : ℝ) (hh : 0 < h) :
                    ∀ n : ℕ, P n = P0 * (1 + h * k) ^ n
```

### 3.2 P*L：形式化逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 语法可编译 | ✅ | 序列与递推在 Lean 中可自然表达。 |
| 类型签名一致 | ✅ | 输入：h, k, P₀, n；输出：P_n = P₀ (1+hk)^n。 |
| 定义等价 | ✅ | `Nat.rec` 与递推定义等价。 |
| 命题等式 | ✅ | 目标等式可用 `induction` 证明。 |
| `#print axioms` | 🟢 低 | 依赖自然数归纳与实数算术；不直接依赖选择公理。 |

**P 层结论**：Mathlib 可支撑本定理形式化。证明结构简单，是 `induction` 策略的标准练习。

## 5. 风险点与判定

| 风险点 | 层级 | 风险等级 | 处理状态 |
|---|---|---|---|
| 把离散解直接等同于连续解 | S/M | 🔴 高 | 需显式取极限 h → 0 |
| 稳定性条件 | M | 🟡 中 | |1 + hk| > 1 时解发散；|<1 时衰减 |
| 自然语言省略归纳验证 | S | 🟡 中 | 应强调闭式解需证明 |
| 步长 h 的符号 | M | 🟢 低 | 通常 h > 0 |

**最终判定**：⚪ 已确认正确。该证明在差分方程公理体系内逻辑完整、跨层同构强度高，适合作为 SMPDL 样本库中“离散正确样本”的基准条目。

## 6. 结论

差分方程指数增长模型是一个**递推 + 归纳**驱动的经典离散案例：

- **S 层**：自然语言“每步增长 (1+hk) 倍”被严格化为递推关系。
- **M 层**：数学结构完整，核心为 `recurrence → closed form by induction`。
- **P 层**：Mathlib 中可用 `Nat.rec` 与 `induction` 直接形式化。
- **跨层映射**：三层对应关系明确，同构强度为 ⭐⭐⭐ 高。

该样本建议标记为：`DifferenceEquation`、`S-ISO / M-ISO / P-ISO`（自洽），并作为与 `DifferentialEquation` 版本对比的基准版本。
