## 1. 命题与声明

论文研究 Tingley 问题：若 $T: S_X \to S_Y$ 是两个 Banach 空间 $X, Y$ 单位球面之间的满射等距，是否总存在满射实线性等距 $\tilde{T}: X \to Y$ 使得 $\tilde{T}|_{S_X} = T$？

典型声明形如：

- 对某一类 Banach 空间（如有限维、严格凸、光滑、或满足某种几何条件的空间），Tingley 问题有肯定答案；
- 并且给出从 $T$ 到 $\tilde{T}$ 的显式延拓构造。

该方向的经典结果包括 Tingley (1987) 的原始问题、Cheng–Dong (2011) 对几乎传递空间的结果、Tanaka (2017) 对 $C(K)$ 空间的结果，以及大量对 $L^p$、$C^*$-代数、JB*-triple 等特殊类的结果。

- 风险：可能把对特殊类（如严格凸）的结果泛化为所有 Banach 空间。

### 2.4 M*L — 数学逻辑结构

- 典型证明结构：
  1. 从球面等距 $T$ 导出某种“端点”或“暴露点”性质；
  2. 利用严格凸性、光滑性或有限维性定义 $T$ 在内部的延拓；
  3. 验证延拓是实线性且保范。
- 陷阱：不同空间类的延拓方法差异很大；严格凸空间的端点唯一性不适用于一般空间。
- 风险：证明可能隐含假设了空间满足某种几何条件（如严格凸），而 README 未披露。

### 2.5 P*D — 编程/形式化依存

- README 可能指向 [Lean](lean/docs/322.md)，但未说明形式化范围。
- 风险：Lean 可能只形式化了：
  - Banach 空间、单位球面、等距的定义；
  - 严格凸空间中的简单延拓；
  - Mazur–Ulam 定理，而非 Tingley 延拓。
- 特别风险：形式化中的“Banach 空间类”可能局限于有限维或严格凸，而 README 未说明。

### 2.6 P*L — 编程逻辑结构

  - 是否严格定义了球面等距与线性延拓；
  - 是否明确量词范围（所有 Banach 空间 / 某类）；
  - 是否给出延拓构造并证明其为满射实线性等距。

## 5. 人工可能需要确认/补充证明的地方

1. **覆盖的 Banach 空间类**：明确定理是对所有 Banach 空间、有限维空间、严格凸空间、光滑空间、$C(K)$、$L^p$ 还是其他类成立。
2. **延拓映射的显式公式**：给出从 $T: S_X \to S_Y$ 构造 $\tilde{T}: X \to Y$ 的具体公式或算法。
3. **实线性与等距性证明**：验证延拓是实线性、满射，并且保持范数；特别验证在球面外也成立。
4. **与已知结果的比较**：说明与 Tingley (1987)、Cheng–Dong (2011)、Tanaka (2017) 等结果的关系，是否覆盖新空间类。
5. **反例检查**：确认所声称的空间类是否包含已知 Tingley 问题开放的反例空间；若包含，结论与已知开放性问题矛盾。
6. **经典空间验证**：对 $\ell^p$、$L^p$、$C[0,1]$ 等经典空间，人工验证延拓构造是否成立。
7. **Lean 主定理范围**：确认 Lean 是否 literally 给出一般 Banach 空间的 Tingley 定理，还是仅证明特殊类或辅助引理。
