# S/M/P × D/L 审查报告：调和级数发散

> 目标：对经典证明「调和级数 ∑(1/n) 发散」执行六格审计。  
> 框架：Göttingen S/M/P × D/L v1.3  
> 日期：2026-10-12

## 0. 证明原文（分组法）

```text
命题：调和级数 H = Σ_{n=1}^∞ 1/n 发散。

证明：将级数按 2 的幂次分组：

H = 1 + 1/2 + (1/3 + 1/4) + (1/5 + 1/6 + 1/7 + 1/8) + ...

每一组进行下界估计：
- 第 0 组：1
- 第 1 组：1/2
- 第 2 组：1/3 + 1/4 > 1/4 + 1/4 = 1/2
- 第 3 组：1/5 + ... + 1/8 > 8 × 1/8 = 1/2（实际 4 项，每项 > 1/8）
- 第 k 组（k ≥ 1）：2^{k-1} 项，每项 > 1/2^k，和 > 1/2

因此 H > 1 + 1/2 + 1/2 + 1/2 + ... = ∞。

故调和级数发散。证毕。
```

### 1.3 M*D：数学依存闭合

```
调和级数定义 H_n = Σ_{i=1}^n 1/i
       ↓
部分和数列 {H_n}
       ↓
分组：H_{2^k} = Σ_{j=0}^{k-1} (第 j 组) + 余项
       ↓
每组下界估计：第 j 组 > 1/2
       ↓
H_{2^k} > 1 + k/2
       ↓
{k} 无上界 ⇒ {H_{2^k}} 无上界
       ↓
{H_n} 无上界 ⇒ 调和级数发散
```

依赖图闭合，无反向边。

**M*D：✅ 通过**

### 1.5 P*D：编程/形式化依存闭合

Lean 骨架：

```lean
theorem harmonic_series_divergent : ¬ Summable (λ n : ℕ => 1 / (n + 1 : ℝ)) := by
  -- 等价于证明部分和无上界
  rw [summable_nat_add_iff]
  apply not_summable_of_partialSums_unbounded
  -- 证明子列 H_{2^k} 无界
  have key : ∀ k : ℕ, partialSum (λ n => 1 / (n + 1 : ℝ)) (2 ^ k - 1) ≥ 1 + k / 2 := by
    induction k with
    | zero => norm_num
    | succ k ih =>
      -- 利用 H_{2^{k+1}} = H_{2^k} + 新加的一组
      calc
        partialSum ... (2^(k+1) - 1)
          ≥ partialSum ... (2^k - 1) + 1/2 := by -- 新加的 2^k 项每项 ≥ 1/2^{k+1}
            sorry
        _ ≥ 1 + k/2 + 1/2 := by linarith [ih]
        _ = 1 + (k+1)/2 := by ring
  intro M
  -- 取 k > 2(M-1)
  sorry
```

主要 `sorry` 是选取足够大的 k 以超过任意界 M，这在 mathlib 中可用 `archimedean` 性质填充。

**P*D：✅ 通过**
