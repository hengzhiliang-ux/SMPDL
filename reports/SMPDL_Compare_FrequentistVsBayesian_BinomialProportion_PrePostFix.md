# SMPDL 基础对比审计：频率主义 ↔ 贝叶斯的二项比例估计

> **对比对象**
> - “PreFix” 版本：频率主义二项比例估计（MLE + 置信区间）
> - “PostFix” 版本：贝叶斯二项比例估计（Beta 先验 + 后验 + 可信区间）
> 
> **审计日期**：2026-10-14  
> **审计框架**：Göttingen S/M/P × D/L v1.5  
> **历史编号**：H13  
> **总体评价**：⚪ ↔ ⚪ 两个版本在各自语义体系内均正确；差异来自“概率”语义解释（客观频率 vs 主观信念度），而非数学计算错误。

---

## 1. 版本声明对比

| 维度 | 频率主义（PreFix） | 贝叶斯（PostFix） |
|---|---|---|
| **主声明** | `p̂ = k/n` 是 `p` 的 MLE；`(1-α)` 置信区间覆盖真实 `p` 的频率为 `1-α` | 给定 Beta 先验，`p | data ~ Beta(α+k, β+n-k)`；`(1-α)` 可信区间包含 `p` 的后验概率为 `1-α` |
| **“概率”语义** | 客观长期相对频率 | 主观信念度 / 不确定性量化 |
| **参数地位** | `p` 是固定未知常数 | `p` 是随机变量，具有分布 |
| **核心工具** | 大数定律、中心极限定理 | 贝叶斯定理、共轭先验 |
| **区间语义** | 重复抽样下覆盖频率 | 给定数据后对参数的不确定性 |
| **历史定位** | Fisher/Neyman-Pearson，20 世纪上半叶 | Bayes (1763)，Laplace，Jeffreys；20 世纪复兴 |
| **典型实例** | 抛硬币 `n` 次，报告 95% 置信区间 | 抛硬币 `n` 次，报告 95% 可信区间 |

## 2. PreFix 版本 SMPDL 速览（频率主义）

详见 `SMP_ProofAnalysis_Frequentist_BinomialProportion.md`。

- **S*D**：自然语言依赖“重复实验 → 长期频率 → 点估计 + 置信区间”的语义链。
- **S*L**：量词清晰，但“置信”一词常被误解读为贝叶斯式概率。
- **M*D**：`Bernoulli(p) i.i.d.` → `MLE p̂ = k/n` → `CLT` → `Wald CI`。
- **M*L**：逻辑完整；`n` 大时渐近覆盖率为 `1-α`。
- **P*D / P*L**：`statsmodels` / `prop.test` 支持良好。

**PreFix 判定**：⚪ 已确认正确（在频率主义语义内）。

## 3. PostFix 版本 SMPDL 六格审计（贝叶斯）

### 3.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| 参数随机化 | 把 `p` 视为随机变量 | ✅ |
| 先验分布 | `p ~ Beta(α, β)` | ✅ |
| 似然函数 | `data | p ~ Binomial(n, p)` | ✅ |
| 后验分布 | `p | data ~ Beta(α+k, β+n-k)` | ✅ |
| 可信区间 | 后验概率 `1-α` | ✅ |

### 3.2 S*L — 语义逻辑结构

- 贝叶斯框架下，“概率”不是客观频率，而是对参数不确定性的量化。
- 可信区间的语义与置信区间完全不同：前者是“给定数据，参数落在区间内的概率”，后者是“重复抽样，区间覆盖参数的频率”。
- ⚠️ 主要 S*L 风险：把两种区间的数值相近当作语义相同。

### 3.3 M*D — 数学依存

```text
Bayesian_Binomial(p, n, k)
    │
    ├── Prior: p ~ Beta(α, β)
    │
    ├── Likelihood: data | p ~ Binomial(n, p)
    │
    ├── Posterior: p | data ~ Beta(α + k, β + n - k)
    │
    └── Credible interval
```

- 依赖关系闭合：共轭先验保证后验闭式。

### 3.4 M*L — 数学逻辑结构

| 检查项 | 频率主义 | 贝叶斯 | 差异说明 |
|---|---|---|---|
| 参数模型 | `p` 固定 | `p` 随机 | 数学对象地位不同 |
| 区间构造 | 基于抽样分布 | 基于后验分布 | 区间来源不同 |
| 大样本行为 | 相合、渐近正态 | 后验集中于真值 | 在 `n → ∞` 下两者趋于一致 |
| 小样本行为 | 可能退化（Wald 区间） | 受先验影响 | 小样本时差异显著 |

### 3.5 P*D / P*L — 编程层

- Python/R：贝叶斯工具（PyMC、Stan、bayestestR）支持良好。
- 风险：需显式报告先验；MCMC 收敛需诊断。

## 4. 跨层映射检查（PostFix vs PreFix）

| 映射 | 频率主义（PreFix） | 贝叶斯（PostFix） |
|---|---|---|
| S → M | “长期频率” → `p` 为固定参数 | “信念度” → `p` 为随机变量 |
| M → P | MLE + CLT → Wald CI | 先验 + 似然 → 后验/HPD |
| S ↔ P | 覆盖率 ↔ 重复抽样 | 后验概率 ↔ 单数据集 |
| S ↔ S | “概率” = 客观频率 | “概率” = 主观信念 |
| M ↔ M | 抽样分布是核心 | 后验分布是核心 |

**跨层结论**：两个版本的 S/M/P 层各自自洽；差异根源于“概率”的语义解释。数学上，频率主义 MLE 对应贝叶斯后验在平坦先验 + 大样本下的极限。

## 6. 变化类型归类

- **变化方式**：**语义迁移**（“概率”语义从客观频率变为主观信念度）。
- **核心假设差异**：
  - 频率主义：参数固定，概率是长期频率；
  - 贝叶斯：参数随机，概率是信念度。
- **证明骨架相似性**：两者都使用二项似然 `Binomial(n, p)`，但一个用于构造抽样分布，一个用于贝叶斯更新。
- **SMPDL 同构标签建议**：`S-BISIM / M-ISO / P-BISIM`。
  - S-BISIM：术语相同但语义不同（置信 vs 可信、频率 vs 信念）；
  - M-ISO：数学结构相通，MLE 是平坦先验下后验的模；
  - P-BISIM：实现路径不同（CLT/MCMC vs 共轭/MCMC）。
- **关键 lesson**：AI 生成统计证明时，必须显式声明所用概率解释框架；不能把“置信区间”与“可信区间”混用，也不能把贝叶斯后验直接当作频率主义抽样分布。

## 6.5 概念奇点（Conceptual Singularity）

### 6.5.1 本组对比中的关键人工洞察

- **把“概率”从客观频率重新解释为主观信念度**：Bayes 1763 年的关键一步是证明，概率可以量化“我们对命题不确定性的认知”。
- **引入先验并承认其主观性**：贝叶斯方法必须选择先验，这在频率主义框架中不存在对应物。
- **认识到同一数学公式（二项似然）可以服务于两种截然不同的推理目标**：频率主义用似然做估计与假设检验；贝叶斯用似然做信念更新。

### 6.5.2 为什么机器难以自动迁移

机器可以从二项模型反推“需要一个区间估计”，但**判断应当输出频率主义置信区间还是贝叶斯可信区间**、并正确解释其语义，需要统计学哲学判断。两种框架的区间数值可能几乎相同，但语义截然不同，机器容易混淆。

## 6.6 断裂强度（Breakage Strength）

| 评估项 | 等级 | 说明 |
|---|---|---|
| **断裂强度** | 🟠 引理替换 | 不是参数微调，而是“概率”语义与“参数地位”发生替换；核心工具从 CLT 变为贝叶斯定理。 |
| **S 层影响** | 高 | “概率”“置信/可信”“参数是否随机”均发生同名异义。 |
| **M 层影响** | 中 | 数学结构相通（二项似然、渐近理论），但目标分布不同。 |
| **P 层影响** | 中 | 实现工具不同，但现代统计软件同时支持两种框架。 |

**判定**：本组迁移是**语义解释框架的替换**，故评为 🟠。
