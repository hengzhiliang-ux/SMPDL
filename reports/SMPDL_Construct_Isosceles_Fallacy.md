# 防前视构建报告：「所有三角形都是等腰」谬误

> 使用流程：`SMPDL_ProofConstruction_AntiForesight.md` v1.0  
> 案例：Rouse Ball 经典谬误证明 — 所有三角形都是等腰  
> 日期：2026-10-12

---

## 0. 显式化

### 0.1 目标命题 P

**自然语言**：任意三角形都是等腰三角形。  
**形式化**：

```
∀ △ABC, AB = AC ∨ AB = BC ∨ AC = BC
```

（注：该命题为假。我们的构建应最终发现无法合法闭合。）

### 0.2 前提 A

- 三角形定义：三个不共线点 A, B, C；
- 角平分线定义；
- 垂直平分线定义；
- 全等三角形判定（SAS, AAS, HL 等）；
- 勾股定理；
- 点到直线距离定义。

### 0.3 可用工具

- 构造角平分线与垂直平分线的交点 P；
- 从 P 向三边作垂线；
- 证明直角三角形全等。

### 0.4 禁用（含等价形式）

- 禁止使用「三角形是等腰的」作为构造或推理理由；
- 禁止假设 P 在三角形内部；
- 禁止假设垂足 D 一定落在边 AC 上（而非延长线上）。

---

## 1. 反向草图（OPEN）

```
P: △ABC 是等腰三角形（例如 AB = BC）
  G₁: 证明 AB = BC
    G₂: 构造点 P 为 ∠B 的平分线与 AC 的垂直平分线的交点
    G₃: 从 P 向 AB、BC、AC 分别作垂线，垂足为 E、F、D
    G₄: 证明 PE = PF（P 在角平分线上，到两边距离相等）
    G₅: 证明 PA = PC（P 在 AC 的垂直平分线上）
    G₆: 证明 △AEP ≅ △ADP（直角 + 公共斜边 AP + PE = PD）
    G₇: 证明 △CFP ≅ △CDP（直角 + 公共斜边 CP + PF = PD）
    G₈: 由 G₆ 得 AE = AD
    G₉: 由 G₇ 得 CF = CD
    G₁₀: AB = AE + EB
    G₁₁: BC = CF + FB
    G₁₂: 证明 EB = FB（由 △PEB ≅ △PFB，直角 + 公共边 BP + PE = PF）
    G₁₃: AB = AD + EB
    G₁₄: BC = CD + FB
    G₁₅: 因为 AD = AE, CD = CF, EB = FB，所以 AB = BC
```

**前视风险点**：

- G₆ 要求 PE = PD，但 PD 是 P 到 AC 的距离，PE 是 P 到 AB 的距离，两者一般不相关；
- G₈ 与 G₉ 要求 D 落在边 AC 上，即 AC = AD + DC；
- G₁₃ 与 G₁₄ 的加法拆分要求 E 在 AB 上、F 在 BC 上、D 在 AC 上，这些都依赖 P 的位置。

---

## 2. 正向重写（尝试）

### 步骤 1：构造点 P（尝试闭合 G₂）

**主张**：设 P 为 ∠ABC 的角平分线与 AC 的垂直平分线的交点。  
**理由**：角平分线和垂直平分线都是直线，若相交则交点存在。  
**前驱**：前提 A。  
**状态**：✅ 形式闭合，但需注意 P 可能在三角形外部。

### 步骤 2：作垂线（尝试闭合 G₃）

**主张**：从 P 向 AB、BC、AC 作垂线，垂足分别为 E、F、D。  
**理由**：点到直线的垂线存在且唯一。  
**前驱**：步骤 1、前提 A。  
**状态**：✅ 形式闭合。

### 步骤 3：证明 PE = PF（尝试闭合 G₄）

**主张**：PE = PF。  
**理由**：P 在 ∠ABC 的角平分线上，因此到 AB 和 BC 的距离相等。  
**前驱**：步骤 1、角平分线性质。  
**状态**：✅ 闭合。

### 步骤 4：证明 PA = PC（尝试闭合 G₅）

**主张**：PA = PC。  
**理由**：P 在 AC 的垂直平分线上，因此到 A 和 C 的距离相等。  
**前驱**：步骤 1、垂直平分线性质。  
**状态**：✅ 闭合。

### 步骤 5：证明 △AEP ≅ △ADP（尝试闭合 G₆）

**主张**：△AEP ≅ △ADP。  
**理由**：

- ∠AEP = ∠ADP = 90°（垂线定义）
- AP 是公共斜边
- 需要 PE = PD 才能用 HL（Hypotenuse-Leg）

**前驱**：步骤 2、步骤 4、需要 PE = PD。

**状态**：❌ **无法闭合**。因为 PE 是 P 到 AB 的距离，PD 是 P 到 AC 的距离，没有任何前提保证 PE = PD。

## 3. 前视漏洞定位

### 3.1 S 层前视

原始谬误证明通常表述为：

> "因为 P 到 AB、BC、AC 三边的距离相等，所以 PE = PF = PD。"

这句话**默认**了 P 到三边距离相等，但：

- P 到 AB 和 BC 相等是因为角平分线；
- P 到 AC 的距离与到 AB、BC 的距离**没有直接关系**。

这就是前视：构造者知道最终需要 △AEP ≅ △ADP，所以**把目标所需的条件**（PE = PD）**悄悄当作已知**。

### 3.2 M 层前视

在依赖图中，PE = PD 的前驱应该是：

```
P 在角平分线上  ──→ PE = PF
P 在垂直平分线上 ──→ PA = PC
```

但要推出 PE = PD，需要额外假设：

- P 到 AB 和 AC 的距离相等；
- 或者 △ABC 是等腰的（AB = BC）。

这两者都等价于目标 P 或其部分。因此依赖图中出现了从 P 到中间节点的**反向边**。

### 3.3 P 层前视（Lean 视角）

```lean
have h_PE_PD : PE = PD := by
  -- 这里没有任何公理或引理支持
  sorry
```

这个 `sorry` **不可填充**：要证明 PE = PD，必须引入与目标等价的条件。

### 3.4 D/L 检查失败点

| 层 | 失败点 | 说明 |
|---|---|---|
| S*D | 🟡 | "P 到三边距离相等" 没有前驱 |
| S*L | ❌ | "PE = PD" 是目标所需条件，不是已知 |
| M*D | ❌ | PE = PD 的依赖图中出现从目标 P 的反向边 |
| M*L | ❌ | 相当于用 AB = BC 证明 AB = BC |
| P*D | ❌ | `have h_PE_PD` 的证明体不可填充 |
| P*L | ❌ | 留下不可消除的 `sorry` |

## 4. 等价循环探测

| 命题 | 是否与 P 等价 | 是否允许 | 说明 |
|---|---|---|---|
| PE = PF | 否 | ✅ | 角平分线性质 |
| PA = PC | 否 | ✅ | 垂直平分线性质 |
| **PE = PD** | **是**（在 △ABC 非退化时等价于 AB = BC） | ❌ | 目标所需条件 |
| **PD = PF** | **是**（等价于 AC = BC） | ❌ | 目标所需条件 |
| △AEP ≅ △ADP | 需要 PE = PD | ❌ | 等价循环入口 |

**结论**：PE = PD 是 P 的等价条件，构成等价循环。🔴

## 5. 边界扫描

| 边界情况 | 是否处理 | 说明 |
|---|---|---|
| P 在三角形外部 | ❌ 未处理 | 原始证明默认 P 在内部；对非等腰三角形，P 实际在外部 |
| D 在 AC 延长线上 | ❌ 未处理 | 导致 AC = \|AD - DC\|，不是 AD + DC |
| 等边三角形 | 平凡成立 | 但个例不能证明全称 |
| 退化三角形 | 未讨论 | 三点共线不构成三角形 |

**关键边界**：当 P 在三角形外部时，D 点落在 AC 的延长线上，因此：

```
AC ≠ AD + DC
```

而是：

```
AC = |AD - DC|
```

这直接破坏 G₈/G₉/G₁₀/G₁₁ 的长度加法步骤。

---

## 6. 结论

「所有三角形都是等腰」证明无法通过防前视构建流程：

- 反向草图识别出 15 个 OPEN 子目标；
- 正向重写阶段在 **G₆（△AEP ≅ △ADP）** 处失败；
- 失败根因：需要 **PE = PD**，而该条件等价于目标 P 的一部分；
- S/M/P × D/L 检查显示 S*L、M*D、M*L、P*D、P*L 同时失败；
- 边界扫描进一步发现 P 点外部位置导致长度加法不合法。

**最终判定**：正向链在 G₆ 处断裂，P 无法得证。❌

**修复方向**：若要加强为合法证明，必须显式引入额外条件，例如：

- 「P 在三角形内部」且「D 落在 AC 上」——但这只在等腰三角形中自动成立，无法作为一般三角形的假设。
