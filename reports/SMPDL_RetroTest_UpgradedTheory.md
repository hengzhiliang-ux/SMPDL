# SMPDL 升级后理论样本重测报告（v3 判据回溯检验）

> **版本**：v1.0  
> **日期**：2026-10-14  
> **性质**：**重测（retro-test）**——B1–B3 执行轮升级了三项理论资产（假说 v3 学科二型论 / 条件类对象定义 / γ 五形态），本报告用**升级后的判据**回溯重跑全部相关历史样本，检验：①升级是否引入新的不一致；②新判据是否改变历史结论；③预测力是否净提升。  
> **与回验的区别**：回验 = 预测 vs 实际（入库时）；重测 = 旧结论 vs 新判据（升级后）。

## 一、重测 1：学科二型论（假说 v3）回溯全部学科级涌现

**新判据**：强学科分两型——分类学型（单通道：纯对象解禁）vs 方法学型（双通道：对象 × 方法辐射）。

| 学科 | 触发律 | 通道解剖 | v3 归型 | 与 v2 结论一致性 |
|---|---|---|---|---|
| 凸分析 | H23 内积 | 对象：凸集理论；方法：优化算法辐射 | 方法学型 ✓ | 一致 |
| Sobolev/分布 | H18 正则性 | 对象：函数空间谱系；方法：FEM 产业 | 方法学型 ✓ | 一致 |
| 均衡理论 | H32 单调 | 对象：USCO 集值分析；方法：VI 求解器/博弈 | 方法学型 ✓ | 一致 |
| 非标准分析 | H34 阿氏 | 对象：*ℝ 结构；方法：转移原理技术 | 方法学型 ✓（中等独立度） | 一致 |
| 拓扑材料 | H42 同伦 | 对象：陈数计算；方法：材料实验/边缘态 | 方法学型 ✓ | 一致 |
| **李理论** | H28 结合 | 对象：李代数分类学；方法：弱（非结合计算史弱） | **分类学型** | **v2 伤 → v3 正例**（重测修复确认） |
| NC 几何 | H4 交换 | 对象：非交换谱分类；方法：Connes 端仍在对象侧 | 分类学型 ✓ | 新归型（v2 未裁） |

**附加发现（重测红利）**：**学科型与律的强度相关**——分类学型学科多由甲级律触发（结合/交换/幂等/消去：公理级移除释放纯对象），方法学型多由乙级/双面律触发（内积/正则性/单调/阿氏/同伦）。候选元规律：**"甲级律→分类学型，乙级双面律→方法学型"**（10 例中 8 例符合，AC 例外——乙级 T2 却长出 L 宇宙分类学；记 80% 一致，待扩样）。

## 二、重测 2：条件类对象定义回溯全部 T2 β 成分

**新判据**：条件类对象 = 由被移除的行为保证划出的系统类（存在论方向：由律边界刻出，非先在实体）。

| T2 律 | β 成分 | 新判据检验 | 重测结果 |
|---|---|---|---|
| LEM | Brouwer 选择序列 | 构造性对象——由"可判定性保证"的边界刻出？选择序列是**直觉主义主动构造**的先在意图对象 | **边缘案例**：一半先在（Brouwer 的形而上学意图）一半边界刻出——条件类定义增加"纯度"维度：选择序列 = **意图型条件类**（构造主义纲领先于律的显式质疑） |
| AC | 内模型 L / 大基数 / AD | L 是 ZFC 内构造（由 AC 的相对一致性需求刻出）✓；大基数是**先在的层级欲望**（不可达基数在 AC 质疑前已被构想） | **混合**：L = 纯条件类 ✓；大基数 = 意图型——AC 案例内部就分两半 |
| CR | 正交/可完备化系统类 | 完全由汇合保证的边界刻出 ✓ | 纯条件类 ✓ |
| 确定性 | DCFL | 由补封闭保证刻出 ✓ | 纯条件类 ✓ |
| 收缩 | 线性类型 | 由复制保证刻出 ✓ | 纯条件类 ✓ |
| Fubini | 主值对象 | 边界刻出 ✓ | 纯条件类 ✓ |

**重测结论**：6 样本中 4 纯条件类 + 2 混合（LEM/AC）——定义需要再一刀：**条件类对象两亚型**：
- **纯条件类**（边界刻出，无先在意图）：正交系统/DCFL/线性类型/主值；
- **意图条件类**（纲领性意图先于律质疑，律的边界事后追认）：Brouwer 序列/大基数。

**修正吸收**：T2 预测卡再精化——T2 → α+元层主；β 弱成分通常为**纯条件类**；若该律的质疑运动**先于形式化**（Brouwer 早于形式系统 20 年——正是律史文档已有记录的"错位"），则可能出现**意图条件类**（更强的 β）——**律史错位参数与 β 强度相关**：错位越大（直觉运动先行），β 越强。AC/LEM 恰是全库错位最大的两例 ✓✓。

**重测红利（意外收获）**：七阶段模型的 L1–L3 期（潜默-摩擦期）长度与涌现类型的联系被首次量化挂钩——**社会性先行运动（直觉主义/构造主义）是 β 成分的放大器**。这条规律可前瞻使用：候选律若已有活跃的反对运动，其 T2 β 预测应上调。

## 三、重测 3：γ 五形态回溯全部 γ 事件

**新判据**：五形态（表征/因果/渐近/成熟/翻译），翻译型 = 失效模式对象化。

全库 γ 事件重新归档（28 事件）：

|---|---|---|---|

| 理想论（H38） | 因果型 | 因果型 | — |
| 逆半群（H40） | 因果型 | 因果型 | — |
| bang（H36） | 因果型 | 因果型 | — |
| Desargues 表征（H37） | 表征型 | 表征型 | — |
| Stone/Hochster（H41） | 表征（对偶强化） | 表征型·对偶强化亚型 | 亚型正式化 |
| Ostrowski（H34） | 渐近型 | 渐近型 | — |
| dequantization（H39） | 渐近型 | 渐近型 | — |
| Tonelli 免费区（H30） | （反向涌现，未归 γ） | **保持非 γ**——免费区不是回收而是定价（γ 收编"旧律"，免费区是"新免费"，方向相反） | 明确排除 ✓ |
| 相伴素数/特殊化序/关键对/拓扑荷冻结/左右完备分裂 | 散落观察 | **翻译型**（原"病即信息"） | 统一收编 ✓ |
| Minty 表征（H32） | γ 辅 | **表征型**（单调性 ⇔ 图形互补——正式 γ 事件而非辅） | 升格 ✓ |
| Urysohn 度量化（H41） | 表征链 | **表征型**（T2 分离 ⇔ 度量化条件） | 归档 ✓ |
| Wagner–Preston（H40） | 因果侧 | 因果（动机）+ 表征（定理）**双标**——动机与定理可分 | **双标制登记** |

**重测结论**：
1. 五形态覆盖全部 28 事件，**无一落入形态间隙**——分类学完备性回溯通过；
2. **Tonelli 免费区的排除**澄清了 γ 边界（γ 收编旧律；免费区是新免费——形态学与方向性的双重判据）；
3. **双标制发现**：因果型与表征型可在同一对象上并存（逆半群：动机因果 + 定理表征）——γ 形态是**属性向量**而非互斥类别（与修订案 A 的向量制呼应——涌现类型学与 γ 形态学都收敛到向量制，**框架的深层一致性**）；
4. Minty/Urysohn 升格后，**乙级律 100% 携带表征型 γ**（12/12）——乙级定义（表征级律）与表征 γ 的对应从统计倾向升格为**定义性关联**。
