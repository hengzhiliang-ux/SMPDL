# 防前视构建试验：Riemann Hypothesis 的矩方法 / Selberg 正交性路线

> 目标：用 SMPDL 防前视构建流程重走 RH 的一条典型研究路线，定位无法闭合的子目标。  
> 路线：矩方法 / Selberg 正交性函数论 → 临界线 ζ(s) ≠ 0  
> 声明：本报告**不声称证明 RH**，仅作为方法论演练。  
> 版本：v1.0 | 日期：2026-10-12 | 框架：S/M/P × D/L · 防前视构建流程

---

## 0. 路线选择说明

在 RH 诊断中，常见的研究路线之一是：

> 通过研究 ζ(s) 在临界线上的矩（moments）
> \[
> I_k(T) = \int_0^T \bigl|\zeta(\tfrac12 + it)\bigr|^{2k}\,dt
> \]
> 的渐近行为，结合 Selberg 正交性（orthogonality of Dirichlet characters / mollifier method），试图控制零点离开临界线的密度，最终证明所有非平凡零点都位于 Re(s) = 1/2。

这条路线极具代表性，因为它同时涉及：
- **分析工具**：矩渐近、Dirichlet 多项式、mollifier
- **算术信息**：ζ 的 Euler 积、素数分布
- **前视诱惑**：从矩的渐近公式直接「看出」零点分布

我们将按 SMPDL 防前视构建流程逐步展开。

## 阶段 0：显式化目标与前提

### 0.1 目标命题 P

\[
\text{RH}: \quad \forall \rho \in \mathbb{C}, \; \zeta(\rho)=0 \land 0<\Re\rho<1 \implies \Re\rho = \tfrac12.
\]

### 0.2 前提集合 A

| 编号 | 前提 | 来源 |
|---|---|---|
| A1 | ζ(s) 在 Re(s) > 1 由 Euler 积定义，可解析延拓到 ℂ\{1}，s=1 为单极点 | 标准解析数论 |
| A2 | 函数方程：ξ(s) = ξ(1-s)，其中 ξ(s) = s(s-1)π^{-s/2}Γ(s/2)ζ(s) | Riemann 1859 |
| A3 | 非平凡零点位于临界带 0 < Re(s) < 1 | 函数方程 + Euler 积 |
| A4 | 零点计数函数 N(T) ~ T/(2π) log(T/(2πe)) | von Mangoldt |
| A5 | Selberg 正交性关系：对“典型”Dirichlet 多项式有均值消去 | Selberg |
| A6 | 矩猜想（Moment Hypothesis）：I_k(T) ~ C_k T (log T)^{k^2} | Keating–Snaith / CFKRS |
| A7 | 零点密度估计：N(σ,T) ≪ T^{1-c(σ-1/2)} 对某些 σ 成立 | Ingham, Huxley 等 |

### 0.3 S/M/P 显式化

| 层 | 显式化内容 |
|---|---|
| **S（语义）** | 把「所有零点在临界线上」翻译成全称量词 + 解析延拓语言；区分「临界线」与「临界带」。 |
| **M（数学）** | 目标等价于证明 N(σ,T) = 0 对所有 σ > 1/2；等价于无 off-line 零点。 |
| **P（编程）** | 可用 Lean 的 `riemannHypothesis` 表述；当前数学库远未覆盖所需解析数论。 |

## 阶段 1：反向草图（子目标树，全部 OPEN）

### 1.1 目标分解

```
P: RH 成立
├── G1: 零点密度 N(σ,T) = 0 对所有 σ > 1/2
│   ├── G2: 对某个 σ_0 > 1/2，证明 N(σ_0,T) = o(T)
│   │   ├── G3: 获得 N(σ_0,T) 的上界估计
│   │   │   ├── G4: 建立 Dirichlet 多项式大值估计
│   │   │   │   ├── G5: 使用矩方法控制 ζ(σ_0 + it) 的 L^k 范数
│   │   │   │   │   ├── G6: 证明 I_k(T) 的精确渐近公式
│   │   │   │   │   └── G7: 从 I_k(T) 推出点态/大值控制
│   │   │   │   └── G8: 使用 Selberg 正交性减少 Dirichlet 多项式相关性
│   │   │   └── G9: 将大值估计转化为零点密度估计（Ingham–Huxley 型）
│   │   └── G10: 证明 o(T) 足以推出 N(σ_0,T) = 0
│   └── G11: 从单一 σ_0 推广到所有 σ > 1/2
└── G12: N(σ,T)=0 等价于 RH
```

### 1.2 前视风险标记

| 子目标 | 前视风险等级 | 原因 |
|---|---|---|
| G6 | 🟡 中 | 矩猜想本身未被证明（k≥3 以上）。 |
| G7 | 🔴 高 | 从 L^k 范数到大值控制需要额外的覆盖/插值论证，常被省略。 |
| G8 | 🟡 中 | Selberg 正交性对一般 Dirichlet 多项式成立，但对 ζ 本身的 mollifier 需要额外验证。 |
| G10 | 🔴 高 | N(σ_0,T) 是非负整数函数；o(T) 只说明密度为零，不说明零点个数为零。 |
| G11 | 🟡 中 | 单一 σ_0 的推广依赖连续性/凸性论证，可能隐藏边界问题。 |

## 阶段 2：正向重写（逐条闭合）

### 2.1 G12：N(σ,T)=0 ⇔ RH

**正向证明**：若 N(σ,T)=0 对所有 σ>1/2，则没有实部 >1/2 的零点；由函数方程 A2，也没有实部 <1/2 的零点；故所有非平凡零点实部 = 1/2。

**状态**：✅ CLOSED（依赖 A2, A3）

### 2.2 G1：RH ⇔ N(σ,T)=0 对所有 σ>1/2

这是 G12 的重新表述，已经闭合。

**状态**：✅ CLOSED

### 2.3 G2：证明存在 σ_0 > 1/2 使 N(σ_0,T) = o(T)

**分析**：已有结果（Ingham 1926）：
\[
N(\sigma, T) \ll T^{\frac{3(1-\sigma)}{2-\sigma}} (\log T)^5.
\]
当 σ > 4/5 时，指数 < 1，因此 N(σ,T) = o(T)。

**状态**：✅ CLOSED（对 σ_0 > 4/5）

### 2.4 G3：获得 N(σ_0,T) 的上界估计

已有的零点密度定理给出了上界，但没有给出零点的精确计数。

**状态**：✅ CLOSED（作为上界）

### 2.5 G4：建立 Dirichlet 多项式大值估计

这是矩方法/正交性方法的核心。需要证明：对适当的 Dirichlet 多项式
\[
D(t) = \sum_{n\leq N} a_n n^{-it},
\]
在“典型”t 处不会同时取大值。

**正向困难**：
- 需要选择系数 a_n；
- 需要控制 D(t) 与 ζ(σ_0+it) 的联合分布；
- Selberg 正交性给出均值消去，但大值集合可能测度很小，正交性不直接适用。

**状态**：⚠️ PARTIAL（有工具，但无法直接闭合 G2→G1 的跳跃）

### 2.6 G5：矩方法控制 L^k 范数

矩方法研究
\[
I_k(T) = \int_0^T |\zeta(\tfrac12+it)|^{2k} dt.
\]

已知：
- k=1：I_1(T) ~ T log T（Hardy–Littlewood）
- k=2：I_2(T) ~ (1/(2π^2)) T (log T)^4（Ingham）
- k≥3：精确渐近公式仍是猜想（Numberphile-level open）

**状态**：⚠️ PARTIAL（仅 k=1,2 严格证明）

### 2.7 G6：证明 I_k(T) 的精确渐近公式

**关键问题**：即使矩猜想成立，G6 仍不是 G5 的充分条件，因为：
- I_k(T) 是 **临界线** Re(s)=1/2 上的矩；
- G5 需要的是 **Re(s)=σ_0 > 1/2** 上的 L^k 范数。

**前视漏洞暴露**：
> 很多人直觉上认为「临界线上的矩大 ⇒ off-line 上的值也大」，但这是把目标（off-line 无零点）需要的信息，悄悄注入了前提。

从 I_k(T) 到 off-line 控制，需要额外工具（如 Levinson 方法、mollifier 方法），不是矩本身能直接给出的。

**状态**：❌ **OPEN / FORESIGHT BLOCKED**

### 2.8 G7：从 I_k(T) 推出点态/大值控制

即使 G6 成立，从 L^k 范数到点态大值也需要：
- 覆盖引理（covering lemma）
- 插值不等式
- 对例外集合的测度控制

这些步骤在文献中存在，但把它们组合成直接证明 N(σ_0,T)=0 的链条，目前无人完成。

**状态**：❌ OPEN

### 2.9 G8：Selberg 正交性减少相关性

Selberg 正交性说明：对不同的原始特征 χ，L(s,χ) 在临界线上的值“近似正交”。但 ζ(s) 本身不是特征和；使用 mollifier 时，需要构造逼近 ζ(s)^{-1} 的 Dirichlet 多项式，其系数涉及 Möbius 函数的复杂结构。

**状态**：⚠️ PARTIAL（工具存在，但直接迁移到 ζ 的 off-line 控制不显然）

### 2.10 G9：大值估计 → 零点密度估计

Ingham–Huxley 型框架存在，但通常需要：
- Dirichlet 多项式的 L^p 范数估计；
- 双线性/多线性形式；
- 对素数分布的额外控制。

这些不是单一矩结果能提供的。

**状态**：⚠️ PARTIAL

### 2.11 G10：N(σ_0,T) = o(T) ⇒ N(σ_0,T) = 0

**这是前视的核心陷阱。**

N(σ_0,T) 是计数函数，取非负整数值。o(T) 只说明：
\[
\lim_{T\to\infty} \frac{N(\sigma_0,T)}{T} = 0.
\]
但 N(σ_0,T) 仍可能以 T^α（α<1）的速度增长，或间歇性跳跃。它**不禁止**存在有限个甚至无限个 off-line 零点，只要密度为零。

要从 o(T) 推出 N(σ_0,T)=0，需要更强的结构信息，例如：
- N(σ_0,T) 对 T 的显式上界为 O(1)；
- 零点实部离散性或刚性；
- 某种解析函数的零点唯一性定理。

这些目前都没有。

**状态**：❌ **OPEN / FORESIGHT BLOCKED**

### 2.12 G11：从单一 σ_0 推广到所有 σ > 1/2

即使 G10 成立，也需要连续性论证。零点计数 N(σ,T) 作为 σ 的函数具有单调性（σ 越大，区域越小，N 越小），所以从 N(σ_0,T)=0 可以直接推出 N(σ,T)=0 对所有 σ ≥ σ_0。但区间 (1/2, σ_0) 仍需要额外覆盖。

若 σ_0 可以任意接近 1/2，则结论成立。但当前零点密度定理只能做到 σ_0 > 4/5 等固定值，无法推到 σ_0 ↓ 1/2。

**状态**：❌ OPEN

## 阶段 3：双向验证

对每个已闭合或部分闭合的子目标，检查其是否同时服务于「从前提推导」和「向目标推进」。

| 子目标 | A → G？ | G → P？ | 状态 |
|---|---|---|---|
| G12 | ✅ A2+A3 | ✅ 等价表述 | 闭合 |
| G2 | ✅ Ingham 密度定理 | ❌ 仅对 σ>4/5，不足以覆盖 (1/2,1] | 部分 |
| G6 | ❌ 临界线矩 ≠ off-line 控制 | ❌ 不能直接服务 G1 | 前视 |
| G10 | ✅ o(T) 是上界 | ❌ o(T) 不蕴含 =0 | 前视 |
| G11 | ✅ 单调性 | ❌ 无法将 σ_0 推至 1/2 | 开放 |

**结论**：G6 和 G10 是两条主要的前视断裂边。

## 阶段 4：等价循环探测

检查证明中是否用 RH 的等价命题来证明 RH。

| 候选循环 | 是否循环 | 说明 |
|---|---|---|
| 用 Lindelöf 假设 ⇒ RH | ✅ 循环 | Lindelöf 与 RH 等价性未证明；不能互相证。 |
| 用矩猜想 ⇒ RH | ✅ 循环 | 矩猜想是独立假设，且其蕴含方向未建立。 |
| 用「所有零点在临界线」作为 G12 的定义 | ❌ 不循环 | 这是显式等价改写，不是证明。 |

**发现**：很多 RH「证明尝试」暗含循环：先假设某个与 RH 等价的猜想（如 Lindelöf、密度假设、矩猜想），然后用它推出 RH。这在逻辑上不构成证明，除非该等价猜想本身已被独立证明。

## 阶段 5：边界扫描

### 5.1 退化情况

| 情况 | 扫描结果 |
|---|---|
| σ = 1/2 | 临界线本身，不是 off-line；目标不处理。 |
| σ = 1 | Euler 积绝对收敛区域，已知无零点。 |
| T → 0 | 非平凡零点要求 Im(ρ) > 0，T 小的时候无零点，trivial。 |
| k = 0 | I_0(T) = T，无信息。 |
| k → ∞ | 矩增长极快，不收敛，无法直接用于控制。 |

### 5.2 隐含假设

- 矩方法通常假设 ζ 在临界线上的「典型行为」能代表全局行为；这是启发式，不是定理。
- Selberg 正交性对「高度」T 的平均成立，但零点位置是点态对象。

## 阶段 6：S/M/P × D/L 判定

| 审查项 | 结果 | 说明 |
|---|---|---|
| S*D | ✅ | 术语（临界线/临界带/零点密度）定义清晰，依存完整。 |
| S*L | ⚠️ | 「矩方法能控制零点」在叙述中常被当作因果，实为启发式。 |
| M*D | ⚠️ | 工具链存在，但 G6→G7→G10 的依赖边未闭合。 |
| M*L | ❌ | G10 的 o(T) ⇒ =0 是非法推理；G11 的推广缺边界控制。 |
| P*D | ❌ | Lean mathlib 缺乏解析数论工具链，无法形式化。 |
| P*L | ❌ | 无 tactic 能自动处理从积分范数到点态零点的跳跃。 |
| 跨层 D/L 映射 | ❌ | S 层的「矩控制零点」直觉无法映射为 M 层的有效定理。 |

**综合判定**：❌ **构建失败，M*L 与跨层映射断裂**。

## 阶段 7：修复策略与最近邻定理地图

### 7.1 断裂点修复建议

| 断裂点 | 修复方向 | 相关已知结果 |
|---|---|---|
| G6（临界线矩 ≠ off-line 控制） | 改研究 Re(s)=σ_0 上的矩或值分布 | Bohr–Jessen, Jessen–Wintner |
| G10（o(T) ⇒ =0） | 需要 N(σ,T) = O(1) 或零点实部刚性 | 目前无通用方法 |
| G11（σ_0 ↓ 1/2） | 需要零点密度定理在 σ→1/2 时指数 <1 | 密度假设（Density Hypothesis）尚未证明 |

### 7.2 最近邻已证定理地图

| 目标缺口 | 最接近的已证结果 | 距离 |
|---|---|---|
| 控制 off-line 零点 | Ingham–Huxley 零点密度定理 | 已证 σ > 4/5，距 σ > 1/2 有 gap |
| 临界线矩 | Hardy–Littlewood / Ingham（k=1,2） | k≥3 为猜想 |
| 零点垂直分布 | Selberg 正交性、Montgomery 对关联猜想（仍开放） | 部分证明 |
| 从解析信息到零点刚性 | Backlund–Landau 引理 | 仅用于数值验证有限区间 |

### 7.3 诚实结论

矩方法 / Selberg 正交性路线目前无法闭合为 RH 的证明。主要障碍不是工具不够强，而是存在两处结构性前视：

1. **把目标需要的信息（off-line 控制）伪装成可由临界线矩推出**；
2. **把渐进密度为零误解为零点个数为零**。

这两处错误在启发式讨论中极易出现，防前视构建流程能把它们显式标记为 OPEN。
