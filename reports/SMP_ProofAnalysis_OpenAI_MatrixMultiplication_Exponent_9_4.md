## 1. 命题与声明

论文声称证明

\[
\omega \le \frac{9}{4} = 2.25 \text{ over } \mathbb{C},
\]

即：两个 n×n 矩阵相乘可以在 O_ε(n^{9/4+ε}) 次算术运算内完成，对任意 ε > 0。

这里 ω 是矩阵乘法指数，定义为使得 n×n 矩阵乘法可在 O(n^{ω+ε}) 时间内完成的下确界。当前人类已知的最佳上界约为 ω ≈ 2.37（由 Vasserotovskaya-Williams、Le Gall 等人通过激光方法逐步改进得到）。声明 ω ≤ 2.25 是一次巨大跃迁。

已知背景包括：
- Strassen (1969) 证明 ω < 2.81。
- Coppersmith–Winograd (1990) 证明 ω < 2.376。
- Stothers (2010)、Vasserotovskaya-Williams (2012)、Le Gall (2014) 逐步改进至约 2.373。
- 激光方法及其张量分解是现有所有突破的核心工具。

### 2.2 S*L — 语义逻辑结构

- 命题形式清晰：存在显式构造使得矩阵乘法指数不超过 9/4。
- 但"秩上界"到"ω 上界"的转换并非自动成立：必须证明该张量的边界秩或渐近秩足够低，并且退化求和可以被任意矩阵乘法张量实现。
- 风险：可能把「某个特定张量的低秩」误作「所有矩阵乘法的低复杂度」；或在复数域与有限域之间混用结论。
- 矩形矩阵乘法与方阵乘法的界限可能被混淆。

### 2.4 M*L — 数学逻辑结构

- 典型证明结构：构造一个三阶张量 T，证明其边界秩低于某个阈值，然后通过激光方法或渐近和将此秩上界转换为矩阵乘法指数的改进。
- 陷阱：张量的边界秩（border rank）低于某个值，并不直接给出 ω 的上界；需要额外的退化（degeneration）和求和（sum）论证。
- 或者：证明中的"张量"可能不是标准的矩阵乘法张量 ⟨n,n,n⟩，其适用范围需要严格验证。

### 2.5 P*D — 编程/形式化依存

- README 提到 Lean，但未说明形式化范围。
- 风险：Lean 可能只形式化了某个特定张量的秩计算或激光方法的某个辅助引理，而非完整的「ω ≤ 9/4」主定理。
- 特别风险：形式化中可能只验证了某个小尺寸张量的低秩，但未证明该结果可放大（blow-up）到任意 n。

### 2.6 P*L — 编程逻辑结构

- 如果形式化存在，需要检查：
  - 是否严格定义了矩阵乘法指数 ω；
  - 是否构造了显式张量并证明其边界秩；
  - 是否完成了从张量秩到 ω 上界的完整转换；
  - 是否处理了复数域上的特征零假设；
  - 是否区分了方阵乘法与矩形矩阵乘法。

## 5. 人工可能需要确认/补充证明的地方

1. **显式张量构造**：给出声称达到 ω ≤ 9/4 的具体张量 T，并公开其边界秩估计。
2. **从秩上界到 ω 上界**：完整证明该张量的低边界秩如何通过激光方法、渐近和或退化技术推出 ω ≤ 9/4。
3. **特征零假设**：说明证明是否仅适用于复数域，以及能否推广到其他特征零域或有限域。
4. **与已知结果的对比**：明确解释为何新结果优于 Coppersmith-Winograd、Stothers、Vasserotovskaya-Williams、Le Gall 等已有上界。
5. **矩形与方阵的区别**：澄清结果是否针对方阵乘法，避免与矩形矩阵乘法指数的混淆。
6. **Lean 主定理范围**：确认 Lean 文件中的 `theorem` 是否 literally 是 `ω ≤ 9/4`，还是某个更弱的辅助结果。
7. **数值常数验证**：验证所有边界秩估计中的数值常数和 ε-依赖性是否正确。
