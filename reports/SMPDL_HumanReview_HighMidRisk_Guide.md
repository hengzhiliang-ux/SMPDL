# SMPDL 高风险 / 中风险声明的人类科学家审查指南

> 基于 Göttingen S/M/P × D/L v1.6  
> 日期：2026-10-13

---

## 1. 为什么需要人类科学家？

SMPDL 的六格审计可以定位风险层（S*D、S*L、M*D、M*L、P*D、P*L），但**不能替代领域专家**对以下内容的判断：

- 外部定理的适用域是否被正确理解；
- 复杂构造是否满足定理前提；
- 自然语言证明与形式化代码之间的语义映射是否忠实；
- 命题是否与已知数学结果相容。

本指南说明五人工岗位（A/B/C/D/E）在高风险、中风险声明中的具体审查动作。

---

## 2. 风险等级定义

| 等级 | 标记 | 含义 |
|---|---|---|
| 高风险 | 🔴/🟡 | 声明强度接近或超过当前数学已知界限；依赖大量外部输入；量词/范畴边界不清；形式化缺失 |
| 中低风险 | 🟢/🟡 | 声明方向与领域已知结果一致；依赖链已明确化；但仍需验证收敛/边界/技术性引理 |
| 已证伪/错误 | 🔴 | 已发现具体反例、符号错误、前提不满足或证明已被官方修复/撤回 |

## 3. 高风险声明：人类科学家审查清单

### 3.1 通用动作

| 岗位 | 核心任务 | 可交付物 |
|---|---|---|
| **A 概念奇点** | 识别声明中“一听就不对劲”的概念跳跃 | 概念奇点清单，标注每个奇点的强度与可接受条件 |
| **B 语义忠实审查** | 逐句核对自然语言证明与摘要、标题、形式化代码之间的语义一致性 | 语义偏差报告，列出 NL↔公式↔代码 的不一致 |
| **C 缺口刻画** | 列出“证明需要什么但尚未给出”的外部引理/假设 | 缺口清单，区分已存在但未引用 vs 尚未证明 |
| **D 陷阱预见** | 针对 TRAP-CHECK v1.0 七类陷阱扫描全文 | 陷阱扫描表，标注高概率触发点 |
| **E 验证解读** | 汇总 A–D 输出，给出“可接受 / 需修改 / 不可接受”的二元/三元判定 | 验证结论与复核路径 |

### 3.2 高风险声明的专项审查

#### 3.2.1 量词范围陷阱

- **检查标题中的全称词**：every / all / arbitrary / every prime / every dimension。
- **动作**：在正文中找到该全称词的定义域；若存在弱化（如“for sufficiently large…”），必须在摘要中披露。
- **工具**：制作“标题量词 ↔ 正文量词”对照表。

#### 3.2.2 外部定理前提陷阱

- **检查**：作者是否明确列出每个外部定理的**全部**前提条件。
- **动作**：逐条核对同族论文/外部结果是否满足这些前提；特别关注修订后的 companion papers。
- **输出**：前提满足矩阵（定理 × 假设 × 是否满足）。

#### 3.2.3 依赖链多米诺风险

- **检查**：论文是否依赖同族其他手稿的正面结论。
- **动作**：画出依赖图，标注哪些上游结论已有独立验证、哪些仍悬而未决。
- **输出**：依赖图 + 风险评级。

#### 3.2.4 P 层缺失风险

- **检查**：是否有 Lean/Coq 形式化覆盖核心结论。
- **动作**：若 P 层缺失，要求作者明确说明“哪些步骤无法被机器检查”；若 P 层存在，检查其范围声明。
- **输出**：形式化覆盖图。

## 4. 中低风险声明：人类科学家审查清单

### 4.1 通用动作

中低风险声明通常方向正确，但需要验证技术性细节。审查重点从“是否可能成立”转向“证明是否严密”。

| 岗位 | 核心任务 | 可交付物 |
|---|---|---|
| **A 概念奇点** | 检查边界条件是否被合理处理 | 边界条件清单 |
| **B 语义忠实审查** | 核对术语在自然语言、公式与图示中的统一性 | 术语一致性报告 |
| **C 缺口刻画** | 识别从外部定理到结论之间的中间引理跳跃 | 中间步骤清单 |
| **D 陷阱预见** | 扫描边界行为、收敛速率、条件概率等技术陷阱 | 陷阱扫描表 |
| **E 验证解读** | 给出“接受 / 小修 / 大修”建议 | 验证结论 |

### 4.2 中低风险声明的专项审查

#### 4.2.1 收敛性论证

- **检查**：是否给出明确的拓扑/度量空间、收敛模式（a.s. / in probability / weakly / in distribution）。
- **动作**：验证 tightness 证明、极限唯一性刻画、边界条件控制。

#### 4.2.2 边界条件

- **检查**：模型在边界上是否定义良好；边界条件是否一致。
- **动作**：构造简单测试用例，验证边界处的行为是否符合直觉。

#### 4.2.3 依赖链明确化

- **检查**：论文是否明确说明每个外部结果的应用位置。
- **动作**：确认 companion results 的版本与假设已被满足。

## 5. 针对本批次 OpenAI 样本的具体审查建议

### 5.1 高风险：Selmer 逆命题（每个素数）

- **A**：质疑“every prime”是否意指所有素数，包括 `p=2` 和坏约化素数。
- **B**：核对摘要中的“every prime”与正文中可能存在的弱化条件是否一致。
- **C**：列出证明中所有隐含假设：BSD、Tate–Shafarevich 有限性、`p`-adic L-函数非零等。
- **D**：扫描“量词范围陷阱”和“隐藏假设陷阱”。
- **E**：邀请椭圆曲线/Selmer 群专家做同行审阅，重点检查 `p`-adic 方法和 Euler 系输入。

### 5.2 高风险：Kähler 四维 log canonical flip 终止性

- **A**：质疑“generalized log canonical”在紧 Kähler（非射影）范畴下的定义是否自洽。
- **B**：核对“独立相对 MMP”与“双有理比较”输入是否被正确引用。
- **C**：列出同族修订稿清单，确认每个输入的当前版本与假设。
- **D**：扫描“前提域陷阱”——射影 MMP 定理是否被直接套用到 Kähler 情形。
- **E**：邀请复代数几何/MMP 专家审阅，重点检查 positivity 与 contraction 论证。

### 5.3 中低风险：GFF/Lipschitz 两弧边界极限

- **A**：检查“two-arc boundary data”的精确定义（弧长、边界类型、高度差）。
- **B**：核对“条件切割”与“环估计”是否确实从 companion weighted annulus circuit theorem 推导。
- **C**：列出从该定理到 GFF 收敛之间的所有中间引理。
- **D**：扫描“位置默认陷阱”——边界附件点不能默认与 bulk 行为相同。
- **E**：邀请概率论/统计物理专家复核收敛论证与边界处理。

### 5.4 已修复/错误：taming ⇒ compatibility（09-23 版）

- **A/B**：核对“cone-equality”与“strict-inclusion”在正文与图示中的表述。
- **C/D**：构造简单四维近复结构实例，验证 tamed 形式集合是否真严格包含 compatible 形式集合。
- **E**：确认 10-06 版修正是否覆盖了所有受影响的推论。

### 5.5 已修复/错误：Ashkin–Teller 联合 scaling limit（09-25 版）

- **A/B**：核对“joint scaling limit”是否同时要求边缘分布与联合分布收敛。
- **C/D**：检查 crossing、boundary-attachment、conditioning、convergence 四处的具体引理。
- **E**：对比 09-25 与 10-06 版本 PDF，定位具体修改段落。

### 5.6 已修复/错误：有限普通 Kähler MMP（09-24 版）

- **A/B**：核对“ordinary”在正文中的定义，避免与射影 MMP 混淆。
- **C/D**：列出所有被声明为“已知结果”的输入定理，确认其 Kähler 版本是否存在。
- **E**：对比 09-24、10-05、10-06、10-07 版本，定位 positivity/contraction 论证的扩展位置。

## 7. 与 SMPDL 六格审计的衔接

本指南中的 A/B/C/D/E 五岗位输出，应直接填入 SMPDL 审计报告的“可执行验证建议”章节。每份审计报告的风险等级，由六格审计中失败的格子决定；人类科学家的具体任务，由本指南根据风险等级分配。

## 文献引用纪律检查

依据 SMPDL 文献引用纪律（真实性核查 + 支持性核查），本报告审查如下：

| 引用对象 | 真实性 | 支持性 | 说明 |
|---|---|---|---|
| 引用的数学/逻辑/编程经典结果 | ✅ 真实 | ✅ 支持 | 方法论文件引用的 Curry-Howard、模型论、类型论等概念属于公共知识。 |
| 引用的具体论文/书籍 | ⚠️ 待查 | ⚠️ 待查 | 若引用具体著作，需按真实性 + 支持性纪律核查。 |
| OpenAI/AI 相关案例 | ⚠️ 待查 | ⚠️ 待查 | 若用 OpenAI 论文作为例子，需核对原论文真实性与范围。 |

**核查结论**：本方法论/指南文件主要依赖经典概念；对具体案例或专著的引用应补充逐条核查。
