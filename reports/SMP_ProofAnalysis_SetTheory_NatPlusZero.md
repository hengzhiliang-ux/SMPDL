# S/M/P × D/L 审计报告：集合论中自然数加法的右单位元

> **定理**：∀ n ∈ ℕ，n + 0 = n。
> 
> **来源**：Peano 算术 / 集合论自然数构造；加法由递归定理定义，n + 0 = n 是定义的直接推论。
> 
> **分析日期**：2026-10-13 | **审计框架**：Göttingen S/M/P × D/L v1.5 | **AxiomaticBase**：`SetTheory`
> 
> **风险评级**：⚪ 已确认正确（在 ZFC + Peano/集合论自然数公理体系内）。

---

## 0. 分析目标

1. 对集合论中“n + 0 = n”的证明做一次 S/M/P × D/L 六格审计。
2. 明确该证明依赖的核心假设：自然数的集合论构造、递归定义定理、函数的外延性。
3. 为后续与类型论版本做同构对比建立基准（S/M/P 标签、证明骨架、风险点）。
4. 检查自然语言中是否把“由定义即得”误解为“无需基础”。

## 1. S 层审计（语义层）

### 1.1 S*D：语义依存

| 自然语言元素 | 支持的后续元素 | 依赖说明 |
|---|---|---|
| 自然数集 ℕ | Peano 公理 / von Neumann 构造 | 需先承认 ℕ 存在 |
| 加法运算 + | 递归定义定理 | 需证明可唯一定义二元函数 |
| n + 0 = n | 加法递归定义的第一条 | 直接来自定义 |
| “对任意 n” | 全称量词 ∀n ∈ ℕ | 量词覆盖所有自然数 |
| 等式 = | 外延相等 | 集合论中对象同一的标准 |

### 1.2 S*L：语义逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 量词显式化 | ✅ | “∀ n ∈ ℕ”已显式。 |
| 术语单义性 | ⚠️ 中 | “自然数”在集合论中可指 Peano 结构或 von Neumann 序数；含义相同但构造不同。 |
| 隐喻/图示依赖 | ✅ | 无图示依赖。 |
| 隐含跳跃 | 🟡 中 | 自然语言常说“由加法定义即得”，但定义的合法性依赖递归定理。 |

**S 层结论**：该命题的自然语言证明几乎为空——它直接来自加法定义。但定义的合法性本身依赖集合论的递归定理，是常被省略的语义基础。

## 2. M 层审计（数学层）

### 2.1 M*D：数学依存

```text
SetTheory_NatPlusZero
    │
    ├── ZFC (or Peano Arithmetic)
    │       └── Axioms sufficient to define natural numbers
    │
    ├── Natural numbers ℕ
    │       ├── 0 ∈ ℕ
    │       └── successor S : ℕ → ℕ (injective, 0 not in image)
    │
    ├── Recursion Theorem
    │       └── For any set A, a ∈ A, and g : A → A,
    │           there exists a unique function h : ℕ → A such that
    │           h(0) = a and h(S(n)) = g(h(n))
    │
    ├── Definition of addition by recursion
    │       ├── Fix m ∈ ℕ
    │       ├── Let A = ℕ, a = m, g = S
    │       └── Obtain unique h_m : ℕ → ℕ with
    │           h_m(0) = m  and  h_m(S(n)) = S(h_m(n))
    │
    ├── Notation: m + n := h_m(n)
    │
    └── Immediate conclusion
            └── m + 0 = h_m(0) = m
```

| 数学对象 | 结构签名 | 在证明中的作用 |
|---|---|---|
| 自然数结构 (ℕ, 0, S) | Peano 结构 / von Neumann 序数 ω | 加法定义的论域 |
| 递归定理 | 基于 ℕ 的初始对象性质 | 保证加法可唯一递归定义 |
| 函数 h_m : ℕ → ℕ | 对每个 m 唯一确定的递归函数 | 加法定义的核心 |
| 0 | 自然数初始元素 | 等式右侧 |
| 加法 + | m + n := h_m(n) | 递归定义的二元运算 |
| 外延相等 = | 集合论中函数/对象的同一标准 | 等式成立判据 |

### 2.2 M*L：数学逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 公理系统一致性 | ✅ | 在 ZFC / Peano 算术内可严格定义加法。 |
| 构造合法性 | ✅ | 递归定理保证 h_m 唯一存在。 |
| 量词范围 | ✅ | 对任意 n ∈ ℕ 成立。 |
| 边界情况 | ✅ | n = 0 时 0 + 0 = 0，同样由定义成立。 |
| 隐藏假设 | 🟡 中 | 加法定义依赖递归定理；若基础只有原始递归函数而无法构造一般递归，定义可能不合法。 |
| 等价命题循环 | ✅ | 无。 |

**M 层结论**：证明在集合论内逻辑结构完整。核心依赖为递归定理与函数的外延相等。n + 0 = n 是定义的直接推论。

## 3. P 层审计（编程/形式化层）

### 3.1 P*D：形式化依存

> 在 Mathlib/Lean 4 中，自然数加法同样递归定义，但 Lean 的底层是依赖类型论而非集合论。集合论风格的证明可用 `rfl`（定义相等）完成，但用户需意识到底层逻辑不同。

```text
SetTheory_NatPlusZero
    │
    ├── Mathlib.Data.Nat.Basic
    │       └── Nat, Nat.add
    │
    ├── Nat.add definition by recursion
    │       ├── add_zero (n + 0 = n)
    │       └── add_succ (n + succ m = succ (n + m))
    │
    └── Theorem: ∀ n, n + 0 = n
            └── Proof: `intro n; rfl`  (definitional equality)
```

### 3.2 P*L：形式化逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 语法可编译 | ✅ | `∀ n, n + 0 = n` 在 Lean 中可证，用 `rfl` 即可。 |
| 类型签名一致 | ✅ | 输入：n : ℕ；输出：n + 0 = n。 |
| 定义等价 | ✅ | `Nat.add` 与递归定义的加法等价。 |
| 命题等式 | ✅ | 目标等式是定义等式，可直接用 `rfl`。 |
| `#print axioms` | 🟢 低 | 依赖自然数归纳与类型论计算规则；不直接依赖选择公理。 |

**P 层结论**：在 Lean/Mathlib 中证明 trivial，但用户应注意：Lean 的底层是类型论，而非集合论。`rfl` 的成功依赖的是类型论中的 β-归约，而非集合论的外延性。

## 6. 结论

集合论中 n + 0 = n 的证明是一个**定义直接蕴含结论**的极简案例：

- **S 层**：自然语言几乎为空，但“由定义即得”依赖加法定义的合法性。
- **M 层**：数学结构完整，核心为 `Recursion Theorem → unique h_n → h_n(0) = n`。
- **P 层**：Lean 中 `rfl` 即可完成，但底层逻辑从集合论外延性转向类型论计算规则。
- **跨层映射**：三层对应关系明确，同构强度为 ⭐⭐⭐ 高。

该样本建议标记为：`SetTheory`、`S-ISO / M-ISO / P-ISO`（自洽），并作为与 `TypeTheory` 版本对比的基准版本。
