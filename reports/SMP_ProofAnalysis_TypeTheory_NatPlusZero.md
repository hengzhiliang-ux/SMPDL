# S/M/P × D/L 审计报告：类型论中自然数加法的右单位元

> **定理**：∀ n : ℕ，n + 0 = n。
> 
> **来源**：Martin-Löf 类型论 / 归纳类型理论；自然数 ℕ 为归纳类型，加法递归定义，n + 0 = n 需用归纳原理证明。
> 
> **分析日期**：2026-10-13 | **审计框架**：Göttingen S/M/P × D/L v1.5 | **AxiomaticBase**：`TypeTheory`
> 
> **风险评级**：⚪ 已确认正确（在 Martin-Löf / 归纳类型理论体系内）。

---

## 0. 分析目标

1. 对类型论中“n + 0 = n”的归纳证明做一次 S/M/P × D/L 六格审计。
2. 明确该证明依赖的核心假设：ℕ 作为归纳类型、加法的递归定义、命题等式 `=` 作为归纳族。
3. 为后续与集合论版本做同构对比建立差异图谱（S/M/P 标签、证明骨架、风险点）。
4. 检查自然语言中是否把“按 n 归纳”当作显然步骤，忽略类型论中等式的构造性。

## 1. S 层审计（语义层）

### 1.1 S*D：语义依存

| 自然语言元素 | 支持的后续元素 | 依赖说明 |
|---|---|---|
| 自然数类型 ℕ | 归纳类型，构造子 0 和 succ | 需先承认类型论归纳基础 |
| 加法 + | 对第一个参数递归定义 | 关键定义 |
| 0 + n = n | 加法定义的 base case | 直接来自定义 |
| (succ m) + n = succ (m + n) | 加法定义的 step case | 直接来自定义 |
| 按 n 归纳 | ℕ 的归纳原理 | 证明策略 |
| n + 0 = n | 归纳结论 | 不是定义直接得出 |
| 等式 = | 命题等式（identity type） | 类型论中的证明对象 |

### 1.2 S*L：语义逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 量词显式化 | ✅ | “∀ n : ℕ”已显式。 |
| 术语单义性 | ⚠️ 中 | “=”在类型论中是命题等式（identity type / Eq），不是集合论的外延相等。 |
| 隐喻/图示依赖 | ✅ | 无图示依赖。 |
| 隐含跳跃 | 🟡 中 | 自然语言常写“对 n 归纳即得”，但归纳步骤需显式使用 succ 情形下的定义。 |
| 蕴涵方向 | ✅ | 由 base case + induction hypothesis + step case 推出结论，方向正确。 |

**S 层结论**：自然语言证明短，但关键语义差异在于“=”是类型论中的归纳族，且加法定义的结构使得 n + 0 = n 需要归纳证明，而非定义直接给出。

## 2. M 层审计（数学层）

### 2.1 M*D：数学依存

```text
TypeTheory_NatPlusZero
    │
    ├── Type-theoretic foundation
    │       ├── Π-types, Σ-types, identity types
    │       └── Inductive types with constructors and recursion/induction principles
    │
    ├── Inductive type ℕ
    │       ├── Constructor 0 : ℕ
    │       └── Constructor succ : ℕ → ℕ
    │
    ├── Induction principle on ℕ
    │       └── To prove ∀ n, P(n), show P(0) and ∀ k, P(k) ⇒ P(succ k)
    │
    ├── Definition of addition by recursion
    │       ├── add 0 n := n
    │       └── add (succ m) n := succ (add m n)
    │
    ├── Proof goal
    │       └── ∀ n : ℕ, add n 0 = n
    │
    └── Inductive proof
            ├── Base: add 0 0 = 0  (by definition)
            └── Step: assume add k 0 = k
                       add (succ k) 0
                       = succ (add k 0)   (by definition)
                       = succ k           (by induction hypothesis)
```

| 数学对象 | 结构签名 | 在证明中的作用 |
|---|---|---|
| 自然数类型 ℕ | 归纳类型，构造子 0, succ | 证明的归纳结构来源 |
| 加法 add : ℕ → ℕ → ℕ | 对第一个参数递归定义 | 核心运算 |
| 0 + n = n | 加法的 base case | 基础情形 |
| (succ m) + n = succ (m + n) | 加法的 step case | 归纳步骤 |
| 命题等式 = | identity type / Eq | 证明目标与归纳假设 |
| 归纳原理 | 与 ℕ 的归纳构造子配对 | 证明策略 |
| refl / rewrite | identity type 的构造子 / 替换规则 | P 层证明工具 |

### 2.2 M*L：数学逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 公理系统一致性 | ✅ | 在 Martin-Löf 类型论 / CoC / pCIC 内可严格证明。 |
| 构造合法性 | ✅ | 加法由 ℕ 的归纳原理合法定义；证明由同一归纳原理完成。 |
| 量词范围 | ✅ | 对任意 n : ℕ 成立。 |

## 3. P 层审计（编程/形式化层）

### 3.1 P*D：形式化依存

> 在 Lean 4 中，ℕ 是归纳类型，`Nat.add` 对第一个参数递归定义。`n + 0 = n` 的证明用 `induction` 或 `Nat.rec`。

```text
TypeTheory_NatPlusZero
    │
    ├── Nat : inductive type
    │       ├── Nat.zero
    │       └── Nat.succ (n : Nat)
    │
    ├── Nat.add : Nat → Nat → Nat
    │       ├── add_zero : ∀ n, 0 + n = n
    │       └── add_succ : ∀ m n, (succ m) + n = succ (m + n)
    │
    └── Theorem: ∀ n, n + 0 = n
            └── Proof by Nat.rec / induction
```

### 3.2 P*L：形式化逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 语法可编译 | ✅ | 在 Lean 4 中可用 `induction` 策略完成。 |
| 类型签名一致 | ✅ | 输入：n : ℕ；输出：n + 0 = n。 |
