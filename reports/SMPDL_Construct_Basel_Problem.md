# 防前视构建报告：Basel 问题 ζ(2) = π²/6

> 使用流程：`SMPDL_ProofConstruction_AntiForesight.md` v1.0  
> 案例：证明 Σ_{n=1}^∞ 1/n² = π²/6  
> 日期：2026-10-12

---

## 0. 显式化

### 0.1 目标命题 P

**自然语言**：自然数平方倒数之和等于 π²/6。  
**形式化**：

```
Σ_{n=1}^∞ 1/n² = Real.pi ^ 2 / 6
```

**结论类型**：无穷级数等式。

### 0.2 前提 A

- 实数 ℝ、无穷级数、收敛定义；
- Fourier 级数理论：函数可展开为三角级数，并在适当条件下逐点收敛；
- 积分与分部积分；
- π 的定义与三角函数周期性。

### 0.3 可用工具

- Fourier 级数展开；
- 分部积分计算系数；
- 逐点收敛定理；
- 代数整理。

### 0.4 禁用（含等价形式）

- 禁止直接使用 ζ(2)=π²/6 作为理由；
- 禁止在计算系数前假设 Fourier 级数会给出目标值；
- 禁止未经证明地交换无穷级数与代入 x=π 的操作。

## 1. 反向草图（全部标记 OPEN）

```
P: Σ 1/n² = π²/6
  G₁: 构造函数 f(x) = x² 在 [-π,π] 上的 Fourier 级数
    G₂: 计算 a_0 = (1/π)∫ x² dx = 2π²/3
      G₃: 计算 a_n = (1/π)∫ x² cos(nx) dx = (-1)^n · 4/n²
        G₄: 证明 Fourier 级数在 x=π 处收敛于 f(π)=π²
          G₅: 代入 x=π
            G₆: 利用 cos(nπ) = (-1)^n 化简
              G₇: 解出 Σ 1/n² = π²/6
```

**前视风险点**：

- G₄ 必须先证明收敛性，不能把「代入后等于 π²」当作已知。
- G₇ 必须是纯代数解方程，不能先知道答案再整理。

## 2. 正向重写

### 步骤 1：构造函数（闭合 G₁）

**主张**：令 f(x) = x²，定义在 [-π, π] 上并做周期延拓。  
**理由**：这是证明所需的显式函数。  
**前驱**：目标 P（需要找到能生成 1/n² 系数的函数）。  
**状态**：✅ 闭合。

### 步骤 2：计算 a_0（闭合 G₂）

**主张**：a_0 = (1/π)∫_{-π}^{π} x² dx = 2π²/3。  
**理由**：直接积分：∫ x² dx = x³/3，代入上下界得 2π³/3，再除以 π。  
**前驱**：步骤 1、积分运算。  
**状态**：✅ 闭合。

### 步骤 3：计算 a_n（闭合 G₃）

**主张**：a_n = (-1)^n · 4/n²。  
**理由**：

- 对 a_n = (1/π)∫ x² cos(nx) dx 做两次分部积分；
- 边界项因周期性消失；
- 得到 a_n = (4/(n²π)) · [x cos(nx)]_{-π}^{π} · (-1)^n 化简后为 (-1)^n · 4/n²。

**前驱**：步骤 1、分部积分、三角函数边界值。  
**状态**：✅ 闭合。

### 步骤 4：收敛性（闭合 G₄）

**主张**：f(x)=x² 的 Fourier 级数在 x=π 处收敛于 f(π)=π²。  
**理由**：f 分段光滑且周期延拓后在 x=π 连续，满足 Dirichlet 逐点收敛定理。  
**前驱**：步骤 1、Fourier 收敛定理。  
**状态**：✅ 闭合。

### 步骤 5：代入 x=π（闭合 G₅）

**主张**：π² = a_0/2 + Σ a_n cos(nπ)。  
**理由**：由步骤 4，级数在 x=π 收敛于 f(π)；将步骤 2、步骤 3 的系数代入。  
**前驱**：步骤 2、步骤 3、步骤 4。  
**状态**：✅ 闭合。

### 步骤 6：利用 cos(nπ)=(-1)^n（闭合 G₆）

**主张**：π² = π²/3 + 4 Σ 1/n²。  
**理由**：

- a_0/2 = π²/3；
- a_n cos(nπ) = (-1)^n · 4/n² · (-1)^n = 4/n²。

**前驱**：步骤 2、步骤 3、步骤 5。  
**状态**：✅ 闭合。

### 步骤 7：解出 ζ(2)（闭合 G₇ 与 P）

**主张**：Σ 1/n² = (π² - π²/3)/4 = π²/6。  
**理由**：由步骤 6 移项并除以 4。  
**前驱**：步骤 6。  
**状态**：✅ 闭合。
