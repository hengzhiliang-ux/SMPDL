# S*L / M*L / P*L 内生依存关系审查报告

**案例**：Rouse Ball「所有三角形都是等腰」经典谬误证明  
**框架**：S（语义）× L（逻辑）、M（数学）× L（逻辑）、P（编程）× L（逻辑）的三工序依存审查  
**目的**：验证在 S/M/P 各层内部加入「逻辑结构层 L」的依存关系分析，能否比单纯分层检查更早/更精确地定位漏洞  
**版本**：初探稿，未实装  

---

## 0. 证明原文

```text
任取三角形 ABC。设 AB 边的垂直平分线与 ∠C 的角平分线交于 P。
由 P 在 AB 垂直平分线上，得 PA = PB。
由 P 在 ∠C 角平分线上，向 AC、BC 作垂线 PU、PV，则 PU = PV。
于是直角三角形 PUA 与 PVB 全等（RHS），故 AU = BV。
又直角三角形 PUC 与 PVC 全等，故 CU = CV。
因此 AC = AU + CU = BV + CV = BC。证毕。
```

---

## 1. 审查框架说明

每一层都执行「三工序」：

| 工序 | 任务 | 输出 |
|---|---|---|
| **工序一 · 元素提取** | 列出该层中所有关键语义/数学/编程元素 | 元素清单 |
| **工序二 · 依存图构建** | 找出元素之间的支持、蕴涵、调用关系 | 有向图 / 依赖链 |
| **工序三 · 闭合性审查** | 检查依赖链是否闭合，是否有隐藏前提、非法跳跃、循环论证 | 风险点与断裂位置 |

最后把三层的断裂位置汇总到 L 层，判断漏洞根因。

---

## 2. S*L 审查：语义层 × 逻辑层

### 工序一：元素提取

| 编号 | 语义元素 | 类型 |
|---|---|---|
| S1 | 「任取三角形 ABC」 | 全称引入 + 几何对象声明 |
| S2 | 「AB 边的垂直平分线与 ∠C 的角平分线交于 P」 | 构造声明 |
| S3 | 「P 在 AB 垂直平分线上，得 PA = PB」 | 性质推导 |
| S4 | 「P 在 ∠C 角平分线上，向 AC、BC 作垂线 PU、PV」 | 构造 + 垂足声明 |
| S5 | 「PU = PV」 | 角平分线性质结论 |
| S6 | 「直角三角形 PUA 与 PVB 全等（RHS），故 AU = BV」 | 全等推理 |
| S7 | 「直角三角形 PUC 与 PVC 全等，故 CU = CV」 | 全等推理 |
| S8 | 「AC = AU + CU = BV + CV = BC」 | 长度加法 + 等式传递 |
| S9 | 「证毕」 | 结论断言 |

### 工序二：依存图构建

```
S1 ──→ S2 ──→ S3 (PA=PB)
       │
       └──→ S4 ──→ S5 (PU=PV)
              │
              ├──→ S6 (RHS 全等) ──→ AU = BV
              │
              └──→ S7 (RHS 全等) ──→ CU = CV
                     │
                     └──────────────→ S8 (长度加法) ──→ S9 (结论)
```

### 工序三：闭合性审查

- ✅ S1→S2：全称引入 + 构造，闭合。
- ✅ S2→S3：垂直平分线性质，闭合。
- ✅ S4→S5：角平分线性质，闭合。
- ✅ S5→S6/S7：RHS 全等条件满足，闭合。
- ⚠️ **S6/S7→S8 断裂**：S8 使用了等式 `AC = AU + CU`，这要求 U 在线段 AC **内部**；但自然语言里没有显式声明「U 在 A 与 C 之间」。

**S*L 风险点**：S8 的加法等式依赖了一个未在语义层显式陈述的「betweenness/on-segment」前提。

## 3. M*L 审查：数学层 × 逻辑层

### 工序一：元素提取

| 编号 | 数学元素 | 类型 |
|---|---|---|
| M1 | 三角形 ABC | 几何对象 |
| M2 | AB 的垂直平分线 l_AB | 直线 / 轨迹 |
| M3 | ∠C 的角平分线 b_C | 射线 |
| M4 | 交点 P = l_AB ∩ b_C | 点 |
| M5 | 距离函数 dist(·,·) | 度量结构 |
| M6 | 垂足 U ∈ AC, V ∈ BC | 点（由投影定义） |
| M7 | 直角三角形 ΔPUA, ΔPVB, ΔPUC, ΔPVC | 全等结构 |
| M8 | 线段长度 AU, CU, BV, CV, AC, BC | 实数量 |
| M9 | 等式 AC = AU + CU | 加法分解 |

### 工序二：依存图构建

```
M1 ──→ M2, M3
M2, M3 ──→ M4
M4 ──→ M5(PA=PB) + M6(U,V 存在)
M6 ──→ M7(四个直角三角形)
M7 ──→ M8(AU, BV, CU, CV 等量关系)
M8 ──→ M9(加法分解) ──→ 结论 AC = BC
```

### 工序三：闭合性审查

- ✅ M1→M4：构造闭合。
- ✅ M4→M6：垂足存在性闭合（对任意点向直线作垂线）。
- ✅ M6→M7→M8：全等推导闭合。
- ⚠️ **M8→M9 断裂**：M9 `AC = AU + CU` 不是由 M8 推出的。**它等价于 U 在线段 AC 内部**这一额外几何条件。M9 与 M8 之间缺少一座桥。

**M*L 风险点**：长度加法分解 `AC = AU + CU` 需要 on-segment 条件，但该条件与三角形是否等腰有关，不能作为无条件前提。

**关键发现**：在非等腰三角形中，P 点实际位于三角形外接圆上，U、V 会落在边的延长线上，此时 `AC = |AU ± CU|`，加法公式不成立。

## 4. P*L 审查：编程层 × 逻辑层

### 工序一：元素提取

| 编号 | 编程/形式化元素 | 对应自然语言 |
|---|---|---|
| P1 | `Triangle A B C` | 三角形声明 |
| P2 | `perp_bisector A B` | 垂直平分线 |
| P3 | `angle_bisector C A B` | ∠C 角平分线 |
| P4 | `P := perp_bisector A B ∩ angle_bisector C A B` | 交点定义 |
| P5 | `dist P A = dist P B` | PA = PB |
| P6 | `U := proj P (line A C)` | 垂足 U |
| P7 | `V := proj P (line B C)` | 垂足 V |
| P8 | `right_triangle P U A ≅ right_triangle P V B` | RHS 全等 |
| P9 | `dist A U = dist B V` | AU = BV |
| P10 | `dist C U = dist C V` | CU = CV |
| P11 | `dist A C = dist A U + dist U C` | 核心加法步骤 |
| P12 | `dist A C = dist B C` | 结论 |

### 工序二：依存图构建

```
P1 ──→ P2, P3
P2, P3 ──→ P4
P4 ──→ P5
P4 ──→ P6, P7
P6, P7 ──→ P8
P8 ──→ P9
P6, P7 ──→ (另一全等) ──→ P10
P9, P10 ──→ P11 ──→ P12
```

### 工序三：闭合性审查

- ✅ P1→P8：构造、投影、全等都可形式化。
- ✅ P8→P9：RHS 全等 → 对应边相等，闭合。
- ✅ P6,P7→P10：同理闭合。
- ❌ **P9,P10→P11 断裂**：在 Lean 中，`dist A C = dist A U + dist U C` **不能**由 `U = proj P (line A C)` 和 P9/P10 推出。它要求 `between A U C`（U 在 A、C 之间），但代码里没有这个假设。

**P*L 风险点**：形式化核会在 P11 处留下不可填充的 `sorry`，证明无法闭合。

---

## 5. 三层断裂位置汇总

| 层对 | 断裂位置 | 缺失的 L 层条件 |
|---|---|---|
| S*L | S8 | U 在线段 AC 内部 / between A U C |
| M*L | M9 | on-segment 条件与三角形形状相关，不能无条件使用 |
| P*L | P11 | `between A U C` 未在形式化前提中出现 |

**L 层根因**：长度加法 `AC = AU + CU` 的合法性依赖「U 在 A、C 之间」这一**几何顺序公理**（betweenness axiom），而证明把它当成了距离函数的代数恒等式。

---

## 6. 结论与框架验证

这次审查验证了 **S*L / M*L / P*L 三工序框架** 的价值：

1. **S*L 发现了语义跳跃**：自然语言里「AU + CU」看起来是合法的加法，因为没有显式说明 U 的位置。
2. **M*L 把跳跃转化为数学条件**：on-segment / betweenness，并指出这个条件对非等腰三角形不成立。
3. **P*L 给出确定性失败**：形式化核无法在 P11 处完成证明，留下 `sorry`。

如果没有 L 层，S/M/P 各层分别检查也能发现问题；但 **S*L/M*L/P*L 的依存视角能更精确地说明：断裂点不是在某层的某个元素本身，而是在「相邻层元素之间的逻辑依赖关系」上**。
