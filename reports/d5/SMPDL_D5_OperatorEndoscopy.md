> **性质**：F4 循环评估（`83f7ef4`）的姊妹篇——咖啡追问「有没有其他算子组成拆分方法作解构测试」的正式回答；设计文档，非执行报告
> **核心主张**：对恢复算子本身做组成拆分 = **把 D-5 剂量学递归一层**（移除公理→测结构存活 ⇒ 移除算子组件→测吸收存活）。循环由此在判定材料层面被拆解：组件的存在性/性质可独立检验，不依赖整体「可指名性」。
> **前置**：`6ef180a`（算子 = 内涵条件参数束，R1–R6 重建模式）+ `57a8fdb`（definitional extension 三件套口径）+ F4 循环评估三层解剖

## 一、问题重述：为什么拆算子能杀循环

F4 循环的要害（评估 §一层 2）：判定材料 = 「等价证明 → 算子命名」的滑步产物，预测证据与判定依据同源。**拆分策略**把「算子」从原子单元降为复合单元：

```
原子观：R 可指名？ ──(是/否)──► 吸收成立？        ← 同源循环
        │
拆分观：R = ⟨层级 tag, 因子链, 公理组, 伴随性, 片段谱⟩
         每个组件独立可测 ──► 组件级预测可证伪      ← 判据解耦
```

关键：组件的检验判据（伴随存在性定理条件、幂等性可证性、中间理论存在性）是**语法/范畴级机械判据**，判定时不需要知道算子有没有名字——「可指名」从判定材料降级为被解释项。

## 二、七种拆分文法（decomposition grammar）

### G-0 · 层级定位（算子自身的 S/M/P 标签）

算子本身活在哪一层：**P 层算子**（纯证明推导，如 A1 单侧⇒双侧——是一条导出定理，无构造）、**M 层算子**（构造/函子，如 Frac、商构造）、**S 层算子**（语义翻译，如 Glivenko 嵌入、Kripke 语义重解释）。
- **独立可测**：算子的输出类型（定理/对象/结构）语法可判
- **解构测试**：跨层配对——同一损伤是否有 P/M/S 三层算子？缺层即「吸收不完整」的信号
- **先例**：run 1 发现 3（剂量层别）递归到算子层

### G-Ⅰ · 单子解剖（monad anatomy）

凡构造型算子近似单子/闭包结构：R = ⟨F, η, μ⟩（自函子 + 单位 + 乘法）。
- **独立可测组件**：η（原结构嵌入的保真度）、μ（**幂等性** F²≅F：恢复做两次 = 做一次？）、结合律
- **解构测试**：删 μ → 一次恢复后是否需要再恢复？**幂等 = 精确吸收，非幂等 = 逼近式吸收**——这给出连续的吸收等级标尺，替代二元「可指名」
- **例**：K10 正则化 int(cl(·)) 是幂等闭包（精确）；代数闭包在 ZF 内可能非幂等（依赖 AC）——同为"恢复"，等级可分

### G-Ⅱ · 伴随分解（adjunction data）

恢复算子常是遗忘函子的（左/右）伴随：R ⊣ U（单位化 ⊣ 忘却；Frac ⊣ 含入）。
- **独立可测**：**伴随存在性 = 伴随函子定理条件**（解集条件 + 连续性/余连续性）——纯范畴机械判据，与命名无关
- **解构测试**：单位/余单位哪个方向保真？伴随对 (R, U) 的哪一半承担吸收？
- **非循环杀伤力最强**：「II 型 ⟺ 恢复算子有伴随」若成立，右端可机械检验——**⇔ 升格表征定理的最便宜路径**（评估途径 E 的低成本版）

### G-Ⅲ · 因子分解（factorization through intermediates）

R: T−A → T 是否真的最短？R = R₂∘R₁ 经中间理论 T*。
- **独立可测**：中间理论的存在性 = 语法对象；**算子长度 ℓ(R)** = 最短因子链长度
- **解构测试**：拆出 T* 后逐因子测；**假设：III 型层数 ≈ ℓ(R)**（分层剥落 ↔ 算子链长——剥落几层就得接几段）
- **例**：Grothendieck 群化 = 自由群生成 ∘ 关系商（ℓ=2）；A14 Mac Lane = 自由严格化 ∘ 凝聚商（ℓ=2）；A1 是纯推导（ℓ=0，P 层）

### G-Ⅳ · 闭包公理分测（closure operator laws）

闭包类算子三公理：外延性 / 单调性 / 幂等性。
- **解构测试**：逐公理移除——去幂等（得邻域算子）、去单调（得对称化残余）、去外延（得预闭包）。哪条公理承重「吸收」？
- **例**：K10 的 int(cl(·)) 本身 = 双因子复合（内窥 ∘ 闭包）——run 2 数据里已有现成标本；K11 生成滤子（上闭包）= 单调恢复不恢复三角（K2 旗的内窥解释）

### G-Ⅴ · 模态公理分解（bang-style axioms）

H36 先例：线性逻辑 bang = 四公理族（dereliction / digging / promotion / weakening），每条独立可测。
- **解构测试**：恢复算子的「复制能力」分解——promotion 缺损 = 只能一次性恢复；digging 缺损 = 恢复不可迭代
- **适用域**：资源敏感语境（H36 家族）；与 G-Ⅰ 幂等性对偶

### G-Ⅵ · 片段索引（fragment-indexed absorption family）

R6 旗的正式化：吸收不是整体谓词而是**片段谱** frag(R): Fragment → {全吸收, 部分, 无}。
- **独立可测**：每个逻辑片段（一阶/高阶/无穷/构造性）分别测传递定理
- **解构测试**：片段谱向量预测残留损伤的位置——「损伤剩在哪」由「谱缺口在哪」决定
- **例**：Łoś 定理谱 = 一阶全吸收 / 高阶无；setoid 商 = 构造性片段全吸收

### G-Ⅶ · 同畴/换畴分解（vertical vs horizontal）

恢复发生在**同一范畴内**（翻译/定义扩张：单位化、局部化）还是**换范畴**（运输到新载体：Riemann 面、HoTT 路径对象）？
- **独立可测**：R 是否保持环境范畴（语法对比）
- **理论接口**：同畴 ≈ definitional extension 家族；换畴 ≈ B4 的 α 主补偿（新对象接替旧职责）——**α/β 之别在内窥下变成算子的几何属性**，预测机变量获得结构基础

## 三、算子解剖签名（anatomy signature）与测试电池

每例 II 型样本产出五元组签名：

```
sig(R) = ⟨ layer ∈ {P,M,S}, ℓ(R) ∈ ℕ, idem(R) ∈ {是/否/部分}, adj(R) ∈ {左/右/无}, frag(R) 向量 ⟩
```

**run 1 六例预填**（征集侧草案，供 run 3 盲测复核）：

| 样本 | layer | ℓ(R) | idem | adj | frag | 备注 |
|---|---|---|---|---|---|---|
| A1 群单侧 | P | 0 | —（推导） | — | 全 | 纯证明算子，无构造体 |
| B7 预序商 | M | 2（等价生成∘商） | 是 | 左伴随（自由完备化侧） | 全 | 幂等闭包典范 |
| C9 cut 消去 | P/M | ≥2（切消除∘正规化） | 是（范式唯一） | — | 构造性片段强 | 终止测度 = 幂等性的算法版 |
| A14 严格化 | M | 2（自由严格∘凝聚商） | 是（范畴等价级） | 有 | 全 | Barrett–Halvorson 口径直接例 |
| C2 DNE⇔LEM | S | 1（Glivenko 翻译） | 是 | — | 否定片段全/经典全 | 片段谱非平凡的活例 |
| D6 Łoś | M | 2（超积∘传递） | — | 有 | **一阶全/高阶无** | G-Ⅵ 的原型标本 |

**解构测试电池**（对签名跑的操作）：
1. **组件移除**：逐个删组件（μ / 伴随一半 / 因子一段 / 某公理），测吸收降级——这是 D-5 方法对算子自身的递归执行（二阶剂量学）
2. **签名聚类**：六例签名是否按降解型自然聚类？若 II 型内部再分出「精确幂等簇」vs「片段受限簇」，F4b 的经验内容就有了结构
3. **最小充分子签名**：哪些组件组合是吸收的最小充分条件？——由此得到的「⇔」是**组件级的表征定理**，循环终结

## 四、非循环性论证（为什么这招成立）

| 组件 | 检验判据 | 是否依赖「算子有名字」 |
|---|---|---|
| adj(R) | 伴随函子定理条件（解集条件 + 连续性） | 否——纯范畴判据 |
| idem(R) | F²≅F 的可证性 | 否——语法可判 |
| ℓ(R) | 中间理论 T* 存在性 | 否——语法对象 |
| frag(R) | 逐片段传递定理 | 否——逐片段可证 |
| layer | 算子输出类型 | 否——语法可判 |

五组件全部机械可检 ⇒ 「可指名性」从**判定材料**降级为**被解释的社会学结果**（命名速度跟得上组件组合的出现速度 = F4b 重述版，此时才是合法的经验命题）。

**与评估五途径的关系**：内窥 = 途径 E（定理化）的低成本前置——不需要完整 bi-interpretability 证明，只需组件级检查；同时给途径 A（σ 解耦）提供算子侧的对照变量（σ 盲测 × 签名盲判的交叉设计不变）。

## 五、可预注册假设（run 3 增补三条）

- **H-endo-1**：II 型精确吸收 ⟺ idem(R)=是 且 adj(R)≠无（单子-伴随完备）；
- **H-endo-2**：III 型剥落层数 ≈ ℓ(R)（跨降解型的结构对应——若成立，II/III 之分 = 算子长度的 0/1 与 ≥2 之分，**降解型分类学获得算子代数基础**）；
- **H-endo-3**：残留损伤位置 = frag(R) 缺口片段（预测损伤去向，而非仅预测恢复）。

三条全部组件级可证伪；H-endo-2 若成立还顺手统一 I–IV 型分类学与 B4 的 α/β 主型（经 G-Ⅶ 换畴标签）。

## 六、限制与诚实款

1. **文法选择本身是新自由度**——七种文法不互相独立（单子/闭包/伴随三文法重叠），run 3 预注册必须先冻结文法组合与组件判据版本，否则拆分自由度会复刻 F2 的口径翻转问题；
2. 拓扑/序论样本（B7 类）的形式化基础设施薄，G-Ⅰ/Ⅱ 判据在弱基设施下可能降级为「教科书级共识」判定（回到半盲口径）；
3. 六例预填签名是征集侧草案（已读 run 1，定向风险同 F2）——run 3 须盲测复核；
4. 组件边界有约定性（cut 消除拆两段还是三段？）——判据：以「中间对象是否在文献中独立存在」为锚，仍残留边缘裁量，如实登记。
