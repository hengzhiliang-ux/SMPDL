## 一、G-0 操作化：层级判定决策树

### 1.1 判据（预注册草案，run 3 冻结版以此为基础）

**问：算子 R 的输入→输出各是什么类型？**

```
R 的输出是……
├─ 命题/定理（同语言同结构内的可推导性）
│   例：A1 单侧⇒双侧；C2 等价类 {LEM,DNE,反证} 互导
│   → 【P 层算子】证明论吸收：损伤被「原来就能推出来」吸收
│
├─ 新对象/构造/函子（产生原理论中不存在或未命名的对象）
│   例：B7 等价类商构造；Frac 分式域；K10 int(cl(·))；D6 超积
│   → 【M 层算子】构造性吸收：损伤被「新对象接管职责」吸收
│
└─ 翻译/ reinterpretation（改变解释函数本身）
    例：C2 Glivenko 嵌入 ⋅*（经典→直觉主义负片段）；Kripke 语义
    → 【S 层算子】语义吸收：损伤被「换一种读法」吸收
```

### 1.2 混合情形：主层/辅层双标签制

多数算子非纯层（cut 消去 = 定理 P + 规范化算法 M）。规则：
- **主层** = 承担吸收职责的核心机制（问：删掉这一半，吸收还成立吗？）
- **辅层** = 支撑机制（删掉不影响吸收成立、只影响效率/表述）
- 双标签记法：`P+M`（P 主 M 辅）/ `M+P` / `S+M` ……
- 边缘判例预注册：**同构/等价处的层级归属**——商构造产生新对象（M）但同时重定义相等（S）：裁定规则 = 看「新对象是否必须」——B7 商集是新对象必须（M 主），Glivenko 不构造任何新对象只重解释（S 主）。此规则本身是测试 T1 的检验对象。

### 1.3 与损伤层的对偶词表（交叉表的轴定义）

| 层 | 损伤形态（run 2 数据源） | 吸收形态（本设计新测） |
|---|---|---|
| S | 唯一性陈述死亡/语义判据失效（F3 的 S-dose：E1 同构拷贝、E3 UIP） | 翻译/重解释 |
| M | 定理群死亡/对象职责悬空（F3 的 M-dose、run 1 死亡列） | 构造/新对象 |
| P | 证明不可达/推导链断裂 | 可推导性恢复 |

## 二、测试电池（四测试 + 预注册假设）

### T1 · 标签盲判可靠性测试（文法有效性前置）

**问题**：G-0 判据本身可用吗？（标签不稳定则后续全废）

- **材料**：16 例算子行（run 1 六例 + run 2 F4 十行去重后合并池）
- **方法**：两名独立判定者按 §1.1 决策树 + §1.2 双标签规则打标签（主层/辅层），互不知对方结果
- **判读**：主层一致率 + κ；辅层一致率单报。κ ≥ 0.6 → 文法 tier-1 可用；[0.4, 0.6) → §1.2 边缘规则修订后重测；< 0.4 → G-0 判据需重构（诚实降格）
- **成本**：低（纯文献级判定）
- **边缘判例即数据**：分歧案例全部登记——它们暴露判据的模糊带，是修订案的原料

### T2 · 层×层交叉表测试（核心测试 · run 2 数据复用）

**问题**：吸收是层特异的吗？（损伤层 ⟺ 算子层？）

- **设计**：行 = 损伤层（每例按 run 2 F3 的 M/S 分层 + run 1 死亡列重新归类），列 = 算子主层（G-0 新标签）
- **假设 H-G0-2（层特异吸收律）**：对角占优——S 层损伤由 S 层算子吸收、M 层损伤由 M 层算子吸收
- **可证伪点**：非对角格出现 = 跨层吸收案例（新发现候选：用构造吸收语义损伤？）
- **已有标本预演**（征集侧草案，盲测复核对象）：

| 样本 | 损伤层 | 算子主层（预标签） | 对角? |
|---|---|---|---|
| C2 DNE⇔LEM | S（二值语义失效）+ M（定理群）| **S+P 双算子**：Glivenko 翻译吸 S 半、互导吸 M 半 | 对角（双层配双层） |
| K10 正则开集 | M（布尔代数对象损失）| M（int(cl) 构造）| 对角 ✓ |
| A1 群单侧 | M（逆元定义悬空）| P（可推导）| **非对角？**——M 损伤被 P 吸收！ |
| E1 ZF−外延 | S（唯一性全弱，F3 结论）| M（Friedman 超穷精细化**构造**模型）| **非对角？**——S 损伤被 M 吸收？ |

  → 预演已经显示对角/非对角并存：**A1 与 E1 是两个潜在反例**。若盲测确认，H-G0-2 收窄为「层特异仅在 X 条件下成立」——条件是什么正是测试的产出。注意 A1 的替代读法：单侧公理下「逆元定义悬空」实为 P 层损伤（定义可修复性是推导问题），损伤层归类本身会被测试校准。
- **统计**：n≈16 小样本，Fisher 仅探索性；主判读 = 对角格占比描述统计 + 逐例机制分析

### T3 · 缺层预测测试（前瞻可证伪）

**问题**：缺某层算子 ⇒ 该层损伤残留？

- **设计**：找「损伤层已知、且初步检索未见该层算子」的案例，预注册预测：该层损伤将持续显影（不被其他层吸收）
- **候选标本**（草案）：
  - **E6 格 lub/glb 唯一性**：S 层损伤（唯一性陈述死）——multilattice 文献是 M 层（新对象）还是 S 层（重解释）？若判 M 主，预测 E6 的 S 层残留将持续（唯一性问题在 multilattice 语境仍是开口）
  - **K2 拟度量三角性**：M 层损伤（完备性定理群死）——对称化算子 d+d^T 只恢复对称不恢复三角，**已知缺 M 层完整算子** → 预测：单向版定理群稳定存在但双向 Banach 型结果永久缺席（除非新算子）——这实际是对 H43 拟度量文献形态的**可检索预测**
- **可证伪点**：若某例缺层但该层损伤自愈（无算子而损伤消失）→ H-G0-2/3 双双受压
- **成本**：中（文献形态检索）

### T4 · P 层机械化测试（G6/Lean 接口 · 长线）

**问题**：P 层标签能否由机器直接检验？

- **依据**：P 层算子 = T−A ⊢ A′（可推导性）——原则上证明论可判定，Lean/Isabelle 可直接验证有限公理系统样本
- **首批样本**：A1（群单侧⇒双侧：Lean mathlib 已有 `left_inv`/`mul_left_inv` 推导路径——几乎零成本）、C2（Glivenko：mathlib 有 `Classical.byContradiction` 相关 but 完整负片段嵌入需新写）
- **产出**：P 层标签从「文献共识」升格「机器验证」——G-0 成为第一个有机械化地基的文法，与 C5/G6 代际合流
- **成本**：A1 近零；C2 中；与 P2-②（Univalence 活体档案）共享基础设施

### 预注册假设汇总（随 run 3 冻结）

| # | 假设 | 测试 | 判读线（草案） |
|---|---|---|---|
| H-G0-1 | 主层标签判定者间可靠 | T1 | κ ≥ 0.6 |
| H-G0-2 | 吸收层特异（损伤层⟺算子主层）| T2 | 对角格 ≥ 10/16 且非对角例全部可归因（损伤层误归类/真跨层）|
| H-G0-3 | 缺层 ⇒ 残留（层完备性是吸收必要条件）| T3 | 2 例预测全部命中；任一自愈即证伪 |

**H-G0-2 若成立的回报**：吸收律获得第一个结构定律（层配对），且 S/M/P 三层词表在损伤侧（F3）与算子侧（G-0）**双向闭合**——剂量学从「记账」升格「层守恒律候选」：*损伤在哪个层发生，吸收必须在哪个层完成*。这会是 D-5 系列最接近物理直觉的表述。

**若部分成立的回报**：非对角案例（A1/E1 预演所见）= 跨层吸收模式——「P 层可推导性能否吸收 M 层损伤」本身成为新分类变量（吸收的层级弹性），照样是产出。

## 三、实施协议（排期建议）

```
第一步（本周可做）：T1 标签盲判——16 例 × 2 判定者（隔离会话 + 人工），κ 计算
第二步（与 T1 并行）：T2 交叉表——damage 侧重归类（可复用 run 2 F3 + run 1 死亡列）
第三步（T1 通过后）：T3 缺层预测 × 2 例预注册（E6/K2）
```

**与其他部件的接口**：T2 的算子主层标签 = 内窥五元签名的第一分量（其余四分量 G-Ⅰ~Ⅶ 可后置）；T4 与 C5 集群/G6 代际共享 Lean 基础设施；T3 的 E6 例同时服务 F3 最弱例复核（裁定报告 §六.6 建议）。

## 四、限制与诚实款

1. 主/辅层划分有裁量空间（「删掉这半吸收还成立吗」的思想实验不是完全机械的）——T1 的 κ 就是这个裁量度的直接测量；
2. T2 的 damage 层归类复用 run 2 F3，而 F3 是「移除外延类公理」的六例——损伤层词表在非外延类样本上的外推（如 A1 的 M/P 归类）未经同等检验，预演表两处「?」如实标注；
3. n=16 的交叉表无功效宣称，描述性为主——这是 G-0 作为「最便宜第一遍分类」的定位使然，非缺陷隐瞒；
4. E1 的 Friedman 精细化是「构造模型恢复定理」——M 构造吸 S 损伤若确认，也可能是损伤层归类问题（「定理群恢复」本身是 M 层可测的）——T2 的双向校准正是为此设计。
