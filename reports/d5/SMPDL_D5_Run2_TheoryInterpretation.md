## 一、定位：D-5 剂量学在数学逻辑中的坐标系

### 1.1 反向数学的镜像结构

D-5 剂量学（"移除一条公理，结构剩下什么"）与 Friedman 反向数学（RM）构成**精确的对偶**：

| 维度 | 反向数学（Big Five 框架） | D-5 剂量学 |
|---|---|---|
| 问句 | "定理 T 需要多强的公理基？"（自下而上） | "公理 A 移除后死亡什么？"（自上而下） |
| 方向 | 定理 → 必要基座 | 公理 → 死亡定理群 |
| 单位 | 子系统强度（RCA₀ → WKL₀ → …） | 降解型（I/II/III/IV）+ 剂量层（S/M/P） |
| 输出 | 承重图 L(T)：T 的证明依赖 | 承重图 L(A)：A 的独占承重面 |
| 证据形态 | 定理 ↔ 系统等价（双向归约） | 死亡/存活/恢复算子档案 |
| 局限 | 二阶算术方言 | 通用但粗粒度（ToC 级） |

**关键判词**：F1 计数法测得的是**"教科书在场性承重"**——它同时编码了"逻辑承重"与"学科建制化程度"两个信号。这是代理指标的本性（预注册 §四诚实款已声明），理论检查确认：这不是缺陷而是**特性**，因为 F1 的对象（公理的"隐形承重"）本身就是社会学-逻辑学混合现象——Lang 在 XVIII 章写表示论，既因为交换性逻辑上承重 det/根理论/对称函数，也因为历史路径（Noether–Brauer 谱系）把这套理论建在了交换域语境里。**run 3 若细分，应把"建制化承重"与"逻辑承重"作为两个可分离变量。**

### 1.2 四条支持的数理逻辑学重述

**F1（隐形承重律）= 哥德尔编码式的不对称**。教科书空间在"交换律"与"逆元律"上的章节投入比 ≈ 2.5–3.3 : 1（独占口径）。逻辑学解读：公理的地位不能从它的**语形位置**（它出现在公理列表的哪里）预测，只能从它的**语义承重**（它的死亡会带走哪些定理群）测量。这本质上是"公理 ≠ 公理列表中的一项"——公理是定理生态位的占据者，而生态位占据与语形显眼度解耦（秩相关弱，F1 预测原文）。交换律的"低调"（人人会背 ab=ba）与其"重仓"（det/对称函数/表示论三大件）的落差，就是隐形承重的教科书显影。

**F2（约束-构造二分律）= 理论等价性的两种失效方式**。从 model theory 视角看：
- **构造型公理**（"存在幺元/逆元"）是 ∃-语句——移除后理论 T−A 仍是 T 的子理论，且往往是 T 的**保守片断或可定义扩张**（分式域/Grothendieck 化/单位化都是 definitional extension 层级的恢复算子，prior-art 文档的 Barrett–Halvorson 口径）。损伤被吸收 ⇒ II/III 型 ⇒ 脆性为零（构造组 15/15 零脆性）。
- **约束型公理**（三角不等式/归纳模式/遗传封闭）是 ∀-语句（或 ∀-模式）——移除后理论**收缩为更弱的理论**，死亡的是"从约束收割的定理"（Banach 不动点收割三角不等式；费马小定理收割归纳；贪心正确性收割遗传性）。损伤**不可定义性恢复** ⇒ I/边缘型集中地。
- **裁定基轴（咖啡 A 裁定）的理论表达**：二分方向性 = "∃-公理与 ∀-公理的降解不对称"。Fisher p≈0.0131 + 构造组零脆性测量的正是这个不对称的方向；5/15 的阈值落差不影响方向，只收窄到 ∀-约束的**三个亚型**（不等式 ∪ 归纳 ∪ 遗传）。逻辑学细化：**脆性集中在"∀-语句约束的对象是无穷对象类"的公理**——三角不等式约束所有三元组、归纳约束所有子集、遗传约束所有子族——无穷 ∀ 的"守恒"成本最高（守恒 = 保持理论的一致性完备性，守不住 ⇒ 定理群坍塌）。其余 ∀-约束（分离 T2/凸性/单调封闭）约束的是**性质**而非**对象类**，守恒成本较低，呈 II/III/IV。

**F3（剂量层别律）= 语法层与语义层的创伤分离**。F3 测得：外延性类公理移除时，**定理群（M 层）近似无损而语义唯一性（S 层）重创**。这是 Curry–Howard–Lambek 层级中"证明论强度"与"范畴语义"分离的经验显影：Friedman 1973 表明 ZF−Ext 内可恢复 ZF 全部定理群（M-dose ≈ 0），但"="的语义决定权（哪个集合"是"哪个）永久旁落给 bisimulation 分层。**理论升格**：S/M 分层不仅是剂量学的记账法，而是证明了"逻辑系统的语义层是独立承重面"——存在这样的公理，它的移除**只**伤语义不伤定理。这在证明论上对应"理论同构但不同构于自身"的微妙地带（autoequivalence ≠ identity）。

**F4（恢复算子吸收律）= 可定义扩张的经验律**。F4（6/6 可指名）的理论内容：II 型（冗余稳健）不是偶然的稳健，而是**恢复算子在场的结构性结果**。definitional extension 三件套（唯一模型扩张/保守扩张/翻译消去）+ bi-interpretability（保持有限可公理化/可判定性）构成的"恢复算子库"是 II 型的语义后盾。逻辑学表述：**T ⊢ A 且 T−A + 恢复算子 R ≡ T（等价/互译）⇒ 移除 A 的损伤 = R 的构造成本**。F4 的"≤ 一代（30 年）"时间窗与逻辑史吻合：恢复算子的发明（Gentzen 切消 2 年、Mac Lane 凝聚 18 年、Glivenko 即时）都是"损伤显影后即刻被领域吸收"的教科书节奏。

### 1.3 四条合一：剂量学的统一理论骨架（候选）

四条支持合并成一句话：**公理的降解命运由其语形类型与语义承重的组合决定**——

```
语形类型          语义承重          降解型         实证
─────────────────────────────────────────────────────────
∃-构造           低/中（可恢复）    II/III         构造组 15/15 稳健
∀-约束(对象类)    高（不可恢复）    I/边缘         K1/K2/K3/K6/K7
∀-约束(性质)      中（部分恢复）    II/III/IV      K8–K15
外延类(唯一性)    S 层独占          III+S 重创     E1–E6
任意              恢复算子在位      II             F4 六例
```

**这是 run 3 的预注册候选骨架**：把"语形类型 × 承重层"作为预测变量、降解型作为输出变量,样本量按亚型分层扩样。

## 三、批判：结论的边界与威胁

### 3.1 有效性威胁清单（数理逻辑学视角）

1. **循环性威胁（最重）**：F1–F4 的"支持"由同一会话链上的征集-裁定协作产生，且裁定人显式声明"计数完全采信征集侧 §1.2 表"（J5 披露 §六.2）。虽然数据/裁定会话分离 + 零型列 + 抽查 3/3 缓解了同源污染，但**采样清单本身**（哪 10 公理、哪 30 例）由知情会话设计——run 1 §四发现 2 的"约束=脆性"直觉可能已经塑造了 F2 的采样框架（约束组 15 例中 5 例恰是后来判脆性的亚型）。这是**采样框架泄漏**（frame leakage），纪律 v2.0 的 F2 条款（术语首现扫描）不覆盖此层。**run 3 对策**：采样清单由第三方会话（或按预注册的机械规则从公理列表全集生成）产生。
2. **代理指标的双信号性**：F1 的 ToC 计数 = 逻辑承重 × 建制化程度。若"交换律承重 > 逆元承重"部分来自 Noether 学派的建制史而非纯逻辑必要性，F1 的"隐形承重"结论需在定理级索引（run 3 候选 ④）上复核。
3. **n 的有效性**：F4 有效 n=6（裁定人合并口径）是四条中样本最薄的——"6/6 可指名"的 95% 置信下界（Clopper–Pearson）≈ 0.61，不能排除真实可指名率低至 61%。F4 结论应标注为"方向性支持，点估计 100%，CI 下界 61%"。
4. **判读线的多重比较**：四条 F 在同一数据上判读，且 F2 的敏感性分析跑了 5 种口径（IV 归属/边缘归属），严格 Bonferroni 校正下 p≈0.0131×4 ≈ 0.052——**恰在边缘**。诚实报告：F2 的"强支持档"在族错误率控制下降为边缘显著；方向性（构造组零脆性）不受影响。
5. **恢复算子的"可指名"判定**：F4 的"可指名"由裁定人判定，而恢复算子的命名本身是历史偶然（Glivenko 翻译 vs 双否定嵌入——同一构造两个名字）。"可指名性"应操作化为"在标准教材/手册中有条目"（run 3 对策：以 Encyclopedic Dictionary of Mathematics 或 nLab 条目存在性为机械判据）。

### 3.2 结论的适用域（如实划定）

- F1 适用于**三书覆盖的通用代数语境**（群/环/域/线性代数）；不适用于格论/李代数（真盲区）与低于 ToC 粒度的理论（粒度盲区）——已在裁定 P3 登记。
- F2 的方向性适用于**教材级公理系统**的移除实验；对**物理公理**（相对论原理）与**高阶语义公理**外推无效——当前证据基础仅限数学内部。
- F3 的"S 层独立承重"限于**一阶/依值类型论语境**的"="语义；对高阶语义（如 univalence 本身）是否成立未知。
- F4 的"恢复算子 ≤30 年吸收"是**历史回溯性**规律（selection on the dependent variable 风险：我们只采样了"已经被吸收"的 II 型——II 型定义本身就包含恢复算子在位，存在定义循环的风险；**这是 F4 最大的理论威胁**：II 型 ⇔ 恢复算子在位可能是同义反复，非经验规律。裁定报告 §4.2 的 R6 旗（片段相对吸收）部分缓解——一阶片段内吸收是片段相对的实证内容——但 run 3 必须预注册**非循环测试**：先按"移除后损伤深度"独立采样，再盲判恢复算子是否在场）。
