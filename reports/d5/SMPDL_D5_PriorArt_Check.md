## 一、逐条核查

### F3 剂量层别律（外延类 = 纯 S-dose）——**实质已知，框架新**

| 先行文献 | 已解读内容 | 与 F3 关系 |
|---|---|---|
| nLab「axiom of extensionality」 | 外延性的三种强度（弱/强外延）；**强外延 = 「等词是终互模拟」**；外延商（extensional quotient）构造 | S-dose 的「语义损伤」已被形式化为 bisimulation 层级——「= 变弱」的精确版本就是互模拟 |
| **Friedman 1973**（JSL 38, 315–319） | ZF−外延中可经超限精细化等价关系**恢复出完整 ZF 模型**——经典集合论嵌入无外延理论 | **外延移除的恢复算子已被构造**（我们的「商修复」= Friedman 的超限精细化） |
| Dana Scott（MO 讨论引） | ZF−E（替换版）可解释于 Z——一致性强度严格降低 | 无外延理论的**解释强度剂量**已测 |
| **Hofmann–Streicher 1994**（LICS，groupoid model） | UIP 独立于内涵 MLTT：等词证明可不唯一——**等词语义的独立性证明** | F3 采样清单里 UIP 一项，其「S-dose」实质 = 群胚模型的经典结论 |
| HoTT 书（例 3.1.9） | UIP 与 univalence 矛盾；h-set/0-截断型 = UIP 成立的类型类 | 「哪些类型服从外延语义」已有完整理论 |

**判定**：F3 的实质内容（外延移除 = 语义层损伤 + 商/解释恢复）**数学界已充分解读**；我们的新增仅是 (a) 把它命名为剂量型并放进 I/II/III/IV 分类学，(b) S/M/P-dose 三分层的**分类框架**。二轮预注册照跑（分类学主张仍可判伪），但论文表述须引 Friedman 1973 / Hofmann–Streicher 1994 为先行。

### F4 恢复算子吸收律（II 型 ⇔ 损伤被恢复算子吸收）——**已有完整形式化机器，这是最大的进口机会**

| 先行文献 | 已解读内容 | 与 F4 关系 |
|---|---|---|
| **Barrett–Halvorson 2016**（Morita equivalence） | 定义扩张「不多说任何东西」三定理：模型唯一扩张 / **保守扩张** / 翻译消解——II 型「损伤被吸收」的精确版 | F4 的「恢复算子」= 定义扩张/解释；「吸收」= 保守性 |
| 定义等价 / Morita 等价 / **bi-interpretability**（Friedman–Visser；Mceldowney 2020） | 理论等价的完整层级：强可互译 ⊃ Morita ⊃ 范畴等价；bi-interpretability 保持有限公理化/可判定性/κ-范畴性 | **II 型样本的精确身份 = 与原理论定义等价（或 Morita 等价）** |
| Gentzen 切消（1935）；Mac Lane 凝聚（1963） | cut 可删 = 序列演算的保守性；弱结合 ⇔ 严格结合 | 库内已知的两例，现可统一归位 |
| Krajíček/Visser 解释格理论 | 理论间的解释偏序格、解释度 | **剂量学的第五单位（解释强度）已有代数结构**——D-4 汇率表可直接进口 |

**判定**：F4 实质 = 「II 型 ⇔ 定义等价/Morita 等价类」——逻辑学已形式化。**但这不是坏消息，是进口清单**：interpretability hierarchy 把我们的 II 型从样本观察升格为有格结构的数学对象；D-4 跨阶梯汇率表有了现成代数。二轮预注册 F4 判读线不变，但「恢复算子」应按定义扩张/解释精确定义。

### F1 隐形承重律（交换律非最轻剂量）——**成分已知，比较排序新**

- Dieudonné 行列式（1943）/ 非交换域上行列式障碍：**已知**——「无交换则 det 需改造」是教科书内容；
- 逆向数学（Big Five）：**方法论先例**——RM 测「定理 T 需要哪些公理」，F1 是转置问题「公理 A 承载哪些定理」；转置本身不是 RM 的标准做法，但完全同族；
- 「结合 > 逆 > 交换 > 单位元」的**比较承重序**：未检索到作为命名结果的先行文献——**新**（但二轮抽样+教科书索引计数仍须做，防单例外推）。

**判定**：成分已知（Dieudonné det、RM 方法论），承重排序主张目前**无直接先行**。

### F2 约束-构造二分律（约束型公理 → 脆性）——**成分已知，二分框架新**

- 拟阵文献：**遗传性+交换性两段式公理化是标准教学**（independence system = 拟阵−交换；丢交换 ⇒ 基数不唯一+贪心失效——**已知**）；greedoid/antimatroid = 遗传性的弱化（accessibility）也是成熟理论（Korte–Lovász–Schrader）；
- 罗宾逊 Q：**重大发现——Robinson 1950/Tarski–Mostowski–Robinson 1953 已有一条逐公理移除定理：Q 的七条公理中移除任何一条，本质不可判定性即失效**（每条都是不可化约的承重件）——这是**1950 年完成的单公理剂量学实验**，D-5 文献综述此前漏引！
- 「约束型 vs 构造型」作为**降解型的预测变量**：未检索到先行——**分类框架新**。

**判定**：样本成分全部已知（且 Robinson 定理给 F2 的约束侧提供了 7 个现成数据点——归纳模式之于 Q 的「近桥」地位 1950 年已证）；二分律作为预测框架仍新、仍可判伪。

## 三、意外收获：Robinson 1950 = 剂量学先驱（埋没的先行工作）

「Q 的七公理每移除一条即丧失本质不可判定性」= 在可判定性指标 σ 上对七公理各做一次 d=1 实验，**结论：Q 的七条全是桥公理**（k_c=1，指标=本质不可判定性）。这既 (a) 证明「单公理移除实验」是曾被认真做过的正经数学，(b) 给 F2 约束组直接供 7 个已判定数据点，(c) 提示剂量学应系统扫**可判定性/本质不可判定性作为 σ 的另一指标**。建议升格为 D-2 普查的首批录入。
