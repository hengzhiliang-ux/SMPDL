**裁定：有效 n = 6**（R7/R8 与 R1/R2 为同对象重复计入，不构成独立样本；R9/R10 为复验行——复验通过则并入 R3/R4 不加 n，复验失败则 R3/R4 各失一格）。理由：预测的对象是"II 型样本"，同一样本的两次征集不产生两个数据点；把 R7/R8 计为独立样本会把同一证据双计入分母，虚增达标难度（9/10 vs 9/6），两个方向都不忠实于"10 例"的字面（冻结文本"6+4=10"中 4 新例里 2 例已被 run 1 覆盖是冻结时点的清单事实）。此裁定为**计数口径澄清，不构成标准修改**（判读线阈值随有效 n 等值换算：≥9/10 ⟺ 全部通过）。
