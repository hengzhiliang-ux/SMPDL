## 二、数理逻辑阐释

### 2.1 κ 悖论即发现：损伤层的基率结构

样本空间不是层均匀的——M 层（定理群）是移除损伤的**默认受创面**（约 2/3），S 层稀有（唯一性类），P 层最少（推导链单独断裂）。逻辑学表述：**对随机选取的公理移除事件 A，P(damage(A) = M) ≫ P(damage(A) = S) ≈ P(damage(A) = P)**。这不是抽样偏差而是结构事实的候选：定理群是公理承重的最大暴露面（公理的主要职责就是生定理）。此基率本身可入 run 3 预注册（「M 层损伤基率 ≥ 50%」作为分布预测——F1 教科书计数的镜像命题）。

### 2.2 层守恒的函子化表述与「强制转换」重构

**函子化**：设移除事件范畴 𝓡（对象 = 移除事件，态射 = 证据关联），层标记是两个函子 D, O: 𝓡 → 𝓛（𝓛 = {P,M,S} 离散三层）。层守恒律的原型表述 = D ≅ O（自然同构）。

**三例跨层吸收摧毁刚性同构**：D6（损伤 M / 算子 P）、E1（损伤 S / 算子 M）、K2（损伤 M / 算子 S）。把它们读成**型强制转换（coercion）**：

- D6：算子 P 服务 M 槽位——「可推导性能覆盖定理职责，当且仅当片段受限」（P ⊑_frag M）
- E1：算子 M 服务 S 槽位——「构造能覆盖语义职责，当且仅当构造是语义的实体化」（M ⊑_reif S）
- K2：算子 S 服务 M 槽位——「重解释能覆盖定理职责，当且仅当定理假设可弱化」（S ⊑_weak M）

**关键观察**：M ⊑ S 与 S ⊑ M 同时在场 ⇒ 层关系**不是偏序**——强制转换不是层级包含而是**带成本的转换系统**。由此层守恒律的正确重构：

> **零成本优先原则**：吸收优先发生在同层（型精确匹配、零成本）；跨层吸收必须经由**可命名的强制转换映射**（三个已录：frag / reif / weak），每次转换付出可识别的代价（片段收窄 / 超穷迭代 / 假设弱化）。

这恰是程序语言类型论中「_subtype 与 coercion 的对立」的移植：层不是刚性类型系统，是 **coercion-calculus**。对角格 = 零成本直接匹配；非对角格 = 经命名转换的有成本匹配；「无法吸收」= 既无同层算子又无可用转换。**预测性推论（run 3 候选 H-G0-2'）**：新样本中跨层吸收若发生，其机制必落入已知转换族或引入新命名转换——不会有「无机制跨层吸收」。

### 2.3 A1 校准事件的模型论解剖：损伤不变性条件

预演把 A1 记为「M 损伤」是**范畴错误**：单侧公理化与双侧公理化的定理闭包**相等**（演绎等价理论——same closure operator），「移除右侧条款」没有杀死任何定理，只是把「右侧」从公理身份降为定理身份。**损伤分型必须对演绎等价不变**——这是分型函子 D 的良定义性条件：

> **D-不变性原则**：若 Cl(T−A) = Cl(T−A′)（演绎闭包相等），则 D(A) = D(A′)。

预演违反了它（同一闭包被记为两种损伤型）。A1 的真实损伤 = 认知组织层（哪些算公理哪些算定理的簿记差异），不在 S/M/P 任何一层——或者说是**第零层（簿记层）损伤**。这提示 G-0 v2 应显式声明零层：演绎等价重排不记损伤。

### 2.4 T3 证伪的量词结构：假设弹性

K2 与 E6 的分裂判定有干净的量词形式。定义残留谓词：

> residue(A, L) ⟺ **∀** 弱化 T′ ∈ Weak(死定理群@L)：T′ 亦死

- K2：**∃** T′（Banach 的轨道完备化变体，Park 线）存活 ⇒ ¬residue(K2, M)。完备性假设有弱化实例——「弹性」；
- E6：**∀** T′（唯一性的一切弱形式——连「至多一个」都是 multilattice 的定义性让步）唯一性内容仍死 ⇒ residue(E6, S)。唯一性陈述无可弱化形式——「刚性」。

**H-G0-3 条件律 = 量词交换律**：缺层 ⇒ 残留，当且仅当损伤定理群的弱化空间为空。这把「假设弹性」变成可预注册的机械变量：Weak(T) 的文献计数（定理有几个存活的弱化变体）。同时揭示 K2 档案高估的根源：run 2 记账把「定理 T 死」当原子事实，但 T 的**模式（schema）存活**（T[完备/轨道完备]）——死亡分型应对 schema 而非 instance 计。这是 dose 记账的单位修正：**剂量单位 = 定理模式，非定理实例**。

### 2.5 三例跨层机制的统一：都是「局部化」

frag（D6：一阶片段）、reif（E1：超穷迭代的局部构造）、weak（K2：轨道完备 = 完备性的 T-局部化）共享同一数学姿势：**把全局性质局部化到子结构上以换取存活**。逻辑学谱系：模型论的有界性/局部性现象（Łoś 一阶局部性 / o-minimality 的局部可定义性）、证明论的片段层级、范畴论的 Kan 局部化。**候选统一命题（H-loc，run 3+）**：跨层吸收 = 层标签在局部化算子下的不保持——局部化 functor L: 𝓛 → 𝓛 不保持层标记，其象的偏移即三个已录转换。若成立，「三机制」收敛为「一原理」（局部化），G-0 文法获得单一生成机制。
