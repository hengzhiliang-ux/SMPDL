# SMPDL 基础对比审计：交换环 vs 非交换环二项式幂

> **对比对象**
> - "PreFix" 版本：交换环中 (ab)ⁿ = aⁿ bⁿ（见 `SMP_ProofAnalysis_CommutativeRing_BinomialPower.md`）
> - "PostFix" 版本：非交换环中 (ab)ⁿ = a(ba)ⁿ⁻¹ b（见 `SMP_ProofAnalysis_NonCommutativeRing_BinomialPower.md`）
> 
> **审计日期**：2026-10-13  
> **审计框架**：Göttingen S/M/P × D/L v1.5  
> **总体评价**：⚪ ↔ ⚪ 两个版本在各自公理体系内均正确；差异来自基础假设（乘法交换律是否存在），而非证明错误。

---

## 1. 版本声明对比

| 维度 | 交换版本（PreFix） | 非交换版本（PostFix） |
|---|---|---|
| **主声明** | 在交换环中，(ab)ⁿ = aⁿ bⁿ | 在非交换环中，(ab)ⁿ = a(ba)ⁿ⁻¹ b |
| **乘法交换律** | 存在：∀a, b, ab = ba | 不存在：一般 ab ≠ ba |
| **关键操作** | 重排因子顺序 | 保持因子顺序，重组括号 |
| **核心工具** | `mul_comm` / 乘法交换律 | `mul_assoc` / 乘法结合律 |
| **结论简洁度** | 简洁，对称 | 较复杂，保留 a 与 b 的耦合结构 |
| **典型反例** | 无 | 矩阵环：取 A, B 为 2×2 矩阵，通常 (AB)² ≠ A² B² |

## 2. PreFix 版本 SMPDL 速览（交换环）

详见 `SMP_ProofAnalysis_CommutativeRing_BinomialPower.md`。

- **S*D**：自然语言依赖“环 → 结合律 → 交换律 → 幂定义 → 归纳”的语义链。
- **S*L**：量词清晰，但“交换律”是常被省略的关键语义条件。
- **M*D**：CommRing → associativity + commutativity → `mul_pow`。
- **M*L**：逻辑完整；n = 0 在含幺环下成立。
- **P*D / P*L**：Mathlib 提供 `mul_pow`，可直接复用。

**PreFix 判定**：⚪ 已确认正确（在交换环体系内）。

## 3. PostFix 版本 SMPDL 六格审计（非交换环）

### 3.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| 非交换环定义 | 环公理 + 乘法未必交换 | ✅ |
| 结合律 | 允许省略括号 | ✅ |
| 幂的定义 | 连乘表示 | ✅ |
| 归纳假设 | (ab)ᵏ = a(ba)ᵏ⁻¹ b | ✅ |
| 结论 | (ab)ⁿ = a(ba)ⁿ⁻¹ b | ✅ |

### 3.2 S*L — 语义逻辑结构

- 非交换版本无法使用“把 b 提到 a 前面”的直觉。
- 通过“保持顺序、提取首尾 a 与 b”完成证明。
- ⚠️ 自然语言中极易写出 (ab)ⁿ = aⁿ bⁿ，这是 S*L 层面的主要风险。

### 3.3 M*D — 数学依存

```text
NonCommutativeBinomialPower
    │
    ├── Ring R (not necessarily commutative)
    │
    ├── Definition: a^n = a·a·...·a
    │
    ├── Associativity: (x·y)·z = x·(y·z)
    │
    └── Induction
            ├── Base n = 1: ab = a·1·b
            └── Step: (ab)^{k+1} = (ab)^k (ab)
                                = a (ba)^{k-1} b a b
                                = a (ba)^{k-1} (ba) b
                                = a (ba)^k b
```

- 依赖关系闭合，无悬空前提。

### 3.4 M*L — 数学逻辑结构

| 检查项 | 交换 | 非交换 | 差异说明 |
|---|---|---|---|
| 量词范围 | 任意 a, b ∈ R | 任意 a, b ∈ R | 论域相同，公理不同 |
| 边界情况 | n = 0 自然成立 | 应限定 n ≥ 1 | 无交换律时 n = 0 公式不适用 |
| 隐藏假设 | 默认含幺 | 默认含幺 | 两者一致 |
| 结论形式 | aⁿ bⁿ（解耦） | a(ba)ⁿ⁻¹ b（耦合） | 交换律决定能否解耦 |

### 3.5 P*D / P*L — 编程层

- 两个版本在 Mathlib 中都可形式化。
- 交换版本直接调用 `mul_pow`。
- 非交换版本需使用 `Ring` 类型类并手动保持顺序，不能误用 `mul_comm`。
- 非交换版本的 P 层风险更高：容易在形式化中错误引入 `CommRing` 实例。

## 4. 跨层映射检查（PostFix vs PreFix）

| 映射 | 交换（PreFix） | 非交换（PostFix） | 变化 |
|---|---|---|---|
| S → M | “交换 a 与 b” → `mul_comm` | “保持 a 在左、b 在右” → `mul_assoc` | 核心操作改变 |
| M → P | `mul_pow a b n` | 手动 `induction` + `mul_assoc` | 形式化策略改变 |
| S ↔ P | 重排 → 交换律引理 | 重组括号 → 结合律引理 | 语义-代码桥梁不同 |
| S ↔ S | (ab)ⁿ = aⁿ bⁿ | (ab)ⁿ = a(ba)ⁿ⁻¹ b | 结论形式变化 |
| M ↔ M | 交换环公理 | 非交换环公理 | 公理基础变化 |

**跨层结论**：两个版本的 S/M/P 层各自自洽，但层间映射关系不同；差异根源于一条公理（乘法交换律）的有无。

## 5. 判定：PostFix 是否为真？

| 维度 | 交换（PreFix） | 非交换（PostFix） |
|---|---|---|
| 自然语言声明真实性 | ⚪ 真 | ⚪ 真 |
| 证明正确性 | ⚪ 正确 | ⚪ 正确 |
| 形式化验证 | ✅ Mathlib `mul_pow` | ✅ 手动证明可行 |
| 与已知数学兼容性 | ✅ 与交换代数兼容 | ✅ 与矩阵论、量子力学等兼容 |
| 退化/极限情况 | n = 0 成立 | n = 1 为恒等；n = 0 需含幺且单独处理 |

**SMPDL 判定（PostFix）**：⚪ **低风险 / 已确认正确**。非交换版本不是对交换版本的“修复”，而是“在更少公理假设下得到的正确推广”。

## 6. 变化类型归类

- **变化方式**：**基础假设迁移**（foundation shift），而非证明错误修复。
- **核心假设差异**：
  - 交换版本：乘法交换律 ab = ba 成立。
  - 非交换版本：不假设乘法交换律；仅保留结合律。
- **证明骨架相似性**：两者都通过“展开幂 → 处理乘积 → 归纳完成”达到结论，但处理顺序的手段不同。
- **SMPDL 同构标签建议**：`S-BISIM / M-BISIM / P-BISIM`。
  - S-BISIM：自然语言骨架相似（“展开幂 + 归纳”），但结论语义不同。
  - M-BISIM：都依赖结合律与归纳，但交换律的存否改变了核心等式。
  - P-BISIM：都可用 Mathlib `Ring` 类族实现，但具体引理不同。
- **关键 lesson**：一条公理的有无可以改变结论形式；在跨基础迁移时，不能默认“证明直觉”可逐字移植。

## 6.5 概念奇点（Conceptual Singularity）

### 6.5.1 本组对比中的关键人工洞察

- **保留归纳骨架，改变重排规则**：`(ab)^n` 的归纳展开在交换与非交换环中形式相同，但交换律的调用位置被“保持顺序”取代。
- **发现非交换形式 `(ab)^n = a(ba)^{n-1}b`**：这一恒等式不是机械反推能直接得到的，而是对四元数等历史案例的抽象。
- **识别乘法交换律是“默认假设”而非代数本质**：Hamilton 1843 年发现四元数后，人类才系统意识到交换律只是可选公理。

### 6.5.2 为什么机器难以自动迁移

机器可以机械展开 `(ab)^n` 并发现 `ab ≠ ba` 时无法合并项，但**重新组织展开式为 `a(ba)^{n-1}b`** 这一“保持循环顺序”的洞察，需要人类对非交换代数结构的识别。

## 6.6 断裂强度（Breakage Strength）

| 评估项 | 等级 | 说明 |
|---|---|---|
| **断裂强度** | 🟠 引理替换 | 乘法交换律被移除；核心恒等式从 `(ab)^n = a^n b^n` 变为 `a(ba)^{n-1}b`。 |
| **S 层影响** | 中 | 符号 `(ab)^n` 相同，但展开语义不同。 |
| **M 层影响** | 中高 | 核心结构从“可重排”变为“保持顺序”，影响所有依赖交换律的恒等式。 |
| **P 层影响** | 低中 | 形式化中只需关闭 `CommMonoid` 类型类假设，但所有调用交换律的位置需人工复核。 |

**判定**：本组迁移是**单条公理移除引发的引理体系替换**，故评为 🟠。
