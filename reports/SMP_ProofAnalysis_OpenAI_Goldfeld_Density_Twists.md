## 1. 命题与声明

**Goldfeld 猜想**：对任意定义在 ℚ 上的椭圆曲线 E，其二次 twists Eᵈ 的解析秩为 0 和 1 的集合在 signed squarefree twists 中各占密度 1/2；平均解析秩趋于 1/2。

**2-逆命题**：若 E 的 2^∞-Selmer corank 为 0 或 1，则解析秩与 Mordell–Weil 秩均等于该 corank，且 Tate–Shafarevich 群有限。

这两个结果合在一起意味着对一大类 twists 的完整 BSD 型控制。

### 2.2 S*L — 语义逻辑结构

- "every elliptic curve over ℚ" — 全称量词。
- "density 1/2" — 需要自然的密度定义和有效的误差项。
- 风险：可能把「对某个具体曲线族成立」误作「对所有曲线成立」，或把「平均上界」误作「精确平均」。

### 2.3 M*D — 数学依存

| 依赖 | 状态 |
|---|---|
| BSD 猜想（部分） | ⚠️ 密度结果通常弱于逐点 BSD，但 2-逆命题接近逐点 |
| Iwasawa Main Conjecture | ⚠️ 未说明 |
| 二次 twists 的 L-函数对称幂 | ⚠️ 未说明 |

| 同族 002 BSD、006 等 | 🔴 版本一致性关键 |

**关键风险**：Goldfeld 猜想需要同时控制 rank 0 和 rank 1 的密度，以及排除 rank ≥ 2 的正密度。后者通常需要非消失结果（non-vanishing）与哥德巴赫型筛法的精细结合。

### 2.4 M*L — 数学逻辑结构

- 密度结论需要构造可测集合并证明极限存在。
- 常见陷阱：
  - 仅证明「至少一半 rank 0 和一半 rank 1」，未证明「恰好各一半」。
  - 仅证明平均秩 ≤ 1/2，未证明 = 1/2。
  - 2-逆命题中对「所有素数 2」的处理可能需要特殊论证。

### 2.5 P*D — 编程/形式化依存

- 未明确提及 Lean 形式化。
- 若依赖数值计算（如大量 twists 的秩计算），需确认计算范围与统计推断的严谨性。

### 2.6 P*L — 编程逻辑结构

## 5. 人工可能需要确认/补充证明的地方

1. **密度定义**：明确 twists 的排序方式（signed squarefree by absolute value）与密度可测性。
2. **rank ≥ 2 排除**：给出排除正密度高秩 twists 的核心论证，这是 Goldfeld 猜想最困难的部分。
3. **2-逆命题的全局性**：确认结果是否对所有椭圆曲线成立，还是仅对满足某些条件（如无理性 2-torsion）的曲线成立。
4. **同族一致性**：核对与 002 BSD、006 等同族论文的版本号和结论范围是否一致。
5. **BSD 精细常数**：若声称完整 BSD 公式，需给出周期、调节子、Tamagawa 数、#Sha 的精确关系。
