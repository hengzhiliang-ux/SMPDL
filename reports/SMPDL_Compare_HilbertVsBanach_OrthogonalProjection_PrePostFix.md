## 1. 版本声明对比

| 维度 | Hilbert（PreFix） | Banach（PostFix） |
|---|---|---|
| **结构** | 内积（⇒ 范数 + 角度） | 仅范数 |
| **闭凸投影** | ✅ 存在唯一 | ❌ 可能不存在（c₀）/不唯一（C[0,1]） |
| **正交分解** | ✅ `H = M ⊕ M^⊥` | ❌ 无内积；零化子在 X* 中 |
| **对偶** | ✅ Riesz：`H* ≅ H` | ❌ 外置：`ℓ¹*=ℓ^∞`，`L^∞*⊋L¹` |
| **核心定理** | 投影 + Riesz | Hahn–Banach 分离（依赖 AC） |
| **几何语言** | 垂直/投影/夹角 | 凸性/分离/次微分 |
| **判定工具** | Jordan–von Neumann（范数⇔内积） | 平行四边形失效即 Banach |
| **历史定位** | Hilbert 1900s / Riesz 1907 | Banach 1932 |
| **形式化** | 🟢 成熟 | 🟡 部分 |

## 2. PreFix 版本 SMPDL 速览（Hilbert）

- **S*D**：内积 → 平行四边形恒等式 → 极小化序列收敛 → 投影 + 变分不等式 → Riesz。
- **S*L**：⚠️ 投影存在性 = 内积 ∪ 完备性的**合礼**，常被误记为完备性单独功劳。
- **判定**：⚪ 框架内正确。

## 3. PostFix 版本 SMPDL 六格审计（Banach）

### 3.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| 仅范数 | 无角度 | ✅ |
| c₀ 不可达反例 | Phelps | ✅ |
| C[0,1] 多解 | Chebyshev | ✅ |
| HB 分离 | AC | ✅ |
| 次微分 | 凸替代 | ✅ |

### 3.2 S*L — 语义逻辑结构

- "⊥"同名异义：Hilbert 中 `M^⊥ ⊆ H`，Banach 中零化子 `M^⊥ ⊆ X*`——**居住在不同空间**。
- 自反性（`X** ≅ X`）成为 Banach 空间的稀缺属性（Hilbert 免费享有）。
- ⚠️ 风险：把 Hilbert 证明（用内积）转写到 Banach 而未替换工具。

### 3.3 M*D — 数学依存

```text
norm only → no parallelogram → projection fails (c₀ / non-unique)
→ dual external (ℓ¹*=ℓ^∞, L^∞*⊋L¹)
→ replacements: Hahn–Banach (AC), subdifferential, duality pairing
```

### 3.4 M*L — 数学逻辑结构

| 检查项 | Hilbert | Banach | 差异 |
|---|---|---|---|
| 投影存在 | ✅ | ❌ c₀ | 反转 |
| 唯一性 | ✅ | ❌ C[0,1] | 反转 |
| 自对偶 | ✅ | ❌ | 反转 |
| 分离定理 | 内积可证 | HB（需 AC） | 公理代价 |

### 3.5 P*D / P*L — 编程层

- Mathlib 两侧均有基础；反例形式化（Phelps 构造）稀缺。

## 4. 跨层映射检查

| 映射 | Hilbert（PreFix） | Banach（PostFix） |
|---|---|---|
| S → M | "角度" → 投影/Riesz | "无角度" → 分离/次微分 |
| M → P | `InnerProductSpace` 成熟 | `NormedSpace` + HB |
| S ↔ S | "⊥" 在 X 内 | "⊥"（零化子）在 X* 内（同名异义） |
| M ↔ M | 几何定理群 | 凸分析定理群 |

**跨层结论**：与 H4（交换/非交换环）同构的"**单结构移除**"模式：只删内积（保完备），投影与自对偶立即坍塌，几何整体换成凸分析。调参旋钮唯一而杀伤面巨大。

## 6. 变化类型归类

- **变化方式**：**公理迁移（移除内积公理，保留范数完备性）引发定理级坍塌** —— 断裂迁移。
- **SMPDL 同构标签建议**：`S-BISIM / M-BISIM / P-BISIM`。
- **关键 lesson**：AI 在 Banach 框架生成证明时，凡 Hilbert 式"取投影""正交分解"步骤全部非法；须替换为 HB 分离/次微分，并声明 AC 依赖。

## 6.5 概念奇点（Conceptual Singularity）

### 6.5.1 关键人工洞察

- **识别内积是几何的唯一来源**：长度保留不等于几何保留——角度消失即投影消失。
- **把"对偶"升格为主角**：Hilbert 中对偶平凡（≅自身），Banach 中对偶成为新大陆（L^∞* 的奇异泛函、自反性分级）。
- **用凸性重建柔软几何**：HB 分离 + 次微分构筑无角度世界的"准垂直"语言。

### 6.5.2 为什么机器难以自动迁移

机器可在给定空间验证投影是否可计算，但**预判"内积消失会摧毁哪些定理、留下哪些"**需要结构依赖网络的全局观。c₀ 反例、L^∞* 严格扩张等关键反例是历史构造的结晶，搜索空间巨大。

|---|---|---|
| **断裂强度** | 🔴 结论反转或不可证 | 投影存在性、唯一性、自对偶三重反转；HB 反而新增 AC 依赖。 |
