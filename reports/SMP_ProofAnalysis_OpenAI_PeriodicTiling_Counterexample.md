## 1. 命题与声明

论文研究 $\mathbb{R}^3$ 中的平移镶嵌（translational tiling）。一个 tile $T \subset \mathbb{R}^3$ 可以镶嵌 $\mathbb{R}^3$，如果存在平移集合 $\Lambda \subset \mathbb{R}^3$ 使得 $T + \Lambda$ 无重叠且几乎处处覆盖 $\mathbb{R}^3$。

典型声明形如：

- 存在一个 tile $T \subset \mathbb{R}^3$ 使得 $T$ 可以镶嵌 $\mathbb{R}^3$，但不存在任何 fully periodic tiling（即不存在有限协体积的平移格 $\Lambda$ 使得 $T + \Lambda$ 镶嵌）；
- 该 tile 是某种多面体或有限个多面体的并。

该方向的经典结果包括 Greenfeld–Tao (2022) 在高维构造的 aperiodic tiles，以及 Berger、Robinson 等的低维非周期镶嵌历史。三维情形此前未有完整反例。

### 2.2 S*L — 语义逻辑结构

- 必须区分“存在某种非周期镶嵌”与“不存在任何周期镶嵌”：前者弱得多。
- 必须区分“tile 是单连通多面体”与“tile 是有限个连通分支的并”。
- 风险：可能把“可构造非周期镶嵌”滑移到“否定三维周期镶嵌猜想”。

### 2.3 M*D — 数学依存

| 依赖 | 状态 |
|---|---|
| Greenfeld–Tao (2022) 高维构造 | ⚠️ 是否被引用并降维 |
| 符号动力系统 / 组合群论 | ⚠️ 是否用于构造 |
| 傅里叶分析 / 周期集刻画 | ⚠️ 是否用于证明非周期 |
| 紧致性论证（存在镶嵌） | 🟡 标准但需显式 |

**关键风险**：三维反例通常需要从高维构造“折叠”到低维，或通过复杂的局部规则实现。构造的显式性与可验证性是关键。

### 2.4 M*L — 数学逻辑结构

- 典型证明结构：
  1. 显式定义 tile $T$（可能为多面体或带标签的 tile）；
  2. 证明 $T$ 能镶嵌 $\mathbb{R}^3$（通过局部可扩展性或 compactness）；
  3. 证明任何镶嵌都不是 fully periodic（通过 Fourier 零点集或周期结构分析）。
- 陷阱：若使用 compactness 证明存在镶嵌，则需确保 tile 满足局部规则的一致性。
- 风险： tile 可能非常复杂，人工难以直观验证其镶嵌性质。

### 2.5 P*D — 编程/形式化依存

- README 可能指向 [Lean](lean/docs/155.md)，但未说明形式化范围。
- 风险：Lean 可能只形式化了：
  - 平移镶嵌的定义；
  - tile 的离散描述；
  - 某个辅助引理，而非完整构造。
- 特别风险：形式化可能无法表达三维几何体的拓扑性质。

### 2.6 P*L — 编程逻辑结构

- 若形式化完整，需要检查：
  - 是否严格定义了 tile、tiling、periodic tiling；
  - 是否给出 tile $T$ 的具体描述；
  - 是否证明了存在性与非周期性两个方向。

## 5. 人工可能需要确认/补充证明的地方

1. **Tile 的显式描述**：给出 $T$ 的具体几何构造（多面体顶点坐标、有限并、标签规则），确保人工可验证。
2. **镶嵌存在性**：证明 $T$ 能镶嵌 $\mathbb{R}^3$，是通过显式构造局部 patch 并扩展，还是通过 compactness/旗标系统。
3. **非周期性证明**：明确证明不存在 fully periodic tiling 的方法（Fourier 零点、周期结构分析、组合障碍等）。
4. **与 Greenfeld–Tao 的比较**：说明三维构造与高维构造的关系，是否直接降维、折叠或全新构造。
5. **算法可验证性**：是否给出算法生成任意大的镶嵌 patch；若没有，人工需构造足够大的 patch 观察是否有周期性。
6. **小 patch 可视化**：人工绘制或生成三维 tile 的小镶嵌 patch，检查局部一致性。
7. **Lean 主定理范围**：确认 Lean 是否形式化了 tile 的几何描述、镶嵌存在性与非周期性，还是仅证明抽象引理。
