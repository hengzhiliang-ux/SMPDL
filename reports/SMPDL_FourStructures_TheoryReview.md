## 二、认知结构：数学心智如何处理假设

### 2.1 四阶段显性化模型（历史-认知双重视角）

| 阶段 | 时期 | 认知模式 | 风险 |
|---|---|---|---|
| 0 前公理化默认 | 古代–17 世纪 | 直觉即基础 | 无法区分"直观显然"与"公理假设" |
| 1 公理化封装 | 19 世纪 | 直觉打包成公理，仍默认唯一 | 把某一系统当"唯一正确" |
| 2 基础危机与替代 | 19 末–20 初 | 发现可替换性 | 混淆"等价表述"与"等价基础" |
| 3 多元基础竞争 | 20 中后期–今 | 基础 = 选择参数 | 未声明 AxiomaticBase 致跨基础误迁移 |

H1–H46 全部 46 组可无残余地落进此模型（阶段 2/3 密集），模型本身通过全库映射检验。

### 2.2 四条认知机制（为何某些假设"先被默认"）

1. **经验根植性**：最先接受的假设最贴身体经验（平面/连续/交换/排中）——**可检验推论：离身体经验越远的假设越晚被接受**（曲率/非交换/非构造性/无穷小四个历史案例方向一致；探索性——"接受时间"无预注册操作化判据、无对照样本，2026-10-15 诚实审查 B1 收紧）；
2. **表达经济性**：默认基础 = 证明效率最高（平行公设省证明 / AC 一次解决存在性 / LEM 简化反证），**不是认知最忠实**——每条经济性都有隐性代价（遮蔽曲率/丧失构造性/无法提取 witness）；
3. **反常积累**：基础变革由反常积累推动而非单一反例（平行公设两千年尝试失败→非欧；Berkeley 批评 200 年→ε-δ；Russell 悖论→公理化）——审校启示："长期被视为显然"的假设最可能是隐性基础；
4. **语言固化**：见 §三（语言学结构，但机制源头在认知——语言形式不变导致认知迁移错误）。

### 2.3 移除-涌现的认知机制（M1/M2/M3）

- **M1 问题不消失**：被移除律回答的问题仍被需要——需求侧不变，供给侧重组（α 补偿型的认知来源）；
- **M2 约束的边界即对象**：律在位时遮蔽一批"不满足者"，移除 = 撤销遮蔽 = **例外物不是被发明而是被解禁**（β 例外型）——这是全项目最有认知科学味道的发现：数学对象有"研究资格"的准入制度；
- **M3 公理化本能**：两个互斥世界都被充分研究后，数学心智必然寻找母结构（γ 回收型）。

### 2.4 认知瓶颈与幸存者偏差（诚实披露款）

- **L3 长停留是常态**：全流程最慢的一步是"反常的再分类"——**意识到需要独立性证明比证明它更难**（Fubini 80 年、Archimedes 两千年）；
- **幸存者偏差**：入选标准偏好"成为历史事件"的移除 ≈ 被填充——"无一例外"断言含同义反复成分，其经验检验只能靠前向登记（OS 轮 + B4 线正在做）；
- C1/C2（有需求/有土壤）涌现条件**尚无操作化判据**（审计 🟠-6 降格），当前为组织性假设。

## 三、语言学结构：命名、语义与术语迁移

### 3.1 S 层的职责：同名异义检测

同一术语在不同基础下语义不同、语言形式不变——这是跨基础迁移错误的主要载体：

| 术语 | 基础 A 义 | 基础 B 义 | 对应组 |
|---|---|---|---|
| 存在 | ∃x P(x) | 可构造 witness + 验证 | H7 |
| 等于 | 外延相等 | identity type / 同构等价 | H9/H12 |
| 收敛 | ε-δ 极限 | 无穷小无限接近 | H6 |
| 直线 | 欧氏直线 | 测地线/大圆 | H1/H16 |
| 交换（积分次序） | 默认权限 | 三档定价（免费/L¹/禁区） | H30 |
| 复制（证明资源） | 背景权利 | 显式商品（bang 付费） | H36 |

### 3.2 语义层的结构判定（ISO/BISIM 的 S 轴）

- **S-ISO**：术语替换后其余结构无需调整即可运行（可审计的对应表）；
- **S-BISIM**：外部可观察性质保持但内部语义实现不同——**同构分类学手册**给出决策树与常见误用清单；
- **语义迁移**（四类迁移之一，🟠 级）：H13"概率"的频率/信念双义是范式案例。

### 3.3 涌现物的命名与污染（对 AI 审校的关键应用）

- 涌现物命名核查：AI 在移除语境生成"新结构"（次微分/语境/分布）时，须核对其与被移除律的关系是否正确（α 补偿还是 β 例外？错配 = 语义错误）；
- **反向错误**：用旧世界概念描述新世界（"角度"入 Banach 空间、"真值表"入量子格）= **涌现物被旧概念污染**；
- **概念奇点**：每组对比中"机器难以自动迁移的人工洞察"——语言的不可翻译点，人类五岗位（A–E）存在的理由。

### 3.4 术语时序 = 司法证据（本项目自身的方法论贡献）

**F2 术语首现扫描**把语言学结构制度化：术语的 git 首现时间可判定"预测是否事后回填"——B4-2 用它抓获冻结算子列回填（lens 术语首现晚于登记 17 小时）；B4-3 用它披露三项名称级早期暴露 + 一轮扫描工具假阴性（勘误 3）。**语言痕迹的时间戳纪律**是回测纪律 v2.0 的取证核心——这是语言学结构对科学诚信工程的直接输出。

## 四、数学结构：律学 · 涌现学 · 预测学（最大板块）

### 4.1 律学三维坐标（律是坐标，迁移是操作）

每条入库律携带三个独立坐标：

```text
强度分级（律在结构中的地位）：甲级 公理级 11 / 乙级 表征级 12（"结构指纹"，拨它=伴随结构同生共死）/ 丙级 规则级 2
认识论档位（真假由什么裁定）：E 定理律 / D 定义律 / I 独立律 —— 审计风险 E<D<I
功能类型（回答什么问题）：T1 对象构成 / T2 行为保证 / T3 不变禁闭
```

### 4.2 移除-涌现理论（"数学的伤口从不留白"）

- **三型**：α 补偿型（谁顶班——更弱更普适）/ β 例外型（被解禁——最富结构性，例外常反客为主）/ γ 统一回收型（被回收——历史地位最高，每次标志学科成熟）；
- **两阶段理论（经三型六验 + 前向 10/10）**：
  - 阶段一（即时）：涌现类型 ← 功能类型（**T1→β / T2→α+元层 / T3→β-现象**）；
  - 阶段二（长期）：γ 回收 ← 领域成熟度，**与功能类型正交**（γ 跨三型分布已验证）；
- **γ 五形态定稿**：表征型（⇔ 即时）/ 因果型（为修复而发明）/ 渐近型（极限影子）/ 成熟型 / **翻译型**（失效模式对象化——"病即信息"三连 H38/H36/H41 的统一形态，预测"失效位置学"）；
- **不对称律（组织性观察）**：**减法倾向生结构，加法倾向生定理**——H29 完备律加入 = 全库唯一加法对照（定理群生根、零新概念）；创造力方向为负。

### 4.3 预测机器与战绩

- 查表规则（机械可推导，非自由裁量）：T1 对象律→β 主 / T2 行为律→α+元层主；
- **前向 10/10**（B4-2 R5–R14 独立盲判：主型 κ=1.00 + 三档 κ=1.00）+ 扩样 3/3（B4-3：主型 κ=1.00 tier-1 通过，单判定者如实披露）；追溯 3（H27–H29）框架外不计入命中率（T3-S2 口径）；
- **B4 基线受压（今日新发现）**："凡移除皆 β"朴素基线在 T2 样本 H45/H46 上 0/2——行为律移除的涌现是 α 补偿主而非 β 解禁主，**预注册判别点实测成立**；
- 标志性命中：bang 付费操作符（H36 教科书级）、即时 γ（H37）、BKT 拓扑相变（H42 β-现象诺奖级）、γ 三形态单组齐聚（H43）。

### 4.4 结构间暗线：跨域锚八个

ℚ-ℝ-*ℝ 三角 / 动力三律轴 / no-cloning（逻辑×物理）/ 几何-代数镜像 / 交换代数三律轴 / 极限↔范式同型 / "病即信息"三连 / 度量-拓扑桥——跨域锚 = 框架押注家族的实证。

### 4.5 学科生长规律

- **学科二型论**：分类学型学科（李理论/NC 几何——纯对象解禁单通道可成）vs 方法学型学科（凸分析/Sobolev/均衡/非标准分析——需独立双通道）；
- **双面律假说 v3（收紧版）**：双面 = 两侧有独立历史实现轨道；T3 禁闭律天然双面；现存学科级涌现全部为双面 ✓；
- **条件类对象**：由被移除的行为保证划出的系统类（正交系统/线性类型/DCFL/Brouwer 序列）——与 T1 遮蔽对象的存在论方向相反；
- 移除一条律长出一门学科：凸分析 / Sobolev-分布 / 测度论（三例学科级）。

### 4.6 统计诚实款

律伴随迁移 🔴 率 RR：小样本 3.73 / 大样本 2.24——**均探索性、显著性不稳健**（Fisher p=0.41），方向一致但全量 43 组重跑 + 预注册判读前不作定律引用（P1-⑦ 待领）。

## 五、逻辑学结构：档位 · 元层 · 自反性

### 5.1 E/D/I 档位与静默风险

| 档 | 裁定者 | 审计风险 |
|---|---|---|
| E 定理律 | 数学内证明 | 低——错用显性报错 |
| D 定义律 | 概念选择 | 中——类型声明错位 |
| I 独立律 | 独立性证明 | **高——错用静默**：暗中假设 LEM/AC 不产生矛盾，只悄悄缩小定理适用域 |

**I 档静默最危险**是 Law-Gate 门控的倾斜依据；同律两侧可异档（H27 布尔 D / 量子 E——跨档正是对比断裂之源）。

### 5.2 升降档位：逻辑学的历史动力学

- **降档**（显性化：律从默认变选择）：平行公设 1868 / 交换律 1843 / 结合律 1843.12 / LEM 1930s / AC 1938-63；
- **升档**（E′ 再定理化：律死后遗产在新框架变回定理）：Gauss-Bonnet / Zorn / Gleason-KS / Curry-Howard / bang / Ostrowski / 理想论……
- **四质疑集群**（1843 代数解放 / 1899–1908 几何-集合 / 1931–38 元数学 / 1963–67 forcing）约 30 年一爆，**工具先于质疑**；
- **裁决工具六代 G1–G6**：几何模型→独立性方法→算术化→forcing→语义发明→**构造性类型论+证明助手（进行中）**。

### 5.3 元层涌现（关于律的算法）——逻辑学结构最具预测力的部分

T2 行为律移除 → α 补偿 + **元层**（把律的检查本身算法化）：规范化定理（Gentzen 1935）/ 力迫（关于 AC 的模型构造，G4）/ KB 完备化 / 静态分析 / 证明助手产业（G6）——元层涌现与 G 代际**精确对应**，功能类型学把零散现象升格为代际实证。

### 5.4 逻辑律作为研究对象（而非先验背景）

LEM（H7：Curry-Howard 回收 + Heyting 代数把布尔回收为特例）/ AC（H8：L 宇宙 + AD 定理化否定 + 力迫元层）/ DC（H20）/ 收缩-弱化（H36：推理语法本身可调，定价优于禁止）/ 量子逻辑（H27：**逻辑是理论的结构属性而非先验**，"真"降为语境内）。五组把"逻辑"从审校的背景规则变成了被审计的对象——这是 SMPDL 对逻辑学结构最根本的姿态转变。

### 5.5 自反性：框架过自己的关卡（逻辑学结构的最高应用）

- **压测→执行→重测**：B1 抓到自家双面律假说的不可证伪缺陷→收紧判据；李理论从反例转正例；零矛盾回溯；
- **回测纪律 v2.0 十关制**：B4-2 三连翻车（同日自判/材料包泄露/冻结回填）逐条立例成硬条款；B4-3 首例全程执行（十关全闭 + 三轮勘误全披露）；
- **κ 双层 + 预注册判读**：理论自身的可信度用与被审计对象同一套逻辑标准管理——**重测 ≡ E 档 `#print axioms` 的元层同构**（理论也要过自己的关卡）。
