# SMPDL 基础对比审计：欧氏 ↔ 球面 ↔ 双曲三角形内角和

> **对比对象**
> - “PreFix-A” 版本：欧氏几何三角形内角和 = π
> - “PreFix-B” 版本：球面几何三角形内角和 = π + Area/R²
> - “PostFix-C” 版本：双曲几何三角形内角和 = π - Area
> 
> **审计日期**：2026-10-14  
> **审计框架**：Göttingen S/M/P × D/L v1.5  
> **历史编号**：H16  
> **总体评价**：⚪ ↔ ⚪ ↔ ⚪ 三个版本在各自公理体系内均正确；差异来自常曲率 `K` 的取值（0 / 正 / 负）。

## 1. 版本声明对比

| 维度 | 欧氏（PreFix-A） | 球面（PreFix-B） | 双曲（PostFix-C） |
|---|---|---|---|
| **主声明** | 任意三角形内角和 = π | 任意球面三角形内角和 = π + Area/R² | 任意双曲三角形内角和 = π - Area |
| **曲率 `K`** | 0 | 正（常数 `1/R²`） | 负（常数 `-1`） |
| **平行公设** | 成立：过直线外一点有唯一平行线 | 不成立：无平行线 | 不成立：过直线外一点有无穷多条平行线 |
| **“直线”定义** | 欧氏直线 | 大圆（测地线） | 双曲测地线 |
| **面积与角度关系** | 独立（面积不影响内角和） | 内角和 > π，角盈 = Area/R² | 内角和 < π，角亏 = Area |
| **历史定位** | Euclid ~300 BCE | 19 世纪非欧几何（Riemann） | 19 世纪非欧几何（Lobachevsky, Bolyai, Gauss） |
| **典型模型** | 平面直角坐标 | 球面坐标 / 嵌入 `ℝ³` | Poincaré 圆盘 / 上半平面 |

## 4. PostFix-C 版本 SMPDL 六格审计（双曲）

### 4.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| 双曲平面（`K = -1`） | 常负曲率空间 | ✅ |
| 双曲测地线 | 双曲距离下的最短路径 | ✅ |
| 双曲三角形 | 三条测地线段 | ✅ |
| Gauss-Bonnet 定理 | 曲率积分 + 外角和 = 2π | ✅ |
| 面积与角亏关系 | `Area = π - (α+β+γ)` | ✅ |

### 4.2 S*L — 语义逻辑结构

- 双曲几何是球面几何的“负曲率镜像”：球面角盈，双曲角亏。
- 关键洞察：把曲率 `K` 从 0 推广到正/负，统一公式为 `α+β+γ = π + K · Area`。
- ⚠️ 主要 S*L 风险：把 Poincaré 模型中的欧氏圆弧线误当作双曲直线；或把双曲“角”与欧氏模型视角混淆。

### 4.3 M*D — 数学依存

```text
HyperbolicTriangleAngleSum
    │
    ├── Hyperbolic plane with K = -1
    │
    ├── Geodesic triangle Δ
    │
    ├── Gauss-Bonnet: K·Area + (π-α)+(π-β)+(π-γ) = 2π
    │
    └── K = -1 ⇒ α+β+γ = π - Area
```

- 依赖关系闭合：依赖双曲几何公理与 Gauss-Bonnet。

### 4.4 M*L — 数学逻辑结构

| 检查项 | 欧氏 | 球面 | 双曲 |
|---|---|---|---|
| 曲率 `K` | 0 | `1/R² > 0` | `-1 < 0` |
| 内角和 | π | π + Area/R² | π - Area |
| 平行线 | 唯一 | 无 | 无穷多 |
| 退化极限 | 面积 → 0，和 → π | 面积 → 0，和 → π | 面积 → 0，和 → π |
| 面积上界 | 无 | `Area ≤ 2πR²`（整个球面） | 无（ideal triangle 面积为 π） |

### 4.5 P*D / P*L — 编程层

- GeoGebra：可在 Poincaré 圆盘模型中绘制并测量。
- Mathlib：双曲几何形式化较少。
- 风险：模型依赖额外坐标变换；测地线不是欧氏直线。

## 5. 跨层映射检查（PostFix-C vs PreFix）

| 映射 | 欧氏 | 球面 | 双曲 |
|---|---|---|---|
| S → M | “作平行线” → 内错角相等 | “月形覆盖” → 面积求和 | “Gauss-Bonnet” → 曲率积分 |
| M → P | 平面几何公理库 | 球面几何 / 曲面积分库 | 双曲几何模型库 |
| S ↔ P | “直线” = 欧氏直线 | “直线” = 大圆 | “直线” = 双曲测地线 |
| S ↔ S | 内角和 = π | 内角和 = π + 角盈 | 内角和 = π - 角亏 |
| 统一公式 | `α+β+γ = π + K·Area`（K=0） | `α+β+γ = π + K·Area`（K>0） | `α+β+γ = π + K·Area`（K<0） |

**跨层结论**：三者共享统一公式 `α+β+γ = π + K·Area`。欧氏、球面、双曲分别对应 `K=0`、`K>0`、`K<0`。这是 Gauss-Bonnet 定理在常曲率曲面上的直接体现。

## 6. 变化类型归类

- **变化方式**：**参数迁移**（曲率 `K` 从 0 变为正 / 负），同时伴随 **公理迁移**（平行公设从“唯一平行线”变为“无平行线”或“无穷多平行线”）。
- **核心假设差异**：
  - 欧氏：`K=0`，平行公设成立；
  - 球面：`K>0`，无平行线；
  - 双曲：`K<0`，无穷多平行线。
- **证明骨架相似性**：三者都可通过 Gauss-Bonnet 定理统一；欧氏是退化极限（`K=0` 或 `Area→0`）。
- **SMPDL 同构标签建议**：`S-ISO / M-ISO / P-BISIM`。
  - S-ISO：内角和与面积的关系统一为 `π + K·Area`；
  - M-ISO：核心结构都是常曲率曲面 + Gauss-Bonnet；
  - P-BISIM：形式化库不同（平面/球面/双曲）。
- **关键 lesson**：AI 生成几何证明时，必须显式声明曲率 `K` 与平行公设状态；不能把“三角形内角和 = π”当作无条件结论，也不能把欧氏辅助线构造直接套用到球面或双曲。

## 6.5 概念奇点（Conceptual Singularity）

### 6.5.1 本组对比中的关键人工洞察

- **把三种几何统一为“常曲率 `K` 取不同值”**：Gauss 的关键发现是，欧氏、球面、双曲不是三种无关几何，而是同一框架的三个参数取值。
- **用 Gauss-Bonnet 定理统一角度与面积**：这是把局部曲率与全局拓扑/几何性质联系起来的核心桥梁。
- **识别平行公设不是逻辑必然**：双曲几何的诞生正是人类意识到“唯一平行线”只是可替换公理之一。

### 6.5.2 为什么机器难以自动迁移

机器可以从“三角形内角和”反推“需要一个连接角度与面积的公式”，但**判断应当用曲率参数 `K` 统一三种几何**、并选择正确的模型（Poincaré 圆盘 / 上半平面）来构造双曲证明，需要几何直觉。双曲测地线的选择与模型表示也不是机械步骤。
