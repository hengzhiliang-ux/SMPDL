## 一、命题陈述

> **中间值定理（Intermediate Value Theorem, IVT）**
>
> 设函数 `f: [0, 1] → ℝ` 连续，且 `f(0) < 0 < f(1)`，则存在 `c ∈ [0, 1]` 使得 `f(c) = 0`。

---

## 二、标准证明

### 2.1 证明概要

1. 定义集合 `S = {x ∈ [0, 1] : f(x) < 0}`。
2. 因 `0 ∈ S`，`S` 非空；又因 `S ⊆ [0, 1]`，`S` 有上界。
3. 由实数完备性（上确界公理），`c = sup S` 存在。
4. 利用 `f` 的连续性证明 `f(c) = 0`：
   - 若 `f(c) < 0`，由连续性存在 `δ > 0` 使 `f(c + δ) < 0`，与 `c` 为上确界矛盾；
   - 若 `f(c) > 0`，同理存在 `δ > 0` 使 `f(c - δ) > 0`，与 `c = sup S` 矛盾。
5. 由排中律（LEM），`f(c) < 0` 或 `f(c) > 0` 或 `f(c) = 0`，故只能 `f(c) = 0`。

## 四、跨层映射检查

| 映射 | 检查项 | 结果 |
|---|---|---|
| S → M | “存在”语义是否对应上确界存在性？ | ✅ 一致 |
| M → P | 上确界公理在 Lean 中是否由 `ConditionallyCompleteLattice` 支持？ | ✅ 一致 |
| S → P | 结论“存在 c”是否可计算提取？ | ❌ 不可计算 |

**跨层风险**：经典 IVT 只保证存在性，不保证可计算性。若后续步骤需要实际求根算法，必须额外假设 `f` 可计算及有效一致连续性。
