# SMPDL 审计报告：OpenAI「平面图与有界树宽图的 L1 常数畸变嵌入」

**审计对象**：Bounded-distortion L1 embeddings of planar and bounded-treewidth graphs
**来源**：OpenAI math 仓库，族 089，2026-09-23 发布
**审计日期**：2026-10-13
**审计框架**：Göttingen S/M/P × D/L 六格审计 v2.1
**审计结论**：🟡 **中度风险研究级声明。有界树宽图嵌入 L1 的常数畸变是经典已知结果；但平面图嵌入 L1 的常数畸变将显著改进 Rao (1999) 的 $O(\sqrt{\log n})$，属于重大声明。README 未披露畸变常数，也未区分平面图与有界树宽图。**

---

## 1. 命题与声明

论文研究最短路径度量空间到 L1 的嵌入。典型声明形如：

- 每个平面图的最短路径度量可以嵌入 L1 且畸变为绝对常数 $C_{\text{planar}}$；
- 每个有界树宽图的最短路径度量可以嵌入 L1 且畸变为仅依赖树宽 $k$ 的常数 $C(k)$；
- 并且可能给出显式嵌入构造或算法。

经典结果包括：
- Rao (1999)：平面图嵌入 L1 的畸变为 $O(\sqrt{\log n})$，一般图为 $O(\log n)$；
- Newman-Rabinovich (2003)：平面图的下界为 $\Omega(1)$，且存在 $O(\sqrt{\log n})$ 嵌入；
- Lee (2005) 等：有界树宽图可嵌入 L1 且畸变为常数。

## 2. S/M/P × D/L 六格审计

### 2.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| 平面图常数畸变嵌入 | Rao / 平面分隔 / 流割 | 🔴 方法未披露 |
| 有界树宽图常数畸变嵌入 | 树分解 / L1 嵌入 | 🟢 已知 |
| 畸变常数显式值 | 构造/分析 | 🔴 未给出 |

**发现**：README 仅给出标题与引用，未说明平面图部分的常数、构造方法，也未说明是否区分两类图。

### 2.2 S*L — 语义逻辑结构

- 必须区分“平面图”与“有界树宽图”：前者是拓扑类，后者是结构类；有界树宽图包含于 $K_{r,r}$-minor-free 图，但平面图是其真子类。
- 必须区分“存在常数畸变嵌入”与“给出显式常数/多项式时间算法”。
- 风险：可能把有界树宽图的结果泛化为所有平面图。

### 2.3 M*D — 数学依存

| 依赖 | 状态 |
|---|---|
| Rao (1999) $O(\sqrt{\log n})$ 嵌入 | ⚠️ 若声称常数，需解释如何改进 |
| 平面图分隔定理 (Lipton-Tarjan) | ⚠️ 是否作为工具 |
| 有界树宽图 L1 嵌入 (Lee 2005) | 🟢 已知 |
| 流割 / 稀疏st-cut 分解 | ⚠️ 是否被形式化 |

**关键风险**：平面图常数畸变嵌入需要突破 Rao 界的新技术；若论文仅处理有界树宽图，则标题中的“平面图”会造成误导。

### 2.4 M*L — 数学逻辑结构

- 典型证明结构（有界树宽）：
  1. 构造树分解；
  2. 将图度量分解为低维 L1 嵌入的直和；
  3. 组合得到仅依赖树宽的常数畸变。
- 典型证明结构（平面图，若可证）：
  1. 用平面分隔递归划分图；
  2. 对每个子区域构造 L1 嵌入；
  3. 用流割或割结构控制全局畸变。
- 陷阱：平面分隔通常带来对数因子；去掉该因子需要全新的割分解。
- 风险：可能把“外平面图/series-parallel”等特殊子类的结果泛化为所有平面图。

### 2.5 P*D — 编程/形式化依存

- README 可能指向 [Lean](lean/docs/089.md)，但未说明形式化范围。
- 风险：Lean 可能只形式化了：
  - 有界树宽图的 L1 嵌入；
  - 平面图度量的基本定义；
  - 某个辅助引理，而非平面图主定理。
- 特别风险：形式化可能无法表达“畸变常数与图大小无关”这一全称量词。

### 2.6 P*L — 编程逻辑结构

- 若形式化完整，需要检查：
  - 是否严格定义了平面图、树宽、L1 嵌入、畸变；
  - 是否给出显式畸变常数；
  - 是否区分两个子定理并分别证明。

## 5. 人工可能需要确认/补充证明的地方

1. **平面图与树宽结论拆分**：分别给出两个定理的精确 statement，避免把树宽结果误述为平面图结果。
2. **平面图畸变常数**：给出 $C_{\text{planar}}$ 的显式值或有效范围，并说明与图大小无关。
3. **突破 Rao 界的方法**：说明如何改进 Rao (1999) 的 $O(\sqrt{\log n})$ 界；是否引入新的平面割分解、流割技术或概率方法。
4. **适用范围**：确认平面图结论是否对所有平面图成立，还是仅对外平面图、series-parallel、网格子类等特殊类成立。
5. **与 Newman-Rabinovich 下界的关系**：说明常数畸变是否与已知下界 $\Omega(1)$ 相容，并给出非平凡上界。
6. **算法性质**：若给出算法，说明是否为确定性多项式时间；若仅存在性，需明确。
7. **Lean 主定理范围**：确认 Lean 是否 literally 给出平面图常数畸变定理，还是仅证明树宽情形或辅助引理。

## 7. 结论与后续建议

族 089 的声明包含有界树宽（已知）与平面图（重大改进）两部分，风险等级为 **🟡 中度**。主要风险在于：
