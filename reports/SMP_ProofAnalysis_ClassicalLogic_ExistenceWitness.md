# S/M/P × D/L 审计报告：经典逻辑存在性证明（非构造性见证）

> **定理**：存在无理数 a, b，使得 a^b 是有理数。
> 
> **来源**：经典例子，常归于 Gelfond 之前 folklore；在 B. J. Gardner & M. Jackson, *The Existence of Irrational Numbers whose Powers are Rational* 等教材中作为非构造性证明范例出现。
> 
> **分析日期**：2026-10-13 | **审计框架**：Göttingen S/M/P × D/L v1.5 | **AxiomaticBase**：`ClassicalLogic`
> 
> **风险评级**：⚪ 已确认正确（在经典逻辑基础内），但 🟡 中风险（从构造性/可计算性角度看未提供显式见证）。

---

## 0. 分析目标

1. 对“存在无理数 a, b 使 a^b 为有理数”的经典非构造性证明进行 S/M/P × D/L 六格审计。
2. 明确核心逻辑依赖：**排中律（Law of Excluded Middle, LEM）**。
3. 展示该证明在经典逻辑中有效，但在直觉主义/构造性基础中不合法。
4. 为与直觉主义构造性版本对比建立 SMPDL 标签与风险点清单。

---

## 1. S 层审计（语义层）

### 1.1 S*D：语义依存

| 自然语言元素 | 支持的后续元素 | 依赖说明 |
|---|---|---|
| “√2 是无理数” | “a = √2 是无理数” | 前提引理 |
| “令 x = √2^√2” | 对 x 进行二值分类 | 构造辅助对象 |
| “x 要么是有理数，要么是无理数” | 分情况讨论 | 依赖排中律的语义 |
| “若 x 是有理数，则 (a,b) = (√2, √2)” | 第一种结论 | 情况 1 |
| “若 x 是无理数，则 (a,b) = (√2^√2, √2)” | 第二种结论 | 情况 2 |
| “无论哪种情况，都存在这样的 a, b” | 最终存在性结论 | 由析取消去得到 |

### 1.2 S*L：语义逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 量词显式化 | ✅ | ∃ 量词在结论中显式。 |
| 术语单义性 | ✅ | “有理数”“无理数”“存在”在经典语义下稳定。 |
| “存在”的语义 | ⚠️ 中 | 经典语义下“∃”只要求非构造性存在；证明不承诺能确定具体是哪一对。 |
| 隐含跳跃 | 🟡 中 | 证明未显式说明它使用了排中律；初学者可能误以为这是构造性证明。 |
| 蕴涵方向 | ✅ | 情况 1 与情况 2 均正确导出 ∃ 结论。 |

**S 层结论**：自然语言证明简洁，但“存在”在此被解释为**非构造性存在**。S*L 的主要风险是读者误以为证明给出了具体 witness。

## 2. M 层审计（数学层）

### 2.1 M*D：数学依存

```text
Existence of a,b ∈ ℝ\ℚ with a^b ∈ ℚ
    │
    ├── Lemma: √2 ∉ ℚ
    │
    ├── Construction: x := √2^√2
    │
    ├── Classical Law of Excluded Middle (LEM)
    │       │
    │       ├── Case 1: x ∈ ℚ
    │       │       │
    │       │       └── Witness: (a,b) = (√2, √2)
    │       │
    │       └── Case 2: x ∉ ℚ
    │               │
    │               ├── Witness: (a,b) = (x, √2)
    │               │
    │               └── Verification: x^√2 = (√2^√2)^√2 = √2^(√2·√2) = √2^2 = 2 ∈ ℚ
    │
    └── Disjunction Elimination: ∃ a,b ∉ ℚ, a^b ∈ ℚ
```

| 数学对象 | 结构签名 | 在证明中的作用 |
|---|---|---|
| 实数 ℝ | 完备有序域 | 论域 |
| 有理数 ℚ | ℝ 的可数子域 | 分类标准 |
| 无理数 ℝ \ ℚ | ℝ 中不属于 ℚ 的元素 | witness 候选集合 |
| √2 | 代数无理数 | 候选底数与指数 |
| x = √2^√2 | 超越数（Gelfond-Schneider）或无理数 | 分类对象 |
| LEM | 经典命题逻辑公理 | 情况二分合法性的来源 |
| 指数律 (a^b)^c = a^(bc) | 实数指数运算性质 | 情况 2 的验证工具 |

### 2.2 M*L：数学逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 公理系统一致性 | ✅ | 在经典逻辑 + ZF/ZFC 体系内严格有效。 |
| 构造合法性 | ⚠️ 中 | `x = √2^√2` 作为实数良定义，但“构造”在此仅指数学存在，不提供可计算 witness。 |
| 量词范围 | ✅ | 存在量词覆盖所有无理数对。 |
| 边界情况 | ✅ | 无退化情形；√2 > 0 保证实数幂良定义。 |
| 隐藏假设 | 🟡 中 | 证明依赖 LEM，且依赖实数指数 `(a^b)^c = a^(bc)` 的合法性。 |
| 等价命题循环 | ✅ | 无。 |

**M 层结论**：证明结构完整，核心依赖为 LEM 与实数指数律。在经典数学中完全合法；其非构造性特征使其在构造主义基础下失效。

## 3. P 层审计（编程/形式化层）

### 3.1 P*D：形式化依存

### 3.2 P*L：形式化逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 语法可编译 | ✅ | 在 Lean 4 经典模式下可编译。 |
| 类型签名一致 | ✅ | 目标为 `∃ a b : ℝ, Irrational a ∧ Irrational b ∧ ∃ q : ℚ, a ^ b = q`。 |
| 定义等价 | ✅ | `Irrational` 与数学定义一致。 |

## 4. 跨层映射检查

### 4.1 S ↔ M

| S 层主张 | M 层形式化 | 同构强度 | 说明 |
|---|---|---|---|
| “存在无理数 a,b” | `∃ a b, Irrational a ∧ Irrational b ∧ ∃ q : ℚ, a ^ b = q` | ⭐⭐⭐ 高 | 直接对应 |
| “令 x = √2^√2” | `let x := Real.sqrt 2 ^ Real.sqrt 2` | ⭐⭐⭐ 高 | 直接构造 |

| “情况 2 验证” | `Real.rpow_mul` + `Real.sqrt_sq` | ⭐⭐⭐ 高 | 指数律与根号平方 |

### 4.2 M ↔ P

| M 层对象/关系 | P 层表达 | 同构强度 | 判据 |
|---|---|---|---|
| 无理数 | `Irrational x` | ⭐⭐⭐ 高 | 谓词定义 |
| 实数幂 | `a ^ b` | ⭐⭐⭐ 高 | 实数指数运算 |
| LEM | `Classical.em P` | ⭐⭐⭐ 高 | 经典公理 |

### 4.3 S ↔ P

| 自然语言步骤 | 形式化代码 | 保真度 |
|---|---|---|

**最终判定**：⚪ 已确认正确（在经典逻辑基础内），但 🟡 中风险（不具备构造性 witness）。

## 6. 结论

该证明是**经典非构造性存在证明**的教科书范例：

- **S 层**：结论“存在”在经典语义下成立，但自然语言容易掩盖其非构造性。
- **M 层**：证明依赖 LEM 与实数指数律；结构完整，无循环或悬空前提。
- **P 层**：在 Lean 4 经典模式下可直接形式化；`#print axioms` 会暴露对选择公理/LEM 的依赖。
- **跨层映射**：三层对应关系明确，同构强度为 ⭐⭐⭐ 高。
- **基础敏感性**：在直觉主义/构造性基础下，该证明失效，因为无法从 LEM 情况分析中提取具体 witness。

该样本建议标记为：`ClassicalLogic`、`S-ISO / M-ISO / P-ISO`（自洽），并作为与 `IntuitionisticLogic` 版本对比的核心条目。
