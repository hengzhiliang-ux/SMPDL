## 二、静→动之桥（核心一节）

**静态对应理论回答「什么对应什么」；结构演变 = 对应在算子扰动下的存亡测试。**

```
静态：律 L ⟷(对应定理)⟷ 结构条件 C          [无时间，一张对照表]
动态：对应对 (L, C) --算子 F--> (F(L), F(C))  [演变事件]
        F 保持对应（F(L) ⟷ F(C) 仍成立）→ 保律算子（内理论变奏）
        F 打断对应（F(L) ⟷̸ F(C)）          → 拆律算子（跨理论断裂）
```

三条桥定理（连接方式打标签）：

1. **对应保持 = 保守性**：Institution 理论的 theory morphism 保定理翻译 ⟺ 我们说的"律全保"。**静态对应 + 算子 = 动态审计对象**；
2. **Sahlqvist 算法性**：静态对应不只存在而且**可计算**（SQEMA 算法）——这意味着"律的框架条件"可以作为审计前的**预检表**：审一个证明前先算出它依赖的每条律对应的框架条件，拆除事件后逐条核对。**静态对应表 = 动态审计的 check-list 生成器**；
3. **保持定理 = 扰动后的幸存者清单**：Łoś（超积下全一阶幸存）、Łoś–Tarski（子结构下正存在句幸存）——每条保持定理直接给出"算子作用后哪些定理必然还在"，即**后结构审计的期望值**。审计 = 对照期望值找缺额（缺额 = 隐律信号）。

> **一句话**：静态对应理论是**字典**，结构演变是**查字典后在扰动下重查**——SMPDL 审计的本质 = 两次查典的 diff。

## 三、SMPDL 算子事件审计模板 v1.0（六格升维）

对象从「一篇证明」换成「**事件三元组 (前结构 S₀, 算子 F, 后结构 S₁)**」，六格照用：

| 审计项 | 问什么（算子事件版） | 通过判据 |
|---|---|---|
| **M\*D 依存** | S₀ 的定理依赖图在 S₁ 中是否原样？ | Łoś/保持定理给出的幸存清单全数在场；缺额逐一归因 |
| **M\*L 逻辑** | S₁ 中旧定理的证明是否仍合法（未偷渡新假设）？ | 无隐律借用（隐律 = 缺额无归因时的探测器报警） |
| **S\*D 语义依存** | 术语对应图是否保持（专名同指）？ | Beth 锚：每个关键术语在新载体有显定义 |
| **S\*L 语义逻辑** | 解释的翻码是否合法（无隐喻滑移）？ | 双射翻码或显式翻译函子 |
| **P\*D 形式依存** | 形式化依赖（库/类型类）在 S₁ 是否可用？ | 编译通过；类型类假设无静默扩张 |
| **P\*L 形式逻辑** | `#print axioms` 是否与 S₀ 同集（无新增公理）？ | 公理集逐项相等 = 保律的机器可验证书 |
| **跨层映射** | S↔M↔P 三层对应在 F 作用前后是否同步保持？ | 对应对 (L,C) 的三层版本同生共死 |

**升降维说明**：六格不变，被审对象升维——这正是 S/M/P×D/L 框架的第一次"对象迁移"（从证明到事件），其自身合法性可用框架审计（跨层映射检查）。

## 四、实跑案例（保律算子 · 前后快照审计）

### 案例 A · H6 超积（ℝ → *ℝ，层0 换装 · 保守扩张型）

| 快照 | 前结构 S₀ | 后结构 S₁ |
|---|---|---|
| 载体 | ℝ（阿基米德序域） | *ℝ（非阿基米德，含无穷小 ε） |
| 律 | 实闭域公理全集 | **同一套公理全保**（Łoś：一阶句逐字保真） |
| 定理群 | IVT/代数基本定理… | 全部原样（且获得非标准新证明） |
| 审计 M*D | ✅ 幸存清单 100%（Łoś 认证在案） | |
| 审计 S*L | ⚠️ 唯一滑移点：「标准部分 st()」是新算子，S₁ 特有（此为新增内容，非缺额） | |
| 审计 P*L | Lean：`Mathlib.NonstandardAnalysis` 公理集与标准分析同（ZFC 内）✅ | |
| **裁定** | **纯保律事件**：缺额 0，新增算子 1（st）→ 归入"横向多样性"，非隐律 | |

### 案例 B · H12 等价强度三级跳（同构→范畴等价→同伦，层2 拆强度 · 谱算子型）

| 快照 | 前结构 S₀ | 后结构 S₁（每级） |
|---|---|---|
| 律 | 群公理（对象层不动） | 同一套——**拆的是等价关系本身**（律的元层） |
| 定理依赖 | 依同构传递的定理 | 逐级缩水：同构不变定理 ⊃ 等价不变 ⊃ 同伦不变 |
| 审计 M*D | 🟡 **分档幸存**：H_n/π_n 只对同伦档保持；白头定理只在同构档——缺额有清晰归因（强度档位），**不是隐律**而是"审计分辨率"切换 | |
| 审计 S*L | 「相同」一词三级滑移——术语同指失败，S 层从 ISO 降 BISIM（与 Taxonomy 六级光谱一致）| |
| **裁定** | **保律（对象律全保）+ 保律拆除元层（等价关系）**：首例「律不动、元层动」——审计模板在此抓到六层塔层2 的独立可拆性 | |

### 案例 C · H13 频率↔贝叶斯（层5 换解释 · 重解释型）

| 快照 | 前结构 S₀ | 后结构 S₁ |
|---|---|---|
| 律 | 概率公理（Kolmogorov 三条） | **一字不动** |
| 解释 | 频率（长期占比） | 信念度（不确定度量） |
| 定理群 | 大数定律/贝叶斯定理 | 同一批定理，双向可读 |
| 审计 S*D | ✅ 术语映射完整（"概率"同指不同义，Beth 锚 = 公理本身）| |
| 审计 M*D | ✅ 定理集相等（平坦先验下 MLE = 后验峰，数值重合点在案）| |
| 审计 P*L | ⚠️ 形式化分库（Isabelle/HOL 概率论 vs 主观贝叶斯库）：公理集同，**证明策略库不同** → P 层 BISIM | |
| **裁定** | **纯保律换义事件**：缺额 0，语义层 ISO→BISIM 降级是唯一可见变化——支持「层5 拆除的信号住在 S 层标签里」| |

## 五、三案例的模板首验小结

1. 模板在三型算子（保守扩张/谱算子/重解释）上全部可执行，六格无一空转；
2. **缺额-归因机制有效**：缺额必须归因（新增算子/分辨率切换/语义降级），无归因缺额 = 隐律报警——案例 A/B/C 的缺额全部有归因，零报警；
3. 跨层映射检查自动复用 Taxonomy 光谱（案例 B/C 的 S 层降级正好落在 ISO→BISIM 轴上）——**两张表（六格 + 光谱）在事件审计中咬合**；
4. 可证伪口：若存在一个保律算子事件使模板六格全部失语（无项可填）→ 模板覆盖不全，需扩格。
