# SMPDL 基础对比审计：欧氏 vs 球面三角形内角和

> **对比对象**
> - “PreFix” 版本：欧氏几何三角形内角和 = 180°（见 `SMP_ProofAnalysis_Euclidean_TriangleAngleSum.md`）
> - “PostFix” 版本：球面几何三角形内角和 = π + Area/R²（见 `SMP_ProofAnalysis_Spherical_TriangleAngleSum.md`）
> 
> **审计日期**：2026-10-13  
> **审计框架**：Göttingen S/M/P × D/L v1.5  
> **总体评价**：⚪ ↔ ⚪ 两个版本在各自公理体系内均正确；差异来自基础假设（平行公设 vs 无平行线 + 常正曲率），而非证明错误。

---

## 1. 版本声明对比

| 维度 | 欧氏版本（PreFix） | 球面版本（PostFix） |
|---|---|---|
| **主声明** | 任意平面三角形内角和 = 180° | 任意球面三角形内角和 = π + Area/R² |
| **“直线”定义** | 欧氏直线（两点确定，可无限延长） | 大圆（过球心的平面与球面交线） |
| **平行线存在性** | 第五公设保证 | 不存在平行线 |
| **关键构造** | 过顶点作平行于对边的辅助线 | 延长三边为完整大圆，构造月形 |
| **核心工具** | 内错角相等 | 月形面积公式 + 球面覆盖计数 |
| **结论与面积关系** | 无（结论为常数） | 内角和超出 π 的部分正比于三角形面积 |

## 2. PreFix 版本 SMPDL 速览（欧氏）

详见 `SMP_ProofAnalysis_Euclidean_TriangleAngleSum.md`。

- **S*D**：自然语言依赖“作平行线 → 内错角相等 → 平角求和”的语义链。
- **S*L**：量词清晰，但“内错角相等”依赖平行公设这一语义前提常被省略。
- **M*D**：ParallelPostulate → alternate_interior_angles → angle_sum。
- **M*L**：逻辑完整；退化情形通常排除。
- **P*D / P*L**：需要平面几何公理库；GeoCoq 可实现，Mathlib/Lean 4 目前无原生支持。

**PreFix 判定**：⚪ 已确认正确（在欧氏体系内）。

## 3. PostFix 版本 SMPDL 六格审计（球面）

### 3.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| 球面三角形定义 | 球面 + 大圆概念 | ✅ |
| 月形面积公式 | 球面对称性 + 大圆是测地线 | ✅ |
| 覆盖关系 | 三边延长后球面被 8 等分 | ✅ |
| 角盈公式 | 月形面积 + 覆盖关系 | ✅ |

### 3.2 S*L — 语义逻辑结构

- 球面版本从“无平行线”出发，无法使用欧氏的辅助平行线论证。
- 通过“月形覆盖”这一新的语义结构完成角度求和。
- ⚠️ “角”在球面语义中指二面角，与欧氏平面角同名异义，是主要 S*L 风险点。

### 3.3 M*D — 数学依存

```text
SphericalTriangleAngleSum
    │
    ├── Sphere(R) + great_circle_is_geodesic
    │
    ├── Definition: SphericalTriangle
    │
    ├── Lemma: lune_area = 2αR²
    │
    ├── Lemma: sphere_partition_by_great_circles
    │
    └── Theorem: α + β + γ = π + Area/R²
```

- 依赖关系闭合，无悬空前提。

### 3.4 M*L — 数学逻辑结构

| 检查项 | 欧氏 | 球面 | 差异说明 |
|---|---|---|---|
| 量词范围 | 任意平面三角形 | 任意球面三角形 | 论域不同 |
| 边界情况 | 退化三角形 | 退化大圆情形 | 两者均给出极限/退化结论 |
| 隐藏假设 | 默认同一平面 | 默认凸三角形（劣弧） | 结构对称 |
| 结论形式 | 常数 180° | π + 面积项 | 曲率效应显式化 |

### 3.5 P*D / P*L — 编程层

- 两个版本都未见 Mathlib/Lean 4 中的完整原生形式化。
- 欧氏可用 GeoCoq/Tarski；球面可用 GeoCoq 或 HOL Light。
- 球面版本在 P 层需要额外引入黎曼/曲面积分结构，复杂度略高于欧氏。

## 4. 跨层映射检查（PostFix vs PreFix）

| 映射 | 欧氏（PreFix） | 球面（PostFix） | 变化 |
|---|---|---|---|
| S → M | “作平行线” → ParallelPostulate | “延长三边为大圆” → great_circle_is_geodesic | 构造工具改变 |
| M → P | `parallel_through` / `alternate_interior_angles` | `great_circle` / `lune_area` | 形式化依赖库改变 |
| S ↔ P | 辅助线 → 公理构造 | 月形 → 面积函数 | 语义-代码桥梁不同 |
| S ↔ S | “内角和为定值” | “内角和 = π + 面积/R²” | 结论定量变化 |
| M ↔ M | 角度测度 + 平行公设 | 角度测度 + 曲率/面积 | 数学结构升级 |

**跨层结论**：两个版本的 S/M/P 层各自自洽，但层间映射关系不同；差异根源于基础假设（平行公设 vs 曲率）。

**SMPDL 判定（PostFix）**：⚪ **低风险 / 已确认正确**。球面版本不是对欧氏版本的“修复”，而是“在不同公理基础下得到的正确推广”。

## 6. 变化类型归类

- **变化方式**：**基础假设迁移**（foundation shift），而非证明错误修复。
- **核心假设差异**：
  - 欧氏：承认第五公设（平行公设），存在唯一平行线。
  - 球面：不存在平行线；空间具有常正曲率 K = 1/R²。
- **证明骨架相似性**：两者都通过“角度分解 + 求和”达到结论，但实现工具不同。
- **SMPDL 同构标签建议**：`S-ISO / M-ISO / P-BISIM`。
- **关键 lesson**：当基础假设改变时，即使“证明直觉”相似，也必须逐层检查 S/M/P 映射；不能把欧氏的辅助构造直接迁移到球面。
