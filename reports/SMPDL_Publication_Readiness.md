## 二、论文类型矩阵（从易到难，均为「若要发」的能力判定）

### 现在就能发（不依赖 run 3）

**T1 · 数据集/语料论文**（完成度 85%）
- 内容：719 AI 手稿审计语料 + H1–H46 双基对比库 + 标注体系（S/M/P×D/L、五轴、ISO/BISIM 标签）
- 形态：Zenodo 数据集论文或 JOSS 类；数据已在 DOI 上
- 卖点：首个「AI 数学证明的结构化审计标注语料」
- 工作量：正式 dataset paper 写作（~1–2 周写作）

**T2 · 方法论/科学诚信论文**（完成度 75%）
- 内容：回测纪律 v2.0——预注册 + 会话分离 + 冻结取证 + 勘误链，附两次真实纠错实录（对象错位 4h 反转 + 过度概括撤回）
- 形态：arXiv preprint → TMLR / NeurIPS Datasets&Benchmarks 线 / AI4Math workshop
- 卖点：「LLM 判定的可信度协议」正中当前 AI-for-math 社区痛点；你的两次翻车实录是稀缺的实证材料
- 工作量：纪律文档的论文化改写（~2–3 周）

### run 3 走正式后解锁

**T3 · 实证规律论文**（run 3 后完成度 60%→75%）
- 内容：移除-涌现两阶段定律 + 隐形承重 + 约束/构造二分 + 层守恒条件律
- 前置：run 3（分层采样 40–60 例 + **异模型或人类判定者** + 定理级索引）——样本与判定独立性是审稿人第一问
- 形态：arXiv → TMLR / Philosophia Mathematica 方法论线 / Historia Mathematica 数字方法线
- 卖点：可证伪的「数学结构经验规律」+ 13/13+run3 前向战绩
- 增量工作：run 3 执行（1–2 会话日）+ 人类校准点（关键！哪怕只人工复核 10 例分歧）+ 写作

**T4 · 理论/分类学论文**（长线，完成度 30%）
- 内容：coercion calculus 定理化（E 路线：definitional extension 证明）+ H-loc 局部化统一
- 前置：run 3 + 形式化样本（Lean/mathlib 3–4 例）
- 形态：J. Experimental Mathematics / 逻辑侧会议（不追求顶级纯数期刊——那是十年尺度的活）
- 定位：诚实说——这条线的完成度最低，且与「非职业研究者」的时间预算最不匹配

## 三、关键判断（一句话版）

1. **T1/T2 与 run 3 无关、现在就够**——数据集与方法论是当前最厚的两块板，且都不需要更大的 n；
2. **T3 是 run 3 的主要回报**——但解锁条件不是「跑完 run 3」而是「跑完 run 3 **且加入人类判定校准点**」：哪怕 10 例人工复核，就把「同模型同偏」这个最大软肋变成「同模型 + 人类抽检」的可辩护设计；
3. **T4 不建议主动追**——它最贵且偏离教学网站主线；让 G-6（Lean 形式化浪潮）自然推送即可；
4. **顺序建议（若将来走正式）**：T2（方法论，材料现成）→ T1（数据集，打包即发）→ run 3 → T3（实证规律）。T2 先发还有附带收益：给 T3 建立方法学引用锚。
