## 一、框架底座：S/M/P × D/L

一切分析在**三层两维**网格中进行：

| 层 | 审什么 | 迁移时问的问题 |
|---|---|---|
| **S 语义层** | 概念的含义与命名 | 同名是否异义？"X"在两侧是同一个 X 吗 |
| **M 数学层** | 定理群与证明骨架 | 哪些定理存活/失效/换轨？承重墙在哪 |
| **P 编程层** | 形式化与计算可及性 | 库/算法是否自动拦截？哪里是盲区 |

两维：**D 依存维**（节点的前驱是否在场）× **L 逻辑结构维**（推理链是否合法）。

**三层联合断言**：跨层结论只有同时通过 S/M/P 三层检查才成立——单层"看起来没问题"是全库反复出现的假象来源（P 层盲区家族已积累七例：H17/H29/H30/H34/H36/H37/H39）。

## 二、结构迁移类型学（对象级）

四类迁移 + 三级强度（39 组实测分布）：

| 类型 | 机制 | 强度与例 |
|---|---|---|
| **参数迁移** | 拨参数不改公理 | 🟡（H5 特征、H19 维数阈等） |
| **语义迁移** | 同名概念换义 | 🟠（H13 概率解释等） |
| **框架迁移** | 换工具链/引擎 | 🟠（H17 测度引擎、H30 定价恢复） |
| **断裂迁移（公理/律移除或加入）** | 拆承重墙 / 补地基 | 🔴/🟠（律组全体） |

**实测（v2.0 修订，原"实测定律"降格）**：律伴随迁移 🔴 率 8/25=32% vs 非律 2/14=14%——RR=2.24，95% CI [0.55, 9.13]，Fisher 双尾 p=0.41（n=39，**统计不显著**）；早期小样本（n=29）曾测 RR=3.73，新增律组 0 🔴 致幅度稀释。**方向一致（律=定理群共享承重墙）但显著性不稳健，不作"定律"引用**：作审计资源倾斜启发式可保留（成本不对称——错倾斜代价低）；升级为定论须待 43 组全量重跑 + 预注册判读（见 LawScreening §七统计纪律框）。

## 三、律学：三维正交分类体系

每条入库律携带三个独立坐标（以 H39 幂等律为例）：

```text
律名：幂等律 a⊕a = a
 ├─ 强度分级：甲级（公理级——半环公理成分）
 ├─ 认识论档位：E 档（定理律——幂等半环定理群完整）
 └─ 功能类型：T1（定义律——定义幂等半环这个对象类）
```

### 3.1 第一维：强度分级（律在结构中的地位）

| 级 | 定义 | 库内数量 | 例 |
|---|---|---|---|
| **甲级 公理级** | 结构公理的直接成分 | 11 | 交换/结合/分配/LEM/AC/DC/二阶归纳/平行公设×2/Archimedes/幂等 |
| **乙级 表征级** | 律 ⇔ 结构的表征定理（双向等价） | 12 | 紧致/平行四边形/DCT/完备/Fubini/CR/单调/守恒/Liouville/Desargues/零因子/确定性 |
| **乙级表征律是"结构指纹"**：拨它 = 整个伴随结构同生共死，且天然配表征定理（生而 E 档）。 | | | |
| **丙级 规则级** | 推理系统的语法规则 | 2 | intro/elim 规则对、收缩/弱化律 |

### 3.2 第二维：认识论档位（律的真假由什么裁定）——"升降档位"的档

| 档 | 名称 | 裁定者 | 审计风险 |
|---|---|---|---|
| **E 档** | 定理律 | 数学内证明（成立与失效都可证） | 低——错用会显性报错（反例可查） |
| **D 档** | 定义律 | 概念选择（划类约定） | 中——错用是类型/类声明错位 |
| **I 档** | 独立律 | 独立性证明（接受/拒绝都无矛盾） | **高——错用静默**：暗中假设 LEM/AC 不产生矛盾，只悄悄缩小定理适用域 |

**升降档位核心操作**（档位迁移 = 数学史的律层叙事）：

```text
降档（显性化 = 律从默认变选择）
  E₀ 默认 ──质疑──> I/D 档：平行公设（1868）、交换律（1843）、结合律（1843.12）
                     LEM（1930s）、AC（1938/1963）

升档（再定理化 = E′：律死后其遗产在新框架中变回定理）
  I ──> E′：Gauss–Bonnet（K=0 特例回收平行公设后果）
        Zorn 定理群（ZFC 内 AC 定价回报）
        Gleason/KS（分配律失效 → 量子表征定理）
        Curry–Howard（LEM ↔ call/cc 证明论再定位）
        bang（收缩律 → 线性逻辑付费操作符）
        Tonelli 免费区 / Ostrowski / 理想论 / dequantization ……
```

**档位规则四条**：
1. **审计风险随 E<D<I 递增**（I 档静默最危险）；
2. **同律两侧可异档**（H27：布尔侧 D / 量子侧 E——跨档正是对比断裂之源）；
3. **独立性 = 假设性的数学化**："内生/假设"的边界由内生定理（forcing/模型构造）内生划定；
4. **律的档位迁移是读数学史的高产地平线**（启发式；原表述"数学史 = 律的档位迁移史"为修辞过强，已降格——平行公设完成 E₀→I→E′ 全程螺旋为标杆例）。

### 3.3 第三维：功能类型（律回答什么问题）——决定移除后涌现什么

| 类型 | 回答 | 移除后即时涌现 | 库内样本（n） |
|---|---|---|---|
| **T1 定义律（对象构成类）** | "这个对象**是什么**" | **β 主**：被遮蔽对象解禁（四元数/例外李代数/无穷小/平面 zoo/tropical 全字典） | 5+（H4/H23/H27/H28/H34/H37/H38/H39…） |
| **T2 保证律（行为构成类）** | "过程**如何运行**" | **α + 元层主**：补偿结构 + 关于律的算法（bang/KB 完备化/力迫/静态分析） | 2+（H7/H8/H17/H20/H26/H30/H31/H36…） |
| **T3 禁闭律（不变量类）** | "**什么保持不变**" | **β-现象**：被禁闭的动力学行为解禁（吸引子/混沌/分形） | 2（H33 守恒亚型 / H35 禁闭亚型——T3 两亚型可独立失效） |

**双面律**：H32（单调）/H21（二阶归纳）主体 T1 + 行为面 T2——假说"学科级涌现 ⇔ 双面律"（现存 3 例学科级涌现 H23/H18/H32 全为双面 ✓）。

## 四、律的生命周期与历史动力学

**七阶段**：L1 潜默 → L2 命名默认 → L3 边界摩擦 → L4 显性质疑 → L5 准独立 → L6 档位裁决 → L7 后续演化（E′/衍生律/沉寂）。

**历史结构**：
- **四大质疑集群**（C1 1843 代数解放 / C2 1899–1908 几何-集合 / C3 1931–38 元数学 / C4 1963–67 forcing），间隔约 30 年，**工具先于质疑**（每集群由一种新裁决工具的发明驱动）；
- **裁决工具六代**：G1 几何模型 → G2 独立性方法 → G3 算术化/构造宇宙 → G4 forcing → G5 语义发明（Kripke/Henkin/量子语境）→ **G6 构造性类型论+证明助手**（进行中；活体样本 = Univalence 的 D→E 实时迁移；元层涌现的规模化）；
- **L3 长停留是常态**（Fubini 80 年、Archimedes 两千年）：全流程最慢的一步是**"反常的再分类"**——意识到需要独立性证明比证明它更难。

## 五、移除-涌现理论（结构再生的机制）

### 5.1 三型涌现

| 型 | 机制 | 判据口诀 |
|---|---|---|
| **α 补偿型** | 新结构接替旧律职责（更弱更普适） | "谁顶班"（HB 分离/bang/正交模律/紧致性衔接） |
| **β 例外型** | 被旧律遮蔽的对象/行为解禁 | "被解禁"（例外李代数/混沌/DCFL/平面 zoo） |
| **γ 统一回收型** | 旧律降格为新母结构的特例/参数 | "被回收"（Gauss-Bonnet/Lebesgue/概形/Ostrowski） |

### 5.2 两阶段理论（经三型六验 + 第四轮三验 = 前向 6/6）

```text
阶段一（即时，移除时刻）：涌现类型 ← 功能类型（T1→β / T2→α+元层 / T3→β-现象）
阶段二（长期，回收时刻）：γ ← 领域成熟度（与功能类型正交：γ 主导已现于 T1/T3，辅型遍布三型）
```

**γ 五形态**（压测执行轮定稿）：
1. **表征型**（即时）：表征定理与移除同时存在（H37 Desargues ⇔ 除环；乙级律天然自带）；
2. **因果型**：回收结构**为修复而发明**（H38 理想论；H40 逆半群——动机在案）；
3. **渐近型**：新世界 = 旧世界的极限影子（H39 dequantization：ε→0）；
4. **成熟型**：领域成熟后统一回收（Gauss-Bonnet / Ostrowski）；
5. **翻译型**（压测转正）：**失效模式本身对象化**（关键对/相伴素数/特殊化序/拓扑荷冻结/左右完备分裂——"病即信息"的统一形态；预测力：任何移除可预期一门"失效位置学"）。

**五涌现维度**：对象 / 补偿结构 / 元层算法 / 跨组规律 / 构造性成本。

**方法论金句**：
- **不对称律（组织性观察，审计 🔴-3 降格）**：减法倾向生结构、加法倾向生定理（H29 对照 + OS-I/II 两轮加法样本定向命中支持；判定依赖"新概念"操作化判据，落地前不作定律引用）；
- **伤口大小决定新生大小**（乙级律移除长学科 ×3 例：凸分析/Sobolev/均衡理论）；
- **定价优于禁止**（bang/Tonelli 免费区/AC 定价回报三连）；
- **当对象背叛你，发明更大的结构**（Dedekind/Lebesgue/Sobolev 三例）；
- **凸性是万能接盘侠**（跨组元涌现：H23/H18/H32）。

## 六、迁移操作手册（升降档位的实操规程）

### 6.1 移除一条律（减法）

```text
Step 1  定坐标：强度（甲/乙/丙）× 档位（E/D/I）× 功能类型（T1/T2/T3）
Step 2  预测涌现（阶段一）：T1→β 对象族；T2→α+元层算法；T3→β-现象
        预测回收（阶段二）：有无表征型（乙级自带）/因果型/渐近型潜质
Step 3  断裂面扫描：S 层同名异义清单 / M 层定理群生死账 / P 层拦截与盲区
Step 4  桥点登记：残存律（Artin 局域桥/正交模律）、免费区（Tonelli）、
        降档阶梯（三元环/Moufang）、镜像字典（几何⇔代数）
Step 5  回验与登记：涌现类型向量（主+辅）回写；偏差触发修订案
```

### 6.2 加入一条律（加法）

预期**无新概念涌现，只有定理群生根**（H29 样板）；检查上游律地位（完备律串联 H10/H11/H17/H6 的"上游回溯"操作）；确认联合锁定条件（ℝ = 阿氏 ∩ 完备——两律开关的参数空间）。

### 6.3 Law-Gate 八问（AI 生成证明的律门控审校）

按 🔴 率优先：①量词档位（一阶/二阶/Henkin）→ ②存在律（LEM/witness，可执行版：`#print axioms` 查 `Classical.choice`）→ ③选择律（AC/DC/Zorn，同法）→ ④交换律族（乘法/极限-积分/重积分）→ ⑤分配律（量子语境兼容块）→ ⑥表征律（所在空间的定义律谁在顶班）→ ⑦几何公设档位 → ⑧衍生律命名归档。

**功能类型快检**（v1.4 新增）：此律定义对象（T1）还是保证行为（T2）？——T2 未声明的场合重点查"行为保证被默认"；T1 未声明的场合重点查"对象类被悄悄扩张/缩小"。

## 九、一句话方法论

> **把数学结构当作参数空间：律是坐标（强度×档位×功能），迁移是操作（拆墙/补地基/降档/E′ 回收），涌现是可预测的产物（功能类型定主型，成熟度定回收），而审校就是在每个"显然"处核对律的档位声明。**
