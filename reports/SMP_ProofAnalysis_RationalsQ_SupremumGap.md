## 1. 声明与版本

**主声明**（ℚ 的三重缺口）：有理数域 `ℚ` 是**有序域**（全序 + 域公理）但**不 Dedekind 完备**：

1. **确界失效**：集合 `A = {q ∈ ℚ : q² < 2}` 在 ℚ 中**非空、有上界、却无上确界**（最小上界在 ℚ 外）；
2. **分割有缝**：Dedekind 分割 `(A, B)` 中存在既无 A 最大元、又无 B 最小元的"缝隙分割"（√2 缺口）；
3. **分析定理群失根**：
   - **中间值定理（IVT）失效**：`f: ℚ → ℚ`，`f(x) = x² - 2`，则 `f(0) = -2 < 0 < 2 = f(2)`，但不存在 `c ∈ ℚ` 使 `f(c) = 0`——连续性救不了缺口；
   - **单调有界收敛失效**：`1, 1.4, 1.41, 1.414, ...`（√2 逼近列）单调有界但在 ℚ 中**不收敛**；
   - **区间套失效**：嵌套闭区间长度 → 0，交可为空。

**版本信息**：
- **形式化基础**：古希腊不可通约（毕达哥拉斯学派 √2 危机）→ Dedekind 1872《连续性与无理数》精确化
- **依赖前提**：有序域公理；反例只需初等数论（√2 无理性的标准论证）
- **AxiomaticBase**：`OrderedField_Q` + `NOT_DedekindComplete`
- **历史定位**：两千年"潜默期"（L1）的经典样本——缺口被直觉绕过（Eudoxus 逼近），直到 1872 年才被律级命名（L2）并裁决（L6）。

### 2.2 S*L — 语义逻辑结构

- ℚ 语义核心：**"数轴是密的但不完整"**——稠密性（任意两点间有点）≠ 完备性（分割无缝）；这是两个常被混淆的拓扑性质。
- "连续函数扫过零点"的直觉在 ℚ 上**表面成立实则失效**——图景是连续的，数系是漏的。
- ⚠️ 风险：把稠密当完备；或把 IVT 失效归咎于"函数不连续"——f(x)=x²−2 在 ℚ 上限制意义下完全连续（ε-δ 可验证）。

### 2.3 M*D — 数学依存

Q_Gaps
