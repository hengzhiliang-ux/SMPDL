# SMPDL 算子透镜样本外检验（OS 轮 · 预注册式）

> **版本**：v1.0（v25 候选 · 未入 curated 基线）
> **日期**：2026-10-15
> **性质**：**前向检验**——用 5 个 H1–H43 之外的历史样本测试算子透镜（`SMPDL_OperatorLens_Restructuring.md`）。
> **预注册声明**：预测规则在揭盲前冻结（§一）；每样本同时登记两个基线预测器（§二）；揭盲与计分在 §三–§四。
> **诚实披露（半盲性质）**：预测者（本会话）知道这些历史——因此本检验测的不是"预测者无知下的命中率"，而是**"冻结的规则机械套用时是否比基线更强"**。真正的盲测须在独立会话执行（B4 协议）。本文件是规则压力测试，非最终战绩。

## 一、预测规则（冻结）

对每个新样本按透镜 §五 查表，**机械执行**（不许看实际算子反推）：

| 若律是… | 预测即时补完算子 | 预测涌现型 |
|---|---|---|
| T1 对象律（减法） | 自由算子（free ⊣ forgetful） | β 主 |
| T2 行为律（减法） | 反射完备化 + 规范化决策算子 | α + 元层主 |
| T1（**加法**，如 H29） | 纯完备化、无新算子类型 | **即时零涌现**；长期 γ 不变量 |
| T3 禁闭律 | 不变量算子 | β-现象 |
| 非律（参数迁移） | 形变算子族（连续参数） | — |

## 二、基线预测器（冻结）

- **B0（朴素多数类）**：凡移除一律预测"自由算子 / β 涌现"（库里 T1 样本最多）；
- **B1（随机）**：七型算子均匀随机。

## 三、样本与揭盲

### OS-1 · Dirichlet 原理击破（变分学，Weierstrass 1870 → Hilbert 1904 → De Giorgi 1960s）

- **事件**：「下半连续泛函必达极小」被 Weierstrass 反例击破（Dirichlet 积分极小序列可逃逸）。
- **预测（规则执行）**：被移除的是行为保证律（极小化**过程**的运行保证）→ **T2 → 完备化 + 元层**。
- **实际**：Hilbert 空间完备化 + 弱收敛（反射性）恢复极小存在（**反射完备化** ✓）；De Giorgi 直接法 = minimizing sequence 的标准算法（**元层/规范化** ✓）。
- **判定**：✅ **主型全中**（完备化 + 规范化；α 涌现）。与 H18（Sobolev）相邻但独立——透镜在同族新样本上复制成功。

### OS-2 · Vitali / Banach–Tarski 可测性击破（测度论，1905 / 1924）

- **事件**：「所有子集 Lebesgue 可测」被 Vitali 击破；AC 下 Banach–Tarski 分球放大悖论。
- **预测（规则执行）**：可测性裁定为**双面**（对象面：可测集类定义 T1；行为面：测度可加行为 T2）——按规则须给双预测：T1 面预测自由算子/β；T2 面预测完备化+元层。
- **实际**：外测度/容度（弱化补偿 α ✓ T2 面）；可测基数与 Solovay 模型（**大基数内模型 = 反射完备化** ✓ T2 面）；决定性公理 AD（**新对象族：策略集合论 = β 解禁** ✓ T1 面）。
- **判定**：✅ **双面律双预测全中**——且 OS-2 成为**双面律第 6 例**（B1 压测「独立轨道」判据的样本外再现：可测集对象轨道与测度行为轨道确为独立定理群）。

### OS-3 · 代数闭律的加入（ℚ → ℚ̄，19 世纪，Abel–Galois 线）

- **事件**：这是**加法**样本（给 ℚ 加代数闭性）——表面上是「加法生结构」的凶险反例（长出了 Galois 理论/类域论整片大陆）。
- **预测（规则执行）**：加法 → **即时零涌现**（定理群生根）+ 长期 γ 不变量算子（两阶段理论）。
- **实际**：即时侧：代数基本定理式定理生根（零新对象类——ℚ̄ 本身就是闭包补完）✓；长期侧：**Galois 对应 = 子域 ↔ 子群的反变对偶化算子**（γ 表征型，成熟期认证）✓。
- **判定**：✅ **差异化命中**——这是透镜对基线 B0 的决定性胜利点：B0 预测 β 涌现（错误），透镜的两阶段理论正确预言「表面结构大爆发其实全部住在长期 γ 侧，即时侧零涌现」。不对称律经住了最凶的反例考验。

### OS-4 · 良基律移除（Foundation → Aczel 非良基集合，1988）

- **事件**：ZF 正则公理（良基性）移除 → 非良基集合论（自指集合合法化）。
- **预测（规则执行）**：良基性是**对象构成律** T1 → 自由算子 → β 解禁。
- **实际**：涌现型 ✓（循环集合/自指对象解禁，β 无误）；**但补完算子是 Aczel 解引理 = 终余代数（terminal coalgebra）**——范畴学身份是**余归纳的规范化构造**，不是自由（归纳）算子。它是对偶方向的"cofree"型。
- **判定**：🟡 **半命中**——涌现型 β 中，算子类型 ✗（自由 → 实为终余代数）。
- **触发透镜修订案 E**：T1 的对象解禁有**两条实现路径**——归纳型律走自由算子、余归纳型律走终余代数；律的（余）归纳极性成为新判定维度。

### OS-5 · 连续统假设 CH（边界样本，库内 §9.3 曾裁定不入律清单）

- **预测（规则执行）**：CH 非律 → 形变算子族（参数化的模型构造）。
- **实际**：迭代力迫 = 连续谱系模型格（**形变** ✓）；但 Woodin Ω-逻辑程序是**分立认证定理**的尝试（对 CH 给终极答案）——非律样本竟长出认证定理野心。
- **判定**：🟡 **边界确认 + 张力登记**——支持「律/非律是程度而非二值」（与库内 §9.3 裁定一致），但 Woodin 程序提示：**只要一个大问题足够承重，数学家会试图把它律化**——"律化冲动"本身成为现象。

## 四、计分与结论

| 样本 | 透镜 | 基线 B0（凡移除皆 β/自由） |
|---|---|---|
| OS-1 Dirichlet | ✅ 主型全中 | ❌（实际无 β 对象解禁） |
| OS-2 可测性 | ✅ 双面双中 | 🟡（β 面中、完备化面漏） |
| OS-3 代数闭（加法） | ✅ 差异化命中 | ❌（预测 β 涌现，错得离谱） |
| OS-4 良基 | 🟡 半命中（型中、算子错） | 🟡（β 中，算子同样错） |
| OS-5 CH | 🟡 边界确认 | 🟡（无差异） |
| **合计** | **3 ✅ + 2 🟡** | **0 ✅ + 3 🟡 + 2 ❌** |

**结论**：
1. 透镜在 5 个样本外事件上 **0 未命中**（3 全中 + 2 半中），且在 OS-3 完成了一次对朴素基线的**差异化胜利**（两阶段理论的定向预测）；
2. 半盲局限下不应报"战绩"，应报：**冻结规则的机械执行与基线确有可测差距**——盲测资格成立，建议入 B4 协议（独立会话真盲跑）；
3. 收获两份透镜修订案与一个新现象：
   - **修订案 E（余归纳极性）**：T1 解禁 = 自由算子 ∨ 终余代数，由律的归纳/余归纳方向决定；
   - **修订案 F（双面律独立轨道样本外复制）**：OS-2 = 双面律第 6 例，B1 收紧判据首次在库外自动应用成功；
   - **新现象「律化冲动」**：非律承重问题会吸引分立化/认证化尝试（Woodin 线）——候选登记为新扫描周期的观察对象。

## 五、对透镜 §六诚实披露的更新

- 披露 1（回溯性）部分缓解：已有 5 样本预注册式检验，但半盲性质未除；
- 披露 2（七型互斥性）**恶化**了一格：OS-4 证明自由/规范化边界还需内部细分（归纳 vs 余归纳）——互斥判据修订方向已给出（伴随方向 + （余）归纳极性）。
