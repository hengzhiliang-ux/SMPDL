## 1. 命题与声明

论文研究 Euler totient 函数 $\varphi$ 的像集大小。设

\[ V(x) = \#\{ m \le x : \exists n \in \mathbb{N}, \; \varphi(n)=m \}. \]

典型声明形如：

- $V(x)$ 具有显式渐近公式
  \[ V(x) = \frac{x}{(\log x)^{1+o(1)}} \cdot L(x) \]
  或更精确地
  \[ V(x) = C \frac{x}{\log x} \exp\left( (c+o(1)) (\log \log x)^2 \right), \]
  其中 $C, c$ 为显式常数；
- 或给出一个带显式误差项的公式，如 $V(x) = M(x) + O\left(x (\log x)^{-\alpha}\right)$。

该方向的经典结果包括 Erdős (1935) 的 $V(x) \sim \frac{x}{(\log x)^{1+o(1)}}$，以及 Ford (1998) 的精确渐近公式，其主项涉及一个二重指数与复杂常数。

| 节点 | 前驱 | 状态 |

**发现**：README 仅给出标题与引用，未说明公式的主项形式、是否包含显式误差项，以及是否覆盖所有 totient 值。

### 2.2 S*L — 语义逻辑结构

- 必须区分「totient 值的个数」$V(x)$ 与「方程 $\varphi(n)=m$ 的解数」；后者通常记为 $a(m)$，其和为 $x$。
- 必须区分「所有 totient 值」与「squarefree / 无重根 totient 值」等子类；Ford 的结果针对全体，但证明极精细。
- 风险：可能把对某子类（如 squarefree 原像）的计数滑移到全体 totient 值。

### 2.3 M*D — 数学依存

| 依赖 | 状态 |
|---|---|
| Erdős (1935) 分布结果 | ⚠️ 是否被引用 |
| Ford (1998) 精确渐近 | ⚠️ 若声称改进，需说明如何改进 |
| 鞍点法 / 复分析 | ⚠️ 是否被形式化 |
| 素数分布与光滑数估计 | 🟡 标准但需要显式 |

**关键风险**：Ford 公式的证明依赖于对 totient preimage tree 的精细刻画和鞍点法。任何显式误差项都需要控制重数 $a(m)$ 的尾部；这通常是最困难的部分。

### 2.4 M*L — 数学逻辑结构

- 典型证明结构：
  1. 将 $V(x)$ 写成对 $n$ 的求和或 preimage tree 的计数；
  2. 用 Ford 方法得到主项；
  3. 用筛法或组合估计控制误差项。
- 陷阱：preimage tree 的每层分支数与素数分布相关，重数 $a(m)$ 在某些 $m$ 处极大，需排除或加权。
- 风险：若论文声称对所有 $m \le x$ 给出显式误差项，则必须处理高重数情形。

### 2.5 P*D — 编程/形式化依存

- README 可能指向 [Lean](lean/docs/024.md)，但未说明形式化范围。
- 风险：Lean 可能只形式化了：
  - $V(x)$ 的定义与基本单调性；
  - 对 $x \le 10^6$ 的数值计算；
  - Ford 公式的某个弱化版本。
- 特别风险：形式化可能无法覆盖鞍点法或复杂解析估计。

### 2.6 P*L — 编程逻辑结构

- 若形式化完整，需要检查：
  - 是否定义了 totient 像集的可判定谓词；
  - 是否显式给出主项与误差项；
  - 是否处理了 $x$ 的大小区间划分。

## 5. 人工可能需要确认/补充证明的地方

1. **主项常数**：要求给出 $V(x)$ 渐近公式中的显式常数，或说明其与 Ford (1998) 公式的关系。
2. **误差项**：明确误差项形式，例如 $O\left(x (\log x)^{-\alpha}\right)$ 中的 $\alpha$，或 $O(x^{\theta})$ 中的 $\theta$。
3. **覆盖范围**：确认定理是对所有 totient 值 $m \le x$ 成立，还是仅对某子类（如原像 squarefree、$\varphi(n)$ 无重根等）成立。
4. **与 Ford 定理的比较**：若声称改进 Ford，需指出改进点；若仅复述 Ford，需说明“显式误差”在何种意义下成立。
5. **高重数原像处理**：说明如何处理满足 $\varphi(n)=m$ 有多个解的 $m$，以及如何控制 tail 贡献。
6. **小 $x$ 数值验证**：人工计算 $V(x)$ 对 $x \le 10^8$ 并与公式预测比较，检验主项形状。
7. **Lean 主定理范围**：确认 Lean 是否 literally 给出完整的渐近公式，还是只证明辅助引理或数值上界。
