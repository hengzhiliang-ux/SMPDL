# S/M/P × D/L 审查报告：鸽巢原理（基本形式）

> 目标：对经典证明「若 n 个物品放入 m 个抽屉且 n > m，则至少有一个抽屉包含不少于 2 个物品」执行六格审计。  
> 框架：Göttingen S/M/P × D/L v1.3  
> 日期：2026-10-12

---

## 0. 证明原文

```text
命题：若 n 个物品被放入 m 个抽屉，且 n > m，则至少有一个抽屉包含至少 2 个物品。

证明：反证法。

假设每个抽屉最多放 1 个物品。那么 m 个抽屉最多放 m 个物品。

但已知 n > m，即物品总数超过 m，矛盾。

因此至少有一个抽屉包含至少 2 个物品。证毕。
```

## 1. S/M/P × D/L 六格审计

### 1.1 S*D：语义依存闭合

| 元素 | 直接前驱 | 状态 |
|---|---|---|
| 「至少一个抽屉 ≥ 2 个物品」 | 抽屉、物品、计数的日常语义 | ✅ |
| 「假设每个抽屉最多 1 个」 | 反证法假设 | ✅ |
| 「m 个抽屉最多放 m 个物品」 | 乘法：m × 1 = m | ✅ |
| 「n > m 与总数 ≤ m 矛盾」 | 已知条件 + 上一步 | ✅ |

**S*D：✅ 通过**

### 1.2 S*L：语义逻辑合法性

| 检查点 | 结果 | 说明 |
|---|---|---|
| 量词纪律 | ✅ | 「至少一个抽屉」对应存在量词 ∃ |
| 反证结构 | ✅ | 假设 ¬P，推出矛盾，得出 P |
| 术语单义 | ✅ | 「物品」「抽屉」「放入」在组合计数中标准化 |
| 无悬空结论 | ✅ | 每步都有前驱 |

**S*L：✅ 通过**

### 1.3 M*D：数学依存闭合

```
命题 P：n > m ⇒ ∃抽屉，|抽屉| ≥ 2
       ↓
反证假设 ¬P：∀抽屉，|抽屉| ≤ 1
       ↓
总物品数 ≤ Σ_{抽屉} 1 = m
       ↓
与 n > m 矛盾
       ↓
P 成立
```

依赖图从反证假设到矛盾，无反向边。

**M*D：✅ 通过**

### 1.4 M*L：数学逻辑合法性

| 检查点 | 结果 | 说明 |
|---|---|---|
| 计数原理 | ✅ | 各抽屉物品数之和等于总物品数 |
| 不等式传递 | ✅ | 每项 ≤ 1 ⇒ 总和 ≤ m |
| 反证结构 | ✅ | 假设推出与已知条件矛盾 |
| 边界扫描 | ✅ | n = m+1 是临界情形，已覆盖 |
| 隐藏假设 | ⚠️ | 抽屉与物品均为有限集合；无限情形需另行讨论 |

**M*L：✅ 通过**（⚠️ 为教学级提示）

### 1.5 P*D：编程/形式化依存闭合

Lean 骨架：

```lean
theorem pigeonhole_principle {α β : Type*} [Fintype β]
    (f : α → β) (ha : Fintype.card α > Fintype.card β) :
    ∃ y : β, {x | f x = y}.toFinset.card ≥ 2 := by
  by_contra h
  push_neg at h
  -- 假设每个纤维大小 ≤ 1
  have h1 : ∀ y, {x | f x = y}.toFinset.card ≤ 1 := by
    intro y
    exact Nat.le_of_lt_succ (h y)
  -- 总元素数 ≤ 目标类型基数
  have h2 : Fintype.card α ≤ Fintype.card β := by
    -- 通过求和 Σ_y |f⁻¹(y)| = |α| 完成
    sorry
  linarith
```

主要 `sorry` 是有限集合上的纤维基数求和，可用 `Finset` 工具填充。

**P*D：✅ 通过**

### 1.6 P*L：形式化逻辑合法性

| 检查点 | 结果 | 说明 |
|---|---|---|
| `by_contra` + `push_neg` | ✅ | 正确实现反证法 |
| 纤维集合 | ✅ | `{x | f x = y}` 良定义 |
| 基数比较 | ✅ | `linarith` 处理整数不等式 |
| 无等价循环 | ✅ | 未用鸽巢原理证明自身 |

**P*L：✅ 通过**

## 3. 边界与反例扫描

| 情形 | 处理 | 状态 |
|---|---|---|
| n = m+1 | 临界情形，证明直接适用 | ✅ |
| n = m | 命题不保证，反例：每个抽屉恰好 1 个 | ✅ |
| m = 0 | n > 0 不可能放入 0 个抽屉，前提空真 | ✅ |
| 无限集合 | 基本形式要求有限；无限版本需另证 | ⚠️ 非本命题必需 |
| 空物品 | n = 0 时 n > m 要求 m < 0，无意义 | ✅ |
