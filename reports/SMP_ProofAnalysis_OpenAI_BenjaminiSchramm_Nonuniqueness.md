## 声明摘要

该论文声称证明了 Benjamini–Schramm 非唯一性猜想：对每个无限连通局部有限非顺从（nonamenable）拟传递图，Bernoulli 边渗流的临界概率 p_c 严格小于唯一性阈值 p_u，从而存在一个非空概率区间使得几乎 surely 存在无穷多个无限簇。这一结果是渗流理论中的核心问题，与 Lyons、Schramm、Peres、Häggström 等人的经典工作密切相关。

Lean 形式化结果建立了 p_c < p_{2→2} ≤ p_u 以及一个公共非空耦合区间，在该区间上几乎 surely 存在无穷多个无限簇。对 Cayley 图，结果对每个非顺从有限生成群的有限对称生成集以及每个 p ∈ (p_c, p_u) 成立。形式化范围与论文核心声明基本一致，但需注意 p_{2→2} 与 p_u 的精确关系以及耦合区间的构造是否在原声明中被完整覆盖。

## TRAP-CHECK v1.0 扫描

- **T1 Scope Creep（范围潜增）**：论文声明对所有非顺从拟传递图成立；Lean 形式化中引入 p_{2→2}，需确认该中间阈值是否在论文中明确说明。
- **T2 Equivalence Misattribution（等价误归）**：需区分 p_c < p_u 与 p_c < p_{2→2} ≤ p_u 是否严格等价；后者是更强的技术陈述。
- **T3 Oracle Substitution（先知替换）**：若 p_{2→2} 的估计依赖新的谱理论结果，其正确性不能仅由 Lean 保证。
- **T4 Circularity（循环）**：若用 Benjamini–Schramm 猜想本身证明 p_{2→2} 的某个关键性质，则构成循环。
- **T5 Missing Constants（常数缺失）**：p_c 与 p_u 之间的距离、耦合区间的长度若未显式给出，则结论的量化信息不足。
- **T6 Constructive Gap（构造性缺口）**：无限簇的存在性通常是非构造性的；若论文声称可估计区间长度，则需额外验证。
- **T7 Computer-Aided Trust Chain（计算机辅助信任链）**：渗流理论中的 almost sure 事件与无限对象形式化复杂，需专家审查。
