# S/M/P × D/L 审计报告：直觉主义/构造性逻辑存在性证明（显式见证）

> **定理**：存在无理数 a, b，使得 a^b 是有理数。
> 
> **来源**：同一命题的构造性证明 folklore； witness (a,b) = (√2, log₂ 9) 及其变体在 Bishop, *Constructive Analysis* 与多种构造性数学教材中作为标准例子出现。
> 
> **分析日期**：2026-10-13 | **审计框架**：Göttingen S/M/P × D/L v1.5 | **AxiomaticBase**：`IntuitionisticLogic`
> 
> **风险评级**：⚪ 已确认正确（在直觉主义/构造性基础内），且提供显式见证。

---

## 0. 分析目标

1. 对“存在无理数 a, b 使 a^b 为有理数”的构造性证明进行 S/M/P × D/L 六格审计。
2. 明确该版本与经典非构造性版本的关键差异：**不使用排中律（LEM）**，而是直接给出一对具体的无理数。
3. 展示如何在直觉主义/构造性基础下，把“∃”解释为“我能构造一个 witness”。
4. 为与经典版本对比建立 SMPDL 标签与风险点清单。

## 1. S 层审计（语义层）

### 1.1 S*D：语义依存

| 自然语言元素 | 支持的后续元素 | 依赖说明 |
|---|---|---|
| “√2 是无理数” | “a = √2 是无理数” | 前提引理 |
| “令 b = log₂ 9” | 需要验证 b 是无理数 | 构造候选指数 |
| “log₂ 9 是无理数” | “b 是无理数” | 关键引理 |
| 指数律 (a^b)^... = a^(...) | 计算 a^b = 3 | 验证工具 |
| “因此 (√2, log₂ 9) 是所求” | 最终结论 | 直接给出 witness |

### 1.2 S*L：语义逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 量词显式化 | ✅ | ∃ 量词显式，且 witness 被显式命名。 |
| 术语单义性 | ✅ | “存在”在构造性语义下表示“可给出具体 witness”。 |
| “存在”的语义 | ✅ | 本证明直接构造 a = √2, b = log₂ 9，符合 Brouwer-Heyting 对 ∃ 的解释。 |
| 隐含跳跃 | 🟢 低 | 唯一需要额外说明的是 log₂ 9 的构造性定义与无理数证明；无 LEM 依赖。 |
| 蕴涵方向 | ✅ | a、b 的无理性 + a^b = 3 ∈ ℚ 直接导出 ∃ 结论。 |

**S 层结论**：自然语言证明直接给出 witness，符合直觉主义/构造性对存在量词的严格解释。主要教学价值在于与经典非构造性证明形成对照。

## 2. M 层审计（数学层）

### 2.1 M*D：数学依存

```text
Constructive Existence of a,b ∈ ℝ\ℚ with a^b ∈ ℚ
    │
    ├── Lemma: √2 ∉ ℚ
    │
    ├── Construction: b := log₂ 9
    │       │
    │       ├── Definition: log₂ 9 is the unique real x with 2^x = 9
    │       │
    │       └── Lemma: log₂ 9 ∉ ℚ  (proof by contradiction of negation)
    │               │
    │               └── Suppose log₂ 9 = p/q; then 2^p = 9^q; contradiction
    │
    ├── Computation: (√2)^(log₂ 9) = 2^((log₂ 9)/2) = (2^(log₂ 9))^(1/2) = √9 = 3
    │
    └── Conclusion: (a,b) = (√2, log₂ 9) is an explicit witness
```

| 数学对象 | 结构签名 | 在证明中的作用 |
|---|---|---|
| 实数 ℝ | 有序域（构造性版本） | 论域 |
| 有理数 ℚ | ℝ 的可判定子集（在构造性数学中较复杂） | 分类标准 |
| 无理数 ℝ \ ℚ | 非 ℚ 的实数 | witness 属性 |
| a = √2 | 代数无理数 | 底数 |
| b = log₂ 9 | 超越数（实际上是超越数，但本证明只需无理） | 指数 |
| 3 ∈ ℚ | 整数 3 | a^b 的结果 |
| 指数律 | 实数指数运算 | 验证 a^b = 3 |

### 2.2 M*L：数学逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 公理系统一致性 | ✅ | 在直觉主义/构造性基础（Heyting 算术、BISH）内有效。 |
| 构造合法性 | ✅ | a = √2 与 b = log₂ 9 均为良定义实数；log₂ 9 的存在性由 2^x = 9 的连续/单调性保证。 |
| 量词范围 | ✅ | 存在量词由显式 witness 满足。 |
| 边界情况 | ✅ | 无退化；√2 > 0 保证实数幂良定义。 |
| 隐藏假设 | 🟢 低 | 不需要 LEM；无理数证明是“证明否定”，在直觉主义中合法。 |
| 等价命题循环 | ✅ | 无。 |

**M 层结论**：证明结构完整。核心差异在于：不再对某个中间对象（如 √2^√2）的有理性做情况分析，而是直接构造一对 witness 并验证其性质。

## 3. P 层审计（编程/形式化层）

### 3.1 P*D：形式化依存

> 以下依存关系以构造性/直觉主义 Lean（不使用 `Classical.em` 或 `Classical.choice`）为参照。Mathlib 中大量分析定理依赖经典逻辑，因此一个完全构造性的形式化需要专门的构造性分析库（如 `mathlib4` 中的部分可计算分析，或 Coq 的 CoRN/TypeTopology）。

```text
IntuitionisticExistenceWitness
    │
    ├── Constructive Real Numbers
    │       │
    │       └── Definition of √2 and log₂ 9
    │
    ├── Lemma: irrational_sqrt_two
    │
    ├── Lemma: irrational_log2_9
    │       │
    │       └── Proof by contradiction of negation
    │
    ├── Lemma: constructive real exponentiation
    │       │
    │       └── (√2)^(log₂ 9) = 3
    │
    └── Theorem: exists_irrational_irrational_rpow_rational
```

### 3.2 P*L：形式化逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 语法可编译 | 🟡 | 完全构造性形式化需专门的构造性分析库；经典 Lean 中 `log₂ 9` 的定义依赖选择公理。 |
| 类型签名一致 | ✅ | 目标与经典版本相同，但证明项提供更丰富信息（包含 witness 与证明）。 |
| 定义等价 | ✅ | `a = √2` 与 `b = log₂ 9` 在构造性实数下等价。 |
| 命题等式 | ✅ | `a^b = 3` 是显式可验证等式。 |
| 形式化核验证 | 🟡 | 经典 Lean 可验证，但会引入非构造性公理；纯构造性形式化需额外库支持。 |
| `#print axioms` | 🟢 低 | 纯构造性形式化下不依赖 `Classical.choice`；经典形式化下会显示依赖。 |

**P 层结论**：构造性证明在原则上可完全形式化，但实际实现受限于当前证明助手的构造性分析基础设施。教学与审校价值高于纯工具化价值。

## 4. 跨层映射检查

### 4.1 S ↔ M

| S 层主张 | M 层形式化 | 同构强度 | 说明 |
|---|---|---|---|
| “令 a = √2” | `a := Real.sqrt 2` | ⭐⭐⭐ 高 | 直接对应 |
| “令 b = log₂ 9” | `b := Real.logb 2 9` | ⭐⭐⭐ 高 | 直接对应 |
| “b 是无理数” | `Irrational b` | ⭐⭐⭐ 高 | 需构造性无理数证明 |
| “a^b = 3” | `a ^ b = 3` | ⭐⭐⭐ 高 | 直接计算 |
| “(a,b) 是 witness” | `⟨a, b, proof⟩` | ⭐⭐⭐ 高 | ∃ 的 BHK 解释 |

### 4.2 M ↔ P

| M 层对象/关系 | P 层表达 | 同构强度 | 判据 |
|---|---|---|---|
| 构造性实数 | `CReal` / 构造性实数类型 | ⭐⭐⭐ 高 | 论域类型 |
| √2 | `Real.sqrt 2` / 构造性根号 | ⭐⭐⭐ 高 | 代数构造 |
| log₂ 9 | `Real.logb 2 9` / 构造性对数 | ⭐⭐⭐ 高 | 通过 2^x = 9 定义 |
| 无理数 | `Irrational x` | ⭐⭐⭐ 高 | 否定性谓词 |
| 指数等式 | `a ^ b = 3` | ⭐⭐⭐ 高 | 可计算验证 |

### 4.3 S ↔ P

| 自然语言步骤 | 形式化代码 | 保真度 |
|---|---|---|
| 定义 a | `let a := Real.sqrt 2` | ✅ 高 |
| 定义 b | `let b := Real.logb 2 9` | ✅ 高 |
| 证明 b 无理 | `have hb : Irrational b := ...` | ✅ 高 |
| 计算 a^b | `have h : a ^ b = 3 := ...` | ✅ 高 |
| 给出 witness | `exact ⟨a, b, ha, hb, 3, h⟩` | ✅ 高 |

**跨层结论**：S/M/P 三层映射清晰。构造性证明的 P 层 richer than 经典版本，因为 ∃ 的证明项本身携带 witness 和验证。

## 5. 与经典版本的同构对比

| 维度 | 经典版本 | 直觉主义/构造性版本 | SMPDL 标注 |
|---|---|---|---|
| 结论 | ∃ a,b ∉ ℚ, a^b ∈ ℚ | ∃ a,b ∉ ℚ, a^b ∈ ℚ | `S-BISIM`（结论相同） |
| 见证 | 不具体给出 | a = √2, b = log₂ 9 | `M-ISO`（数学对象/信息不同） |
| 核心工具 | LEM + 情况分析 | 显式构造 + 计算验证 | `P-ISO`（都是存在性证明，但程序不同） |
| “存在”语义 | ∃ = ¬∀¬ | ∃ = 可构造 witness | `S-ISO`（语义不同） |
| 是否可计算 | 否 | 是（可计算到任意精度） | `P-ISO` / `M-ISO` |
| 证明长度 | 较短 | 稍长（需构造 b 并证无理） | `P-ISO`（目标相同） |

## 7. 结论

该证明是**构造性存在证明**的教科书范例：

- **S 层**：直接给出 witness，符合直觉主义对 ∃ 的严格语义。
- **M 层**：不依赖 LEM；核心为显式构造 (√2, log₂ 9) 并验证其性质。
- **P 层**：比经典版本提供更丰富的证明项（witness + 验证）；完全构造性形式化需专门库支持。
- **跨层映射**：三层对应关系明确，同构强度为 ⭐⭐⭐ 高。
- **与经典版本对比**：结论相同但信息量不同——构造性版本额外提供了可计算的 witness。

该样本建议标记为：`IntuitionisticLogic`、`S-ISO / M-ISO / P-ISO`（与经典版本相比），或 `S-BISIM / M-ISO / P-ISO`（结论相同但 witness 信息不同）。
