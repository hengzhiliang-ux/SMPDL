## 声明摘要

该论文声称证明了对数 Brunn–Minkowski 不等式：对任意维数中的原点对称凸体，其对数 Wulff 组合的体积不小于两端点体积的几何平均；并进一步声称标量膨胀 B-猜想对所有偶对数凹 Radon 测度成立，以及 Lebesgue 体积情形下的加性 L_p Brunn–Minkowski 不等式在 0 < p < 1 时成立。这些结果是凸几何中极具影响力的开放问题，与 Kolesnikov、Milman、Livne Bar-on、Saroglou 等人的工作密切相关。

Lean 形式化结果证明：对每个维数 n ≥ 1，任意原点对称凸体 K, L ⊂ R^n 与 0 ≤ t ≤ 1，其对数 Wulff 组合的体积至少为 |K|^{1−t} |L|^t。形式化不假设边界光滑性或坐标轴无条件性。B-猜想与 L_p Brunn–Minkowski 的附加声明未被明确覆盖，形式化范围集中但不完整。

- **T3 Oracle Substitution（先知替换）**：若证明使用新的椭圆型方程或质量输运技术，其正确性不能仅由 Lean 保证。
- **T4 Circularity（循环）**：若用 B-猜想或 L_p BM 作为对数 BM 证明中的隐含假设，则构成循环。
- **T5 Missing Constants（常数缺失）**：体积下界中的指数 1−t 与 t 需显式处理；等号情形的常数分类需完整。
- **T6 Constructive Gap（构造性缺口）**：对数 Wulff 组合的构造与体积计算需显式；若依赖紧性论证，需确认可测性。
