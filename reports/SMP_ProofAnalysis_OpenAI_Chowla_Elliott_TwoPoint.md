## 1. 命题与声明

**普通两点 Chowla 猜想**：对任意固定的非比例仿射形式 a₁n + b₁, a₂n + b₂，Liouville 函数的相关和

\[
\sum_{n \le X} \lambda(a_1 n + b_1) \lambda(a_2 n + b_2) = O\left(\frac{X}{(\log X)^c}\right)
\]

对某个绝对常数 c > 0 成立。

**二元修正 Elliott 猜想**：对任意两个模不超过 1 的复乘性函数 f, g，若其中一个对任意 Dirichlet 特征乘以 nⁱᵗ 都一致 nonpretentious，则其相关和在固定剩余类中趋于 0。

### 2.2 S*L — 语义逻辑结构

- 「every fixed pair of nonproportional affine forms」——全称量词。
- 「absolute exponent」——声称对仿射形式一致有效。
- 风险：可能证明了对「充分大的 X」成立但常数依赖仿射形式；或仅对特殊形式成立。

### 2.3 M*D — 数学依存

| 依赖 | 状态 |
|---|---|
| Matomäki-Radziwiłł-Tao 对 Chowla 的突破 | 🟡 已知部分结果 |
| pretentiousness / log-correlations 理论 | ⚠️ 未说明 |
| 熵递减方法 | ⚠️ 未说明 |
| 有限模型/ nilsequence 理论 | ⚠️ 未说明 |

**关键风险**：当前最佳结果（MRT）对一般 Chowla 仅给出 o(X)，且对 log 平均。获得逐点 log 幂节省需要显著超越现有技术。

### 2.4 M*L — 数学逻辑结构

- 相关和趋于 0 的证明通常需要：
  1. 将乘性函数分解为结构化 + 伪随机部分；
  2. 控制结构化部分（nilsequence）；
  3. 对伪随机部分应用大筛或熵估计。
- 风险：某一步中的误差项可能不够小，无法得到 log 幂节省。

### 2.5 P*D — 编程/形式化依存

- README 提到 [Lean](lean/docs/007.md)。
- 风险：形式化可能只覆盖了有限模型或特例，未覆盖一般非比例仿射形式。

### 2.6 P*L — 编程逻辑结构

- 若使用算法验证小参数，需确认其是否支持全称归纳。
- 若 Lean 证明依赖具体大常数，需检查其来源。

## 5. 人工可能需要确认/补充证明的地方

1. **定量指数来源**：证明中常数 c 是否显式可计算，是否对所有非比例仿射形式一致。
2. **剩余类一致性**：摘要提到 "fixed residue classes"，需明确这是否覆盖所有允许的 gcd 条件。
3. **与 MRT 的边界**：明确本结果相对于 Matomäki-Radziwiłł-Tao 改进在哪里。
4. **Lean 范围**：确认 Lean 形式化是否覆盖了一般情形，还是仅验证了核心引理。
5. **反例测试**：对一些简单的非比例形式（如 n, n+1）检查大 X 时的相关和是否确实显示 log 幂衰减。
