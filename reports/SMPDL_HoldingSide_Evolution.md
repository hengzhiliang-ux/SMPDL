## 一、核心发现

**证明成立伴随的不是结构静止，而是另一种方向的演化：定型化（consolidation）。**

失效侧演化是**发散式**的（解禁新大陆 / 补偿新工具 / 回收新母结构）；成立侧演化是**收敛式**的——结构被律**唯一钉死**、经济性**兑现**、适用边界被**画清**。同律双侧（H27 布尔/量子、H46 二次型/挠子）提供天然对照：同一历史时期，失效侧长出新学科，成立侧长出**表征、算法与边界**。

## 二、定型化五形态（P0–P4）

| 形态 | 名称 | 内容 | 库内证据 |
|---|---|---|---|
| **P0** | **定理群生根** | 旧问题批量解决、定理成群就位，**零新概念**（表达经济兑现：免费午餐） | H29 ℚ→ℝ 完备律加入：IVT/BWT/CPT/Heine-Borel 批量生根；H23 Hilbert 侧：Riesz 自对偶、投影存在/唯一**免费享有** |
| **P1** | **表征化 + 唯一性** | 律升格为**双向表征定理**（律 ⇔ 结构类）+ 结构被唯一钉死（"构造非唯一、结构唯一"） | Stone 1936 布尔 ⇔ 集合域（H27 成立侧）；Jordan–von Neumann 1935 平行四边形律 ⇔ Hilbert（乙级表征律原型）；Hasse–Minkowski 1923 局部-整体 ⇔ 二次型等价（H46 成立侧）；Ostrowski 表征（H34）；Hilbert 公理唯一性（H29） |
| **P2** | **算法化 / 可判定化** | 律的成立被转化为**有效判定程序**（关于律的算法在成立侧同样涌现） | Hasse–Minkowski → 有理二次型等价的有效判定；Church–Rosser 汇合（H31）→ 规范化算法 / Knuth–Bendix 完备化 |
| **P3** | **参数化回收**（γ 的成立侧视图） | 成立结构在母结构中被**再定位为特例/参数**——律不死，被降格为坐标值 | K=0 成为 Gauss-Bonnet 特例（H16）；布尔 = Heyting ⊔⊥ 特例（H7）；Riemann = Lebesgue 特例（H17）；经典 = tropical 极限影子（H39） |
| **P4** | **边界测绘** | 成立域被精确画图：**何处成立、何处失效、何处被绕开**——边界本身成为研究对象 | H46：二次型 ✓ / 亏格 1 挠子 ✗ / Brauer–Manin 条件刻画中间地带；H42"绕开式失效"三路（热力学/量子/结构绕开而律本体不破）；H34 阿氏 ⊥ 完备双律分解连续统 |

## 三、机制解释

1. **经济兑现**（FS-1 表达经济性的成立侧归宿）：律在位 = 证明效率最高的基础；成立侧演化就是把这份效率**一次性兑现**为定理群（P0）与免费结构（Hilbert 自对偶"免费享有"）；
2. **档位视角**：成立侧是律升格为 **E 档定理律 → 乙级表征律**的产地——"乙级 ⇔ 表征 γ 定义性关联 12/12"（FS-3 §4.4）的另一半事实是：**那 12 条表征定理全部诞生于成立侧**。失效侧给出 γ 回收（母结构），成立侧给出 ⇔ 表征（结构指纹）——γ 的两副面孔；
3. **需求拉动**：失效侧的出现反过来**倒逼**成立侧的 P4（边界测绘）——没有 Lind–Reichardt 1942，就不需要回答"Hasse 原理到底对哪些形式成立"；边界测绘是两侧演化的**接头处**（Selmer 群从失效侧量化缺口，Brauer–Manin 从成立侧刻画条件——同一结构两种读法）。

## 四、不对称律的完整图景

```text
                同一条律
          ┌─────────┴─────────┐
      失效侧（移除）        成立侧（保持）
      发散式演化            收敛式演化
      β 新对象解禁          P0 定理群生根（零新概念）
      α 新工具顶班          P1 表征化 + 结构唯一性
      γ 母结构回收   ◄──►   P3 被参数化（γ 镜像）
      元层算法（何时安全）    P2 算法化（如何判定）
      新大陆                P4 边界测绘（两侧接头）
```

**修正一处旧表述**：移除-涌现文档曾把加法侧概括为"不诞生新概念"（H29）——成立侧分析显示这不等于"没有演化"：成立侧产出的是**表征定理、判定算法与边界刻画**，它们是结构知识，只是**收敛型**而非发散型的结构知识。"减法生结构、加法生定理"应精化为：**减法生发散结构（新对象族），成立/加法定收敛结构（指纹+算法+边界）**。

## 五、可检验推论

1. **表征产地论**：未来任何律的表征定理（⇔ 型）应首现于其成立侧文献脉络——可用 H44/H45 成立侧检验（维数不变律的表征定理 = 覆盖维数论在"维数良定义对象类"一侧；单值性的表征 = 覆叠空间分类定理）；
2. **接头推论**：每当失效侧涌现量化补偿结构（Selmer 型），成立侧应在 ±20 年内出现对应边界刻画（Brauer–Manin 型）——H46 时间链 1951/1970 与 1959/1962 初步吻合；
3. **AI 审校应用**：AI 证明在律成立语境的典型错误将与 P1/P2 错配有关（把表征当定义循环使用 / 把判定算法的适用域越出边界）——可在 OpenAI 语料定域检验。

## 六、局限（诚实款）

- 成立侧样本的系统性抽样**弱于**失效侧：库的入选标准（断裂事件）使成立侧多以对照组身份出现，无独立成组的成立侧样本（H46 对照设计是首个双侧设计，建议推广为标准）；
- P0–P4 形态学为回溯归纳，未做前向登记；推论 1/2 为本轮新登记的候选预测，按回测纪律 v2.0 须先 git 冻结再回验；
- "±20 年接头窗口"取自单例（H46），探索性。
