# 数学史演进中被迁移的内容与证明骨架

**版本**：v2.5  
**日期**：2026-10-14  
**范围**：本文档分析数学史演进过程中"证明骨架"如何在不同基础之间被迁移、改造与失效，并将已生成的 43 组 SMPDL 案例（H1–H43）映射到迁移类型矩阵，揭示哪些内容具有跨历史的可迁移性，哪些内容会在迁移中断裂。

---

## 一、核心问题

数学史不仅是定理的积累史，更是**证明骨架的迁移史**。同一套推理策略或概念结构，常常在不同历史时期被重新解释、移植到新的基础之上：

- 欧氏几何的“三角形”骨架 → 球面几何、双曲几何、黎曼几何
- Newton/Leibniz 的“无穷小”骨架 → Weierstrass 的 ε-δ → Robinson 的非标准分析
- 经典逻辑的“存在性证明”骨架 → 直觉主义的“构造性证明”
- 交换代数的“行列式/理想”骨架 → 非交换代数、算子代数
- 有限组合的“归纳/鸽巢”骨架 → 无限组合、紧致性论证

SMPDL 的核心价值之一，就是把这种历史迁移过程**显式化、结构化、可审计化**。

---

## 二、迁移内容的三个层次

沿用 SMPDL 的 S/M/P 三层框架，数学史中被迁移的内容也可分为三类：

| 层次 | 迁移内容 | 历史示例 |
|---|---|---|
| **S 层：语义/概念骨架** | 术语、直观图像、结论表述 | “直线”、“平面”、“存在”、“等于”、“收敛” |
| **M 层：数学/结构骨架** | 定理、公理、不变量、核心引理 | 三角形内角和公式、中间值定理、二项式展开、向量空间基存在性 |
| **P 层：证明/方法骨架** | 证明策略、算法、形式化技巧 | 反证法、归纳法、区间套、对角线法、Zorn 引理、二分法 |

**关键观察**：历史上被迁移最频繁的往往是 **P 层方法骨架**，其次是 **M 层结构骨架**；**S 层语义骨架**最容易因基础不同而“同名异义”。

## 三、迁移类型矩阵

### 3.1 按迁移结果分类

| 迁移类型 | 定义 | 典型案例 | SMPDL 标签 |
|---|---|---|---|
| **直接迁移（Direct Transfer）** | 骨架几乎不变，仅基础参数改变 | 欧氏三角形内角和 → 球面三角形内角和 | `S-ISO / M-ISO / P-BISIM` |
| **参数迁移（Parametric Transfer）** | 骨架保留，但需调整关键参数 | 微分方程 → 差分方程（步长 h） | `S-ISO / M-BISIM / P-BISIM` |
| **公理迁移（Axiomatic Transfer）** | 骨架保留，但某条公理被替换/移除 | 交换环 → 非交换环；ZFC → ZF；经典逻辑 → 直觉主义 | `S-BISIM / M-BISIM / P-BISIM` |
| **语义迁移（Semantic Transfer）** | 结论形式不变，但语义改变 | 集合论 n+0=n → 类型论 n+0=n；经典存在 → 可计算存在 | `S-ISO / M-BISIM / P-BISIM` |
| **断裂迁移（Broken Transfer）** | 骨架迁移后结论失效或不可证 | 有限图 δ≥2 ⇒ 有环 → 无限图；ZFC 基存在 → ZF | `S-ISO / M-BISIM / P-BISIM` |
| **升级迁移（Upgrading Transfer）** | 骨架增强，结论更强 | 经典 IVT → 可计算 IVT | `S-ISO / M-BISIM / P-BISIM` |

### 3.2 按 SMPDL 层级分类

| 层级 | 可迁移内容 | 迁移障碍 | 历史示例 |
|---|---|---|---|
| **S → S'** | 术语和直观 | 同名异义 | “直线”在欧氏/球面/非欧中不同 |
| **M → M'** | 定理和结构 | 公理强度/结构不变量 | 向量空间基在 ZFC/ZF 中可证性不同 |
| **P → P'** | 证明策略 | 形式化库支持/规则限制 | 反证法在直觉主义中受限 |
| **S → M** | 语义到结构 | 术语定义不足 | “无穷小”从直观到严格化 |
| **M → P** | 定理到算法 | 可计算性约束 | IVT 从存在性到二分法 |
| **P → S** | 方法到语义 | 结论解释差异 | 非标准分析导数与标准导数语义等价 |

## 四、四十三组案例的迁移骨架分析

### H1 欧氏 ↔ 球面：三角形内角和

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | “三角形”从平面图形迁移到测地线三角形；“内角和”语义从 180° 变为 π + Area/R² |
| **M 层** | 核心结构从“平行公设 + 平角”变为“测地线 + 曲率” |
| **P 层** | 证明策略从“作平行线”变为“球面余弦定理/面积公式”；部分几何直观可迁移 |
| **迁移类型** | 参数迁移：曲率 K 从 0 变为正数 |
| **断裂点** | “过一点作平行线”在球面上不存在 |

### H2 微分 ↔ 差分：指数增长

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | “增长率 ∝ 当前量”的直观相同 |
| **M 层** | 连续版本用导数/指数函数；离散版本用递推/几何序列 |
| **P 层** | 连续用分离变量；离散用数学归纳；Euler 离散化建立联系 |
| **迁移类型** | 参数迁移：连续参数 h → 0 |
| **断裂点** | 离散版本在 h 过大时可能发散或震荡 |

### H3 有限 ↔ 无限图：最小度环

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | “最小度 ≥ 2”的术语相同 |
| **M 层** | 核心引理“最长路径存在”在有限中成立，在无限中失效 |
| **P 层** | 最长路径法可直接用于有限；无限需紧致性/选择论证 |
| **迁移类型** | 断裂迁移：论域基数改变导致结论反转 |
| **断裂点** | 无限双向路径 δ=2 但无环 |

### H4 交换 ↔ 非交换：二项式幂

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | (ab)ⁿ 的符号形式相同，但展开语义不同 |
| **M 层** | 核心结构从“可重排”变为“保持顺序” |
| **P 层** | 归纳骨架相同，但交换律调用位置改变 |
| **迁移类型** | 公理迁移：移除乘法交换律 |
| **断裂点** | (ab)ⁿ = aⁿbⁿ 在非交换中不成立 |

### H5 特征 0 ↔ 特征 p：二项式展开

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | (a+b)ᵖ 的符号形式相同 |
| **M 层** | 核心数论事实反转：p | C(p,k) 在特征 p 下成立 |
| **P 层** | 归纳骨架相同，但二项式系数模 p 后消失 |
| **迁移类型** | 参数迁移：特征 char(R) 改变 |
| **断裂点** | 中间项全部消失，出现 Freshman's Dream |

### H6 标准 ↔ 非标准分析：导数定义

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | “切线斜率”直观相同；严格语义不同 |
| **M 层** | 数系从 ℝ 变为 *ℝ；极限从 ε-δ 变为无穷小无限接近 |
| **P 层** | 证明策略从 ε-δ 量词变为超滤子/转移原理 |
| **迁移类型** | 语义迁移：同一结论在不同数系中表述 |
| **断裂点** | 非标准分析需要额外的模型论基础 |

### H7 经典 ↔ 直觉主义逻辑：存在性证明

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | “存在”语义从 ¬∀¬ 变为 witness + 验证 |
| **M 层** | 命题逻辑结构相同，但 LEM 不可用 |
| **P 层** | 反证法/分情况法受限；需显式构造 |
| **迁移类型** | 公理迁移：禁用排中律 |
| **断裂点** | 经典非构造性证明无法提取 witness |

### H8 ZFC ↔ ZF：向量空间基

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | “基”的术语相同 |
| **M 层** | 存在性结论在 ZFC 中成立，在 ZF 中不可证 |
| **P 层** | Zorn 引理在 ZF 中不可用；需其他方法或证明不可能 |
| **迁移类型** | 公理迁移：移除选择公理 |
| **断裂点** | 最后一步“极大线性无关集 ⇒ 基”在 ZF 中断裂 |

### H9 集合论 ↔ 类型论：n+0=n

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | n+0=n 的符号结论相同；但“等于”语义不同 |
| **M 层** | ℕ 的构造从集合论递归变为归纳类型；证明从定义变为结构归纳 |
| **P 层** | 集合论风格用 `rfl`；类型论风格用 `induction` |
| **迁移类型** | 语义迁移 + 基础框架迁移 |
| **断裂点** | 外延相等与 identity type 不可直接等同 |

### H10 经典分析 ↔ 可计算分析：IVT

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | “存在根”从经典 ∃ 变为可计算 ∃ |
| **M 层** | 增加有效一致连续性假设；从存在性变为可构造性 |
| **P 层** | 从上确界法变为区间二分法；可提取算法 |
| **迁移类型** | 升级迁移：存在性升级为可计算性 |
| **断裂点** | 经典连续函数不一定满足可计算 IVT 条件 |

### H11 紧致空间 ↔ 非紧致空间：最值定理

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | “连续函数”术语相同；但“有界/取最值”的结论强度不同 |
| **M 层** | 核心引理由“有限覆盖定理 + 紧致性”支撑的 Weierstrass 定理，在非紧致空间中失效 |
| **P 层** | 紧致版本用 `IsCompact` 类型类；非紧致版本需构造具体反例函数 |
| **迁移类型** | 参数迁移：紧致性参数从“成立”变为“不成立”；兼具断裂迁移特征 |
| **断裂点** | 非紧致空间中连续函数可无界或不取最值（如 `f(x)=1/x` 在 `(0,1]`） |

### H12 同构 ↔ 范畴等价 ↔ 同伦等价

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | “相同”语义从“严格可逆”弱化为“自然同构意义下相同”再到“同伦意义下相同” |
| **M 层** | 核心工具从可逆态射对，变为函子 + 自然同构，再变为连续映射 + 同伦 |
| **P 层** | 形式化库从 `Iso` 切换到 `Equivalence` 或 `HomotopyEquiv` |
| **迁移类型** | 语义迁移 / 升级迁移：逆的强度逐层减弱，但保留的信息结构重新组织 |
| **断裂点** | 同构 ⇒ 范畴等价 / 同伦等价，但逆命题不成立 |

### H13 频率主义 ↔ 贝叶斯

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | “概率”语义从“长期频率”变为“主观信念度”；“置信区间”与“可信区间”同名异义 |
| **M 层** | 核心工具从 MLE + CLT 变为先验 + 似然 + 后验；数学对象从固定参数变为随机变量 |
| **P 层** | 形式化库从 `statsmodels`/`prop.test` 切换到 PyMC/Stan/`bayestestR` |
| **迁移类型** | 语义迁移：概率解释框架替换 |
| **断裂点** | 同一数据下，95% 置信区间 ≠ 95% 可信区间；先验选择影响贝叶斯结论 |

### H14 经典代数簇 ↔ 概形

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | “几何对象”从“点集”升级为“局部环化空间”；“点”从 `k^n` 中坐标升级为素理想 |
| **M 层** | 核心工具从 Hilbert Nullstellensatz 的经典对应，变为层论、局部化与结构层 |
| **P 层** | 形式化从 CAS 可计算的点集/理想计算，切换到复杂的层化空间与 `Scheme` 类型类 |
| **迁移类型** | 升级迁移：几何对象定义升级，保留更多代数信息 |
| **断裂点** | 经典簇丢失幂零信息；概形框架下理想与子概形一一对应 |

### H15 解析数论 ↔ 代数数论

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | “素数分布”语义相同，但“研究工具”语义从复分析函数变为代数扩张中的 Frobenius |
| **M 层** | 核心工具从 Dirichlet L-函数 `L(1, χ) ≠ 0` 变为分圆域 + Chebotarev 密度定理 |
| **P 层** | 形式化从解析函数库切换到代数数域/Galois 库 |
| **迁移类型** | 方法骨架迁移：同一结论的不同数学分支证明 |
| **断裂点** | 两种证明依赖的理论网络完全不同；代数证明给出密度 `1/φ(q)` |

### H16 欧氏 ↔ 球面 ↔ 双曲

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "直线""平行""角"在三种几何中同名异义，但可用曲率 `K` 重新单义化 |
| **M 层** | 核心工具从平行公设/内错角相等，变为 Gauss-Bonnet 定理；统一公式 `α+β+γ = π + K·Area` |
| **P 层** | 形式化库从平面几何，切换到球面/双曲几何库 |
| **迁移类型** | 参数迁移（`K = 0 / >0 / <0`）+ 公理迁移（平行公设状态） |
| **断裂点** | 欧氏辅助线构造在球面/双曲中失效；双曲存在 ideal triangle（面积 π，内角和 0） |

### H17 Riemann ↔ Lebesgue 积分

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "可积""积分"同名异义；"a.e."宽容语义为 Lebesgue 新增 |
| **M 层** | 分划方向从定义域翻转到值域；工具从达布和换为 MCT→Fatou→DCT 引理链 |
| **P 层** | 形式化厚度极不对称（Riemann 薄 / Lebesgue 厚）；数值验证存在盲区 |
| **迁移类型** | 升级迁移 + 结论反转（交换断裂 → DCT 成立） |
| **断裂点** | Dirichlet 型列在 Riemann 下极限不可积（🔴）；数值采样无法暴露此差异 |

### H18 经典解 ↔ 弱解

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "解"同名异义（C² 逐点 vs H¹ 变分）；正则性从前置变后置 |
| **M 层** | 工具箱整体更换（Green → Sobolev/Lax–Milgram）；存在性↔正则性方向交换 |
| **P 层** | FEM 与弱形式原生协同；经典逐点只能近似 |
| **迁移类型** | 升级迁移 + 存在性↔正则性双向交换 |
| **断裂点** | L 形域角点无经典解；弱解 ∉ H²（`r^{2/3}sin(2θ/3)` 奇异） |

### H19 单复变 ↔ 多复变

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "奇点""自然域""延拓"语义全面反转（点 → 余维 1 集；域自由 → 域受限） |
| **M 层** | 工具箱整体更换（Laurent/留数 → 层论/全纯凸性/Levi 伪凸） |
| **P 层** | 形式化从成熟跌至空白 |
| **迁移类型** | 参数迁移（复维数 n）引发结论反转（维度阈值相变） |
| **断裂点** | n≥2 孤立奇点自动可去；非全纯域存在（Hartogs 被迫延拓） |

### H20 有限 ↔ 无限 Ramsey

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "大"的语义分档（有限尺寸 vs 无限）；"任意大有限"≠"无限" |
| **M 层** | ZF → ZF+DC；紧致性衔接成为必需引理 |
| **P 层** | 数值通道消失（有限可穷举 / 无限仅形式化） |
| **迁移类型** | 参数迁移 + 公理迁移（方向一致的强度加深） |
| **断裂点** | 有限递归不能极限化为无限构造；DC 使用点需逐处核查 |

### H21 一阶 ↔ 二阶逻辑

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "模型""语义""有限"全面同名异义；隐藏第三档（Henkin 语义） |
| **M 层** | 元定理体系整体翻转（紧致/LS/完备性 ✅→❌；范畴性 ❌→✅） |
| **P 层** | 机械化可行性消失（不可判定性） |
| **迁移类型** | 语义迁移引发元定理级结论反转 |
| **断裂点** | "有限性"二阶可定义 → 紧致性反例；二阶归纳 → 范畴性阻挡 LS |

### H22 Hilbert ↔ 自然演绎

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "证明"同名异义（平坦序列 vs 带结构可归约树） |
| **M 层** | 切消去/子公式/一致性/witness 全套仅在自然演绎侧成立 |
| **P 层** | 从组合子弱像到证明助手产业（Curry–Howard） |
| **迁移类型** | 框架迁移引发结构元定理从无到有（能力等价、分析力反转） |
| **断裂点** | Hilbert 无规范化定理；detour 不可系统性消除 |

### H23 Hilbert ↔ Banach

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "⊥""对偶"同名异义（居住空间改变：X 内 vs X* 内） |
| **M 层** | 几何定理群整体换成凸分析定理群（HB 分离 + 次微分） |
| **P 层** | 两侧均有形式化，反例侧（Phelps）稀缺 |
| **迁移类型** | 公理移除（内积）引发定理群坍塌 |
| **断裂点** | c₀ 投影不可达；C[0,1] 多解；L^∞* ⊋ L¹（HB 反而新增 AC 依赖） |

### H24 线性 ↔ 置换表示

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "表示"同名异义（向量空间 vs 集合作用） |
| **M 层** | 完备不变量从有到无（特征标完备 vs 需 Burnside 环补回） |
| **P 层** | 工具链两侧齐备（GAP/Mathlib） |
| **迁移类型** | 语义迁移 + 信息结构单向桥（线性化不可逆） |
| **断裂点** | 特征标相同但置换不同构（信息损失）；轨道计数 ≠ 同构判定 |

### H25 连续流 ↔ 离散映射

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "轨道""周期""混沌"同名但内容物不同（光滑曲线 vs 点列） |
| **M 层** | 定理体系整体更换（P–B/Dulac → Sharkovsky/拓扑熵） |
| **P 层** | 两侧数值均顺畅（离散最友好） |
| **迁移类型** | 参数迁移（时间结构）引发定理群替换 |
| **断裂点** | 离散无 div/Dulac 对应；混沌门槛坍缩（3 维 → 1 维）；截面桥单向 |

### H26 正则 ↔ 上下文无关

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "可识别""封闭"同名异义（语义层随机器升级） |
| **M 层** | 布尔代数结构坍塌为半格 + 隐藏 DCFL 层 |
| **P 层** | 判定器从全类消失（等价不可判定墙） |
| **迁移类型** | 升级迁移（机器资源）引发封闭性/判定性反转 |
| **断裂点** | 交/补不封闭（L₁∩L₂ 例）；等价/包含不可判定（PCP 归约） |

### H27 布尔 ↔ 量子逻辑

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "真""概率""命题"全面同名异义（全局 → 语境内/兼容块） |
| **M 层** | 定理群从布尔代数 + Stone 表示，整体换为正交模格 + KS/Gleason 量子定理群 |
| **P 层** | 有限 KS 构型（Peres 33/Cabello 18 向量）可穷举验证；一般理论形式化稀缺 |
| **迁移类型** | 公理迁移（甲级律：分配律移除）引发语义三重坍塌 |
| **断裂点** | dim≥3 分配律失效（三平面反例）；KS 全局真值指派不可能；Gleason 概率收窄为密度算子；dim=2 为模格中间档 |

### H28 结合 ↔ 非结合代数

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "乘积""幂"同名异义（数 vs 括号树）；括号从排版升为语义 |
| **M 层** | 定理群从广义结合律 + Frobenius（≤4 维）换为交错律/雅可比 + Hurwitz（≤8 维换价）；例外结构（G₂、例外李代数）涌现 |
| **P 层** | Mathlib `Octonions` 无 `pow` 实例——类型系统自动编码断裂（全库最优雅的 P 层拦截样本） |
| **迁移类型** | 公理迁移（甲级律：结合律移除）引发记号坍塌 + 封顶换价 |
| **断裂点** | aⁿ 失义（括号敏感）；Cayley-Dickson 阶梯每倍维杀一律；Artin 局域桥（2-gen 子代数恢复结合） |

### H29 ℚ ↔ ℝ 完备律

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "连续""完备""无缝"同名异义（归因陷阱：IVT 失效在数系不在函数）；稠密 ≠ 完备 |
| **M 层** | 定理群整体反转：IVT/单调收敛/区间套/HB(ℝ) 在 ℚ ❌ 在 ℝ ✅；唯一性表征（完备序域 ≅ ℝ）；五构造一结构 |
| **P 层** | `Rat`/`Real`/浮点三层活标本；浮点 IVT 假象 = 结构性盲区 |
| **迁移类型** | 公理加入（乙级律：完备律）引发定理群生根——全库唯一"加法断裂"，与减法族镜像 |
| **断裂点** | {q²<2} 无 sup；√2 逼近列 Cauchy 不收敛；上游律串联 H10/H11/H17/H6 |

### H30 条件收敛 ↔ 绝对可积

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "交换""存在""收敛"同名异义（默认权限 → 三档定价）；"两逐次积分都存在 ⇒ 相等"是陷阱 |
| **M 层** | ±π/4 反例（次序进入答案）→ Tonelli 非负免费侧 + Fubini L¹ 侧；σ-有限性显影为律组成部分；一维同构 = Riemann 重排 |
| **P 层** | Mathlib `MeasureTheory.Product` σ-有限类型类显影；对称网格数值盲区 |
| **迁移类型** | 框架迁移引发交换律从失效到三档定价恢复（与 H17 姊妹篇：极限-积分 / 积分-积分定价手册） |
| **断裂点** | 条件收敛禁区（正负部各自发散，次序决定无穷分账）；σ-有限不可去 |

### H31 非汇合 ↔ Church–Rosser

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "范式""答案"同名异义（多值歧义 vs 唯一） |
| **M 层** | 斜条带/并行归约证明技术 + KB/Newman/正交判定工具群入场；律检查算法化（元层涌现） |
| **P 层** | 两侧 P 层均强（反例可算 + CR 多形式化，罕见对称） |
| **迁移类型** | 框架迁移（一般 TRS → λβ 结构条件）引发范式唯一性反转 |
| **断裂点** | a→b,a→c 双范式；关键对不合一；扩展演算 CR 不自动继承 |

### H32 单调 ↔ 非单调集值

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "不动点/均衡"语义升档（单值→集值，与 H18 放宽换存在同构） |
| **M 层** | 定理群换轨（Tarski 系 → Kakutani/Nash/VI 系）；单调三段身世（免费定理→可购条件→Minty 几何表征） |
| **P 层** | 双产业对峙（静态分析 vs 博弈/VI 求解器） |
| **迁移类型** | 公理移除（单调律）引发免费午餐终止 + 凸性接棒 |
| **断裂点** | 递减跳跃反例；去凸值 Kakutani 失效；凸性接盘侠规律（跨 H23/H18/H32） |

### H33 耗散 ↔ 变分对称

| 骨架 | 迁移情况 |
|---|---|
| **S 层** | "守恒"同名异义（特权缺席 vs 对称证书）；解释权从经验移交对称结构 |
| **M 层** | Noether 三件套（第一/逆/第二定理）入场；守恒-对称双向汇率；有限/无限维分档 |
| **P 层** | 符号自动提取（Noether 包）+ 数值漂移验证；"证无守恒"半盲 |
| **迁移类型** | 结构加入（变分+对称）引发守恒定价——与 H29 同属加法侧但产物为解释框架 |
| **断裂点** | 一般系统零首次积分；扰动破坏 {G,H₁}≠0；规范⇒恒等式（非守恒荷） |

## 五、迁移成功/失败的一般规律

### 5.1 迁移成功的条件

| 条件 | 说明 |
|---|---|
| **层级映射闭合** | 骨架在 S/M/P 各层之间的新基础下仍保持映射 |
| **核心引理可用** | 证明所依赖的关键引理在替代基础中仍成立或可替代 |
| **术语单义** | 术语在替代基础中有明确对应，避免同名异义 |
| **参数可调整** | 可调参数（如 K, h, char）在替代基础中有合法取值 |

### 5.2 迁移失败的典型模式

| 失败模式 | 说明 | 案例 |
|---|---|---|
| **核心引理失效** | 证明中某关键引理在替代基础中不成立 | H3 最长路径存在性、H8 Zorn 引理 |
| **公理被移除** | 某条默认公理在替代基础中不成立 | H4 交换律、H7 LEM、H8 AC |
| **语义无法对应** | 术语在替代基础中无直接对应 | H1 平行线、H6 无穷小 |
| **参数超出合法范围** | 可调参数取值导致结构不合法 | H5 特征 p |
| **可计算性缺失** | 存在性证明无法提取算法 | H10 经典 IVT → 可计算 IVT |

### 5.3 迁移中的“隐性断裂”

最危险的迁移不是明显失败，而是**看似成功、实则某层已断裂**：

| 现象 | 风险 |
|---|---|
| 术语相同但语义不同 | S 层断裂，M/P 层继续 |
| 定理成立但证明不可形式化 | P 层断裂 |
| 结论成立但 witness 不可提取 | S/M 层一致，但应用层断裂 |

这正是 SMPDL 跨层映射检查要捕捉的风险。

## 六、迁移骨架对人类研究者的启示

### 6.1 教学启示

- 不要只教“结论”，要教“骨架”：
  - 欧氏/球面/双曲三角形内角和共享“曲率影响角度和”的骨架；
  - 经典/可计算 IVT 共享“区间收缩逼近根”的骨架。
- 让学生画出“迁移路径图”，比背诵结论更有效。

### 6.2 审稿启示

- 审稿人应问：作者迁移了哪个骨架？哪个层级可能断裂？
- 常见危险信号：
  - “由经典 IVT 知存在 c，故可计算 c”；
  - “有限图结论对任意图成立”；
  - “特征 0 结果推广到一般域”。

### 6.3 AI 审校启示

- LLM 擅长迁移 P 层骨架（证明策略），但容易忽略 S/M 层基础差异。
- 审校系统应强制：每迁移一个 P 层策略，必须检查其 S/M 层依赖是否闭合。

### 6.4 形式化工程启示

- 在 Lean/Coq 中，迁移骨架常体现为：
  - 类型类参数调整；
  - 公理声明开关；
  - 术语重新定义。
- 形式化前先做 SMPDL 迁移审计，可避免大量返工。

## 七、SMPDL 迁移审计工作流

```text
Step 1: 识别源基础中的证明骨架
        ↓ 提取 S/M/P 三层关键内容
Step 2: 识别目标基础中的对应骨架
        ↓ 检查术语、定理、策略是否可对应
Step 3: 执行跨层映射检查
        ↓ 标记 S→M、M→P、P→S 映射是否闭合
Step 4: 判定迁移类型
        ↓ 直接迁移 / 参数迁移 / 公理迁移 / 语义迁移 / 断裂迁移 / 升级迁移
Step 5: 生成迁移报告
        ↓ 明确成功条件、断裂点、审校建议
```

## 九、结语

数学史是一部“骨架迁移史”。同一套推理策略在不同时代被反复使用，但每次迁移都伴随着基础假设的重新校准。SMPDL 的使命，就是让这种迁移从隐性直觉变为可审计的结构：

> **识别被迁移的骨架，标注它依赖的基础，判断它在目标基础中是否仍然合法。**
