# SMPDL 十组对比：调参来源矩阵

**版本**：v1.0  
**日期**：2026-10-13  
**范围**：本文档识别并汇总已生成的 10 组（30 份）SMPDL“同构证明、异基础”对比报告中，每组对比的核心“调参旋钮”——即可改变的假设参数、其默认值与替代值、参数类型、影响的 SMPDL 层级，以及迁移风险等级。

---

## 一、核心观点

每组“同构证明、异基础”对比都可以被抽象为：**在同一证明骨架上，调整一个或多个基础参数，导致结论/语义/证明对象发生变化**。

识别这些“调参旋钮”有助于：

1. **快速定位跨基础迁移风险**：知道调什么参数，就知道哪里会出错；
2. **设计教学示例**：把抽象的基础差异转化为具体的参数变化；
3. **指导形式化实现**：在证明助手中把参数设为显式假设或类型类参数；
4. **构建 AI 审校规则**：自动检测某参数是否被无意识默认。

## 三、按参数类型分类

### 3.1 几何/分析常数型

| 旋钮 | 参数空间 | 对应组 |
|---|---|---|
| 曲率 `K` | `K = 0`, `K > 0`, `K < 0` | H1 |
| 离散化步长 `h` | `h → 0` 或 `h > 0` | H2 |
| 数系模型 | `ℝ`, `*ℝ`, 可计算实数表示 | H6, H10 |

**特点**：参数取值通常构成连续或有序空间，不同取值之间有极限/收敛关系（如 Euler 离散化收敛到微分解）。

### 3.2 公理开关型

| 旋钮 | 开关状态 | 对应组 |
|---|---|---|
| 乘法交换律 | 开 / 关 | H4 |
| 排中律 LEM | 开 / 关 | H7 |
| 选择公理 AC | 开 / 关 | H8 |

**特点**：二元开关，开与关往往导致结论真值或证明结构发生质变。

### 3.3 结构不变量型

| 旋钮 | 取值空间 | 对应组 |
|---|---|---|
| 域的特征 `char(R)` | 0 或素数 `p` | H5 |
| 论域基数 / 有限性 | 有限 / 无限 | H3 |

**特点**：参数是代数或组合结构的不变量，改变它可能引发“Freshman's Dream”或存在性反转。

### 3.4 基础框架型

| 旋钮 | 可选框架 | 对应组 |
|---|---|---|
| 数学基础 | 集合论 / 类型论 | H9 |
| 分析基础 | 经典 / 可计算 / 非标准 | H6, H10 |

**特点**：参数改变的是整个数学对象的构建方式，影响最深、最系统化。

## 四、按影响层级分类

### 4.1 主要影响 S 层（语义层）

| 组 | S 层变化 |
|---|---|
| H4 | 交换 `(ab)ⁿ = aⁿbⁿ` → 非交换 `(ab)ⁿ = a(ba)ⁿ⁻¹b` |
| H7 | “存在”= ¬∀¬ → “存在”= 可构造 witness |
| H10 | “存在根” → “可计算根 + 算法” |

### 4.2 主要影响 M 层（数学层）

| 组 | M 层变化 |
|---|---|
| H1 | 平行公设 → 无平行线 + 常正曲率 |
| H3 | 最长路径存在性引理由有限性保证 → 无限性不保证 |
| H5 | `p ∤ C(p,k)` → `p | C(p,k)` |
| H8 | Zorn 引理可用 → 不可用 |
| H9 | 递归定义 + 外延相等 → 归纳类型 + identity type |

### 4.3 主要影响 P 层（证明/编程层）

| 组 | P 层变化 |
|---|---|
| H2 | `ℝ → ℝ` + `deriv` → `ℕ → ℝ` + `Nat.rec` |
| H6 | ε-δ 形式化 → 超滤子/超实数构造 |
| H9 | `rfl` / 集合论风格 → `induction` + identity type |
| H10 | 纯存在性证明 → 可提取算法证明 |

## 五、迁移风险等级解释

| 风险等级 | 含义 | 对应组 |
|---|---|---|
| **高** | 默认基础结论不能直接迁移到替代基础；必须显式添加/移除参数 | H3, H4, H5, H7, H8, H10 |
| **中** | 结论可互译，但证明工具与形式化路径差异显著 | H1, H6, H9 |
| **低** | 结论通过极限/收敛关系保持联系，迁移相对安全但需检查精度 | H2 |

## 六、调参旋钮在 SMPDL 审校中的应用

### 6.1 审校检查清单

对于每份 SMPDL 报告，审校者应回答：

1. **调参旋钮是什么？**（如 LEM、AC、char、K、h 等）
2. **当前取值是什么？**（默认值还是替代值？）
3. **该取值是否在 `AxiomaticBase` 中显式声明？**
4. **证明中是否有步骤无意识依赖了默认值？**
5. **若迁移到替代取值，哪些 S/M/P 层会断裂？**

### 6.2 AI 生成证明审校规则

可将上表转化为自动检查规则：

```text
IF 出现“三角形内角和 180°” THEN 检查 AxiomaticBase 是否包含 Euclidean
IF 出现“存在 c 使 f(c)=0” THEN 检查是否需要 ComputableAnalysis
IF 出现“任意向量空间有基” THEN 检查是否依赖 AC/ZFC
IF 出现“(ab)^n = a^n b^n” THEN 检查是否声明 CommutativeRing
IF 出现“δ(G) ≥ 2 ⇒ 存在环” THEN 检查是否声明 FiniteGraph
```

## 七、与人类研究者工作的衔接

### 7.1 教学设计

把每组抽象为“调一个旋钮，看结论怎么变”：

- H1：调曲率 K，看三角形内角和如何变化；
- H4：关掉交换律，看 (ab)ⁿ 展开如何变化；
- H7：关掉 LEM，看存在性证明如何必须给出 witness；
- H10：打开可计算性，看存在性如何升级为算法。

### 7.2 论文审稿

审稿人可使用本矩阵快速判断：

> 作者是否把某个默认参数（如 char=0、有限性、LEM）的结论，无意识推广到了替代参数情形？

### 7.3 形式化工程

在 Lean/Coq 中，可将这些旋钮实现为：

- 类型类参数：`[Fintype V]` / `[Infinite V]`
- 公理开关：`open Classical` / `noncomputable theory`
- 结构参数：`[CommRing R]` / `[Ring R]`
- 特征参数：`[CharZero R]` / `[CharP R p]`
