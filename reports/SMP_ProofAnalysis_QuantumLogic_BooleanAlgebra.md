## 1. 声明与版本

**主声明**（布尔代数 = 经典命题宇宙）：命题等价类集合 `B = Prop/≡` 在运算 `∧, ∨, ¬` 下构成**布尔代数**——满足全部格公理且特别地满足**分配律**：

```text
a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c)
a ∨ (b ∧ c) = (a ∨ b) ∧ (a ∨ c)
```

**完备定理群**（分配律的"伴随结构"）：

1. **De Morgan 律**：`¬(a ∧ b) = ¬a ∨ ¬b`；
2. **排中律（顶底补）**：`a ∨ ¬a = ⊤`，`a ∧ ¬a = ⊥`（命题格语义下 LEM 是补结构的一部分）；
3. **Stone 表示定理**：每个布尔代数同构于集合域——语义可完全"经典集合化"；
4. **分配格 ⇒ 模格**：分配律蕴含模律 `a ≤ c ⇒ a ∨ (b ∧ c) = (a ∨ b) ∧ c`；
5. **真值表语义**：2 元布尔代数 `{0,1}` 上取值完备（Gödel 完备性在此语义下）。

**版本信息**：
- **形式化基础**：Boole (1847, 1854)；Stone (1936)
- **依赖前提**：格公理（ absorption, 幂等, 交换, 结合）+ 补 + 分配
- **AxiomaticBase**：`BooleanAlgebra` + `DistributiveLattice`
- **历史定位**：分配律在经典逻辑中**从未被质疑**——它是"命题即集合"世界观的结构化石。
