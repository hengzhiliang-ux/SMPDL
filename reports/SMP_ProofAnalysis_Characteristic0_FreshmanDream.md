# S/M/P × D/L 审计报告：特征 0 下的二项式展开

> **定理**：设 R 为特征 0 的交换环，p 为素数，则对任意 a,b ∈ R，
> 
> \[(a+b)^p = \sum_{k=0}^{p} \binom{p}{k} a^k b^{p-k}.\]
> 
> 特别地，中间项 \(\binom{p}{k} a^k b^{p-k}\)（\ 0 < k < p \)）一般不为零，因此 **Freshman's Dream** \((a+b)^p = a^p + b^p\) **不成立**。
> 
> **来源**：标准二项式定理；任何抽象代数/交换代数入门教材。
> 
> **分析日期**：2026-10-13 | **审计框架**：Göttingen S/M/P × D/L v1.5 | **AxiomaticBase**：`Characteristic0`
> 
> **风险评级**：⚪ 已确认正确。

---

## 0. 分析目标

1. 对特征 0 下的二项式展开进行 S/M/P × D/L 六格审计。
2. 明确核心依赖：\(\binom{p}{k}\) 在 \(0 < k < p\) 时是不被 \(p\) 整除的正整数。
3. 为与特征 \(p\) 下的 Freshman's Dream 对比建立基准：同一展开骨架，因“特征”假设不同而得到不同结论。
4. 标注 SMPDL 同构标签与风险点。

## 1. S 层审计（语义层）

### 1.1 S*D：语义依存

| 自然语言元素 | 支持的后续元素 | 依赖说明 |
|---|---|---|
| “展开 \((a+b)^p\)” | 得到 \(p+1\) 个有序乘积项 | 代数乘法分配律 |
| “合并同类项” | 得到二项式系数 | 依赖 \(a\) 与 \(b\) 可交换 |
| “\(\binom{p}{k}\) 是整数系数” | 系数在环中有意义 | 特征 0 保证系数不被 \(p\) 消去 |
| “中间项非零” | 结论：展开式含 \(p+1\) 项 | 系数与 \(a^k b^{p-k}\) 非零 |

### 1.2 S*L：语义逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 量词显式化 | ✅ | 对任意特征 0 交换环中的元素 \(a,b\)。 |
| 术语单义性 | ✅ | “二项式系数”“特征 0”“交换环”定义稳定。 |
| 隐含跳跃 | 🟢 低 | 需说明 \(\binom{p}{k}\) 在 \(0<k<p\) 时不被 \(p\) 整除；这是数论事实。 |
| 蕴涵方向 | ✅ | 由分配律 + 组合计数 + 特征 0 非零系数，得到完整展开。 |

**S 层结论**：自然语言证明直接；主要语义风险在于学生可能混淆“特征 0”与“特征 p”下 \(\binom{p}{k}\) 的行为。

## 2. M 层审计（数学层）

### 2.1 M*D：数学依存

```text
BinomialExpansion_Char0
    │
    ├── CommutativeRing R
    │
    ├── char(R) = 0
    │       │
    │       └── 所有正整数系数在 R 中非零
    │
    ├── Binomial Theorem
    │       │
    │       └── (a+b)^p = Σ_{k=0}^p C(p,k) a^k b^{p-k}
    │
    ├── Number Theory Lemma
    │       │
    │       └── 0 < k < p ⟹ p ∤ C(p,k)
    │
    └── Conclusion: (a+b)^p ≠ a^p + b^p in general
```

| 数学对象 | 结构签名 | 在证明中的作用 |
|---|---|---|
| 交换环 R | `CommRing R` | 论域 |
| 特征 0 | `CharZero R` | 保证整数嵌入无挠 |
| 素数 p | 正整数 | 展开次数 |
| 二项式系数 C(p,k) | 正整数 | 合并同类项后的系数 |
| a^k b^(p-k) | R 中元素 | 第 k 项单项式 |
| 分配律与交换律 | 环公理 | 展开与合并合法 |

### 2.2 M*L：数学逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 公理系统一致性 | ✅ | 在交换环 + 特征 0 的公理体系内严格成立。 |

| 量词范围 | ✅ | 对任意 a,b ∈ R 成立。 |

| 等价命题循环 | ✅ | 无。 |

**M 层结论**：证明结构完整。核心依赖为二项式定理与“\(p \nmid \binom{p}{k}\)”这一数论事实；在特征 0 下中间项系数非零。

## 6. 结论

特征 0 下的二项式展开是一个**依赖数论细节的正确证明**：

- **S 层**：自然语言清晰；主要教学风险是与特征 \(p\) 情形的混淆。
- **M 层**：核心结构为“分配律展开 → 组合计数 → 系数非零”；在特征 0 下中间项保留。
- **P 层**：Mathlib 可直接形式化；`add_pow` 与 `Nat.choose` 提供完整支持。
- **跨层映射**：三层对应关系明确，同构强度为 ⭐⭐⭐ 高。
- **与特征 p 对比**：同一展开骨架在特征 \(p\) 下因 \(p \mid \binom{p}{k}\) 导致中间项消失，得到 Freshman's Dream。

该样本建议标记为：`Characteristic0`、`S-ISO / M-ISO / P-ISO`（自洽），并作为与 `CharacteristicP` 版本对比的基准版本。
