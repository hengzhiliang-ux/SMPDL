## 1. 命题与声明

论文研究 Jacobsthal 函数 $g(n)$：与 $n$ 互素的最大连续整数间隙，即

\[ g(n) = \max_{a \in \mathbb{Z}} \min_{\substack{a < m \le a + g(n) \\ \gcd(m,n)=1}} 1 \]

典型声明形如：

- 对每个正整数 $n$，$g(n) \le C \, \omega(n)^2$，其中 $\omega(n)$ 为 $n$ 的不同素因子个数，$C$ 为某显式绝对常数；
- 或更精确地，$g(n) \le 2^{\omega(n)}$、$g(n) \ll \omega(n)^2 \log^2 \omega(n)$ 等显式形式。

该方向的经典结果包括 Kanold 对素数幂次情形的工作、Stevens 的 $g(n) \le 2^{\omega(n)}$ 上界，以及 Iwaniec (1978) 的 $g(n) \ll \omega(n)^2 \log^2 \omega(n)$。所谓“二次上界”若指 $O(\omega(n)^2)$，则它比 Iwaniec 的已知结果更强（少了一个 $\log^2$ 因子）。

## 2. S/M/P × D/L 六格审计

### 2.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |

**发现**：README 仅给出标题与引用，未说明上界是 $O(\omega(n)^2)$ 还是 $O(\omega(n)^2 \log^2 \omega(n))$，也未说明是否对所有 $n$ 或仅对某子族成立。

### 2.2 S*L — 语义逻辑结构

- 命题中的量词需要明确：是对**所有**正整数 $n$，还是对充分大 / 无小素因子的 $n$？
- “二次上界”必须区分自变量：是对 $\omega(n)$ 二次，还是对 $\log n$ 二次？两者数学含义完全不同。
- 风险：可能把“存在某个二次型上界”滑移到“对所有 $n$ 一致成立且常数最优”。

### 2.3 M*D — 数学依存

| 依赖 | 状态 |
|---|---|
| Kanold 素数幂次公式 | ⚠️ 是否被引用并推广 |
| Iwaniec (1978) $O(\omega^2 \log^2 \omega)$ | ⚠️ 若声称 $O(\omega^2)$，需解释如何去掉对数因子 |
| Stevens $g(n) \le 2^{\omega(n)}$ | ⚠️ 是否作为中间步骤 |
| 中国剩余定理 / 覆盖系统 | 🟢 标准工具 |

**关键风险**：若论文声称 $g(n) \le C \omega(n)^2$，则它改进了 Iwaniec 的已知上界。这需要新的解析或组合思想；否则可能是把 $O(\omega^2 \log^2 \omega)$ 误述为二次。

### 2.4 M*L — 数学逻辑结构

- 典型证明结构：
  1. 对 $n = p_1^{a_1} \cdots p_k^{a_k}$，利用 CRT 把问题化为模 $p_i$ 的覆盖；
  2. 用素数分布或覆盖系统给出区间内与所有 $p_i$ 互素的点的最大间隙；
  3. 综合得到 $g(n)$ 的显式上界。
- 陷阱：$g(n)$ 对素数幂 $p^a$ 的精确值已知为 $p^a - p^{a-1} + 1$ 的推广，但对多个素数幂的组合需要小心处理最大间隙。
- 风险：若论文声称对所有 $n$ 一致成立，则需单独处理小 $n$ 与高度合成数。

### 2.5 P*D — 编程/形式化依存

- README 可能指向 [Lean](lean/docs/021.md)，但未说明形式化范围。
- 风险：Lean 可能只形式化了：
  - Jacobsthal 函数的定义与基本性质；
  - 对若干小 $n$ 的数值验证；
  - 某个特定子族（如 squarefree $n$）的上界，而非一般 $n$。
- 特别风险：形式化中是否把 $O(\omega(n)^2)$ 写成缺乏显式常数的渐近符号。

### 2.6 P*L — 编程逻辑结构

- 若形式化完整，需要检查：
  - 是否严格定义了 $g(n)$ 为最大值；
  - 是否显式给出常数 $C$；
  - 是否处理了 $n=1$ 等平凡边界情形。

## 5. 人工可能需要确认/补充证明的地方

1. **显式常数**：要求给出不等式 $g(n) \le C \, \omega(n)^2$ 中的具体 $C$ 值，或说明其为有效可计算常数。
2. **与已知结果的比较**：明确与 Iwaniec (1978)、Kanold、Stevens 的结果的关系，特别是若声称改进 Iwaniec，需给出关键引理。
3. **素数幂与高度合成数行为**：验证 $n = 2 \cdot 3 \cdot 5 \cdots p_k$ 与 $n = p^a$ 时上界是否仍然成立且尖锐。
4. **小 $n$ 验证**：人工计算 $n \le 10^6$ 时 $g(n)$ 与 $\omega(n)^2$ 的比值，检验常数 $C$ 的合理性。
5. **Lean 定理语句核对**：确认 Lean 主定理 literally 给出对所有 $n$ 的一致显式上界，而非仅定义 $g(n)$ 或证明渐近陈述。
6. **证明方法披露**：若使用覆盖系统、CRT、筛法或组合论证，需说明哪一步产生二次因子，哪一步可改进以去掉对数项。
7. **误差项与渐近符号**：若结论为渐近形式，需说明是否对任意 $n$ 有效，还是仅对 $n \to \infty$ 成立。

## 7. 结论与后续建议

族 021 的声明在结构上属于经典解析数论问题，数学对象明确，风险等级为 **🟡 中度**。主要风险不在于方向本身，而在于：

- README 未披露“二次”所指的自变量与常数；
- 若声称 $O(\omega(n)^2)$，则需要解释如何改进 Iwaniec 的已知结果；
- Lean 形式化可能仅覆盖定义与小规模验证，而非完整一致上界。

1. 下载并阅读 `lean/docs/021.md` 与 PDF 正文，确认主定理的显式常数与量词；
