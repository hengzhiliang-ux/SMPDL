# S/M/P × D/L 审计报告：欧氏几何三角形内角和定理

> **定理**：平面三角形三内角之和等于 180°（或 π 弧度）。
> 
> **来源**：Euclid, *Elements*, Book I, Proposition 32。
> 
> **分析日期**：2026-10-13 | **审计框架**：Göttingen S/M/P × D/L v1.5 | **AxiomaticBase**：`Euclidean`
> 
> **风险评级**：⚪ 已确认正确（在欧氏几何公理体系内）。

---

## 0. 分析目标

1. 对欧几里得《几何原本》第一卷命题 32（三角形内角和等于两直角）做一次 S/M/P × D/L 六格审计。
2. 明确证明依赖的核心假设：第五公设（平行公设）。
3. 为后续与球面/双曲/黎曼版本做同构对比建立基准（S/M/P 标签、证明骨架、风险点）。
4. 检查自然语言证明中是否存在未显式化的引理或假设迁移。

## 1. S 层审计（语义层）

### 1.1 S*D：语义依存

| 自然语言元素 | 支持的后续元素 | 依赖说明 |
|---|---|---|
| 三角形 ABC 的定义 | 构造过 A 点平行于 BC 的直线 | 需先承认三角形与直线的存在性 |
| 第五公设（平行公设） | “可作唯一平行线” | 保证构造合法 |
| 平行线性质（内错角相等） | 将 ∠B、∠C 搬到 A 点两侧 | 角度相等的语义来源 |
| 平角 = 180° | 结论 ∠A + ∠B + ∠C = 180° | 角度度量约定 |

### 1.2 S*L：语义逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 量词显式化 | ✅ | “任意三角形”在标准叙述中通常显式或默认；建议形式化时写为 `∀ △ABC ⊂ 欧氏平面`。 |
| 术语单义性 | ⚠️ 中 | “直线”在欧氏几何中默认可无限延长；“平行”默认共面且不交。 |
| 隐喻/图示依赖 | ⚠️ 中 | 证明高度依赖“画一条辅助平行线”的构造性隐喻，需确保其公理化合法性。 |
| 隐含跳跃 | 🟡 中 | 自然语言常省略“内错角相等”本身需要平行公设保证。 |
| 蕴涵方向 | ✅ | 由“三小角拼成平角”推出“内角和为 180°”，方向正确。 |

**S 层结论**：自然语言证明简洁但依赖两个隐性语义约定——（1）平行公设保证辅助线存在且唯一；（2）“内错角相等”不是自明的，而是平行公设的推论。教学中若省略这两点，易造成“显然”幻觉。

## 2. M 层审计（数学层）

### 2.1 M*D：数学依存

```text
TriangleAngleSum = 180°
    │
    ├── 反证或直接构造：任选三角形 ABC
    │
    ├── 第五公设（ParallelPostulate）
    │       │
    │       └── 过 A 存在唯一直线 l ∥ BC
    │
    ├── 平行线性质：内错角相等（AlternateInteriorAngles）
    │       │
    │       ├── ∠B = ∠(AB, l)  （左侧内错角）
    │       └── ∠C = ∠(AC, l)  （右侧内错角）
    │
    ├── 平角定义：StraightAngle = 180°
    │       │
    │       └── ∠(AB, l) + ∠BAC + ∠(AC, l) = 180°
    │
    └── 替换得：∠B + ∠A + ∠C = 180°
```

| 数学对象 | 结构签名 | 在证明中的作用 |
|---|---|---|
| 欧氏平面 | Hilbert/Tarski 平面几何公理模型 | 论域 |
| 三角形 ABC | 三点不共线，三边为线段 | 定理对象 |
| 过 A 平行于 BC 的直线 l | 由 ParallelPostulate 保证 | 关键构造 |
| 角度 ∠A, ∠B, ∠C | 实数（弧度或度） | 待求和量 |
| 内错角相等 | ParallelPostulate 的推论 | 角度搬运工具 |
| 平角 | 角度测度公理 | 求和基准 |

### 2.2 M*L：数学逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 公理系统一致性 | ✅ | 在 Hilbert 或 Tarski 欧氏几何公理体系内可严格证明。 |
| 构造合法性 | ✅ | 第五公设保证过 A 可作唯一平行线。 |
| 量词范围 | ✅ | 对任意非退化三角形均成立。 |
| 边界情况 | ✅ | 退化三角形（三点共线）通常排除在外；若不退化，结论仍形式成立（角度为 0° 或 180° 的极限）。 |
| 隐藏假设 | 🟡 中 | 证明默认“在同一平面内”；在三维空间中需限定三角形所在平面。 |
| 等价命题循环 | ✅ | 无。 |

**M 层结论**：证明在欧氏公理系统内逻辑结构完整。核心依赖为 ParallelPostulate；其等价形式（Playfair 公理、直角公设等）也可替代。

## 3. P 层审计（编程/形式化层）

### 3.1 P*D：形式化依存

> 本证明未见 Mathlib/Lean 4 中直接对应“欧氏平面几何”的完整形式化库可直接调用。GeoCoq（基于 Coq）提供了 Tarski 几何公理的形式化，包含三角形内角和定理的相关证明。以下依存关系以 GeoCoq/Tarski 公理体系为参照。

```text
EuclideanTriangleAngleSum
    │
    ├── Tarski_axioms 或 Hilbert_axioms
    │       │
    │       └── parallel_postulate
    │
    ├── Definition: Triangle A B C (non-collinear)
    │
    ├── Lemma: alternate_interior_angles (requires parallel_postulate)
    │
    ├── Definition: Angle measure / betweenness
    │
    └── Theorem: sum_of_angles_eq_straight
```

### 3.2 P*L：形式化逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 语法可编译 | 🟡 | 若使用 GeoCoq 可实现；Lean 4/Mathlib 目前无原生平面几何公理库。 |
| 类型签名一致 | ✅ | 输入：三角形三点；输出：角度和 = π。 |
| 定义等价 | ✅ | 欧氏角度测度与形式化角度（如 `euclidean_angle`）等价。 |
| 命题等式 | ✅ | `∠A + ∠B + ∠C = π` 可直接作为目标等式。 |
| `#print axioms` | ⚠️ | 需显式检查是否意外引入选择公理（Classical.choice）或实数完备性公理。 |

**P 层结论**：欧氏几何的形式化需要完整的平面几何公理库；本证明的 P 层风险主要来自“辅助构造”在形式语言中的精确表达。

## 4. 跨层映射检查

### 4.1 S ↔ M

| S 层主张 | M 层形式化 | 同构强度 | 说明 |
|---|---|---|---|
| 作过 A 平行于 BC 的直线 | `parallel_postulate` + 构造 `l` | ⭐⭐⭐ 高 | 第五公设直接支持 |
| 内错角相等 | `alternate_interior_angles` 引理 | ⭐⭐⭐ 高 | 平行公设的推论 |
| 三角拼成平角 | 角度测度公理 + 平角定义 | ⭐⭐⭐ 高 | 角度函数可加性 |
| 内角和 = 180° | `angle A + angle B + angle C = π` | ⭐⭐⭐ 高 | 直接对应 |

### 4.2 M ↔ P

| M 层对象/关系 | P 层表达 | 同构强度 | 判据 |
|---|---|---|---|
| 三角形 | `Triangle A B C` / `~ Col A B C` | ⭐⭐⭐ 高 | 非共线性谓词 |
| 平行线 | `Par A B C D` 或 `parallel l1 l2` | ⭐⭐⭐ 高 | 平行谓词 |
| 角度 | `euclidean_angle A B C` | ⭐⭐⭐ 高 | 角度函数 |
| 角度和 | `euclidean_angle A B C + ... = Real.pi` | ⭐⭐⭐ 高 | 实数等式 |

### 4.3 S ↔ P

| 自然语言步骤 | 形式化代码 | 保真度 |
|---|---|---|
| 任取三角形 | `Variable A B C : Point; Hypothesis ~ Col A B C` | ✅ 高 |
| 作平行线 | `pose l := parallel_through A (line B C)` | ✅ 高（需公理库支持） |
| 内错角相等 | `apply alternate_interior_angles` | ✅ 高 |
| 平角求和 | `rewrite <- straight_angle_sum; ring` | ✅ 高 |

**跨层结论**：S/M/P 三层映射高度一致；主要风险在于 P 层需要额外的平面几何公理库支撑。

## 5. 风险点与判定

| 风险点 | 层级 | 风险等级 | 处理状态 |
|---|---|---|---|
| 自然语言省略“内错角相等”依赖平行公设 | S/M | 🟡 中 | 应在教学中显式声明 |
| 证明默认在同一平面内 | M | 🟢 低 | 欧氏平面几何默认论域 |
| 退化三角形未讨论 | M | 🟢 低 | 通常排除或作为边界说明 |
| P 层缺少原生 Lean/Mathlib 形式化 | P | 🟡 中 | 可用 GeoCoq 替代；Mathlib 几何化仍是待建基础设施 |
| 角度测量依赖实数结构 | M/P | 🟢 低 | 标准数学基础 |

**最终判定**：⚪ 已确认正确。该证明在欧氏几何公理体系内逻辑完整、跨层同构强度高，适合作为 SMPDL 样本库中“经典正确证明”的基准条目。

## 6. 结论

欧氏几何三角形内角和定理的证明是一个**结构清晰、依赖单一公理**的经典案例：

- **S 层**：自然语言简洁，但需显式化平行公设和“内错角相等”的依赖关系。
- **M 层**：数学结构完整，核心为 ParallelPostulate → alternate_interior_angles → angle_sum。
- **P 层**：需要完整的平面几何公理库；在 GeoCoq 中已有实现基础，在 Lean/Mathlib 中尚缺原生支持。
- **跨层映射**：三层对应关系明确，同构强度为 ⭐⭐⭐ 高。

该样本建议标记为：`Euclidean`、`S-ISO / M-ISO / P-ISO`（自洽），并作为与 `Spherical`、`Hyperbolic`、`Riemannian` 版本对比的基准版本。
