## 0. 统一定义模板

每个岗位按以下八元组定义，保证同精度、可对照、可考核：

| 字段 | 含义 |
|---|---|
| **定义** | 一句话定义 + 三条限定（划清岗位边界） |
| **输入 / 输出** | 岗位消费什么对象、产出什么对象 |
| **判定标准** | 什么条件下算「该岗位动作已完成」 |
| **亚型分解** | 岗位内部的 2–4 个亚型 |
| **相邻边界** | 与最易混淆岗位的区分判据（速判规则） |
| **案例锚点** | 案例库中的标准例证 |
| **机器化程度** | 机器可替代/辅助的边界 |
| **工作流落点** | 在五步构造协议 / 六格审查中的位置 |

## A. 概念奇点（Conceptual Singularity）

### A.0 定义

> 在证明构造中，从**无目标牵引**的状态下发明出使推理链得以闭合的**关键构造、整体框架或中间概念**的行为。

**三条限定**：

1. **生成性**：产出必须是新的数学对象（构造/框架/概念），不是对已有推理的判定——做判定的是 B/C/D/E。
2. **非机械性**：该产出**不能**从目标命题经机械反推必然命中；若反推唯一确定，则只是普通推理步骤，不构成奇点。
3. **稀疏性**：一个证明通常只含 1–2 个概念奇点，其余步骤为机械推理；若处处「需要发明」，说明问题对当前工具集是开放的（转入 C）。

### A.1 输入 / 输出

| 方向 | 内容 |
|---|---|
| 输入 | OPEN 子目标 + 已证引理库 + 领域工具集 |
| 输出 | 候选构造/框架/概念 + **其良定义性论证** + 与目标依赖图的接合点 |

### A.2 判定标准

- ✅ 构造使依赖图中至少一个 OPEN 子目标变为可闭合；
- ✅ 构造本身**不引用目标命题**（防前视纪律）；
- ✅ 良定义性已独立论证（构造对象存在、唯一或表示无关）。

### A.3 亚型分解

| 亚型 | 名称 | 案例 |
|---|---|---|
| A1 | **构造发明** | 欧几里得 N = p₁…pₙ+1；Cantor 对角数 y；Euler 对 641 = 5·2⁷+1 的分解 |
| A2 | **框架选择** | √2 选反证法；Basel 选 Fourier 级数而非 sin 乘积；Wilson 选双向刻画 |
| A3 | **概念提出** | Kempe 链（证明虽错，概念存活并进入五色定理证明）；「最简分数」「自逆元」「不变量候选」 |

### A.4 相邻边界

- **vs D**：产出「新想法」→ A；产出「已有想法的失效点」→ D。
- **vs C**：奇点**成功**闭合子目标 → A；尝试后判定「当前工具集不存在此类构造」→ 转入 C。

### A.5 案例锚点

欧几里得 N+1（A1 原型）；Basel 的 Fourier 路线选择（A2 原型）；Kempe 链（A3 原型——证明死亡、概念永生）。

### A.6 机器化程度

❌ **最低**。构造空间巨大且无梯度；LLM 可做「类库检索式」构造（从训练分布采样相似构造），但**无目标牵引的原创构造**无系统方法。机器合理角色：构造的**验证者**（良定义性检查）与**检索者**（类库匹配）。

### A.7 工作流落点

五步协议第 ① 步（反向草图的整体形状）与第 ② 步（正向重写中的构造节点）；六格中的 S/M 层上游。

## B. 语义忠实审查（Semantic Faithfulness Audit）

### B.0 定义

> 对**跨层映射**（自然语言 ↔ 形式语言、直觉表述 ↔ 严格表述、口头约定 ↔ 显式前提）的忠实性进行**判定**的行为，回答「翻译前后的数学内容是否同一」。

**三条限定**：

1. **跨层性**：只发生在层与层的界面（S→M、S→P、M→P）；层内失效归 D。
2. **判定性**：不产生新数学内容，只产出「忠实 / 不忠实 + 差异定位」；若审查中发现需要新概念，转交 A。
3. **不可机械化**：消解 NL 歧义位于 SCI = ∞（Bastounis–Circelli–Hansen），任何算法都无法保证完备——这是**计算理论边界**，不是工程限制。

### B.1 输入 / 输出

| 方向 | 内容 |
|---|---|
| 输入 | 源文本 + 目标文本 + **人工注册的映射锚点清单** |
| 输出 | 忠实性判定 + 差异清单（位置 / 类型 / 数学后果分级） |

### B.2 判定标准

- ✅ 差异清单为空；或
- ✅ 每条差异被**证明**为语义等价（可互相推出且强度相同）。
- ❌ 存在未判定差异 → 审查未完成，验证结论不得跨层引用。

### B.3 亚型分解

| 亚型 | 名称 | 案例 |
|---|---|---|
| B1 | **歧义消解** | 「连续函数」的定义域、「几乎处处」的测度、「有界」的界、「充分小」的量化 |
| B2 | **映射核对** | NS 事件 Lemma 8.6：NL m+4 ↔ Lean m+5（锚点比对发现强度漂移） |
| B3 | **隐含假设挖掘** | 等腰谬误的 betweenness；领域惯例（「显然」背后的教科书引理） |

### B.4 相邻边界

- **vs D**：漂移发生在**两个表述之间** → B；失效发生在**单一论证内部** → D。NS m+4→m+5 是 B；等腰 P 点位置是 D（同一份 NL 证明内部的几何断言不成立）。
- **vs E**：B 判定**翻译对不对**；E 判定**验证结果意味着什么**。NS 事件中「NL↔Lean 不对应」是 B，「所以 Lean ✅ 不能为 NL 背书」是 E。

### B.5 案例锚点

Navier–Stokes Lost in Translation（B2 原型，两周人工 vs 88 小时机器）；等腰谬误 betweenness（B3 原型）。

### B.6 机器化程度

❌ **理论禁止**（SCI = ∞）。机器合理角色：锚点间**机械 diff**（人工注册锚点后）、候选差异生成器（ChatGPT 报差异、人工核真伪——NS 事件中多数机器报告为误报）。

### B.7 工作流落点

五步协议第 ③ 步（双向验证）的核心；六格中所有带「跨层」标记的边。

## C. 缺口刻画（Gap Characterization）

### C.0 定义

> 对**未完成的证明或开放问题**，定位推理链的断裂点、判定断裂性质（技术性 vs 本质性）、并刻画「已有工具能到什么」与「目标需要什么」之间的**结构性距离**的行为。

**三条限定**：

1. **面向未完成**：对象是 OPEN 子目标或开放猜想；看似完成的草案的失效分析归 D。
2. **元数学性**：比较的是「路线能力集」与「目标需求集」，不是执行推理——执行归 A 或机器。
3. **导航性**：产出必须能指导下一步探索方向的取舍，纯描述性抱怨（「这很难」）不构成缺口刻画。

### C.1 输入 / 输出

| 方向 | 内容 |
|---|---|
| 输入 | 未闭合依赖图 + 目标命题 + 候选路线库 + 最近邻已证定理地图 |
| 输出 | 缺口位置（定位到子目标）+ 缺口类型（S/M/P × D/L 归类）+ 技术/本质判定 + 结构性理由（「为什么现有工具不够」） |

### C.2 判定标准

- ✅ 缺口定位到**具体子目标**而非泛泛「整条路线不行」；
- ✅ 给出结构性理由（缺失的工具/不变量/桥梁是什么形态）；
- ✅ 技术/本质判定附证据（本质性 = 已知理论障碍，如 ACC 的不变量缺失）。

### C.3 亚型分解

| 亚型 | 名称 | 案例 |
|---|---|---|
| C1 | **断点定位** | RH：「局部/统计 → 全称」的断裂点精确到 Li 系数正性的全称化步骤 |
| C2 | **性质判定** | ACC：「无非平凡 AC 不变量」判定为本质性缺口（非技术不足） |
| C3 | **距离刻画** | 最近邻定理地图：孪生素数 ↔ Zhang 7×10⁷ 有界间隙，距离 = 「有界 → 2」 |

### C.4 相邻边界

- **vs A**：尝试构造后判定「此类构造不存在于当前工具集」→ C；构造成功 → A。
- **vs D**：证明**未完成**，问「缺什么」→ C；草案**看似完成**，问「错在哪」→ D。
- **vs E**：C 刻画「证明与目标的距离」；E 刻画「验证结果与声称的距离」。

### C.5 案例锚点

RH 诊断（C1 原型）；ACC 五路线阻塞分析（C2 原型——五条路线的缺口逐一归类）；ACC 归纳路线潜在循环识别（C 与循环探测的接口）。

### C.6 机器化程度

❌ **低**。机器可维护依赖图与 OPEN 状态（C 的账房），但「为什么不够」的结构性理由需要元数学判断。半自动方向：缺口类型的自动归类（按 S/M/P × D/L 标签）。

### C.7 工作流落点

五步协议第 ① 步的 OPEN 标注与第 ④ 步（循环探测中「潜在循环」的性质判定）；六格审查的 M*L、S*L 格。

## D. 陷阱预见（Trap Foresight）

> **专项文档**：`SMPDL_TrapForesight_Taxonomy.md`（七类分类学 + TRAP-CHECK v1.0 · 21 条）。此处给出与其他岗位同精度的摘要定义。

### D.0 定义

> 对**已成形的证明草案**做**层内、边界、失效导向**的主动审查，识别论证在特殊情形、退化构型、表示选择或操作交互下的失效点。

**三条限定**：

1. 面向**已有论证**（草案已具雏形）——发明归 A；
2. 面向**层内断裂**——跨层漂移归 B；
3. 面向**边界失效**——开放问题的缺失归 C。

### D.1 输入 / 输出

| 方向 | 内容 |
|---|---|
| 输入 | 成形证明草案 + TRAP-CHECK 清单 + 陷阱模式库 |
| 输出 | 失效点清单（位置 / 类型七分类 / 触发情形）+ 修复建议或修复不可能判定 |

### D.2 判定标准

21 条 TRAP-CHECK 全部过检，或每条命中项已修复/已登记反例。

### D.3 亚型（七类）

I 表示 / II 不动点 / III 位置默认 / IV 运算次序 / V 前提域 / VI 量词范围 / VII 操作交互。

### D.4 相邻边界

速判规则：产出「第 k 步在情形 X 下不成立」→ D；产出「两个版本不对应」→ B；产出「这条路线缺什么」→ C。

### D.5 案例锚点

等腰谬误 P 点在外接圆（III 原型）；Kempe 双链交互（VII 原型）；Basel 收敛先于代入（IV 原型）。

### D.6 机器化程度

⚠️ **半自动**：人工建库 + 机器扫库 + 人工处理库外；「错误记忆库」最难机器化。

### D.7 工作流落点

五步协议第 ⑤ 步（边界扫描）；六格审查的 M*L、S*L 格。

## E. 验证解读（Verification Interpretation）

### E.0 定义

> 对**验证工具的输出**（机器证明、Lean 编译、枚举结果、数值证据），判定其**实际证明了的命题**与**证据强度**的行为——回答「这个验证到底为哪个数学断言提供了多强的支持」。

**三条限定**：

1. **面向验证结果**：输入是工具的输出，不是证明文本本身——文本审查归 B/D。
2. **解释性**：产出是形式输出到数学断言的**翻译**与**定级**，不是新的证明。
3. **含社会维度**：部分判定（机器证明可接受性）是共同体规范问题，无纯形式答案。

### E.1 输入 / 输出

| 方向 | 内容 |
|---|---|
| 输入 | 验证工具输出（✅/枚举表/数值结果）+ 验证规格说明（验证了哪个命题、在什么公理/假设下） |
| 输出 | ① 实际被证命题的精确表述 ② 证据强度评级 ③ 与原声称命题的差距清单 ④ 未覆盖部分清单 |

### E.2 判定标准

- ✅ 能精确回答「被验证的命题是什么」；
- ✅ 能量化或定性表述「与原命题的差距」（更弱/更强/不同）；
- ✅ 未覆盖部分（sorry、额外公理、界外情形）全部显式列出。

### E.3 亚型分解

| 亚型 | 名称 | 案例 |
|---|---|---|
| E1 | **规格审查** | NS 事件：Lean ✅ 验证的是「m+5 版本定理」，不是 NL 的「m+4 版本」——绿色对勾挂在了形式对象上 |
| E2 | **目标函数审查** | AI 自动形式化优化「编译通过」而非「语义忠实」——验证系统的激励结构审查 |
| E3 | **可接受性判定** | Appel–Haken：1482 构形机器检查是否算「证明」——共同体的人工判定；Kepler 猜想 Flyspeck 十年形式化 |

### E.4 相邻边界

- **vs B**：B 问「翻译对不对」，E 问「验证结果意味着什么、能撑多远的声称」。NS 事件中两个动作缺一不可。
- **vs C**：E 刻画「验证与声称的距离」；C 刻画「证明与目标的距离」。
- **vs D**：D 找证明内容的失效点；E 找**验证行为本身**的前提缺陷（目标函数错位、规格漂移）。

### E.5 案例锚点

NS 事件「Lean ✅ ≠ NL 正确」（E1+E2 原型）；Appel–Haken 可理解性缺口（E3 原型）；ACC 中 Bridson–Lishak 下界的解读（「搜索失败不构成反例证据」——E 与 D-VI 的接口）。

### E.6 机器化程度

⚠️ **半自动**：规格提取（Lean 声明的机械读取）可自动；「差距的数学意义」与「可接受性」必须人工。AI 时代此岗位工作量**不降反升**（722 篇手稿无人能全审）。

### E.7 工作流落点

六格审查的 P 层下游（P*D、P*L 格的结果解读）；五步协议之后的「发布闸门」位置。

## 6. 岗位区分决策树

遇到一个审查/构造动作，按序判定归属：

```
Q1. 动作产出了新的数学对象/框架/概念？
    YES → A（概念奇点）
    NO  ↓
Q2. 动作在比较两个不同层/不同语言的表述是否同一？
    YES → B（语义忠实审查）
    NO  ↓
Q3. 动作对象是未完成的证明/开放问题，问的是「缺什么」？
    YES → C（缺口刻画）
    NO  ↓
Q4. 动作对象是已成形草案，问的是「哪里会错」？
    YES → D（陷阱预见）
    NO  ↓
Q5. 动作对象是验证工具的输出，问的是「它到底证明了什么」？
    YES → E（验证解读）
    NO  → 普通机械推理（机器层，非人工岗位）
```

## 7. 两两边界矩阵

|  | A | B | C | D | E |
|---|---|---|---|---|---|
| **A** | — | A 造内容，B 判翻译 | A 成功闭合，C 判定不可闭合 | A 发明，D 防守 | A 产出证明，E 解读其验证 |
| **B** | | — | B 管两表述之间，C 管证明与目标之间 | B 管层间，D 管层内 | B 判翻译对错，E 判验证意义 |
| **C** | | | — | C 面向未完成，D 面向已成形 | C 量证明↔目标距离，E 量验证↔声称距离 |
| **D** | | | | — | D 找内容失效点，E 找验证行为前提缺陷 |
| **E** | | | | | — |

## 8. 交叉与流转规则

| 触发情形 | 流转 | 案例 |
|---|---|---|
| B 判定翻译不可能忠实，需要重新构造 | B → A | NS 事件后续：若需重写 Lean 证明以对应 NL，新构造归 A |
| A 反复失败，判定工具集不足 | A → C | ACC 不变量候选全部失败后 → C2「本质性缺口」判定 |
| C 的缺口被新构造填上 | C → A | 若有人发明非平凡 AC 不变量，缺口转回构造流程 |
| D 发现失效无法修复，且是路线级缺陷 | D → C | Kempe：交互陷阱不可修复 → 判定路线缺口（四色定理需新路线） |
| E 发现验证规格漂移 | E → B | 发现「验证的不是原命题」→ 转 B 做逐点映射核对 |
| 边界扫描（D-VI）发现搜索下界问题 | D ↔ E | Bridson–Lishak：既是量词陷阱（D-VI）也是证据解读（E） |

**总原则**：岗位是**动作的类型**，不是人的固定分工；同一个人在一次审查中可在五岗位间多次流转，但每次动作必须归属且仅归属一个岗位——这是防前视纪律在元层面的对应：**审查动作本身也必须可审计**。

## 9. 五岗位总表

| 岗位 | 一句话定义 | 输入 | 输出 | 机器化 | 落点 |
|---|---|---|---|---|---|
| **A 概念奇点** | 无目标牵引下发明闭合推理链的关键构造/框架/概念 | OPEN 子目标 + 引理库 | 候选构造 + 良定义论证 | ❌ 最低 | 协议 ①② 步 |
