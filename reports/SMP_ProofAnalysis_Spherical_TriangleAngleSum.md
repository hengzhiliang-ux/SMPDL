# S/M/P × D/L 审计报告：球面几何三角形内角和定理

> **定理**：半径为 R 的球面上，球面三角形三内角之和满足 α + β + γ = π + Area/R²，即内角和大于 π，超出部分（球面角盈）与面积成正比。
> 
> **来源**：Girard, *Problema de quadratura trianguli spherici* (1625–1626)；标准叙述见 Todhunter, *Spherical Trigonometry*。
> 
> **分析日期**：2026-10-13 | **审计框架**：Göttingen S/M/P × D/L v1.5 | **AxiomaticBase**：`Spherical`
> 
> **风险评级**：⚪ 已确认正确（在球面几何公理体系内）。

---

## 0. 分析目标

1. 对球面三角形内角和定理（Girard 定理）做一次 S/M/P × D/L 六格审计。
2. 明确证明依赖的核心假设：球面为正定常曲率曲面、不存在平行线、大圆为测地线。
3. 与欧氏版本建立同构对比：识别证明骨架的相似之处与基础假设差异。
4. 标注 SMPDL 同构标签（`S-ISO / M-ISO / P-BISIM` 等）。

## 1. S 层审计（语义层）

### 1.1 S*D：语义依存

| 自然语言元素 | 支持的后续元素 | 依赖说明 |
|---|---|---|
| 球面/球面三角形定义 | 大圆作为“边” | 球面几何的基本对象 |
| 大圆是测地线 | 边可无限延长为完整大圆 | 用于构造“月形” |
| 月形面积公式 | 面积与顶角成正比 | 推导角盈关系 |
| 球面对称性/覆盖关系 | 三个顶角与三角形面积的关系 | 关键组合论证 |
| 平面角与球面角的区别 | “角”指大圆平面二面角 | 语义迁移点 |

### 1.2 S*L：语义逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 量词显式化 | ✅ | 定理对任意球面三角形成立；R 为球半径。 |
| 术语单义性 | 🟡 中 | “三角形”在球面几何中默认由三个大圆劣弧围成；“角”指大圆平面夹角，与平面角量纲相同但几何意义不同。 |
| 隐喻/图示依赖 | ⚠️ 中 | 证明依赖将球面分割为 8 个球面三角形的图示；自然语言中“覆盖”关系易表述不清。 |
| 隐含跳跃 | 🟡 中 | 从“三个月形覆盖球面”到“角盈 = 面积”需要精确的组合计数。 |
| 蕴涵方向 | ✅ | 由月形面积公式与覆盖关系推出角盈公式，方向正确。 |

**S 层结论**：球面证明的语义风险高于欧氏版本，主要集中在“球面角”与“平面角”的同名异义、以及月形覆盖的组合论证。

## 2. M 层审计（数学层）

### 2.1 M*D：数学依存

```text
SphericalTriangleAngleSum > π
    │
    ├── 球面 S²(R) 与测地线（大圆）定义
    │
    ├── 球面三角形 ABC：三边为大圆劣弧
    │
    ├── Girard 定理证明路径
    │       │
    │       ├── 三边延长为完整大圆 → 球面被分成 8 个球面三角形
    │       │
    │       ├── 月形 L_A, L_B, L_C 的面积
    │       │       │
    │       │       └── Area(L_A) = 2α R²,  etc.
    │       │
    │       ├── 覆盖关系：三个月形覆盖整个球面 + 原三角形 + 对径三角形
    │       │       │
    │       │       └── 2αR² + 2βR² + 2γR² = 4πR² + 2·Area(△ABC)
    │       │
    │       └── α + β + γ = π + Area/R²
    │
    └── 等价形式：球面角盈 E = α + β + γ - π = Area/R²
```

| 数学对象 | 结构签名 | 在证明中的作用 |
|---|---|---|
| 球面 S²(R) | 常曲率 K = 1/R² 的二维黎曼流形 | 论域 |
| 球面三角形 | 三个大圆劣弧围成的区域 | 定理对象 |
| 大圆 | 过球心的平面与球面的交线 = 测地线 | 球面几何中的“直线” |
| 月形（lune） | 两个大圆围成的区域，顶角 α | 面积工具 |
| 球面角 α, β, γ | 大圆平面二面角 | 待求和量 |
| 球面面积 | 曲面积分 / 球面几何公式 | 角盈基准 |

### 2.2 M*L：数学逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 公理系统一致性 | ✅ | 在球面几何公理（或与黎曼几何公理相容）体系内可严格证明。 |
| 构造合法性 | ✅ | 大圆存在且唯一；延长边得到完整大圆合法。 |
| 量词范围 | ✅ | 对任意非退化球面三角形成立；退化情形（三点共大圆）给出 α + β + γ = π。 |
| 边界情况 | ✅ | 当 Area → 0 时，退化为欧氏情形：α + β + γ → π。 |
| 隐藏假设 | 🟡 中 | 证明默认凸球面三角形（边为劣弧）；若允许优弧三角形，需调整面积/角的取值。 |
| 等价命题循环 | ✅ | 无。 |

**M 层结论**：证明结构完整。核心依赖为“球面常正曲率 + 大圆即测地线 + 月形面积公式”。当 R → ∞ 时，公式平滑退化为欧氏结论，体现基础假设的极限迁移。

## 3. P 层审计（编程/形式化层）

### 3.1 P*D：形式化依存

> 与欧氏情形类似，Mathlib/Lean 4 目前缺乏原生球面几何形式化库。HOL Light、Coq/GeoCoq 或 Mizar 中有相关基础。以下依存关系以 GeoCoq/球面几何公理为参照。

```text
SphericalTriangleAngleSum
    │
    ├── Sphere_S2R_axioms
    │       │
    │       └── great_circle_is_geodesic
    │
    ├── Definition: SphericalTriangle A B C (convex)
    │
    ├── Lemma: lune_area (angle α, radius R) = 2α R²
    │
    ├── Lemma: sphere_partition_by_great_circles
    │
    └── Theorem: girard_theorem
            │
            └── α + β + γ = π + Area/R²
```

### 3.2 P*L：形式化逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 语法可编译 | 🟡 | GeoCoq/HOL Light 可实现；Lean 4/Mathlib 需额外建立球面几何库。 |
| 类型签名一致 | ✅ | 输入：球面三点 + 凸性条件；输出：角度和与面积的等式。 |
| 定义等价 | ✅ | 球面角与二面角、面积与曲面积分等价。 |
| 命题等式 | ✅ | `α + β + γ - π = Area / R²` 可直接作为目标。 |
| `#print axioms` | ⚠️ | 需检查是否意外依赖选择公理；实数与积分公理不可避免。 |

**P 层结论**：球面几何的形式化相对成熟但分散在不同证明助手中；与欧氏版本相比，P 层需要额外引入黎曼/曲面积分结构。

## 7. 结论

球面三角形内角和定理是**基础假设改变导致结论定量变化**的典范：

- **S 层**：术语“角”“直线”“三角形”与欧氏版本同名但语义不同，是主要教学风险点。
- **M 层**：核心结构为“月形面积分解 + 球面覆盖计数”，替代了欧氏的“平行线 + 内错角”结构。
- **P 层**：需要黎曼/球面几何形式化库；在 GeoCoq/HOL Light 中已有实现基础。
- **跨层映射**：三层对应关系明确，同构强度为 ⭐⭐⭐ 高。
- **与欧氏对比**：证明骨架可类比为“角度分解与求和”，但实现工具因曲率/平行公设差异而不同，建议标注 `S-ISO / M-ISO / P-BISIM`。

该样本建议标记为：`Spherical`、`S-ISO / M-ISO / P-BISIM`，并作为与 `Euclidean`、`Hyperbolic`、`Riemannian` 版本对比的核心条目。
