## 一、S 语义结构（FS Paper2 谱系）

### 1.1 今日核心：语义层 = 独立承重面（S-dose 实证）

FS Paper2 的语义结构原本管「同名异义检测 + 涌现物命名核查」。今天给它添了一块地基：**F3 剂量层别律 ✅（6/6）**——外延类公理移除时定理群近似无损（Friedman 1973）而唯一性陈述全体弱化。语义不再只是「审计时要查的层」，而是**会被单独打伤的层**：

- 损伤侧新词：S-dose（E1 同构拷贝不可区分 / E3 等词证明唯一性死 / E6 lub-glb 唯一性弱化为「至多一个」）；
- 吸收侧新词：S 层算子 = 翻译/重解释（Glivenko 负片段嵌入是范例）；
- **S 层的三重身份闭合**：审计层（Paper2 的职责）→ 损伤层（F3）→ 吸收层（G-0 算子轴）——同一「S」在三本账上语义一致，框架内部自洽。

### 1.2 今日的语义结构事件：术语即对象（拟度量二义）

T3-B 勘误是 FS Paper2 §「同名异义」的**活标本**：「拟度量」一词两个所指——

| 所指 | 移除事件 | 对象名 |
|---|---|---|
| quasimetric（标准义） | −对称律 | H43 的实验 |
| semimetric | −三角不等式 | K2 的实验 |

两个不同实验共用一个中文名，导致检索词错位 → Park 论文「标题看似完美匹配」→ 判定方向错误 → 咖啡质询 → 撤回重测（JMS 1995 反例）→ 结论反转。**这重复了 Paper2 的核心论题**（语言形式不变 + 语义所指变 = 迁移错误的载体），只是这次载体不是数学史而是本项目自己的判定管线。教训已固化：判据 v2 §0 加「样本身份消歧前置关卡」。

### 1.3 「可指名性」的语义学降格

F4 循环评估的最大理论动作：**「恢复算子可指名」从判定材料降级为被解释的社会学结果**——判定改用语义中立判据（伴随函子定理条件、F²≅F 可证性、中间理论存在性）。这是 Paper2「涌现物命名核查」的反向应用：名字不再是证据，成为待解释项（命名速度是否跟得上组件出现速度 = F4b 的合法经验形态）。

## 二、M 数学结构（FS Paper3 谱系）

### 2.1 承重的可测量化：F1 隐形承重律 ✅

Paper3 的律学三维坐标（强度/档位/功能）描述律的身份；今天补上**律的重量**：

- 独占口径均值比 3.3×（剔真盲区）/ 2.48×（全样本）——交换律教科书承重 ≫ 逆元律，「低调公理重仓持有」；
- 联合承重分账（Galois/扩张理论 = 交换+逆元各自单独致死）——承重图 L(A) 从隐喻变成有借代规则的账本；
- **诚实边界**：ToC 计数 = 逻辑承重 × 建制化程度双信号（F1 的社会学混入已在判据 v2 登记）。

### 2.2 脆性的语形定位：F2 与 ∃/∀ 不对称

构造组（∃-公理）15/15 零脆性 vs 约束组脆性集中于**不等式 ∪ 归纳 ∪ 遗传**三类 ∀-约束——Paper3 的功能类型学（T1/T2/T3）今天获得了**语形层的基础候选**：∃ 构造移除 → 恢复算子可造（definitional extension 家族）；∀ 约束（作用于无穷对象类）移除 → 守恒成本过高 → 定理群坍塌。Fisher p=0.0131 的方向性由咖啡 A 裁定收档（二分方向性基轴）。

### 2.3 恢复算子的代数解剖（内窥七文法）

M 层今日最大增量：恢复算子不再是原子「可指名物」，而是可分解的代数对象——

- **五元签名** sig(R) = ⟨layer, ℓ(R), idem, adj, frag⟩；
- 七文法中三个有 M 层地基：G-Ⅰ 单子解剖（幂等性 = 精确 vs 逼近吸收的连续标尺）、G-Ⅱ 伴随分解（恢复算子 ⊣ 遗忘函子；伴随存在性定理条件 = 机械判据）、G-Ⅲ 因子链（ℓ(R) ≈ III 型剥落层数假设）；
- **剂量单位修正**：定理 schema ≠ 定理实例（K2 教训）——有界 semimetric 片段的 BCP 存活说明死亡要对模式计，不对实例计。

### 2.4 M 层基率结构（统计再审查的发现）

损伤主层边际分布 M ≫ S ≈ P（κ 悖论的根源）——候选结构事实：**公理的最大暴露面是定理生成**。可预注册为「M 基率 ≥ 50%」分布预测。

## 三、P 编程结构（FS 系谱系下的 P 层）

### 3.1 判据的可执行性分级

今天事实上建立了一条「判据机械化梯度」：

| 级 | 判据 | 今日用例 |
|---|---|---|
| 已机械 | git 时间戳首现扫描 | F2 条款（B4-2 抓回填的取证核心） |
| 半机械 | 伴随存在性条件 / F²≅F 可证性 / 定理模式存活计数 | 内窥签名的检验方案 |
| 待机械（G6） | Lean/Isabelle 机器验证 | T4：A1 群单侧 ⇒ 双侧在 mathlib 已有推导路径（近零成本试点） |
| 永久人工 | γ 细分 / 概念奇点 | B4 判据三分（Q3 人工必填）的延续 |

**P 层算子**（可推导性吸收）获得独立身份：A1（单侧推双侧）、C9（切消去 = 可推导性恢复 + 正规化算法）——P 层吸收的判定材料是「这在原系统内就能推出来」，天然最接近机器可检。

### 3.2 体系的自动纠错循环（P 层自反成就）

T3-B 全程四小时：冻结预测（git 存证）→ 检索命中（Park）→ 判定证伪 → 用户质询 → 对象错位确认 → 撤回 → 标准定义重测（JMS 反例 3/3）→ 连锁勘误四文档 → 结论反转。**这条管线本身是 P 结构的产物**——没有 git 时间戳、没有预注册冻结、没有勘误条款，这个错误会永久潜伏。「重测 ≡ E 档 `#print axioms`」的自反同构今天有了实证案例。

## 四、D 依存维（框架的 D）

### 4.1 承重账本的操作化

D 维今日从「审计报告里的依赖描述」升格为**分账规则明确的账本**：

- 独占承重 / 联合承重双口径（F1 判定 P2 裁定独占口径忠于冻结文本）；
- keystone 存活为主判据（预注册 §四）；
- 存活函数 σ 与剂量分层（S/M/P-dose 带层标签）；
- 盲区分级：真盲区（学科不在教材 = 测在场性）vs 粒度盲区（低于 ToC 分辨率）——**测量仪器的分辨率成为 D 维的一等公民**。

### 4.2 跨层依赖的显式化：coercion 即 D 的层间边

层×层交叉表（T2：对角 91.7% vs 机遇 54.9%）的完整解读需要**层间边**：frag（D6 一阶片段、K2 有界片段）/ reif（E1 超穷精细化实体化语义）——每条边有名字、有代价（片段收窄 / 超穷迭代）。weak 槽位空缺开放（Park 撤回后无实例）。D 维的完整图景 = 层内承重（对角）+ 层间转换（coercion 边）+ 转换代价账单。
