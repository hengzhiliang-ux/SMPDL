## 1. 命题与声明

**无理性指数**：实数 α 的无理性指数 μ(α) 定义为最小的实数 μ，使得对所有充分大的 q，

\[
\left|\alpha - \frac{p}{q}\right| \ge q^{-\mu - \varepsilon}
\]

对任意 ε > 0 成立。

论文声称 **μ(π) = 2**。作为推论，Flint–Hills 级数

\[
\sum_{n \ge 1} \frac{1}{n^3 \sin^2 n}
\]

收敛。

### 2.2 S*L — 语义逻辑结构

- "for every ε > 0 and all sufficiently large denominators q" — 全称量词。
- 风险：可能把「对某个 ε 的下界」或「对特殊 q 序列的下界」误作 μ=2。

### 2.3 M*D — 数学依存

| 依赖 | 状态 |
|---|---|
| 圆周率的有理逼近理论 | ⚠️ 未说明 |

| Beukers 型积分 | ⚠️ 未说明 |
| Salikhov 上界改进 | 🟡 已知 |

**关键风险**：证明 μ(π)=2 通常需要构造一列整数线性形式 aₙπ − bₙ → 0，并证明其误差衰减足够快以排除所有高分母逼近。π 的特殊性使得此类构造极为困难。

### 2.4 M*L — 数学逻辑结构

- 反证法：假设存在无限多有理逼近 |π − p/q| < q^{-2-ε}，导出矛盾。
- 风险：构造的矛盾可能只排除某些特殊逼近序列，未排除所有可能。

### 2.5 P*D — 编程/形式化依存

- README 提到 [Lean](lean/docs/017.md)。
- 风险：形式化可能只覆盖了级数收敛性与 μ=2 的蕴含关系，未证明 μ=2 本身。

### 2.6 P*L — 编程逻辑结构

- 若使用数值验证，需确认是否从有限数据外推到全称结论。

## 5. 人工可能需要确认/补充证明的地方

1. **逼近序列显式化**：给出具体的 aₙ, bₙ 或积分表示。
2. **误差估计**：证明 |aₙπ − bₙ| 的衰减速率足以推出 μ(π) ≤ 2+ε。
3. **与 Salikhov 上界的对比**：明确本证明如何突破 μ(π) ≤ 7.6063 到 μ(π)=2。
4. **Flint–Hills 推导**：确认 μ(π)=2 确实蕴含该级数收敛，且未反向使用。
5. **Lean 范围**：确认形式化覆盖的是核心命题还是仅推论。
