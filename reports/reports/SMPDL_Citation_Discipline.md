# SMPDL 文献引用纪律（Citation Discipline）

> 规则：第一，必须进行真实性核查；第二，必须对论据是否被引用文献支持进行核查。  
> 版本：v1.0  
> 日期：2026-10-13  
> 适用范围：Göttingen 数学史索引检索、SMPDL 证明审计、AI 生成证明审查、所有线上线下学术输出。

---

## 一、两条硬纪律

### 纪律 1：真实性核查（Authenticity Check）

任何被引用的文献、定理、人物言论、历史事件或外部数据，必须先通过以下至少一种方式确认其真实存在：

| 核查方式 | 适用对象 | 最低要求 |
|---|---|---|
| **原始出版物核对** | 论文、书籍、预印本 | 核对标题、作者、期刊/出版社、年份、卷期页、DOI/arXiv 号 |
| **权威二次来源交叉验证** | 定理命名、历史事件 | 至少两个独立权威来源（如 MathWorld、PlanetMath、MacTutor、学术综述）一致 |
| **官方仓库/记录核对** | AI 生成论文、代码、数据集 | 核对仓库地址、commit hash、发布日期、作者声明 |
| **直接引用原文** | 人物言论、轶事 | 给出可追溯到原始文献的页码或段落，禁止转述自未标注的通俗读物 |

**禁止行为**：
- 引用“听说”“据传”“某数学家说过”而无具体出处。
- 将小说、科普文章、博客、社交媒体帖子作为事实来源而不加说明。
- 使用 AI 生成的“ plausible-sounding but fake ”文献（如伪造的 DOI、不存在的作者）。

### 纪律 2：支持性核查（Support Check）

引用文献后，必须进一步验证：**被引文献是否真的支持当前论据**。

| 核查项 | 问题 |
|---|---|
| **范围匹配** | 引文结论的适用范围是否覆盖当前命题？ |
| **方向匹配** | 引文是支持、反对还是中立？是否存在断章取义？ |
| **强度匹配** | 引文给出的是精确定理、近似界、启发性观察还是猜想？ |
| **前提匹配** | 当前论证的前提是否满足引文定理的假设？ |
| **版本匹配** | 引文是否已被后续工作修正、撤回或加强？ |

**禁止行为**：
- 引文只出现在附近主题，但未直接证明当前论断。
- 把引文中的“猜想”“open problem”“under certain assumptions”偷换为“已证定理”。
- 忽视引文的反向结果或前提限制。

## 二、在 S/M/P × D/L 框架中的位置

文献引用纪律横跨三层：

| 层 | 对应核查 | 典型失败 |
|---|---|---|
| **S（语义层）** | 引文描述是否准确？是否存在夸大或弱化？ | 把“部分结果”说成“完整证明” |
| **M（数学层）** | 引文定理的假设、结论、适用范围是否被正确转述？ | 忽略定义域限制，把函数域结果套用到数域 |
| **P（编程层）** | 形式化证明中引用的库/定理是否真实存在且版本匹配？ | 引用未形式化或已弃用的库定理 |
| **D（内生依存）** | 当前步骤依赖的文献是否真实存在且可被获取？ | 引用不存在或不可获取的文献 |
| **L（内在逻辑结构）** | 文献结论到当前结论的推理是否合法？ | 用等价命题循环证明，或从弱结论推出强结论 |

## 三、操作流程

### 3.1 引用前

1. **记录完整元数据**：作者、标题、期刊/出版社、年份、DOI/arXiv/URL、页码。
2. **获取原文**：优先获取 PDF 或官方网页，避免仅依赖摘要或二手介绍。
3. **标注引用意图**：在草稿中写明“本处引用 X 是为了支持 Y”。

### 3.2 引用时

1. **直接引用或准确转述**：若转述，必须不扭曲原意。
2. **明确标注限制**：若引文仅在特殊条件下成立，须在正文中说明。
3. **区分事实与解释**：史实、定理、计算结果是事实；动机、影响、评价是解释。

### 3.3 引用后

1. **反向检查**：假设读者只读引文，能否得到与正文相同的结论？
2. **更新检查**：确认引文未被撤回、修正或替代。
3. **可追溯性检查**：从正文到引文到原文，链路是否完整？

## 四、针对 AI 生成证明的额外要求

AI 生成文本特别容易伪造引用或误述引文。审查时必须：

- **🔴  hallucinated citation**：要求 AI 提供可核实的 DOI/arXiv/URL；若无法提供，按“未引用”处理。
- **🔴  misrepresented support**：即使 DOI 存在，也要抽查原文，确认 AI 对引文的概括准确。
- **🔴  outdated dependency**：AI 可能引用已被撤回或替代的结果；必须检查文献的当前状态。
- **🟡  vague appeal to authority**：如“著名数学家普遍认为”“文献中已有大量研究”等表述，必须替换为具体引用。

## 五、检查清单

```markdown
- [ ] 每条引用都有完整元数据（作者/标题/年份/出处/标识符）。
- [ ] 每条引用都能追溯到可获取的原文或官方记录。
- [ ] 引文结论的方向、范围、强度与当前论断匹配。
- [ ] 引文的前提假设被当前论证满足，或已显式说明不满足之处。
- [ ] 引文未被后续工作撤回、修正或替代。
- [ ] AI 生成文本中的引用已逐条人工抽查。
- [ ] 所有“众所周知”“普遍认为”已替换为具体引用或删除。
```

## 六、与 Göttingen 数学史检索的结合

在数学史“同思路检索”中，引用纪律意味着：

1. **A 级同构（同思路同构）**：不仅要求结构可逐点对应，还要求对应的历史文献真实存在，且其结论确实支持该对应。
2. **B 级部分同构**：必须明确标出哪些部分有文献支持，哪些部分是推测。
3. **C 级启发类比**：可引用文献作为“思想共鸣”，但不得作为论证依据。
