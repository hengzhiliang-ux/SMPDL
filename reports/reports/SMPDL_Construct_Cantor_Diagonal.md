# 防前视构建报告：Cantor 对角线论证

> 使用流程：`SMPDL_ProofConstruction_AntiForesight.md` v1.0  
> 案例：证明 [0,1] 区间实数不可数  
> 日期：2026-10-12

---

## 0. 显式化

### 0.1 目标命题 P

**自然语言**：[0,1] 区间内的实数不能排成一个可数序列。  
**形式化**：

```
¬∃ f : ℕ → [0,1], f 是满射
```

**结论类型**：全称否定性命题（不存在枚举）。

### 0.2 前提 A

- 实数 [0,1] 的十进制（或任意进制 b ≥ 2）展开；
- 可数集定义：集合 S 可数当且仅当存在满射 f : ℕ → S；
- 实数平方/有序域基本性质；
- 数字 0–9 的逐位比较可判定两个展开是否相同（在唯一表示下）。

### 0.3 可用工具

- 反证法；
- 逐位构造；
- 进制展开。

### 0.4 禁用（含等价形式）

- 禁止直接使用「[0,1] 不可数」或其等价表述；
- 禁止在构造 y 之前假设「列表一定有遗漏」；
- 禁止允许 0.999... 与 1.000... 的双重表示干扰逐位比较。

## 1. 反向草图（全部标记 OPEN）

```
P: [0,1] 不可数
  G₁: 反证，假设存在满射 f : ℕ → [0,1]
    G₂: 写出每个 f(n) 的十进制展开 x_n = 0.d_{n,1} d_{n,2} ...
      G₃: 构造对角数字 e_n，使 e_n ≠ d_{n,n}
        G₄: 证明 y = 0.e_1 e_2 ... 是合法 [0,1] 实数
          G₅: 证明 ∀n, y ≠ x_n
            G₆: 推出 y 不在枚举中，与满射矛盾
```

**前视风险点**：

- G₃ 不能只因为「想要 y 不在列表中」而选择 e_n；必须显式定义 e_n 作为 d_{n,n} 的函数。
- G₅ 不能先知道 y 不在列表中再比较；比较必须基于逐位差异的独立证明。

## 2. 正向重写

### 步骤 1：引入反证假设（闭合 G₁）

**主张**：假设存在满射 f : ℕ → [0,1]。  
**理由**：反证法允许假设 ¬P。  
**前驱**：反证法规则。  
**状态**：✅ 闭合。

### 步骤 2：写出每个 f(n) 的十进制展开（闭合 G₂）

**主张**：对每个 n，选择 x_n = 0.d_{n,1} d_{n,2} ... 为 f(n) 的一个十进制表示。  
**理由**：实数的小数展开存在（标准分析）。  
**前驱**：步骤 1、实数展开定理。  
**状态**：✅ 闭合。

### 步骤 3：构造对角数字 e_n（闭合 G₃）

**主张**：定义

```
e_n = 1  若 d_{n,n} ≠ 1
e_n = 2  若 d_{n,n} = 1
```

**理由**：这是一个完全定义的函数 φ : {0,...,9} → {1,2}，且对任意输入都有 φ(d) ≠ d。  
**前驱**：步骤 2。  
**状态**：✅ 闭合。

### 步骤 4：y 是合法 [0,1] 实数（闭合 G₄）

**主张**：y = 0.e_1 e_2 ... ∈ [0,1]。  
**理由**：

- 每个 e_n ∈ {1,2}，因此 y 是一个合法的十进制小数；
- 0 ≤ y ≤ 0.222... = 2/9 < 1；
- 由于不含 0 或 9，y 的十进制表示唯一。

**前驱**：步骤 3、实数级数收敛性。  
**状态**：✅ 闭合。

### 步骤 5：y 与每个 x_n 在第 n 位不同（闭合 G₅）

**主张**：∀n ∈ ℕ, y 与 x_n 在第 n 位小数不同，因此 y ≠ x_n。  
**理由**：

- 由定义，y 的第 n 位是 e_n，x_n 的第 n 位是 d_{n,n}；
- 由 φ 的定义，e_n ≠ d_{n,n}；
- y 的表示唯一，故 y ≠ x_n。

**前驱**：步骤 2、步骤 3、步骤 4。  
**状态**：✅ 闭合。

### 步骤 6：推出矛盾（闭合 G₆ 与 P）

**主张**：y ∈ [0,1] 但 y 不在 f 的值域中，与 f 满射矛盾。  
**理由**：步骤 5 证明 y ≠ f(n) 对所有 n 成立；步骤 4 证明 y ∈ [0,1]。  
**前驱**：步骤 1、步骤 4、步骤 5。  
**状态**：✅ 闭合。

### 3.1 M 层详细检查

**依赖图**：

```
反证假设 H: ∃ f 满射
    ↓
每个 f(n) 的十进制展开
    ↓
定义 e_n = φ(d_{n,n})
    ↓
y = 0.e_1 e_2 ... 合法且在 [0,1]
    ↓
∀n, y 与 x_n 在第 n 位不同
    ↓
y 不在 f 值域中
    ↓
与 H 矛盾 → [0,1] 不可数
```

- **无循环**：没有从 P 或矛盾节点指向中间节点的边。
- **隐藏假设**：实数十进制展开存在且可逐位比较；已通过选择 {1,2} 避免双重表示问题。

### 3.2 P 层详细检查（Lean 骨架）

```lean
theorem cantor_uncountable_anti_foresight : ¬ Countable (Set.Icc 0 1) := by
  rintro ⟨f, hf⟩
  -- 对每个 n，取 f n 的一个十进制数字序列
  choose d hd using fun n => exists_digit_seq (f n)
  -- 构造对角数字
  let e : ℕ → ℕ := fun n => if d n n = 1 then 2 else 1
  -- 由 e 构造 y
  let y : ℝ := ∑' n, e n * (10 : ℝ) ^ (-(n + 1 : ℤ))
  have hy : y ∈ Set.Icc 0 1 := sorry
  -- 证明 y 与每个 f n 在第 n 位不同
  have h_ne : ∀ n, y ≠ f n := by
    intro n
    have h_diff : digit_at y n ≠ digit_at (f n) n := by
      -- digit_at y n = e n = φ(d n n)
      -- digit_at (f n) n = d n n
      sorry
    intro h_eq
    rw [h_eq] at h_diff
    contradiction
  -- 与满射矛盾
  have h_surj : ∃ n, f n = y := hf hy
  rcases h_surj with ⟨n, hn⟩
  exact h_ne n (by rw [hn])
```

所有 `sorry` 在标准库中可填充，无等价循环。
