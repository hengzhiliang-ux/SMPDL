## 1. 命题与声明

原论文声明：不存在算法能够判定任意给定整数系数多元多项式是否存在有理零点；即 Hilbert 第十问题在有理数域 `ℚ` 上是否定的。

该问题在整数域 `ℤ` 上的否定答案由 Matiyasevich、Robinson、Davis、Putnam（MRDP 定理，1970）完成，但在有理数域上的对应问题一直是开放问题。

**发现**：README 极简，未说明证明如何绕过已知障碍。从整数 H10 到有理数 H10 的核心障碍在于：并非所有丢番图集都能用 `ℚ`-多项式“简单”编码（如存在性量词、高度控制等）。

### 2.2 S*L — 语义逻辑结构

- “no algorithm decides whether an integer-coefficient polynomial in an arbitrary number of variables has a rational zero”——这是一个清晰的全称否定命题。
- 但“Hilbert's tenth problem over ℚ”通常被理解为“多项式方程 `P(x₁,...,xₙ)=0` 是否有 `ℚ`-解”，本摘要限定为“integer-coefficient polynomial”——这与 MRDP 的整数系数表述一致，但 `ℚ`-解与 `ℤ`-解的编码差异正是核心难点。
- 🔴 **语义范围陷阱**：若证明实际只覆盖某种特殊形式的多项式（如齐次、某些变量约束），则与“arbitrary”之间可能存在落差。

### 2.3 M*D — 数学依存

正向依赖链（假设性重构）：
1. MRDP 定理：整数 Hilbert 第十问题不可判定
2. 某种从 `ℤ`-丢番图集到 `ℚ`-多项式存在性有理零点的编码
3. 可能使用椭圆曲线、Diophantine 模型论、或 Poonen 等人关于 `ℚ` 上 Diophantine 可定义性的工作
4. ⇒ `ℚ` 上 Hilbert 第十问题不可判定

**检查**：第 2 步是开放问题的核心。已知 Poonen 证明若存在子群秩为 1 的椭圆曲线则 `ℤ` 在 `ℚ` 上 Diophantine，从而推出 `ℚ` 上 H10 不可判定；但该椭圆曲线存在性是未解决问题。本论文如何绕过此障碍未在 README 中说明。
