# S/M/P × D/L 审查报告：二元 AM-GM 不等式

> 目标：对经典证明「对任意 a,b ≥ 0，(a+b)/2 ≥ √(ab)」执行六格审计。  
> 框架：Göttingen S/M/P × D/L v1.3  
> 日期：2026-10-12

---

## 0. 证明原文

```text
命题：对任意非负实数 a, b，有 (a+b)/2 ≥ √(ab)，等号成立当且仅当 a = b。

证明：

考虑实数 √a 和 √b。因为实数平方非负，有

  (√a - √b)² ≥ 0。

展开得

  a - 2√(ab) + b ≥ 0，

即

  a + b ≥ 2√(ab)。

两边除以 2，得

  (a+b)/2 ≥ √(ab)。

等号成立当且仅当 √a - √b = 0，即 a = b。证毕。
```

### 1.3 M*D：数学依存闭合

```
实数平方非负：∀x ∈ ℝ, x² ≥ 0
       ↓
令 x = √a - √b，其中 a,b ≥ 0
       ↓
(√a - √b)² ≥ 0
       ↓
展开：a - 2√(ab) + b ≥ 0
       ↓
移项：a + b ≥ 2√(ab)
       ↓
同除 2：(a+b)/2 ≥ √(ab)
       ↓
等号条件：√a = √b ⇔ a = b
```

依赖图从实数平方非负到最终不等式，无反向边。

**M*D：✅ 通过**

### 1.4 M*L：数学逻辑合法性

| 检查点 | 结果 | 说明 |
|---|---|---|
| 平方根定义 | ✅ | a,b ≥ 0 保证 √a, √b 为实数 |
| 展开式正确 | ✅ | (√a - √b)² = a + b - 2√(ab) |
| 不等式同除正数 | ✅ | 2 > 0 |
| 等号双向 | ✅ | x² = 0 ⇔ x = 0；√a = √b ⇔ a = b（因 a,b ≥ 0） |
| 边界扫描 | ✅ | a=0 或 b=0 时不等式退化为非平凡式，仍成立 |
| 隐藏假设 | ⚠️ | 依赖实数有序域性质与平方根存在性；在标准分析中视为已知 |

**M*L：✅ 通过**（⚠️ 为教学级提示）

### 1.5 P*D：编程/形式化依存闭合

Lean 骨架：

```lean
theorem amgm_two (a b : ℝ) (ha : 0 ≤ a) (hb : 0 ≤ b) :
    (a + b) / 2 ≥ Real.sqrt (a * b) := by
  have h : (Real.sqrt a - Real.sqrt b) ^ 2 ≥ 0 := by
    apply sq_nonneg
  have h2 : (Real.sqrt a - Real.sqrt b) ^ 2 = a + b - 2 * Real.sqrt (a * b) := by
    rw [sub_sq]
    rw [Real.sq_sqrt ha, Real.sq_sqrt hb]
    rw [← Real.sqrt_mul (by linarith)]
    ring
  linarith [h, h2, Real.sqrt_nonneg (a * b)]
```

所有步骤在 Lean 的实数库中可直接形式化。

**P*D：✅ 通过**

### 1.6 P*L：形式化逻辑合法性

| 检查点 | 结果 | 说明 |
|---|---|---|
| `sq_nonneg` | ✅ | 对应实数平方非负 |

| 等号条件 | ✅ | 可追加 `eq_iff` 分支证明 |
| 无等价循环 | ✅ | 未用 AM-GM 证明自身 |

**P*L：✅ 通过**

## 3. 边界与反例扫描

| 情形 | 处理 | 状态 |
|---|---|---|
| a = 0, b = 0 | 两边均为 0，等号成立 | ✅ |
