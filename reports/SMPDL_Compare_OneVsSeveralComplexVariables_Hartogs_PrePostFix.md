# SMPDL 基础对比审计：单复变 ↔ 多复变的 Hartogs 现象

> **对比对象**
> - "PreFix" 版本：单复变延拓景观（`SMP_ProofAnalysis_ComplexAnalysis_OneVariable.md`）
> - "PostFix" 版本：多复变 Hartogs 现象（`SMP_ProofAnalysis_ComplexAnalysis_SeveralVariables.md`）
> 
> **审计日期**：2026-10-14  
> **审计框架**：Göttingen S/M/P × D/L v1.5  
> **历史编号**：H19  
> **总体评价**：⚪ ↔ ⚪ 两侧各自正确；**维度从 1 到 ≥2 引发定性结论反转**——域的自由性消失、孤立奇点消失。

## 1. 版本声明对比

| 维度 | 单复变（PreFix） | 多复变（PostFix） |
|---|---|---|
| **自然定义域** | 任意开集都可为某函数的自然域 | 存在"非全纯域"——其上所有函数被迫延拓 |
| **孤立奇点** | 可去/极点/本性，丰富理论 | **不存在**（自动可去） |
| **奇点载体** | 点 | 实余维 ≥1 的集合（超曲面） |
| **延拓自由度** | 函数可拥有自然边界 | Hartogs：洞被自动填满 |
| **核心工具** | Laurent 展开、留数 | 多圆柱 Cauchy、全纯凸性、Levi 伪凸 |
| **单值性** | Riemann 面解决 | 延拓域层（Oka 的畴理论） |
| **历史定位** | Cauchy/Riemann/Weierstrass 19 世纪 | Hartogs 1906 出生证明 |
| **形式化** | 🟢 成熟 | 🔴 稀缺 |

## 2. PreFix 版本 SMPDL 速览（单复变）

- **S*D**：Cauchy 积分 → 恒等定理（刚性）→ 奇点分类 → 自然边界。
- **S*L**："域自由"直觉——每个域都是某函数的家。
- **判定**：⚪ 框架内正确。

## 3. PostFix 版本 SMPDL 六格审计（多复变）

### 3.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| 逐变量 Cauchy | 多圆柱 | ✅ |
| Hartogs 延拓 | 余维 ≥2 洞自动填 | ✅ |
| 全纯域/全纯凸 | Cartan–Thullen | ✅ |
| Levi 伪凸 | Oka 解决 | ✅ |

### 3.2 S*L — 语义逻辑结构

- 语义反转核心：**"函数选择域"变为"域筛选函数"**——非全纯域上不存在"忠诚"的全纯函数。
- 孤立奇点的消失让 Laurent/留数工具整体失效，代之以层论与全纯凸性。
- ⚠️ 风险：从 n=1 平移直觉（"挖个点做奇点"）到 n≥2 直接错误。

### 3.3 M*D — 数学依存

```text
polydisc Cauchy → Hartogs (auto-extension) → domain of holomorphy → holomorphic convexity → Levi problem
```

### 3.4 M*L — 数学逻辑结构

| 检查项 | n=1 | n≥2 | 差异 |
|---|---|---|---|
| 去心域上函数 | 可有本性奇点（1/z） | 全部延拓 | 结论反转 |
| 域自由性 | 任意域为自然域 | 非全纯域存在 | 定性断裂 |
| 奇点理论 | Laurent 三分类 | 余维 1 超曲面奇点 | 工具更换 |

### 3.5 P*D / P*L — 编程层

- 单复变 Mathlib 成熟；多复变几乎空白——P 层不对称是本组之最。

## 4. 跨层映射检查

| 映射 | n=1（PreFix） | n≥2（PostFix） |
|---|---|---|
| S → M | "奇点=点" → Laurent | "奇点=余维1集" → 层/凸性 |
| M → P | 留数/级数库 | （空白） |
| S ↔ S | "域"自由 | "域"受函数全体约束（同名异义） |
| M ↔ M | 刚性 + 自由延拓并存 | 刚性更强（延拓被迫） |

**跨层结论**：维度 n 是本组的**单一调参旋钮**，但旋钮跨过 1→2 引发的是**定性相变**而非量化渐变——与 H3（有限/无限图）、H11（紧致/非紧致）同属"阈值型断裂"家族。

## 6. 变化类型归类

- **变化方式**：**参数迁移（复维数 n）引发结论反转** —— 归入断裂迁移家族。
- **SMPDL 同构标签建议**：`S-ISO / M-BISIM / P-BISIM`（骨架同是"Cauchy 积分→延拓"，但结论结构反转）。
- **关键 lesson**：AI 生成复分析证明时必须显式声明变量个数；"挖去孤立点构造反例"的手法在 n≥2 非法。

## 6.5 概念奇点（Conceptual Singularity）

### 6.5.1 关键人工洞察

- **发现余维现象**：多变量中"点"太薄，挂不住奇点——奇点需要超曲面级的"面积"。这是几何维数感的历史级洞察。
- **把"域的合法性"本身变成研究对象**：从研究函数到研究哪些域配拥有函数（全纯凸性）。
- **提出 Levi 问题**：几何（伪凸）与函数论（全纯域）的深层等价，开启层论方法。

### 6.5.2 为什么机器难以自动迁移

机器可以执行逐变量 Cauchy 积分验证 Hartogs 构造，但**预判"维度会反转结论"**需要对余维/几何容量的直觉——1/z 反例在 n=1 的成功恰好是误导性经验。单复变工具箱（Laurent）在 n≥2 的失效也非形式可推，而是历史发现的意外。

## 6.6 断裂强度（Breakage Strength）

| 评估项 | 等级 | 说明 |
|---|---|---|
| **断裂强度** | 🔴 结论反转或不可证 | 同一手法（挖孤立点）在两侧结论相反；域自由性定性消失。 |
| **S 层影响** | 高 | "奇点""自然域""延拓"语义全面反转。 |
| **M 层影响** | 高 | 工具箱整体更换（Laurent/留数 → 层论/凸性）。 |
| **P 层影响** | 高 | 形式化支持从成熟跌至空白。 |

**判定**：维度阈值相变，结论反转，评为 🔴。
