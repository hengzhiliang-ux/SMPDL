## 一、预测什么：预测空间的三层对象

### 1.1 核心预测问题（对任何待移除/已移除的律）

| 问题 | 预测目标 | 输出形式 |
|---|---|---|
| **Q1 涌现什么** | 阶段一即时涌现的主型与辅型 | 类型向量（β/α+元层/β-现象 + 辅型） |
| **Q2 如何回收** | 阶段二 γ 的形态与时间 | γ 五形态之一（表征/因果/渐近/成熟/翻译） |
| **Q3 断裂多深** | 断裂强度与三层影响面 | 🔴/🟠/🟡 + S/M/P 各层评级 |
| **Q4 桥在哪里** | 残存律/免费区/降档阶梯/镜像字典 | 桥点清单 |
| **Q5 谁来接盘** | 跨组规律（如凸性接盘侠） | 跨域锚候选 |

### 1.2 预测的精度分级

- **精确预测**：涌现物可点名（如 H36 预测"bang 付费补偿"→ 教科书命中）；
- **类型预测**：涌现物可定型（H34 预测"无穷小对象族解禁"→ 三实现确认类型）；
- **方向预测**：只判涌现方向（β 有无、元层有无）；
- **反预测**：预测"无"（H29 加法零涌现——对照组价值）。

**方法论原则**：宁要可证伪的方向预测，不要不可检验的全面描述。

## 二、怎么预测：五步规程（操作化）

```text
Step 1 定坐标 —— 律的三维刻度
   强度（甲/乙/丙）× 档位（E/D/I）× 功能类型（T1/T2/T3，双面律拆两面）

Step 2 查矩阵 —— 预测矩阵查表
   ┌──────────┬──────── T1 定义律 ┬─── T2 保证律 ─────┬─── T3 禁闭律 ─┐
   │ 即时涌现  │ β 主（对象族解禁）│ α + 元层主（算法） │ β-现象（行为解禁）│
   │ γ 倾向   │ 表征型（若乙级）  │ 因果型常见        │ 渐近型可能    │
   └──────────┴──────────────────┴───────────────────┴──────────────┘
   修正项：双面律 → 学科级涌现风险 ↑；乙级自带表征 γ；跨域锚候选查域邻接

Step 3 扫边界 —— 断裂面预扫描
   S：哪些词将同名异义（列清单）
   M：哪些定理将生死反转（定理群账本）
   P：框架是否自动拦截 / 盲区在哪（押注家族第几例）

Step 4 登记预测 —— 入库前显式登记（falsifiable 纪律）
   预测表写明：主型/辅型/γ 形态/桥点/强度，**先登记后入库**（第四轮起为标准流程）

Step 5 回验登记 —— 入库后逐项对照
   命中 ✓ / 偏差 →（触发修订案）/ 缺口 →（新现象命名登记）
   偏差与缺口同等重要：唯一后验偏差产出了整个功能类型判据
```

**预测判据速查卡（三条主规则 + 四条修正）**：

1. **T1 → β**：律定义对象类 ⇒ 移除释放被遮蔽对象；
2. **T2 → α+元层**：律保证行为 ⇒ 移除产生判定需求 ⇒ 涌现补偿结构 + 关于律的算法；
3. **T3 → β-现象**：律禁闭行为 ⇒ 移除释放被禁动力学（注意 T3 双亚型：守恒/禁闭可独立失效）；
4. 双面律 → 学科级风险 ↑（H23/H18/H32 全中）；
5. 乙级 → 表征型 γ 自带（即时）；
6. 定价优于禁止——优先预测"付费化"而非"失效"（bang/Tonelli/AC 定价回报）；
7. 框架押注家族——P 层"看起来正常"不构成律在场的证据（七例背书）；
8. **β 放大器（重测轮新增）**——候选律若已有活跃的**社会性先行反对运动**（直觉主义之于 LEM、构造主义之于 AC），T2 β 预测上调（意图条件类出现）；
9. **γ 双标制（重测轮新增）**——γ 形态是属性向量非互斥类别（因果动机 + 表征定理可并存）；乙级律 100% 携带表征 γ（定义性关联）。

## 三、预测的方法论根基（为什么它成立）

1. **功能先验**：律的功能（回答什么问题）决定移除后的**需求结构**——需求不变则供给重组（α）、需求解禁则对象入场（β）、需求释放则行为涌现（β-现象）；
2. **成熟度正交**：γ 与功能无关、只与领域年龄相关——两阶段可分别预测、分别验证；
3. **历史可重复**：同类律的移除在历史上反复产生同类涌现（Cayley-Dickson 阶梯每一级 = 一次 β；每次"判定需求" = 一次元层算法）；
4. **falsifiable 纪律**：预测先登记、回验必回写、偏差产修订——框架的进化与其预测对象共同演化。

**局限声明**（诚实条款）：样本量仍小（T1 n≈8、T2 n≈8 含早期组、T3 n=2）；"学科级涌现 ⇔ 双面律"是 3/3 的小样本假说；预测在律的**定性形态**上有效，对**定量时机**（何时成熟）无效。

## 四、往哪预测：三级路线图

### 4.1 近期（候选池内 · 可立即执行）

| 目标 | 预测要点 | 检验价值 |
|---|---|---|
| **消去律**（T1） | β 主（Burnside 世界解禁）+ γ 因果型候选（逆半群理论为修复而建） | T1×因果 γ 交叉首验 |
| **Hausdorff T2**（T1） | β 主（非 Hausdorff 现象）+ γ 表征型（T0–T4 谱系即表征） | "分离公理 = 律的连续旋钮族"假说 |
| **三角不等式对称律**（T1） | β（拟度量对象）+ γ 渐近型候选（信息几何中的渐近度量） | 小律完整流程走样板 |
| T3 第三样本（拓扑荷/绕数守恒） | β-现象 + γ 表征型 | T3 脱离 n=2 |

### 4.2 中期（理论压测 · 寻找反例）

| 压测方向 | 目的 |
|---|---|
| **单面律长出学科？** | 双面律假说的反例搜索——找 T1 纯单面却产生学科级涌现的候选 |
| **T2 出现纯 β？** | 功能判据的边界探查 |
| **γ 四形态之外的第五形态？** | 回收分类学的完备性压测 |
| **预测机器自动化**（P2-④ LLM 盲判） | 判据能否迁移给机器——人机分工的协作层实测 |

|---|---|

## 五、预测与回验的登记纪律（表格规范）

每次预测-回验登记五个字段：

```text
轮次 | 组号 | 预测（登记版） | 实际 | 判定（✅命中 / ❌偏差→修订案 / ⚠️缺口→新现象）
```

**禁止事后修饰**：预测一经登记不得改写（修订以"修订案"追加而非覆盖）；偏差与命中同权重登记——**错误产生信息**是本框架与占术的分界线。

## 六、一句话

> **预测不是预知未来，而是把"数学为什么这样演化"压缩成可查表、可证伪、可回写的判据——命中率证明理解，偏差深化理解，两者都登记。**
