# 防前视构建报告：前 n 个奇数之和等于 n²

> 使用流程：`SMPDL_ProofConstruction_AntiForesight.md` v1.0  
> 案例：证明 1 + 3 + ... + (2n-1) = n²  
> 日期：2026-10-12

---

## 0. 显式化

### 0.1 目标命题 P

**自然语言**：对任意正整数 n，前 n 个奇数的和等于 n 的平方。  
**形式化**：

```
∀ n ∈ ℕ⁺, Σ_{i=1}^n (2i-1) = n²
```

**结论类型**：全称等式命题。

### 0.2 前提 A

- 自然数 ℕ、加法、乘法定义；
- 求和符号 Σ 与有限和的结合律；
- 数学归纳法原理；
- 基本代数恒等式：k² + 2k + 1 = (k+1)²。

### 0.3 可用工具

- 数学归纳法；
- 代数运算。

### 0.4 禁用（含等价形式）

- 禁止直接使用 P(n) 作为理由来证明 P(n)；
- 禁止在归纳步骤中把目标等式当作已知恒等式使用；
- 禁止用「因为右边是 n²，所以左边也要凑成 n²」这类前视语言。

---

## 1. 反向草图（全部标记 OPEN）

```
P: ∀n ≥ 1, Σ_{i=1}^n (2i-1) = n²
  G₁: 基例 n = 1
    G₂: 验证 1 = 1²
  G₃: 归纳步骤
    G₄: 假设 P(k) 对某个 k ≥ 1 成立
      G₅: 表达 Σ_{i=1}^{k+1} (2i-1) = Σ_{i=1}^k (2i-1) + (2(k+1)-1)
        G₆: 用归纳假设替换 Σ_{i=1}^k (2i-1) 为 k²
          G₇: 化简 k² + (2k+1) = (k+1)²
```

**前视风险点**：

- G₆ 必须在 P(k) 被显式假设后才能使用，不能提前知道「它一定是 k²」。
- G₇ 必须是纯代数恒等式，不能依赖「目标是 (k+1)²」。

---

## 2. 正向重写

### 步骤 1：基例 n = 1（闭合 G₁、G₂）

**主张**：当 n = 1 时，左边 = 1，右边 = 1² = 1，等式成立。  
**理由**：直接计算。  
**前驱**：自然数定义。  
**状态**：✅ 闭合。

### 步骤 2：引入归纳假设（闭合 G₄）

**主张**：假设对某个 k ≥ 1，Σ_{i=1}^k (2i-1) = k²。  
**理由**：数学归纳法允许在归纳步骤中引入 P(k)。  
**前驱**：数学归纳法规则。  
**状态**：✅ 闭合。

### 步骤 3：拆分 k+1 情形（闭合 G₅）

**主张**：Σ_{i=1}^{k+1} (2i-1) = Σ_{i=1}^k (2i-1) + (2(k+1)-1)。  
**理由**：有限和的结合律与最后一项分离。  
**前驱**：步骤 2、有限和定义。  
**状态**：✅ 闭合。

### 步骤 4：应用归纳假设（闭合 G₆）

**主张**：Σ_{i=1}^{k+1} (2i-1) = k² + (2k+1)。  
**理由**：将步骤 2 的假设代入步骤 3 的拆分式。  
**前驱**：步骤 2、步骤 3。  
**状态**：✅ 闭合。

### 步骤 5：代数化简（闭合 G₇ 与 P）

**主张**：k² + (2k+1) = (k+1)²。  
**理由**：展开右边 (k+1)² = k² + 2k + 1，与左边相同。  
**前驱**：代数恒等式、步骤 4。  
**状态**：✅ 闭合。

### 3.1 M 层详细检查

**依赖图**：

```
命题 P(n)
    ↓
基例 P(1)：1 = 1²
    ↓
归纳假设 P(k)
    ↓
Σ_{i=1}^{k+1} (2i-1) = Σ_{i=1}^k (2i-1) + (2k+1)
    ↓
代入 P(k) 得 k² + (2k+1)
    ↓
代数恒等式得 (k+1)²
    ↓
P(k+1) 成立
    ↓
∀n ≥ 1, P(n)
```

- **无循环**：P(k) 只在归纳步骤中使用一次，不回流。
- **隐藏假设**：数学归纳法原理；ℕ 的良序性。

### 3.2 P 层详细检查（Lean 骨架）

```lean
theorem odd_sum_square_anti_foresight (n : ℕ) (hn : n > 0) :
    ∑ i in Finset.Icc 1 n, (2 * i - 1) = n ^ 2 := by
  induction n, hn using Nat.le_induction with
  | base =>
    -- 基例 n = 1
    norm_num
  | succ n ih_n ih =>
    -- 归纳步骤：从 n 推到 n+1，其中 n ≥ 1
    rw [Finset.sum_Icc_succ_top (by linarith)]
    rw [ih]
    ring
```

所有步骤自动可证，无等价循环。
