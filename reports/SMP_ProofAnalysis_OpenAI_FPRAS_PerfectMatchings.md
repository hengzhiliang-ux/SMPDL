# SMPDL 审计报告：OpenAI「一般图完美匹配 FPRAS」

**审计对象**：A Fully Polynomial Randomized Approximation Scheme for Perfect Matchings in General Graphs  
**来源**：OpenAI math 仓库，2026-09-23  
**审计日期**：2026-10-13  
**审计框架**：Göttingen S/M/P × D/L 六格审计 v1.4  
**审计结论**：🔴 **高风险声明，存在与已知计数复杂性障碍直接冲突的 M*L 缺口；在独立专家验证前不应采信。**

---

## 1. 命题与声明

**主定理（Theorem 1.1）**：存在统一经典随机算法，对任意有限简单无向图 G，在输入长度、ε⁻¹、log δ⁻¹ 的多项式时间内，以至少 1−δ 的概率输出 Ẑ，使得

(1−ε)Z(G) ≤ Ẑ ≤ (1+ε)Z(G)

其中 Z(G) 为 G 的完美匹配数；若 Z(G)=0 则算法确定性地返回 0。

**意义**：若成立，将解决一般图完美匹配近似计数这一长期开放问题；作为推论，将给出行列式/永久式近似算法的非二分图推广。

## 2. S/M/P × D/L 六格审计

### 2.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| 算法存在 | 状态空间构造 + 混合时间证明 + 计数比值估计 | ✅ 结构清晰 |
| 多项式时间 | 谱间隙 + 采样误差 + 冷却阶段数 | ⚠️ 依赖多个同时成立的界 |
| 零输出正确 | 可行性判定子程序 | ✅ Edmonds 多项式时间可判定 |

**发现**：摘要与定理 1.1 的依存关系清晰，无悬空结论。

### 2.2 S*L — 语义逻辑结构

- 量词明确：「任意有限简单无向图」「所有有理参数 ε, δ」。
- 无「几乎所有」到「所有」的非法全称跳跃。
- ⚠️ 关键短语「worst-case bit time」在后续分析中需严格保持；若证明中某步实际为「高概率时间」或「期望时间」，则出现 S→M 语义漂移。

### 2.3 M*D — 数学依存

正向依赖链：
1. 完全图 K_n 的完美匹配数可精确计算。
2. 通过逐步降低非边活动度（activity cooling）把 K_n 的分布变形到目标图 G。
3. 每一步用「两洞分区比」估计当前比值；顶点尺度更新维持 row-wise balance。
4. 辅助图（subdivision + weak clique edges + tree bags）保持 partition function 膨胀可控。
5. 在乘积状态空间上用局部 switch + cycle exchange + 正交分解证明谱间隙。
6. 乘积累加得到 Z(G) 的近似。

**检查**：链条长且每一步依赖前一步的误差控制；任何一步界失效都会传导到最终算法。

### 2.4 M*L — 数学逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 量词范围 | ✅ | 全称所有简单无向图 |
| 边界情况 | 🔴 | **已知障碍**：cstheory.SE 明确证明，仅有 ≤n 与 ≤n−1 匹配数的 FPRAS 无法推出完美匹配数的 FPRAS，因为 multiplicative error 在差值 x−y 上不可控（x=y 时无法区分）。OpenAI 声称绕过此障碍，但需额外说明为何其状态空间/估计器不受此下界约束。 |
| 隐藏假设 | 🔴 | 算法声称「returns zero with certainty when no perfect matching exists」。若整体为随机近似算法，零输出的确定性需要独立的多项式时间可行性判定；此子步骤本身成立（Edmonds 算法），但与近似计数算法接口时须保持误差隔离。 |
| 谱间隙 | ⚠️ | 证明使用「quadrangulation signed identity」和「replica gap」，这些是新工具，尚未在独立文献中验证。 |
| 冷却阶段数 | ⚠️ | 逐步降低活动度需要多项式个阶段；每一阶段误差控制需用 union bound 或更精细方法，证明中相关常数是否显式影响多项式指数。 |

**关键外部障碍**：

> cstheory.StackExchange 问题 20943/20947 指出：知道 x 与 y 的乘性近似（1±ε）并 **不能** 给出 x−y 的乘性近似；当 x=y 时，任何返回 v 满足 |v|≤2ε|x| 都可通过乘性检验，但真实差为 0，算法无法以高概率返回 0。  
> 来源：https://cstheory.stackexchange.com/questions/20943/fpras-for-perfect-matching/20947

OpenAI 的算法若通过逐步差分估计 Z(G)，则必须正面解释为何该障碍不适用。引言中提到的 Štefankovič–Vigoda–Wilmes 下界针对 JSV 型链，但上述差分障碍是信息论/近似计数基本限制，不依赖于具体链。

### 2.5 P*D — 编程依存

- 形式化在 `lean/formalization.yaml` 中列出，但复杂算法的 Lean 形式化通常只能覆盖**最终定理语句**和关键引理，难以覆盖完整概率分析。
- 依赖外部实现： Edmonds  blossom 算法、树动态规划、Monte Carlo 采样器。

### 2.6 P*L — 编程逻辑结构

- Lean 4 形式化若通过，仅说明形式化语句内部一致。
- ⚠️ 对于随机算法，形式化通常需引入额外公理或概率库假设；`#print axioms` 可能显示意外依赖。
- ⚠️ 算法的「多项式时间」在 Lean 中通常形式化为「存在某个多项式」，并不给出具体可运行实现或实际复杂度常数。

## 4. 已知外部证据

- Jerrum–Sinclair (1989) 给出一般图**所有匹配数**的 FPRAS，但完美匹配只是其子集。
- Jerrum–Sinclair–Vigoda (2004) 给出**二分图**完美匹配/非负矩阵永久的 FPRAS。
- Štefankovič–Vigoda–Wilmes (2018) 证明 JSV 型链在一般图上 torpid mixing。
- OpenAI 声称使用不同状态空间（colored enlarged graph + product of perfect-matching spaces），但需解释为何仍能绕过差分障碍。

## 5. 判定：证明是否为真？

| 维度 | 结论 |
|---|---|
| **Lean 形式一致性** | ✅ 已通过（据 OpenAI） |
| **与已知障碍的兼容性** | 🔴 **直接冲突风险**：cstheory.SE 给出的差分障碍是近似计数基本限制，除非 OpenAI 证明其估计器不依赖差分 |
| **算法可运行性** | ⚠️ 即使证明正确，文中提到大量辅助构造（tree bags、subdivision、replicas），实际可执行性未知 |
| **新颖性/影响** | 若正确，将是近似计数领域的重大突破 |

**SMPDL 判定**：本论文存在显著的 **M*L 结构性风险**：近似计数中的基本差分障碍未被显式排除，且证明链条极长，任何一处误差界失效都会传导。P 层通过不能消除这一 M 层风险。按 SMPDL 风险分级，标记为 **M*L 高风险 / 待独立专家验证**。

## 6. 可执行验证建议

1. **A 岗位（概念奇点）**：识别 OpenAI 是否发明了新的「无差分」估计器；若只是 JSV 链的变体，则与已知下界冲突。
2. **B 岗位（语义忠实审查）**：核对 Lean 形式化定理是否 precisely 对应「任意简单无向图 + 任意有理 ε, δ」的全称版本。
3. **D 岗位（陷阱预见）**：检查是否犯「近似 → 精确」或「x 与 y 分别可近似 ⇒ x−y 可近似」的非法跳跃（TRAP-CHECK IV / VI）。
4. **E 岗位（验证解读）**：即使 Lean 通过，也要区分「定理语句形式正确」与「算法真的在多项式时间内以声明的精度工作」。
