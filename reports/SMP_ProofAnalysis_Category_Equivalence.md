> **历史编号**：H12-PostFix-A

---

## 1. 声明与版本

**主声明**：两个范畴 `C` 与 `D` 等价，当且仅当存在函子 `F : C → D` 与 `G : D → C` 以及自然同构 `η : G ∘ F ≅ id_C` 与 `ε : F ∘ G ≅ id_D`。

**版本信息**：
- **形式化基础**：范畴论（Eilenberg & Mac Lane, 1945；Grothendieck 广泛使用）
- **依赖前提**：范畴、函子、自然变换、自然同构
- **典型实例**：有限维向量空间范畴与矩阵范畴的等价；集合与离散范畴的骨架等价
- **AxiomaticBase**：`CategoryTheory` + `Equivalence`

## 2. S/M/P × D/L 六格审计

### 2.1 S*D — 语义依存

| 节点 | 前驱 | 状态 |
|---|---|---|
| 范畴定义 | 对象、态射、复合、恒等、结合律 | ✅ |
| 函子定义 | 保持结构与恒等的映射 | ✅ |
| 自然变换 | 函子之间的态射族 | ✅ |
| 自然同构 | 每个分量都是同构的自然变换 | ✅ |

### 2.2 S*L — 语义逻辑结构

- 范畴等价是“相同”的较弱表述：不要求对象一一对应，只要求结构在“同构意义下”对应。
- 经典口号：“等价范畴拥有相同的范畴性质（up to isomorphism）”。
- ⚠️ 风险：容易与同构混淆；范畴等价**不是**范畴之间的同构（后者要求函子双向互为严格逆）。

### 2.3 M*D — 数学依存

```text
Equivalence(C, D)
    │
    ├── Functor F : C → D
    │
    ├── Functor G : D → C
    │
    ├── Natural isomorphism η : G ∘ F ≅ id_C
    │
    └── Natural isomorphism ε : F ∘ G ≅ id_D
```

- 依赖关系闭合：只需要范畴、函子、自然变换。

### 2.4 M*L — 数学逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 定义量词 | ✅ | 存在函子对与自然同构。 |
| 与范畴同构的区别 | ✅ | 范畴同构要求 `G ∘ F = id_C`（严格相等）；等价只要求自然同构。 |
| 典型判据 | ✅ | `F` 全忠实且本质满射 ⇒ `C` 与 `D` 等价。 |
| 退化情形 | ✅ | 任意范畴与其骨架等价。 |

### 2.5 P*D / P*L — 编程层

- Lean 4 / Mathlib：`CategoryTheory.Equivalence` 定义了范畴等价，含 unit 与 counit 自然同构。
- Coq / HoTT：等价在更高阶同伦类型中进一步深化为“弱等价”。
- 风险：形式化中严格相等 `=` 与自然同构 `≅` 的区分是关键。
