# S/M/P × D/L 审计报告：非交换环中二项式幂恒等式

> **定理**：设 (R, +, ·) 为含幺非交换环。对任意 a, b ∈ R 与 n ∈ ℕ⁺，有 (ab)ⁿ = a(ba)ⁿ⁻¹ b。
> 
> **来源**：标准抽象代数教材，非交换环基本性质。
> 
> **分析日期**：2026-10-13 | **审计框架**：Göttingen S/M/P × D/L v1.5 | **AxiomaticBase**：`NonCommutativeRing`
> 
> **风险评级**：⚪ 已确认正确（在非交换环公理体系内）。

---

## 0. 分析目标

1. 对非交换环中 (ab)ⁿ = a(ba)ⁿ⁻¹ b 的归纳证明做一次 S/M/P × D/L 六格审计。
2. 明确证明失效的核心原因：乘法交换律不再可用，因子顺序必须保持。
3. 为后续与交换环版本做同构对比建立差异图谱（S/M/P 标签、证明骨架、风险点）。
4. 检查自然语言证明是否误把“不可重排”当作“不可计算”。

## 1. S 层审计（语义层）

### 1.1 S*D：语义依存

| 自然语言元素 | 支持的后续元素 | 依赖说明 |
|---|---|---|
| 环 R 的定义 | 元素 a, b ∈ R 与乘法封闭性 | 需先承认环结构 |
| 乘法结合律 | 将 (ab)ⁿ 展开为 a·b·a·b·…·a·b | 允许省略括号 |
| **无** 乘法交换律 | 不能重排 a 与 b 的顺序 | 证明骨架与交换情形分道扬镳 |
| 幂的定义 aⁿ = a·a·…·a | 得到 a(ba)ⁿ⁻¹ b | 将 ab 的幂重写为 a 开头、b 结尾 |
| 归纳假设 (ab)ᵏ = a(ba)ᵏ⁻¹ b | 推导 k+1 情形 | 数学归纳法的语义支点 |

### 1.2 S*L：语义逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 量词显式化 | ✅ | “对任意 a, b ∈ R 与 n ∈ ℕ⁺”可显式写为 ∀a, b ∈ R, ∀n ∈ ℕ⁺。 |
| 术语单义性 | ⚠️ 中 | “非交换环”需明确是否仍要求含幺（1）；n = 0 情形在无幺环中需单独处理。 |
| 隐喻/图示依赖 | ✅ | 无图示依赖；证明是符号操作。 |
| 隐含跳跃 | ⚠️ 中 | 从 (ab)ⁿ 到 a(ba)ⁿ⁻¹ b 的“把首 a 与尾 b 提出来”需要 careful 验证。 |
| 蕴涵方向 | ✅ | 由结合律与保持顺序推出 (ab)ⁿ = a(ba)ⁿ⁻¹ b，方向正确。 |

**S 层结论**：自然语言证明需要强调“不可交换”这一否定性条件。若默认交换，证明会错误地推出 (ab)ⁿ = aⁿ bⁿ。

## 2. M 层审计（数学层）

### 2.1 M*D：数学依存

```text
(ab)^n = a (ba)^{n-1} b
    │
    ├── Ring Axioms
    │       ├── (R, +) is an abelian group
    │       ├── (R, ·) is a monoid with identity 1 (unless rng)
    │       └── Distributivity
    │
    ├── Associativity of multiplication
    │       └── ∀ a, b, c ∈ R : (a·b)·c = a·(b·c)
    │
    ├── Absence of commutativity
    │       └── In general a·b ≠ b·a
    │
    ├── Definition of power: a^n = a · a · ... · a (n times)
    │
    └── Mathematical induction on n ≥ 1
            ├── Base n = 1: (ab)^1 = ab = a (ba)^0 b = a · 1 · b
            └── Inductive step: (ab)^{k+1} = (ab)^k (ab)
                                          = a (ba)^{k-1} b a b   (IH)
                                          = a (ba)^{k-1} (ba) b   (associativity)
                                          = a (ba)^k b
```

| 数学对象 | 结构签名 | 在证明中的作用 |
|---|---|---|
| 非交换环 R | `(R, +, ·, 0, 1)` without ab = ba | 论域与公理基础 |
| 元素 a, b | R 中任意元素 | 定理对象 |
| 自然数 n ≥ 1 | 指数，用于归纳 | 归纳变量；n = 0 需含幺假设 |
| 乘法结合律 | 环公理 | 允许重新括号化，但不允许重排因子 |
| **无** 乘法交换律 | 非交换环特征 | 决定证明不能简化为 aⁿ bⁿ |
| 数学归纳法 | 自然数递归原理 | 证明对所有 n ≥ 1 成立 |

### 2.2 M*L：数学逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 公理系统一致性 | ✅ | 在含幺非交换环公理体系内可严格证明。 |
| 构造合法性 | ✅ | 仅涉及括号重组，无额外构造。 |
| 量词范围 | ✅ | 对任意 a, b ∈ R 与 n ∈ ℕ⁺ 成立。 |
| 边界情况 | ⚠️ 中 | n = 0 时需含幺环且 (ab)⁰ = 1 = a·b⁰·b 仅在 a, b 可逆或含幺下成立；公式 a(ba)ⁿ⁻¹ b 在 n = 0 时不直接适用。 |
| 隐藏假设 | 🟡 中 | 证明默认 R 含幺；若仅要求无幺环，n = 0 无意义。 |
| 等价命题循环 | ✅ | 无。 |

**M 层结论**：证明在非交换环公理系统内逻辑结构完整。核心特征不是“交换律缺失”，而是“顺序保持”成为证明骨架。

## 3. P 层审计（编程/形式化层）

### 3.1 P*D：形式化依存

> 本证明在 Mathlib/Lean 4 中可直接利用 `Ring` 类型类（不要求交换）与 `npow` 定义。关键是不能误用 `mul_pow`，而需手动保持因子顺序。

```text
NonCommutativeBinomialPower
    │
    ├── Mathlib.Algebra.Ring.Defs
    │       └── Ring R
    │
    ├── Mathlib.Algebra.GroupWithZero.Defs
    │       └── npow (a ^ n)
    │
    └── Theorem: mul_pow_eq_mul_pow_of_commute
            └── 仅当 a, b 可交换时才等于 a^n b^n
    │
    └── Manual proof for (a * b) ^ n = a * (b * a) ^ (n - 1) * b
            ├── Base n = 1: `simp`
            └── Inductive step: `rw [pow_succ, ih, mul_assoc]`
```

### 3.2 P*L：形式化逻辑结构

| 检查项 | 状态 | 说明 |
|---|---|---|
| 语法可编译 | ✅ | 使用 `Ring R` 而非 `CommRing R` 即可；证明手动完成。 |
| 类型签名一致 | ✅ | 输入：a, b : R, n : ℕ；输出：`(a*b)^n = a * (b*a)^(n-1) * b`。 |
| 定义等价 | ✅ | `Ring` 与数学定义“含幺环（未必交换）”等价。 |
| 命题等式 | ✅ | 目标等式可作为引理独立证明。 |
| `#print axioms` | ✅ | 依赖环公理与自然数归纳；不意外依赖选择公理。 |

**P 层结论**：Mathlib 已提供非交换环基础。本证明的 P 层风险来自“是否误用 `mul_pow`”——若使用 `CommRing` 实例化会改变数学基础。

## 5. 风险点与判定

| 风险点 | 层级 | 风险等级 | 处理状态 |
|---|---|---|---|
| 自然语言误把非交换结论写成 aⁿ bⁿ | S/M | 🔴 高 | 必须在教学中强调“不可交换” |
| n = 0 边界在任意环中的处理 | M | 🟡 中 | 含幺环下 1 = a·b⁰·b = a·b 不成立；应限定 n ≥ 1 |
| 形式化时误用 `mul_pow` | P | 🔴 高 | 需使用 `Ring` 而非 `CommRing` |
| 矩阵环等具体例子的验证 | M/P | 🟢 低 | 可用 2×2 矩阵快速检验 |

**最终判定**：⚪ 已确认正确。该证明在非交换环公理体系内逻辑完整、跨层同构强度高，是与交换版本对比的“异基础变体”关键样本。

## 6. 结论

非交换环中 (ab)ⁿ = a(ba)ⁿ⁻¹ b 的证明是一个**骨架相似但语义关键条件反转**的代数案例：

- **S 层**：自然语言必须强调“不可交换”是否定性前提；否则证明会被错误简化。
- **M 层**：数学结构完整，核心为 `associativity + order-preservation → regrouping → equality`。
- **P 层**：Mathlib 的 `Ring` 类型类足以支撑；关键是避免误用 `CommRing`/`mul_pow`。
- **跨层映射**：三层对应关系明确，同构强度为 ⭐⭐⭐ 高。

该样本建议标记为：`NonCommutativeRing`、`S-ISO / M-ISO / P-ISO`（自洽）。与 `CommutativeRing` 版本对比时，S/M/P 标签建议为 `S-BISIM / M-BISIM / P-BISIM`：骨架相同（结合律 + 归纳），但交换律的存否改变了 M 层核心事实与 P 层可调用定理。
