## 二、填补环节深审（七项发现）

### 1. 🔴 S4→S5 衍生透明度缺口（隐藏自由度，最重要）

G1 实况：S4 diff 产出受创槽清单（A3/B1/A7/B2）→ 协调方把它**翻译成五任务**写进生成提示词（「重建切消」「设计补偿」…）。**这一步翻译没有预注册**——任务措辞本身在引导生成方向（「重建核心元定理」预设了切消是核心；Girard 恰好也这么做，所以 G1 走通了，但通道是真实存在的）。

**勘误方案**：冻结件新增 **「diff→任务衍生表」**——每个受创槽到提示词任务的映射逐行预注册（例：B1 悬空 → 任务 2「重建其证明或给出反例」，措辞模板固定），协调方零自由度。衍生表随冻结件 commit。

### 2. 稳固判据的「负约束」补充

生成侧故意不定义「稳固」（防泄漏，维持）——但可加**负约束**（说什么不算稳固），不泄漏方向只收紧质量下限：
- 禁「重新引入被拆律的等价物」（如以隐式复制顶替收缩——PFE-3 已抓但提示词层先挡一道）；
- 禁「删除受创槽涉及的定理群来假装稳固」（把账销了不叫修复）；
- 禁「只报告成功」——受创槽若无法修复必须如实声明（诚实条款已有，升格为任务级）。

### 3. 候选间差异机制（同模型 ×3 之后必须回答的问题）

正式轮同模型 ×3：三份候选**靠什么不同**？若提示词逐字相同，差异只剩采样温度——多样性可能不足。两案：
- **A 统一提示词**（默认）：差异 = 纯采样方差——测「框架生成力的稳定性」（同一约束是否稳定收敛到同一方向）；
- **B 扰动臂**（可选追加）：三份分别用「保守倾向 / 中性 / 探索倾向」的**预注册措辞变体**（变体表随冻结件登记）——测「解空间宽度」。
建议：**默认 A，G2 起可开 B**。G1 试运行（4 厂异模型）实际充当了 B 的粗版——4 份全部收敛到 LL 方向 = 方向稳定性的初次证据。

### 4. 单程 vs 多程填补（迭代深化选项）

Girard 真实过程是多程的（coherent spaces 语义先行 → 规则后出）；G1 是单程。PFE 禁重试防的是**刷门**，不应连带禁止**深化**。区分两概念：
- **刷门**（禁止）：同一候选修补到过门为止；
- **多程深化**（可选项）：候选可见**自己前轮的不可证处清单**（非审查者建议），再生成深化版——这是模拟「数学家的第二轮草稿」。
建议：v1.3 登记「多程深化」为**可选模式**（每靶至多一轮深化，深化版与单程版分列登记，不合并比较）；默认仍单程。

### 5. 片段声明字段（R1 勘误）

冻结件必填：本靶生成限定在**命题片段 / 一阶 / 高阶**哪一层。G1 未声明，候选自由选了命题层为主（恰好 Girard 1987 主体也是命题层，又是一次侥幸走通）。量词处四候选全部诚实悬置或给通则区雏形——说明一阶是天然深水区，正式轮应显式分级。

### 6. 填补深度规格（产出下限）

「至少 3 个可证命题 + 证明概要」在 G1 恰好够判定用（判定者据此做机制维对照）。固化为标准下限：**受创槽数 × 1 个修复动作 + 3 个可证命题 + 1 个不可证对照**（反面对照是判定侧的重要材料——C1 的 A⇏A·A 被三位判定者引用）。

### 7. 评分→判定接口（成本规则）

判定会话目前看全部候选（试运行 4 份 × 4 判定者 = 16 次，试运行无所谓）。正式轮成本规则建议：**评分卡胜者 + 全部 PFE 草案进判定；评分败者（完整结构组内）存档不判**——草案是「历史可达性边界」数据，比落选的完整结构更有判定价值。

## 三、G3.5 评分卡：未实测环节的零成本校准

评分卡（受创槽修复 40% / PFE 可证 25% / 自洽 20% / 非平凡 15%）**一次都没跑过**。G1 四候选 + 四判定者的现成数据允许**回溯校准**：

```
回溯评分（协调方机械执行 + 咖啡复核）：
  对 C1–C4 逐份打分 → 与 G5 判定强度排序对照
  （预期：C3 ≥ C1 > C4 > C2 —— 若评分排序与判定强度排序一致 = 权重初校准通过；
   不一致 = 权重或维度需修订——这本身是 falsifiable 检验）
```

零 LLM 成本，半小时机械工作。建议随 v1.3 定版后立即执行，作为评分卡的首次标定（标注「回溯校准，非前向验证」）。
