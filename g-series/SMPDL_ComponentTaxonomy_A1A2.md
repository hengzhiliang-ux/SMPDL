## 二、A1/A2 两大类重组（咖啡 2026-10-23 拍板）

```
              数学结构 = (载体 ; 算子)
    ┌───────────────┴───────────────┐
    │ A1 载体大类（场侧）            │ A2 算子大类（机器侧）
    │ 这个世界由什么组成             │ 在场上能做什么
    └───────────────┬───────────────┘
                    │ 桥接类：定理层把两侧钉在一起
```

| 大类 | 成分（7+7） | 角色 |
|---|---|---|
| **A1 载体大类** | A1 载体 / C1 被禁族 / C2 病理族 / A7 镜像字典 / D3 结构锚 / D4-参数·语义迁移 / 载体阶梯 | 场、场上住着谁、场的坐标与拨钮 |
| **A2 算子大类** | A2 算子 / A3 律束 / A4 残存律 / A5 免费区 / B3 补偿判据族 / E3 元层算法 / D4-框架迁移 | 机器、机器的契约、顶班机、关于机器的机器 |
| **桥接类（6）** | B1 定理群 / B2 表征定理 / B4 回收 γ / A6 降档阶梯 / D1 生命周期 / D2 档位迁移 | 两侧联合产物与共用时钟 |

**拆法谱系**：
- **载体拆（动场）**：换载体（球面、*ℝ、tropical）｜弱化载体（非 Hausdorff、非紧）｜升格载体（ℝ→概形）
- **算子拆（动机器）**：拆契约 = **律靶**（交换/收缩/LEM）｜拆机器 = **算子靶**（正交投影/选择/变量绑定）

**同构回声**：A1/A2 二分即数学自身的组织方式——泛代数「代数=(A;F)」、Bourbaki 母结构、范畴论对象/态射皆为其变体；20 世纪统一（范畴论）的发现正是 A1/A2 一体两面。
