## 二、双锚原则（T_L / T_S 分治）

```
律锚〈L, T_L〉：拆什么 + 拆解时刻 → 供 T-lock（生成会话的世界截止线）
结构锚〈S, T_S〉：补什么 + 对照目标 → 供 G5 判定（hit/miss 基准）
通常 T_S ≥ T_L；两个 T 分别声明，分别进入不同白名单（§五）
```

- 结构锚操作化定义 = **Corry 制度化锚**（完整理论论述固定于文本之年）；
- 锚型异议机制沿 S8a v2：判定侧认为应取其他锚型 → 附「史学异议」，计分仍按登记锚型，异议走勘误通道；
- 纯结构靶（无明确律锚）须「代律声明」：显式写明结构锚的对偶面。

## 三、T-lock 规格（知识年代锁 · 负向锁）★重点

**规则**：对目标结构下手时，禁用一切**记录时间 > T_L** 的数学知识（显式层：术语/人名/定理名/引理/记号）。

三件执行器，缺一不可：

### 3.1 提示词侧（T_L 材料包）

- 题解冻结件的生成提示词**只含 T_L 前材料**：题面（律/算子 + 残骸语境 + 职责清单）用 T_L 前语言表述；
- **禁入提示词**（H36 例）：Girard、bang、线性逻辑、coherent spaces、proof nets、relevant/affine logic 学派名、linear types——以及一切 T_S 侧术语；
- 材料包构建流程：从 T_L 前文献选 3–5 份「语境件」（H36 例：Gentzen 1935 sequent 框架原文表述 + 「结构规则现为显式但默认」一句语境），逐件登记进冻结件。

### 3.2 输出侧（年代扫描）

- 生成输出全文做**术语年代扫描**：出现的每个专名（人名/定理名/结构名/记号）查记录年，晚于 T_L = **违规登记**；
- 扫描脚本机械执行（沿 citation discipline 术语扫描升级版），违规清单原样落盘（不删改输出）；
- 违规分级：🟡 单点违规（个别术语泄漏，正文思路无依赖）｜🔴 结构性违规（补完核心依赖 T_L 后概念）——分级标准预注册：**违规概念出现在「补完结构的定义/核心命题」中 = 🔴；仅出现在旁注/例子里 = 🟡**。

### 3.3 判定侧（T 时刻工具清单卡）

- 判定会话开场先产出「T_L 时刻可用工具清单」（例：T_L=1935 时 Zorn 引理 1935 ✅、Hörmander 次椭圆 ❌）；
- 用途①：核查候选结构的首批命题**可否用 T_L 前工具证明**（与 PFE 门联动）；
- 用途②：抓「暗用」——不用后世名词但用了后世思想的，对照工具清单逐命题审；
- 清单卡随判定输出一并落盘（自身也是数据）。

**规则**：候选结构晋级「完整结构」的硬门槛——**仅用 T_L 前的概念体系，把该技术的核心思想解释清楚**（T_L 时刻的数学家读得懂）。

### 4.1 通过判据（预注册）

| 判据        | 检查什么                                                             |
| --------- | ---------------------------------------------------------------- |
| PFE-1 词汇  | 解释全文的术语 ∈ T_L 前词汇表（年代扫描复审）                                       |
| PFE-2 动机  | 核心思想可用 T_L 前问题意识表述（H36 例：「子证明可标记为可重用」是 1935 语言能表达的；「资源敏感的类型论」不是） |

### 4.2 门后处置（两档，均登记保留）

- **四判据全过** → 晋级「完整结构」→ 进 G3.5 评分卡；

### 4.3 PFE 门材料包（每靶冻结件内置）

- T_L 前词汇表（该靶专属，10–30 词）：从 T_L 材料包语境件中提取；

## 六、五步生成流（咖啡 2026-10-23 13:24 拍板 · **13:28 修正 S1/S2 优先级：框架先于结构** · 取代原 G0–G5 线性序）

```
S1 二分框架就位     ——A1 载体面 / A2 算子面 / 桥接带（成分词汇表两大类）为常设底座：
                    框架先于任何具体结构——本体是网格，结构是载入物
S2 结构锚定         ——【在框架内锚定】选定结构，24 槽成分逐槽落位登记
                    （锚定 = 网格登记，产出拆前状态 G₀）
S3 拆一面           ——选定一面下手（载体拆：换/弱化/升格；算子拆：拆契约/拆机器）
S4 成分波动清点     ——【拆完看哪些动了】G₀ vs 拆后登记 G₁ 的机械 diff：
                    🔴 击穿 / 🟡 悬空 / 🟢 无恙（描述性登记，非预测）
S5 稳固性填补生成   ——【填补新内容使结构稳固】以「恢复稳固」为目标生成补完候选；
                    生成约束 = diff 受创槽清单（只补受创的，不动健康的）+ T-lock + PFE 门
                    ——新结构在填补中自然涌现（非先射箭后画靶）
```

**v1.2 优先级反转的三点后果**：

1. **锚定 = 网格登记**：「结构锚定」不再是选靶命名，而是**把该结构 24 槽逐槽落位到 A1/A2/桥接的动作**——锚定产物就是拆前状态 G₀（一张填好的网格）。S4 因此升级为**纯 diff**：G₀ 与 G₁ 两张登记网格的机械比对，连「扫描判定标准」的主观性都消掉了（拆前拆后都是登记行为，波动就是差集）；
2. **Tier A 重定位为「首批载入清单」**：框架先行意味着 G 系是**通用生成器**，不是历史菜单执行器——任何结构（含非历史结构、未来新结构）都可载入；历史靶（Girard 1987 等）只是首批载入物，其特权仅在于「有 T_S 可对照」；无历史对照的载入物 = 纯生成模式（跳过 G5 四格分类中的命中检验，只走新颖候选分支）；
3. **与 A1/A2 拍板的一致性**：13:03 的两大类重组本来就说「A1/A2 二分即数学自身的组织方式」（泛代数 (A;F)、范畴论对象/态射皆其变体）——框架先于结构正是这个论断的操作化：结构从来都是「载体+算子」的复合物，二分不是我们对其做的事，是其存在的方式。

**五步流相对原 G0–G5 的两个关键变化**：

1. **S4 是描述性清点，不是预测登记**（咖啡 1=「拆完看哪些动了」）——原设计的 G2.5 影响推演**删除**。生成会话看到的受创槽位清单来自机械扫描事实，不含我方理论预期——**消除「生成被 T→涌现 映射污染」的通道**（原 G3' 虽禁读总纲 §五，但协调方打包提示词时的自由度是隐性泄漏源；现在提示词内容 = 纯机械扫描结果，打包自由度归零）；
2. **S5 生成目标 = 稳固性，不是「补出历史结构」**（咖啡 2=「填补使结构稳固，新结构自然涌现」）——生成提示词里**不出现任何「应当涌现什么」的暗示**，只出现「这些槽位受创，请修复稳固」。涌现是结果不是指令——这比原设计更忠于「生成」的本义，也彻底排除目标泄漏（原 G5 对照历史的设计保留，但移到判定侧：历史对照是**事后检验**，不是生成指令）。

**S4 成分波动机械 diff 规程**（v1.2 预注册操作定义——G₀/G₁ 双登记差集法）：

- **拆前登记 G₀**：S2 锚定时逐槽登记（每槽内容 + 该内容依赖哪些面/律/机器——依赖登记是拆后 diff 的基础）；
- **拆后登记 G₁**：S3 拆解后同一结构再登记一遍（登记动作与 G₀ 完全同构）；
- **波动 = G₀ Δ G₁**（逐槽差集）：🔴 击穿（内容所依赖的面被拆，槽内容灭）/ 🟡 悬空（部分依赖，内容残存但支撑结构受损）/ 🟢 无恙（零依赖）；
