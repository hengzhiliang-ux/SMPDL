## 一、三区架构（正式化）

```
┌─ A 区【现代知识合法区】───────────────────────────┐
│  R0 取靶 · S1 框架就位 · S2 逐槽登记 · S3 拆解决策  │
│  · S4 diff（机械）· 题解冻结件撰写                │
│  规则：描述与决策层，现代数学完全合法——             │
│       登记的现代知识不构成前视违规                  │
└──────────────┬────────────────────────────────┘
               ↓ 冻结件 commit（A→B 唯一门）
┌─ B 区【T-lock 无前视区】──────────────────────────┐
│  S5 补完生成（时间锁·免联网·自报条款）             │
│  · 年代扫描 · PFE 门（忠实性检查，不对照历史答案）  │
│  规则：生成会话只见 T_L 材料+受创槽清单+衍生表任务；│
│       产物**原样冻结**——不删改、不对照现代知识      │
└──────────────┬────────────────────────────────┘
               ↓ 新构造冻结 commit（B→C 单向门）
┌─ C 区【轮后集中审查区】────────────────────────────┐
│  一轮全部靶完成后：G5 对照判定 · 评分 · 四格分类    │
│  · 微假说回验 · 三组对照（H/A/R 臂）               │
│  规则：C 区结果永不回流改写 B 区已冻结产物；        │
│       影响下一轮只能走 E1 版本化勘误               │
└──────────────────────────────────────────────┘
```

**一轮试验的定义（新明文）**：一轮 = 全部预注册靶（首批 = G3'/G4/G5 三靶）的 B 区全部完成并冻结。**C 区集中审查在该轮整体结束后统一进行**——不逐靶即时判定。

## 三、三区制的三个关键后果

1. **A 区合法性的意义**：S2 登记从此**放手用现代数学**（此前史努比撰写冻结件时对现代术语的使用处于「未明文灰色地带」）——登记精度大幅提升，且**不构成污染**，因为 B 区会话根本看不到登记件（只见衍生表输出的 T_L 化任务）；
2. **「一次性全部冻结」升级**：既然 C 区集中审查，则**全部靶的题解冻结件应在轮前一次立齐**（三份冻结件同一批 commit）——这比逐靶冻结更强地防「协调方看着上轮结果设计下轮」（跨轮污染的根除方案，呼应 D-12 衍生表）；
3. **新构造的价值保全**：「达成后不对照、直接冻结」意味着 B 区产物在 C 区审查前是**完整未修饰状态**——审查发现的问题走 E1 登记为勘误数据，**永不回改冻结产物**（E 系「错误产生信息」原则的 B 区版）。
