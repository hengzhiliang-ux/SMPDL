## 一、三区知识分区架构（G-L8 · 咖啡 21:25 拍板）

```
A 区【现代知识合法】R0 取靶 · S1 框架 · S2 逐槽登记 · S3 拆解决策 · S4 diff · 冻结件撰写
    ——登记用现代数学不构成前视违规（B 区会话看不到登记件）
      ↓ 冻结件同批 commit（A→B 唯一门，G-L9）
B 区【T-lock 无前视】S5 生成（时间锁·免联网·自报）→ 年代扫描 → PFE 门
    ——新构造达成后不对照现代知识，原样冻结
      ↓ 新构造冻结 commit（B→C 单向门）
C 区【轮后集中审查】G5 对照判定 · 评分 · 四格分类 · 微假说回验 · 三组对照臂
    ——结果永不回流改 B 区产物；修正只走 E1
```

**轮定义**：一轮 = 全部预注册靶（首批 G3'/G4/G5）B 区完成并冻结；C 区集中审查轮后统一执行。

## 二、RR 七阶段正式规程

### R0 取靶
- **三判据**（预注册）：承重（甲/乙级优先）｜存活（受创槽占比 10–60% 探索性带宽，G1=17% 为 n=1 标定点）｜可述（拆除指令 T_L 语言可表述）；
- **反向核查**：平凡性（可容许规则 FAIL）/ 致命性（骨架死亡 FAIL）；
- **粒度声明**：单拆默认；对拆须证捆绑；族拆单独论证；
- **参照系**：八型目录（人类 M1–M6 + AI M7–M8）——新靶须声明模式对应（R0-H+）；
- **换靶**：同结构换面 = 新冻结件 + 新 G₀；2×3 导航格登记；T_L 联动重查。

### R1 冻结（题解冻结件字段全表）
24 槽 G₀（含依赖栏+判面依据）/ 拆解定义 / **片段声明**（命题/一阶/高阶，E2 系）/ **代律声明二选一**（场约束 or 机器契约，E2-4）/ **diff→任务衍生表**（逐行预注册，D-12）/ **稳固负约束三禁**（禁隐式重导入/禁销账修复/强制报不可修复）/ **深度下限**（受创槽×1 修复 + 3 可证 + 1 不可证对照）/ T_L 材料包 + 词汇表 + 黑名单（含记号层条款）/ PFE 反例对照卡 / 评分卡 / 结构锚论文白名单 / 判别二问（删除+替换测试，双重登记条款）。

### R2 生成
- **同模型 ×3 独立会话**（默认，测框架生成稳定性）；可选扰动臂（预注册措辞变体，测解空间宽度）；
- 免联网 + 禁网指令 + 强制自报；无法关网模型输出打「环境联网标记」单列；
- 多程深化 = 可选模式（候选可见自己前轮不可证清单深化一轮，分列登记不与单程混比）。

### R3 扫描
术语年代机械扫描前置（PFE-1 双通道之一）；违规分级 🟡/🔴（定义/核心命题中=🔴，旁注=🟡）；记号层违规规则（正典符号 = 🔴）。

### R4 PFE 门
- **PFE-1 机械扫描前置 + 双异厂审查者复核**（F-1/F-2）；
- **概要级闭合口径**（PFE-3/4 标准 = 1935 札记级——Gentzen 1935 本身即概要级；完整形式证明不作门要求，留未来 Lean）；
- 诚实降级保护条款（「以现有工具无法解决」≠ FAIL）；PASS/FAIL 禁修改建议。

### G3.5 评分卡（机械算分）
受创槽修复度 40% ｜ PFE 可证性 25% ｜ 自洽性 20% ｜ 非平凡性 15%；平分并列不掷币。
**回溯校准条款（D-18）**：v1.3 落盘后立即对 G1 四候选执行机械打分，与 G5 强度排序（C3≥C1>C4>C2）对照——一致=权重校准通过；不一致=权重本身被证伪走 E1。标注「回溯校准，非前向验证」。

### R5 判定
- **双判定者**（异厂，联网核验结构锚论文）；重大分歧升级第三判定者；分歧登记不强判（E1-4）；
- **规则级同构粒度**（预注册：② 门槛 = 结构维 ≥2 个**规则级**同构点 + 规则级对应表；连词级读法废弃，E1-3）；
- 四格分类：T_L 前命中 / **T_S 后命中 🔥** / 新颖候选→文献门 / 🔴 结构性违规。

### R6 收尾（C 区集中）
机械汇总 → E4 双面登记 → 微假说回验（全部靶齐后一次性盲态）→ 三组对照臂执行 → 收尾报告 → 落点登记四件 → 下一轮规划（E1 通道）。
